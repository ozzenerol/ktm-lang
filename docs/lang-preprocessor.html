    The preprocessor

    C's #define, #if and #include, simplified: a macro names one value, and there are no function-like macros.

    #define#

    A macro names a number, a string, or an expression of other macros.

    #define APP_NAME "demo"
#define VERSION  3
#define BUFFER   (VERSION * 1024)
#define RATIO    (VERSION / 2.0)

void main()
{
  printf("%s v%d, %d bytes, %.1f\n", APP_NAME, VERSION, BUFFER, RATIO);
  printf("%s %s\n", typeof(BUFFER), typeof(RATIO));
}

    demo v3, 3072 bytes, 1.5
i64 f64
    • A macro has the type of its value: f64 if any operand is a float, otherwise i64.
    • Comparisons and &&, ||, ! give an i64 0 or 1.
    • A cast to a built-in type works and sets the type: #define HALF ((f64)5 / 2) is 2.5.
    • Names in a macro's value must be other macros (structs are unknown to it).
    • End a line with \ to go on to the next.

    No function-like macros. #define SQ(x) ((x) * (x)) is the error "function-like macros are not supported": write a function, which the compiler inlines. With a space, #define CALC (2 * 21) is an ordinary macro.

    For numbers, a const is usually better: it is typed and scoped.

    Conditional compilation#

    #if, #ifdef, #ifndef, #elif, #else, #endif, #undef and #error, as in C.

    #define LEVEL 2

void main()
{
#if LEVEL > 2
  printf("high\n");
#elif LEVEL == 2 && !defined(QUIET)
  printf("level two\n");
#else
  printf("low\n");
#endif
}

    level two

    From the command line#

    -DNAME defines a macro (with no value). This example is built with ktm -DVERBOSE:

    void main()
{
#ifdef VERBOSE
  printf("verbose mode\n");
#else
  printf("quiet mode\n");
#endif
}

    verbose mode

    Per platform#

    #ifdef IS_LINUX
  u8 *os = "Linux";
#elif defined(IS_MACOS)
  u8 *os = "macOS";
#else
#error "unsupported platform"
#endif

    Predefined macros#

    MacroDefined when
    IS_LINUX, __linux__Compiling for Linux
    IS_MACOS, __macos__Compiling for macOS
    IS_X86_64, __x86_64__Targeting x86_64
    IS_ARM_64, __aarch64__Targeting arm64
    __ARCH__Always: the architecture name as a string
    __KTM_JIT__ / __KTM_AOT__Running in the JIT or REPL / compiling a binary
    __KTM_VERSION__, __DATE__, __TIME__, __TIMESTAMP__Always
    __KTM_LINK_SQLITE3__ktm was built with SQLite

    To check another platform's branches without its machine: ktm -S --target=aarch64-apple-darwin file.ktm.

    #ifjit and #ifaot#

    Short for #ifdef __KTM_JIT__ and #ifdef __KTM_AOT__.

    void main()
{
#ifjit
  printf("running in the JIT\n");
#else
  printf("running as a compiled binary\n");
#endif
}

    running as a compiled binary

    Errors#

    • #error message stops the build and prints the message.
    • An #else or #endif with no #if, a second #else, or an #if never closed, is an error.
    • Extra tokens after an #if condition are an error.
    • #undef takes effect where it is: code above it keeps the old value.

    #include and #link#

    #include "util.ktm"       // relative to this file: pasted in
#include <thing.ktmh>     // from the installed include directory
#link <sqlite3>           // link a C library, like -lsqlite3
#link "./libmine.so"      // a path, relative to the working directory
    • For ktm code, prefer modules to #include.
    • #link works for compiled programs, the JIT and the REPL alike. See Calling C.
    • A file that can't be read is an error at the #include, and the rest of the file is still checked.
