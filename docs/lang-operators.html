    Operators and casts

    The C operators, with a few additions: chained comparisons, typeof, and stricter rules for unary operators.

    Arithmetic and bits#

    void main()
{
  i64 a = 7, b = 2;
  printf("%d %d %d %d %d\n", a + b, a - b, a * b, a / b, a % b);
  printf("%d %d %d %d %d %d\n", a & b, a | b, a ^ b, ~a, a << 2, a >> 1);
  printf("%.2f\n", 7.0 / 2);
}

    9 5 14 3 1
2 7 5 -8 28 3
3.50

    Assignment, increment#

    void main()
{
  i64 n = 10;
  n += 5;      // 15
  n *= 2;      // 30
  n <<= 1;     // 60
  n %= 7;      // 4
  i64 before = n++;
  i64 after = ++n;
  printf("%d %d %d\n", before, after, n);
}

    4 6 6

    An assignment used as a value has the type of its left side, so the value is truncated to fit:

    void main()
{
  u8 c;
  i64 v = (c = 300);   // 300 doesn't fit in a u8
  printf("%d\n", v);
}

    44

    Comparisons and logic#

    ==, <, &&, ! and the rest always give 0 or 1.

    void main()
{
  f64 half = 0.5;
  u8 *none = null;
  printf("%d %d %d %d\n", half && 1, !half, none || 0, !none);
  printf("%d\n", 2 < 2.5);              // an int and a float compare as floats
}

    1 0 0 1
1
    • A float is true when it isn't 0.0, a pointer when it isn't null.
    • && and || stop as soon as the answer is known, as in C.
    • On u64 values, >>, /, % and comparisons are unsigned.
    void main()
{
  u64 big = 0xFFFFFFFFFFFFFFFF;
  i64 neg = -1;
  printf("%d %d\n", big > 1, big >> 60);
  printf("%d %d\n", neg > 1, neg >> 60);
}

    1 15
0 -1

    Chained comparisons#

    As in maths: lo < x < hi means lo < x && x < hi.

    void main()
{
  i64 x = 5;
  printf("%d %d %d\n", 1 < x < 10, 1 < x < 3, 0 <= x <= 5);
}

    1 0 1

    The conditional operator#

    void main()
{
  for (i64 n = 0; n < 3; n++) {
    printf("%d item%s\n", n, n == 1 ? "" : "s");
  }
  i64 x = -4;
  printf("%d\n", x < 0 ? -x : x);
}

    0 items
1 item
2 items
4

    Unary minus and complement#

    Unary - and + need a number, ~ needs an integer. A narrower integer is widened to i64 first.

    void main()
{
  u8 small = 200;
  printf("%d %d\n", -small, ~small);   // widened before
}

    -200 -201

    -p on a pointer and ~f on an f64 are compile errors.

    sizeof, alignof, typeof#

    struct Pair { i32 a; i64 b; };

void main()
{
  i64 arr[10];
  printf("%d %d\n", sizeof(arr), sizeof(arr) / sizeof(arr[0]));
  printf("%d %d\n", sizeof(Pair), alignof(Pair));
  printf("%s | %s | %s\n", typeof(1 + 1), typeof(&arr[0]), typeof(arr));
}

    80 10
16 8
i64 | i64 * | i64[10]

    typeof becomes a string at compile time. Its operand is never evaluated:

    i64 noisy() { printf("called!\n"); return 1; }

void main()
{
  printf("%s\n", typeof(noisy()));
}

    i64

    Casts#

    As in C: the type in parentheses before the value. A cast binds tighter than any binary operator.

    void main()
{
  f64 f = 3.9;
  i64 i = (i64)f;                  // truncates
  printf("%d\n", i);
  printf("%.1f %.1f\n", (f64)(7 / 2), (f64)7 / 2);
  printf("%.1f\n", (f64)-i / 2);   // ((f64)-i) / 2

  u8 *s = "hey";
  i64 address = (i64)s;
  printf("%c\n", *(u8 *)address);
}

    3
3.0 3.5
-1.5
h
    • A cast applies to the whole postfix expression after it: (i64)p.n casts p.n.
    • Any type works, function pointers included: (fn(i64) i64)p.
    • A variable hides a type of the same name, so (x) stays a value in parentheses.

    Precedence#

    The same as C, from tightest to loosest:

    OperatorsKind
    a[i] f() a.b a->b x++ x--Postfix
    - ! ~ *p &x ++x (T)x sizeofUnary
    * / %Multiplicative
    + -Additive
    << >>Shifts
    < <= > >=Relational (chain)
    == !=Equality
    &, then ^, then |Bitwise
    &&, then ||Logical
    ?:Conditional
    = += -= ...Assignment

    There is no exponent operator: use math.power(x, y) or libc.pow. See Maths.
