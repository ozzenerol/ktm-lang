    2. JSON in and out

    Shelf gets its first real routes: save a bookmark, list them, read one, delete one. Requests and replies are JSON, made from structs by the compiler. The bookmarks live in memory for now; chapter 5 moves them to PostgreSQL.

    main.ktm#

    import date, json, net.http, reflect, str, uuid, vec;

/* A saved link */
@json struct Bookmark {
    String id;
    String url;
    String title;
    String createdAt;
};

/* What a client sends to save one */
@json struct NewBookmark {
    u8[] url;
    u8[] title;
};

/* Every bookmark, in memory for now (chapter 5 moves them to PostgreSQL) */
vec.Vec&lt;Bookmark&gt; gBookmarks;

/* The index of the bookmark with this id, or -1 */
i64 find(u8[] id)
{
    for (i64 i = 0; i &lt; gBookmarks.len; i++) {
        if (str.equals(gBookmarks.data[i].id[0:], id)) { return i; }
    }
    return -1;
}

void list(http.Writer *w, http.Request *r)
{
    w.json(200, reflect.of(gBookmarks));
}

void get(http.Writer *w, http.Request *r)
{
    i64 i = find(r.param("id"));
    if (i &lt; 0) {
        w.error(404, "no such bookmark");
        return;
    }
    w.json(200, reflect.of(gBookmarks.data[i]));
}

void create(http.Writer *w, http.Request *r)
{
    NewBookmark in = http.decode&lt;NewBookmark&gt;(r);
    Bookmark b;
    b.id = uuid.v7().string();
    b.url = str.from(in.url);
    b.title = str.from(in.title);
    b.createdAt = date.formatUnix(date.unixNow(), "%Y-%m-%dT%H:%M:%SZ");
    gBookmarks.push(b);
    w.json(201, reflect.of(b));
}

void remove(http.Writer *w, http.Request *r)
{
    i64 i = find(r.param("id"));
    if (i &lt; 0) {
        w.error(404, "no such bookmark");
        return;
    }
    Bookmark b = gBookmarks.removeAt(i);
    b.id.free();
    b.url.free();
    b.title.free();
    b.createdAt.free();
    w.status(204);
}

i32 main()
{
    http.Mux mux;
    mux.handle("GET /bookmarks", &amp;list);
    mux.handle("POST /bookmarks", &amp;create);
    mux.handle("GET /bookmarks/{id}", &amp;get);
    mux.handle("DELETE /bookmarks/{id}", &amp;remove);

    http.Options o;
    o.threads = 1;      /* one loop: the list in memory isn't shared between threads */
    printf("Shelf listening on http://localhost:8080\n");
    return http.listen(8080, &amp;mux, null, &amp;o);
}

    Structs as JSON#

    • @json before a struct makes the compiler write its JSON code: w.json(201, reflect.of(b)) encodes it, http.decode<NewBookmark>(r) reads the request body into one. The file must import json;.
    • The keys are the field names (createdAt); @key("created_at") on a field picks another, @skip leaves one out (JSON: structs).
    • Bookmark owns its texts (String, freed with .free()); NewBookmark only views the request's (u8[]), which is all a request's data needs: what http.decode made is freed when the handler returns. That's why create copies the url and title with str.from before keeping them.
    • A vector of structs encodes as an array: w.json(200, reflect.of(gBookmarks)).

    Routes with parameters#

    "GET /bookmarks/{id}" matches /bookmarks/ and one more segment, which the handler reads with r.param("id"). GET and DELETE on the same path are two routes, two handlers. IDs are UUIDv7s: unique without a counter, and in the order they were made, which chapter 7 uses for paging.

    Status codes#

    CodeWhenHow
    200Here is what you asked forw.json(200, ...)
    201Created: the new bookmark is the bodyw.json(201, ...)
    204Done, nothing to send backw.status(204)
    400The body isn't the JSON we expectby itself, from http.decode
    404No such bookmarkw.error(404, "no such bookmark"): {"error": "..."}

    One loop, for now#

    o.threads = 1 runs the server on one event loop. By default it runs one per core, and they would all touch gBookmarks at once. With one loop, handlers run one at a time (each runs until it waits for something), so the list needs no lock. From chapter 5 the data is in PostgreSQL, which handles that, and this line goes.
