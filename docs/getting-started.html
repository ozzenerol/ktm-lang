    Getting started

    Build ktm, compile your first program, and set up a project with a module.

    1. Requirements#

    • Linux on x86_64 or arm64, or macOS on Apple Silicon. On Windows, use WSL2.
    • A C compiler (gcc or clang), make and cmake: ktm uses the C compiler to assemble and link.
    • Optional: the SQLite development package, for the sql module.

    2. Build and install#

    From the repository root, as your normal user:

    ./build.sh             # builds ./ktm and the library into build/prefix
./build.sh --install   # also installs to /usr/local (asks for sudo for the copy)
    OptionDoes
    --testBuild, then run the unit, JIT and LSP test suites
    --installInstall ktm and the library
    --sqliteInclude the SQLite bindings
    --debugA debug build with AddressSanitizer
    --cleanStart from scratch

    Environment: INSTALL_PREFIX=$HOME/.local installs elsewhere, CC=clang picks the C compiler, JOBS=4 limits parallel jobs, KTM_TEST_TIMEOUT (seconds, default 60) limits each test.

    Without installing, point ktm at the local build: ./ktm --install-dir=build/prefix hello.ktm -o hello. These docs assume ktm is on your PATH.

    Check it:

    $ ktm --version
ktm v0.14.0

    3. Hello, world#

    Save this as hello.ktm:

    void main()
{
  printf("Hello, %s!\n", "world");
}

    Hello, world!

    Run it three ways:

    ktm hello.ktm -o hello && ./hello   # compile to a native binary
ktm -jit hello.ktm                    # compile in memory and run
ktm -run hello.ktm                    # compile to a temporary binary and run

    4. Something real#

    A word counter: read a file named on the command line, count the words, print the top three.

    import cstr, fs, map, os, str, vec;

struct Count { u8[] word; i64 n; };

i64 byCount(Count *a, Count *b) { return b.n - a.n; }

i32 main(i32 argc, u8 **argv)
{
  if (argc < 2) {
    os.eprintf("usage: %s FILE\n", argv[0]);
    return EXIT_FAIL;
  }
  ad String text = fs.readAll(cstr.view(argv[1]));
  if (!text.ptr) {
    os.eprintf("can't read %s\n", argv[1]);
    return EXIT_FAIL;
  }

  ad map.Map<u8[], i64> counts = map.new<u8[], i64>();
  ad u8[][] words = str.split(text, " ");
  for (auto w : words) {
    u8[] t = w.trim();
    if (t.len) { counts.set(t, counts.getOr(t, 0) + 1); }
  }

  ad vec.Vec<Count> top = vec.new<Count>();
  i64 it = 0;
  Count c;
  while (counts.next(&it, &c.word, &c.n)) { top.push(c); }
  top.sort(&byCount);
  for (i64 i = 0; i < top.len && i < 3; i++) { printf("%d %s\n", top.get(i).n, top.get(i).word); }
  return EXIT_OK;
}
    $ ktm wc.ktm -o wc
$ echo "the cat and the dog and the bird the end" > words.txt
$ ./wc words.txt
4 the
2 and
1 cat

    With -run or -jit, everything after the source file goes to the program, even words that look like ktm's own options: ktm -run wc.ktm -v words.txt gives the program -v. Anywhere else, -- ends ktm's options the same way.

    The same program, checked here with a fixed text instead of a file:

    import map, str, vec;

struct Count { u8[] word; i64 n; };

i64 byCount(Count *a, Count *b) { return b.n - a.n; }

void main()
{
  u8[] text = "the cat and the dog and the bird";
  ad map.Map<u8[], i64> counts = map.new<u8[], i64>();
  ad u8[][] words = str.split(text, " ");
  for (auto w : words) {
    u8[] t = w.trim();
    if (t.len) { counts.set(t, counts.getOr(t, 0) + 1); }
  }

  ad vec.Vec<Count> top = vec.new<Count>();
  i64 it = 0;
  Count c;
  while (counts.next(&it, &c.word, &c.n)) { top.push(c); }
  top.sort(&byCount);
  for (i64 i = 0; i < top.len && i < 2; i++) { printf("%d %s\n", top.get(i).n, top.get(i).word); }
}

    5. A project with a module#

    Put related code in a directory whose files start with module and its name. Mark what others may use pub.

    shapes/
├── main.ktm
└── geometry/
    └── area.ktm
    // geometry/area.ktm
module geometry;

pub i64 rect(i64 w, i64 h) { return w * h; }
    // main.ktm
import geometry;

void main()
{
  printf("%d\n", geometry.rect(3, 4));
}
    cd shapes && ktm main.ktm -o shapes && ./shapes
12

    Only the main file is named: ktm finds geometry by the import. More on Modules.
