    LibraryReference: json

    JSON: structs

    Turn a struct into JSON and back in one call. Mark it @json and the compiler writes the code, so it is fast.

    At a glance

    @json struct User { i64 id; String name; };
User u = json.decode<User>(text);          // throws json.ERR_DECODE on bad input
defer u.freeDecoded();                     // or json.free(reflect.of(u))
String out = json.encode(reflect.of(u));   // json.encode(..., 2) to indent
json.decode<User>(text, json.STRICT);      // unknown and missing keys are errors

    Decode and encode#

    import json, reflect;

enum Role { guest, admin };

@json struct Tag { u8[] name; i64 weight; };
@json struct User { i64 id; String name; Role role; Tag[] tags; };

void main()
{
  User u = json.decode<User>("{\"id\": 7, \"name\": \"Ada\", \"role\": \"admin\","
                             " \"tags\": [{\"name\": \"math\", \"weight\": 3}], \"since\": 1843}");
  defer u.freeDecoded();
  printf("%d %s %s %s\n", u.id, u.name, reflect.name(u.role), u.tags[0].name);

  u.id = 8;
  ad String text = json.encode(reflect.of(u));
  printf("%s\n", text);
}

    7 Ada admin math
{"id":8,"name":"Ada","role":"admin","tags":[{"name":"math","weight":3}]}
    • A key the struct has no field for is ignored ("since" above).
    • A field the JSON leaves out is zero.
    • An enum is written as its member's name.

    Types#

    ktmJSON
    A structAn object of its fields, in order (private fields are skipped)
    Integers, floats, boolNumbers, true/false
    An enumIts member's name
    String, u8[], u8 *, a u8 arrayA string
    Other arrays and slices, vec.Vec<T>Arrays
    A pointer (to a struct, a number, a bool, an enum, a String...)What it points to, or null; decoding allocates it, freeDecoded frees it

    A union, a function pointer or a void * can't be JSON.

    Errors#

    Anything that doesn't fit throws json.ERR_DECODE, with the line and column and the path to the value.

    import json;

@json struct Tag { u8[] name; i64 weight; };
@json struct User { i64 id; Tag[] tags; };

void main()
{
  u8[] inputs[] = {
    "{\"tags\": [{\"weight\": \"high\"}]}",
    "{\"id\": 1,",
    "[1, 2]",
  };
  for (auto in : inputs) {
    try {
      User u = json.decode<User>(in);
    } catch (Error e) {
      printf("%s\n", e.message);
    }
  }
}

    1:22: tags[0].weight: expected an integer, got a string
1:10: id: expected a key, got the end of the input
1:1: expected an object, got an array

    When json.decode<T> throws, it has already freed what it filled in.

    Strict decoding#

    With json.STRICT, a key with no field and a missing key are errors.

    import json;

@json struct Point { i64 x; i64 y; };

void main()
{
  u8[] inputs[] = {"{\"x\": 1, \"y\": 2}", "{\"x\": 1}", "{\"x\": 1, \"y\": 2, \"z\": 3}"};
  for (auto in : inputs) {
    try {
      Point p = json.decode<Point>(in, json.STRICT);
      printf("ok: %d %d\n", p.x, p.y);
    } catch (Error e) {
      printf("%s\n", e.message);
    }
  }
}

    ok: 1 2
1:9: y: missing
1:22: z: no such field in Point

    @json and @yaml#

    Mark a struct @json (or @yaml, or both) and the compiler writes its encoder and decoder as methods. The struct's file must import json (or yaml).

    MethodDoes
    u.toJson(&w)Writes it to a json.Writer
    u.fromJson(&r)Reads it from a json.Reader
    u.freeDecoded()Frees what fromJson (or decode) allocated
    u.toYaml(&w), u.fromYaml(&r)The same for YAML
    • json.encode, json.decode and json.free call these methods by themselves, at any depth. Adding @json makes existing code faster with no other change.
    • Without @json, the same calls work by reflection, about 3 times slower to decode.
    • ktm --expand file.ktm prints the generated methods.

    Field attributes#

    AttributeEffect
    @key("display-name")The key in the text
    @skipNever written or read (never required by STRICT)
    @omitEmptyNot written when 0, empty or null
     
    import json, reflect, yaml;

enum Role { guest, admin };

@json @yaml
struct Tag {
  String name;
  @omitEmpty i64 weight;
};

@json @yaml
struct User {
  i64 id;
  @key("display-name") String name;
  Role role;
  Tag[] tags;
  @skip i64 visits;
};

void main()
{
  User u = json.decode<User>("{\"id\": 7, \"display-name\": \"Ada\", \"role\": \"admin\","
                             " \"tags\": [{\"name\": \"math\", \"weight\": 3}, {\"name\": \"poetry\"}]}");
  defer u.freeDecoded();
  printf("%d %s %s %d tags\n", u.id, u.name, reflect.name(u.role), u.tags.len);

  json.Writer w = json.writerNew();
  defer w.free();
  u.toJson(&w);
  ad String text = w.take();
  printf("%s\n", text);

  yaml.Writer y = yaml.writerNew();
  defer y.free();
  u.toYaml(&y);
  ad String doc = y.take();
  printf("%s", doc);
}

    7 Ada admin 2 tags
{"id":7,"display-name":"Ada","role":"admin","tags":[{"name":"math","weight":3},{"name":"poetry"}]}
id: 7
display-name: Ada
role: admin
tags:
  - name: math
    weight: 3
  - name: poetry

    Filling a value you have#

    json.decode(text, reflect.of(x)) fills an existing value. Fields the JSON leaves out keep what they had, so zero it first.

    import json, reflect;

struct Config { i64 port; i64 workers; bool debug; };

void main()
{
  Config c = {8080, 4, false};        // defaults
  json.decode("{\"workers\": 16}", reflect.of(c));
  printf("%d %d %d\n", c.port, c.workers, c.debug);
}

    8080 16 0

    That is a handy way to apply a config file on top of defaults.

    Memory#

    • Decoding allocates the Strings, slices, Vecs, u8 * strings and pointed-to structs it fills.
    • u.freeDecoded() or json.free(reflect.of(u)) frees them all and zeroes the fields, also after a decode that threw half way.
    • Use them only on values that decode filled.
    • A decoded Vec is an ordinary one: push grows it.
