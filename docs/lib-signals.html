    LibraryReference: signal

    Signals

    Handle a signal with signal.handle, or let a poll() loop stop cleanly on Ctrl-C and SIGTERM with signal.stopInit.

    Handling a signal#

    signal.handle(sig, handler, flags, mask, &old). The handler is SIG_DFL, SIG_IGN, or a void f(i32 sig) passed as (i64)(&f).

    import libc, signal;

i64 hits = 0;

void onUsr1(i32 sig)
{
  hits++;
}

void main()
{
  signal.Action old;
  signal.handle(libc.SIGUSR1, (i64)(&onUsr1), libc.SA_RESTART, 0, &old);
  libc.raise(libc.SIGUSR1);
  libc.raise(libc.SIGUSR1);
  signal.action(libc.SIGUSR1, &old);      // put the old one back
  printf("%d signals, the old handler was SIG_DFL: %d\n", hits, old.handler == libc.SIG_DFL);
}

    2 signals, the old handler was SIG_DFL: 1
    • flags defaults to SA_RESTART: a blocking read, write or accept carries on after the handler. With 0 it returns -1 and EINTR (poll always does).
    • mask (signal.bit(SIGUSR2) | ...) holds other signals back while the handler runs.
    • old, if given, receives the previous action, for signal.action(sig, &old).
    • libc.signal(sig, handler), C's own, is the same with SA_RESTART.

    Ignoring SIGPIPE#

    Writing to a socket whose peer has gone raises SIGPIPE, which ends the program. Ignore it to get an error instead:

    signal.handle(libc.SIGPIPE, libc.SIG_IGN);   // now write() returns -1 with EPIPE

    Or use net.send, which never raises it.

    What a handler may do. It interrupts the program anywhere, on any thread. It may set a global, call write, _exit, kill or raise, and must leave errno as it found it. Allocating, printing, throw or taking a lock there can deadlock or corrupt memory.

    Stopping a server cleanly#

    signal.stopInit() handles SIGINT and SIGTERM for a poll() loop: it returns an fd that becomes readable when either arrives. From then on signal.stopRequested() is true and signal.stopSignal() says which came.

    import libc, signal;

void main()
{
  i32 fd = signal.stopInit();
  libc.pollfd p;
  p.fd = fd;
  p.events = libc.POLLIN;
  libc.raise(libc.SIGTERM);                // as if `kill` had been run on us
  if (libc.poll(&p, 1, 1000) == 1 && signal.stopRequested()) {
    printf("stopping cleanly after signal %d\n", signal.stopSignal());
  }
}

    stopping cleanly after signal 15

    The loop finishes what it is doing and returns. A second Ctrl-C ends the program at once, in case the loop never gets there. In a coroutine loop, wait on the same fd: see the coroutine loop.

    Signal numbers#

    libc defines SIGHUP, SIGINT, SIGQUIT, SIGKILL, SIGUSR1, SIGUSR2, SIGPIPE, SIGALRM, SIGTERM, SIGCHLD and the job-control signals SIGCONT, SIGSTOP, SIGTSTP, SIGTTIN, SIGTTOU, with each platform's numbers.

    import libc;

void main()
{
  printf("INT %d, KILL %d, TERM %d\n", libc.SIGINT, libc.SIGKILL, libc.SIGTERM);
}

    INT 2, KILL 9, TERM 15

    Signal actions are shared by all threads; a signal sent to the process goes to one thread that doesn't block it.
