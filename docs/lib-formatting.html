    Format strings

    printf, str.format, appendFormat, os.eprintf, throw and the cstr formatters share one format language.

    Conversions#

    ConversionPrints
    %d %iA signed integer (all 64 bits)
    %uAn unsigned integer
    %x %X %oHex (lower / upper case), octal
    %f %e %gAn f64, as C prints it
    %sA C string; in a literal format also a u8[] or a String
    %c %CA character; %C in upper case
    %pA pointer: 0x and 16 hex digits
    %QA string escaped as a C literal
    %%A %
     
    void main()
{
  printf("%d %i %u\n", -42, 7, 3000000000);
  printf("%x %X %o\n", 255, 255, 8);
  printf("%f %e %g\n", 3.25, 31250.0, 0.0001);
  printf("%s %c %C %Q %%\n", "text", 'k', 'k', "a\tb");
}

    -42 7 3000000000
ff FF 10
3.250000 3.125000e+04 0.0001
text k K a\tb %

    Flags, width and precision#

    Between the % and the letter, in this order:

    1. Flags: - left-justify, 0 pad with zeros, + always a sign, a space where a plus would go, # a 0x / 0 prefix.
    2. Width: the minimum number of characters.
    3. Precision after a .: decimals for floats, the maximum length for %s, the minimum digits for integers.
    void main()
{
  printf("[%5d] [%-5d] [%05d]\n", 42, 42, 42);
  printf("[%+d] [% d] [%#x] [%#o]\n", 7, 7, 255, 8);
  printf("[%.2f] [%8.3f] [%-8.1f]\n", 3.14159, 3.14159, 3.14159);
  printf("[%.3s] [%.3d]\n", "abcdef", 7);
}

    [   42] [42   ] [00042]
[+7] [ 7] [0xff] [010]
[3.14] [   3.142] [3.1     ]
[abc] [007]

    Width from an argument#

    * takes the width or precision from the arguments.

    void main()
{
  for (i64 w = 1; w <= 3; w++) {
    printf("[%*d] [%.*f]\n", w * 2, w, w, 3.14159);
  }
}

    [ 1] [3.1]
[   2] [3.14]
[     3] [3.142]

    Tables#

    struct Row { u8 *name; i64 count; f64 share; };

void main()
{
  Row rows[] = {{"apples", 12, 0.4}, {"pears", 3, 0.1}, {"plums", 15, 0.5}};
  printf("%-8s %5s %7s\n", "fruit", "count", "share");
  for (auto r : rows) {
    printf("%-8s %5d %6.1f%%\n", r.name, r.count, r.share * 100);
  }
}

    fruit    count   share
apples      12   40.0%
pears        3   10.0%
plums       15   50.0%

    Where the text goes#

    CallWrites to
    printf(fmt, ...)stdout (buffered)
    os.eprintf(fmt, ...)stderr
    str.format(fmt, ...)A new String
    s.appendFormat(fmt, ...)The end of a String
    cstr.format(fmt, ...)A new C string, mem.free it
    cstr.formatToSize(buf, n, fmt, ...)A fixed buffer, like snprintf
    throw(code, fmt, ...)The error's message
     
    import cstr, mem, str;

void main()
{
  ad String s = str.format("%s-%03d", "id", 7);
  u8 *c = cstr.format("%.1f%%", 99.5);
  u8 small[8];
  cstr.formatToSize(small, sizeof(small), "%s-%d", "overflow", 12345);
  printf("%s %s [%s] %d\n", s, c, small, cstr.len(small));
  mem.free(c);
}

    id-007 99.5% [overflo] 7

    Checked at compile time#

    For a literal format, the compiler checks the number of arguments. These are errors with the way to do it in the message:

    • %D, %T, %F: format a date with date.format.
    • A slice or String passed to a format that isn't a literal: pass s.cstr().

    Details#

    • C's length modifiers l, ll, h, hh, z, j are accepted and ignored, so C formats can be pasted in.
    • %c of a wider integer prints its bytes as characters, low byte first (up to 8); the value 0 prints nothing.
    • An unknown conversion is printed as written, with a warning on stderr, and still uses up its argument.
    • printf is buffered: call os.flush() before running a command that writes to the same terminal.
