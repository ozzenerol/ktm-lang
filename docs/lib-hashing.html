    LibraryReference: hash

    Hashing

    The hash module: SHA-256, CRC-32, FNV-1a, hex, and a constant-time compare.

    CallGivesUse it for
    hash.sha256(data, out)The 32-byte digest in outIntegrity, signatures, content addresses
    hash.crc32(data, prev)The IEEE CRC-32 (zip, gzip, PNG)Checksums
    hash.fnv1a(data)A fast 64-bit hashTables, sharding, cache keys; not security
    hash.hex(bytes)Lowercase hex, a StringPrinting digests
    hash.equalCt(a, b)Equality in constant timeComparing tokens, MACs, digests

    SHA-256#

    import hash;

void main()
{
  u8 d[hash.SHA256_SIZE];
  hash.sha256("abc", d);
  ad String hex = hash.hex(d);
  printf("%s\n", hex);
}

    ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad

    An out shorter than hash.SHA256_SIZE throws ERR_BOUNDS.

    In pieces#

    For data that arrives in parts (a file read in blocks, a body off a socket):

    import hash;

void main()
{
  hash.Sha256 h = hash.sha256New();
  h.update("a");
  h.update("bc");
  u8 d[hash.SHA256_SIZE];
  h.final(d);                     // also starts h over
  ad String hex = hash.hex(d[0:8]);
  printf("%s...\n", hex);

  h.update("abc");                // the next message
  u8 again[hash.SHA256_SIZE];
  h.final(again);
  printf("same: %d\n", hash.equalCt(d, again));
}

    ba7816bf8f01cfea...
same: 1

    A Sha256 holds no memory: nothing to free. h.reset() drops what was fed without finishing.

    CRC-32#

    It chains: hash.crc32(b, hash.crc32(a)) is the CRC of a followed by b.

    import hash;

void main()
{
  printf("%x %x\n", hash.crc32("123456789"), hash.crc32("56789", hash.crc32("1234")));
}

    cbf43926 cbf43926

    FNV-1a#

    import hash;

void main()
{
  u8[] users[] = {"ann", "bob", "cy", "dan"};
  for (auto u : users) {
    printf("%s -> shard %d\n", u, hash.fnv1a(u) % 7);
  }
}

    ann -> shard 5
bob -> shard 2
cy -> shard 1
dan -> shard 0

    Comparing secrets#

    str.equals stops at the first difference, which tells an attacker how many leading bytes were right. hash.equalCt takes the same time whatever the bytes are.

    import hash;

bool checkToken(u8[] given, u8[] expected)
{
  return hash.equalCt(given, expected);
}

void main()
{
  printf("%d %d %d\n", checkToken("s3cret", "s3cret"), checkToken("s3creX", "s3cret"),
         checkToken("short", "s3cret"));
}

    1 0 0

    Texts of different lengths return false at once: the length itself is not kept secret.
