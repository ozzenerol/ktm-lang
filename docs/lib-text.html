    Text helpers

    Comparing without case, encoding for URLs and HTML, and splitting file names.

    Ignoring case#

    Each of these works as the function without Fold, with A-Z equal to a-z:

    equalsFold  compareFold  findFold  containsFold  startsWithFold  endsWithFold
    import str;

void main()
{
  u8[] header = "Connection: Keep-Alive";
  u8[] name, value;
  str.splitFirst(header, ": ", &name, &value);
  printf("%d %d\n", name.equalsFold("connection"), value.containsFold("keep-alive"));
  printf("%d %d\n", str.findFold("Hello World", "WORLD"), "photo.JPG".endsWithFold(".jpg"));
}

    1 1
6 1

    Only ASCII letters fold: é and É are different. That is what protocol text wants: HTTP header names, MIME types, file extensions, hex.

    URLs and HTML#

    FunctionDoes
    str.urlEncode(s)One URL component: all but A-Z a-z 0-9 - _ . ~ becomes %XX
    str.urlEncodePath(s)The same, keeping /, for a whole path
    str.formEncode(s)Like urlEncode with a space as +, as HTML forms send it
    str.urlDecode(s, &out)%XX back to bytes; + stays
    str.formDecode(s, &out)Also + to a space
    str.htmlEscape(s)& < > " ' as entities
     
    import str;

void main()
{
  ad String q = str.urlEncode("tom & jerry/2");
  ad String path = str.urlEncodePath("/docs/read me.txt");
  ad String form = str.formEncode("a b");
  printf("%s?q=%s  %s\n", path, q, form);

  ad String got;
  if (str.formDecode("q=tom+%26+jerry%2F2", &got)) { printf("%s\n", got); }
  printf("valid: %d\n", str.urlDecode("100%", &got));

  ad String html = str.htmlEscape("<b>\"5 < 6\"</b>");
  printf("%s\n", html);
}

    /docs/read%20me.txt?q=tom%20%26%20jerry%2F2  a+b
q=tom & jerry/2
valid: 0
&lt;b&gt;&quot;5 &lt; 6&quot;&lt;/b&gt;
    • The encoders return a new String that is yours.
    • The decoders write into a String you pass (cleared first, its memory reused) and return false, with it empty, when a % isn't followed by two hex digits.
    • A decoded value can hold any byte, %00 and %2F included: check it before using it as a file name.
    • htmlEscape makes text safe in HTML content and in a quoted attribute.

    Paths and file names#

    CallGives
    fs.ext(name)The extension, from the first . of the last part: .tar.gz
    fs.cutExt(name)The name without it
    str.splitLast(path, "/", &dir, &file)Directory and file name
    fs.join(a, b), fs.join(a, b, c)The parts with one / between them, a new String
     
    import fs, str;

void main()
{
  u8[] dir, file;
  str.splitLast("usr/lib/libktm.tar.gz", "/", &dir, &file);
  printf("%s + %s\n", dir, file);
  printf("%s + %s\n", fs.cutExt(file), fs.ext(file));

  ad String p = fs.join("/var", "log/", "app.log");
  ad String abs = fs.join("ignored", "/etc", "hosts");    // an absolute part restarts
  printf("%s %s\n", p, abs);
}

    usr/lib + libktm.tar.gz
libktm + .tar.gz
/var/log/app.log /etc/hosts

    fs.ext and fs.cutExt return views of the name.

    Glob patterns#

    cstr.globMatch(s, pattern) matches a whole string: * is any run of characters, ? any one.

    import cstr;

void main()
{
  u8 *files[] = {"main.ktm", "main.c", "notes.md", "test_1.ktm"};
  for (auto f : files) {
    if (cstr.globMatch(f, "*.ktm")) { printf("%s ", f); }
  }
  printf("| %d\n", cstr.globMatch("banana", "b?n*a"));
}

    main.ktm test_1.ktm | 1
