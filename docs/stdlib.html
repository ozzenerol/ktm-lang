    Prelude#

    In every program without an import: the Error struct, EXIT_* and the integer limits.

    Error struct
    struct Error
{
  i64 code;
  u8 *message;
  u8 *file;
  i32 line;
};

    What a throw carries and `catch (Error e)` binds: the code (usually an enum member), a message (never NULL, "" without one), and the file and line of the throw. The message is freed when the catch block is left: copy it (StrNew) to keep it.

    String struct
    struct String
{
  u8 *ptr;
  i64 len;
  i64 cap;
};

    A string you own: its bytes (UTF-8 by convention) at ptr, len of them, room for cap, and always a NUL after the last one, so s.cstr() is free. Made empty (nothing allocated) by str.new() or a declaration, grown by its methods (module str's), freed by s.free(): `String s = str.new(); defer s.free();`. A String converts to a u8[] view of its bytes wherever one is expected. Its fields are read-only outside module str.

    Memory#

    Allocation and raw memory operations. import mem;

    mem.alloc function
    void *alloc(u64 size);

    `size` uninitialised bytes; null when out of memory or when `size` is too large (such as a negative number passed as a u64).

    mem.free function
    void free(void *ptr);

    Free a block from MAlloc, CAlloc or ReAlloc. null is ignored.

    mem.size function
    u64 size(void *ptr);

    The size the block was asked for (not the capacity malloc rounded it up to); 0 for null.

    mem.set function
    void *set(void *dst, i32 ch, u64 len);

    Set `len` bytes at `dst` to the low byte of `ch`; returns `dst`.

    mem.copy function
    void *copy(void *dst, void *src, u64 len);

    Copy `len` bytes from `src` to `dst`, front to back; returns `dst`. Overlapping buffers are not supported: use memmove for those.

    mem.allocZero function
    void *allocZero(u64 newSize);

    `new_size` zeroed bytes. One argument, the total size, unlike C's calloc(count, size). null when out of memory.

    mem.realloc function
    void *realloc(void *ptr, u64 newSize);

    A new block of `new_size` bytes holding the start of `ptr` (as much as fits); `ptr` is freed and the result is always a different pointer. ReAlloc(null, n) is MAlloc(n). When out of memory it returns null and leaves `ptr` as it was, still yours to free.

    proc.spawn function
    Proc *spawn(u8 **argv, Opts *opts=null);

    Start argv[0] (looked up in $PATH unless opts->no_path) with the arguments argv, a null-terminated list; never through a shell. opts null or all zero: the child inherits our stdin, stdout, stderr, working directory and environment. null on failure, with Errno() saying why (ENOENT for a program that doesn't exist, EACCES, ...).

    proc.wait function
    i64 wait(Proc *p);

    Wait until p ends. Returns its exit code (0-255), or -1 if a signal killed it (the signal is in p->term_signal).

    proc.done function
    bool done(Proc *p);

    Without waiting: true once p has ended (then reaped: p->exit_code and p->term_signal are set), false while it runs.

    proc.kill function
    bool kill(Proc *p, i32 sig=PROC_SIGTERM);

    Send sig to p (to its whole process group if it was started with new_group). false if p has already been reaped or kill fails.

    proc.communicate function
    i64 communicate(Proc *p, u8[] input, String *out=null, String *err=null);

    Write input (nothing if it is empty) to p's stdin and close it, read p's stdout and stderr until both reach EOF, then wait for p. *out / *err get what was read as a new String (yours; what was in them is replaced, not freed), empty with a null ptr for a stream that isn't a PIPE; pass null to read and drop a stream. A child that exits without reading all of its input is fine: the rest is dropped. Returns what wait returns.

    proc.release function
    void release(Proc *p);

    Close our pipe ends and free p (null is ignored). A child that is still running is waited for: ProcKill it first to stop it.

    proc.run function
    String run(u8 **argv, i64 *code=null);

    Run argv (no shell; stdin /dev/null, stderr inherited) and return what it printed on stdout as a new String (yours), with one trailing newline removed; its exit code (as wait) in *code. Empty with a null ptr if it couldn't be started (os.errno() says why).

    proc.shell function
    i64 shell(u8[] command);

    Run `command` with the shell (`sh -c`). Returns the command's exit code (0-255), or -1 if it was killed by a signal or the shell could not be run. The shell itself gives 127 for a command it can't find.

    proc.shellf function
    i32 shellf(u8 *fmt, ...args);

    Call the shell with `printf`-like formatting. Returns what System returns: the exit code (0-255), or -1 if the command was killed by a signal, could not be run, or fmt is null.

    proc.shellQuote function
    String shellQuote(u8[] s);

    s in single quotes for sh, as a new String (yours): each ' becomes '\'' and an empty s gives ''. Nothing in it is expanded by the shell, so proc.shellf("ls %s", q) passes s as one word.

    proc.shellOutput function
    String shellOutput(u8 *fmt, ...args);

    Run a shell command, built with `printf`-like formatting, and return what it printed to stdout as a new String (yours). One trailing newline is removed. The exit status is not returned: a failing command gives whatever it printed, often "". stderr is not captured. Returns when the shell exits, not waiting for background jobs it started. An empty String with a null ptr if fmt is null or the shell can't be started.

    map.IntMapNode struct

    Coroutines#

    Functions that pause and resume on their own stacks. import coro;

    coro.Coroutine struct
    struct Coroutine;
    coro.spawn function
    Coroutine *spawn(fn(void *arg) void *body, void *arg=null, i64 stackSize=0);

    A new coroutine that will run fn(arg) on its own stack of stack_size bytes (0 = 256 KiB; rounded up to whole pages, at least 4), with an inaccessible guard page below it so an overflow crashes instead of writing over other memory. Nothing runs until the first CoroutineNext. null if the stack can't be mapped.

    coro.next function
    void *next(Coroutine *c, void *send=null);

    Run c until it yields or returns, and return the value it yielded or, once its function has returned (CoroutineDone(c) is then true), the function's return value. `send` becomes the return value of the CoroutineYield that c is paused in; the first CoroutineNext ignores it (the function gets its arg). If c's function throws, the throw goes on from here. null if c is already done.

    coro.yield function
    void *yield(void *value=null);

    Inside a coroutine: pause it and hand value to the CoroutineNext that resumed it. Returns the `send` of the CoroutineNext that resumes it again.

    coro.done function
    bool done(Coroutine *c);

    true once c's function has returned or thrown (also for null).

    coro.current function
    Coroutine *current();

    The coroutine that is running, null on a thread's own stack.

    coro.release function
    void release(Coroutine *c);

    Free c. Its stack goes to the calling thread's cache for the next CoroutineNew of the same size (at most CORO_CACHE_MAX stacks), otherwise it is unmapped. A coroutine paused in CoroutineYield is dropped where it is: whatever it allocated is not freed. c must not be running. null is ignored.

    coro.go function
    Coroutine *go(fn(void *arg) void *body, void *arg=null, i64 stackSize=0);

    Start body(arg) as a coroutine of this thread's loop: it first runs in the next turn of coro.run (or when coro.run is called), and the loop releases it when its function returns. If it throws, coro.run throws that error on (see coro.run). stackSize as for coro.spawn. Returns the coroutine (only valid until it ends), null if its stack can't be mapped. Can be called inside a loop coroutine, or before coro.run.

    coro.wait function
    i64 wait(i32 fd, i16 events, i64 ms=-1);

    In a loop coroutine: pause until fd is ready for events (POLLIN, POLLOUT, ...) and return its revents (> 0; POLLHUP, POLLERR and POLLNVAL count), or 0 once ms milliseconds passed (ms < 0: no limit). stop() doesn't end it, so work in flight finishes.

    coro.waitIdle function
    i64 waitIdle(i32 fd, i16 events, i64 ms=-1);

    coro.wait for "waiting for more work" (the next request, the next client): the same, but -1 at once when coro.stop() was called, and -1 when it is called during the wait.

    coro.sleep function
    void sleep(i64 ms);

    In a loop coroutine: pause for ms milliseconds while the others run (0: just let them have a turn).

    coro.accept function
    i32 accept(i32 lfd, i64 ms=-1);

    In a loop coroutine: the next client of listening socket lfd, as a non-blocking fd (lfd is made non-blocking too); -1 when ms passed (ms < 0: no limit), on coro.stop(), or when lfd can't accept (EBADF, EINVAL: os.errno() says which). Out of fds or memory (EMFILE, ENFILE, ENOBUFS, ENOMEM) it neither spins nor retries at once: every coro.accept of the loop rests until coro.close() frees an fd, or 2 s passed. For 10 s after that it checks with dup(lfd) before each accept() that two fds are free (one for the client, one for its work) and rests again if not: on macOS a failed accept() has already taken the client off the queue and resets it.

    coro.close function
    i32 close(i32 fd);

    close(2) fd, and let a coro.accept resting out of fds try again. Can be called anywhere.

    coro.stop function
    void stop();

    Ask the loop to wind down: every coro.waitIdle and coro.accept, now and later, returns -1; plain waits and sleeps go on, so the work in flight finishes, and coro.run returns once every coroutine has ended. Can be called anywhere, also before coro.run.

    coro.stopping function
    bool stopping();

    true once coro.stop() was called (until coro.run returns).

    coro.run function
    void run();

    Run this thread's loop until every coroutine coro.go started has ended, then free the loop (a later coro.go starts afresh, not stopping). Called on the thread's own stack: inside a coroutine it throws ERR_LOOP. When a loop coroutine throws, that coroutine is released and coro.run throws the error on; the others stay, and another coro.run carries on with them.
