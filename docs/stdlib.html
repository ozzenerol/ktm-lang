    Prelude#

    In every program without an import: the Error struct, EXIT_* and the integer limits. How to use it

    Error struct
    struct Error
{
  i64 code;
  u8 *message;
  u8 *file;
  i32 line;
};

    What a throw carries and catch (Error e) binds: the code (usually an enum member), a message (never NULL, "" without one), and the file and line of the throw. The message is freed when the catch block is left: copy it (cstr.dup) to keep it.

    String struct
    struct String
{
  u8 *ptr;
  i64 len;
  i64 cap;
};

    A string you own: its bytes (UTF-8 by convention) at ptr, len of them, room for cap, and always a NUL after the last one, so s.cstr() is free. Made empty (nothing allocated) by str.new() or a declaration, grown by its methods (module str's), freed by s.free(): String s = str.new(); defer s.free();. A String converts to a u8[] view of its bytes wherever one is expected. Its fields are read-only outside module str.

    Memory#

    Allocation and raw memory operations. import mem; How to use it

    mem.alloc function
    void *alloc(u64 size);

    size uninitialised bytes; null when out of memory or when size is too large (such as a negative number passed as a u64).

    mem.free function
    void free(void *ptr);

    Free a block from mem.alloc, mem.allocZero or mem.realloc. null is ignored.

    mem.size function
    u64 size(void *ptr);

    The size the block was asked for (not the capacity malloc rounded it up to); 0 for null.

    mem.set function
    void *set(void *dst, i32 ch, u64 len);

    Set len bytes at dst to the low byte of ch; returns dst.

    mem.copy function
    void *copy(void *dst, void *src, u64 len);

    Copy len bytes from src to dst, front to back; returns dst. Overlapping buffers are not supported: use memmove for those.

    mem.allocZero function
    void *allocZero(u64 newSize);

    new_size zeroed bytes. One argument, the total size, unlike C's calloc(count, size). null when out of memory.

    mem.realloc function
    void *realloc(void *ptr, u64 newSize);

    A new block of new_size bytes holding the start of ptr (as much as fits); ptr is freed and the result is always a different pointer. mem.realloc(null, n) is mem.alloc(n). When out of memory it returns null and leaves ptr as it was, still yours to free.

    Room for n more bytes (and the NUL after them)

    str.String.appendByte function

    str.String.appendFormat function
    void String.appendFormat(u8 *fmt, ...args);

    printf's format at the end

    t's bytes before byte at (0 to len)

    void String.remove(i64 a, i64 b);

    Empty, keeping its room

    str.String.clone function
    String String.clone();

    A copy of it, its own

    str.String.cstr function
    u8 *String.cstr();

    Its bytes as a C string, NUL-terminated ("" when it has none)

    str.String.toLower function
    void String.toLower();

    ASCII letters in place

    str.String.toUpper function
    void String.toUpper();
    str.String.reverse function
    void String.reverse();

    Its bytes in reverse order (bytes: a multi-byte UTF-8 character is reversed too)

    str.String.take function
    u8 *String.take();

    Its bytes as a C string that is now yours (mem.free it), null when it has none; it is empty after. For C: u8 *text = fs.readAll(p).take();

    str.String.free function
    void String.free();

    Its bytes given back; it is empty after, so a second free() of the same String does nothing

    str.find function
    i64 find(u8[] s, u8[] needle);

    Where needle first is in s, -1 when it isn't (an empty needle is at 0)

    str.findLast function
    i64 findLast(u8[] s, u8[] needle);

    Where needle last is in s, -1 when it isn't

    str.contains function
    bool contains(u8[] s, u8[] needle);
    str.startsWith function
    bool startsWith(u8[] s, u8[] prefix);
    str.endsWith function
    bool endsWith(u8[] s, u8[] suffix);
    str.compare function
    i64 compare(u8[] a, u8[] b);

    <0, 0 or >0 as a sorts before, with or after b (bytes, then length)

    str.toUint function
    bool toUint(u8[] s, u64 *out);

    An unsigned number in base 10, or 16 after 0x / 0X, or 2 after 0b

    str.toInt function
    bool toInt(u8[] s, i64 *out);

    A signed number: an optional + or -, then as toUint

    str.toFloat function
    bool toFloat(u8[] s, f64 *out);

    A floating point number as C writes one: 1.5, -2e10, .5, inf, nan

    str.equals function
    bool equals(u8[] a, u8[] b);

    The same bytes

    str.trim function
    u8[] trim(u8[] s);

    s without the whitespace at its ends: a view of it, nothing copied

    str.split function
    u8[][] split(u8[] s, u8[] sep);

    The parts of s between the seps, views of it (an empty sep: s whole). The list is allocated: u8[][] parts = s.split(","); defer parts.free();

    str.join function
    String join(u8[][] parts, u8[] sep);
String join<V>(V *parts, u8[] sep);

    The parts with sep between them, as a new String (yours): String line = str.join(words, " "); defer line.free();

    The same for a Vec of Strings or of views (anything with .len and .get(i)): str.join(&names, ", "). Generic, so str needn't import vec.

    str.String.replace function
    void String.replace(u8[] old, u8[] new);

    Every old in it replaced by new (an empty old changes nothing)

    str.decodeRune function
    i32 decodeRune(u8[] s, i64 *at);

    The code point at byte *at of s, *at moved past it; U+FFFD for bytes that aren't UTF-8 (then *at moves one byte), -1 at the end

    str.runeCount function
    i64 runeCount(u8[] s);

    How many characters s holds (each byte that isn't UTF-8 counts as one)

    str.validUtf8 function
    bool validUtf8(u8[] s);

    Whether all of s is UTF-8

    str.toLower function
    u8 toLower(u8 ch);

    An ASCII letter in the other case, any other byte as is

    str.toUpper function
    u8 toUpper(u8 ch);
    str.isSpace function
    bool isSpace(u8 ch);

    ' ', '\t', '\n', '\v', '\f' or '\r'

    str.trimStart function
    u8[] trimStart(u8[] s);

    s without the whitespace at its start, a view of it

    str.trimEnd function
    u8[] trimEnd(u8[] s, u8[] chars = " \t\n\v\f\r");

    s without what is at its end of the bytes in chars (whitespace when left out), a view of it

    str.splitFirst function
    bool splitFirst(u8[] s, u8[] sep, u8[] *before, u8[] *after);

    s around the first sep: *before and *after, views of it, and true; or false, with *before all of s and *after empty, when sep isn't in it

    str.splitLast function
    bool splitLast(u8[] s, u8[] sep, u8[] *before, u8[] *after);

    As splitFirst, around the last sep

    str.compareFold function
    i64 compareFold(u8[] a, u8[] b);

    <0, 0 or >0 as a sorts before, with or after b, ignoring ASCII case (as if both were lowercase)

    str.equalsFold function
    bool equalsFold(u8[] a, u8[] b);

    The same bytes, ignoring ASCII case: equalsFold("Content-Length", "content-length")

    str.findFold function
    i64 findFold(u8[] s, u8[] needle);

    Where needle first is in s ignoring ASCII case, -1 when it isn't (an empty needle is at 0)

    str.containsFold function
    bool containsFold(u8[] s, u8[] needle);
    str.startsWithFold function
    bool startsWithFold(u8[] s, u8[] prefix);
    str.endsWithFold function
    bool endsWithFold(u8[] s, u8[] suffix);
    str.urlEncode function
    String urlEncode(u8[] s);

    s percent-encoded as one URL component (a query value, a path segment): every byte but A-Z a-z 0-9 - _ . ~ becomes %XX, space included (%20). A new String, yours.

    str.urlEncodePath function
    String urlEncodePath(u8[] s);

    As urlEncode, keeping '/': for a whole path ("/a b/c" -> "/a%20b/c")

    str.formEncode function
    String formEncode(u8[] s);

    As urlEncode, with space as '+': application/x-www-form-urlencoded, what HTML forms send

    str.urlDecode function
    bool urlDecode(u8[] s, String *out);

    s with each %XX turned back into its byte, into *out (a String, replaced: what was in it is cleared, its memory reused). '+' stays '+'. False, with *out empty, when a '%' isn't followed by two hex digits. The result can hold any byte, %00 and %2F included: check it before using it as a path.

    str.formDecode function
    bool formDecode(u8[] s, String *out);

    As urlDecode, with '+' as a space: for form data and query strings

    str.htmlEscape function
    String htmlEscape(u8[] s);

    s with & < > " ' as &amp; &lt; &gt; &quot; &#39;, safe in HTML text and in a quoted attribute value. A new String, yours.

    C strings#

    NUL-terminated u8 * strings: formatting, comparison, copying and conversion. import cstr; How to use it

    cstr.cmpLen function
    i64 cmpLen(u8 *s1, u8 *s2, i64 len);

    Compare at most len bytes like C's strncmp: < 0, 0 or > 0, bytes compared as unsigned, stopping at a NUL. null sorts before every string (two NULLs are equal), whatever len is.

    cstr.cmpLenNoCase function
    i64 cmpLenNoCase(u8 *s1, u8 *s2, i64 len);

    cstr.cmpLen ignoring ASCII case, like C's strncasecmp.

    cstr.copy function
    void copy(u8 *dst, u8 *src);

    Copy src and its NUL into dst, which must be big enough. A null src copies "" and a null dst does nothing.

    cstr.cmp function
    i64 cmp(u8 *s1, u8 *s2);

    Compare like C's strcmp: < 0, 0 or > 0, bytes compared as unsigned. null sorts before every string; two NULLs are equal.

    cstr.toLower function IS_X86_64
    u8 toLower(u8 ch);

    ch in lower case: only 'A'-'Z' change (ASCII).

    cstr.toUpper function IS_X86_64
    u8 toUpper(u8 ch);

    ch in upper case: only 'a'-'z' change (ASCII).

    cstr.isSpace function IS_X86_64
    bool isSpace(u8 ch);

    true for ' ', '\t', '\n', '\v', '\f' and '\r'.

    cstr.hash function IS_X86_64
    u64 hash(u8 *str);

    A 64-bit hash of str's bytes: h = h * 31 + c from 0, then a final mix (murmur3's), so similar keys spread over the low bits; "" hashes to 0. The same value on every target.

    cstr.toInt function
    i64 toInt(u8 *str);

    The integer at the start of str (like atol); 0 for null

    cstr.view function
    u8[] view(u8 *s);

    The bytes of a C string, before its NUL, as a u8[] (a view, nothing copied; empty for null): where a u8[] is wanted, cstr.view(path)

    cstr.len function
    u64 len(u8 *buf);

    The length of buf before its '\0', 0 for null. libc's strlen, which reads a word at a time: about 5x the old byte loop.

    cstr.dupLen function
    u8 *dupLen(u8 *buf, i64 len);

    A new string with at most the first len bytes of buf, stopping at its NUL (like C's strndup); always NUL terminated. A negative len is 0 and a null buf gives "".

    cstr.dup function
    u8 *dup(u8 *buf);

    A new copy of buf, "" for null; mem.free it

    cstr.count function
    i64 count(u8 *src, i64 ch);

    How many times the byte ch is in src (0 for null)

    cstr.firstOf function
    u8 *firstOf(u8 *src,u8 *marker);

    The first byte of src that is one of the bytes in marker, null when none is (or either is null)

    cstr.lastOf function
    u8 *lastOf(u8 *src,u8 *marker);

    The last byte of src that is one of the bytes in marker, null when none is (or either is null)

    cstr.quote function
    u8 *quote(u8 *ptr,i64 flags = 0);

    A new string of ptr escaped for a C literal: \n \r \t \v \f \" \\ and \xNN for other control bytes (what %Q prints); with PRTF_SLASH each % is doubled too. mem.free it.

    cstr.formatArgs function
    u8 *formatArgs(u8 *_dst, u8 *fmt, u64[] args);

    formatTo with the arguments in a slice, for functions that take ... and pass it on

    cstr.concatArgs function
    u8 *concatArgs(u64[] args);

    concat with the strings in a slice

    cstr.concat function
    u8 *concat(...args);

    A new string of every argument (C strings) one after another; mem.free it

    cstr.formatTo function
    u8 *formatTo(u8 *dst=null,u8 *fmt,...args);

    The formatted text written into dst, with no bound (see formatToSize for a fixed buffer); with dst null, into a new block that you mem.free. Returns where it wrote.

    cstr.formatToSize function
    u8 *formatToSize(u8 *dst, i64 size, u8 *fmt, ...args);

    Format into dst, which has room for size bytes, like C's snprintf: at most size-1 characters are written, always followed by a '\0' (size <= 0 writes nothing), and longer output is cut short. Returns dst. cstr.formatTo(dst, ...) has no bound, so use this for a fixed buffer.

    cstr.format function
    u8 *format(u8 *fmt,...args);

    The formatted text in a new block of exactly its size; mem.free it

    cstr.appendFormat function
    u8 *appendFormat(u8 *_dst,u8 *fmt,...args);

    Append formatted text to the heap string _dst (mem.alloc, cstr.dup, cstr.formatTo(null, ...) or a previous cstr.appendFormat; null starts a new one), growing it when it is full, and return it. The block may move and the old pointer is then freed, so always write s = cstr.appendFormat(s, ...) and never pass a string literal or a stack buffer. Each call measures the whole of _dst to find its end, so n appends cost O(n^2) for a long string: in a loop keep the length yourself with cstr.appendFormatLen, or collect the pieces and cstr.formatTo them once.

    cstr.appendFormatLen function
    u8 *appendFormatLen(u8 *_dst, i64 *_len, u8 *fmt, ...args);

    cstr.appendFormat for a string whose length the caller keeps in *_len, so no cstr.len per call. _dst may be null (with *_len 0) to start one.

    cstr.globMatch function
    bool globMatch(u8 *testStr, u8 *wildStr);

    Wildcard match of the whole of testStr: '*' matches any run of characters (also none) and '?' any one character; everything else matches itself. false if either string is null.

    Files#

    Reading and writing files, directories, file status and path names. import fs; How to use it

    fs.FileStat struct
    struct FileStat {
    u64 st_dev;
    u64 st_ino;
    u64 st_nlink;
    u32 st_mode;
    u32 st_uid;
    u32 st_gid;

    i64 st_size;
    i64 st_blksize;
    i64 st_blocks;

    libc.timespec st_mtim;
    libc.timespec st_ctim;
    libc.timespec st_btim;
};

    Portable (across MacOS and Linux) stat structure

    fs.FileKind enum
    enum FileKind { file, dir, link, other };

    What a FileStat describes: FileStat.kind()

    fs.DirEntry struct
    struct DirEntry {
    u8[] name;
    FileKind kind;
    String path;
};

    One entry of a directory. kind is what the entry itself is: a symlink is a link, never what it points to. name and path (the directory's path, a /, the name) are the Dir's own: they are valid until its next next() or close().

    fs.Dir struct
    struct Dir {
    libc.DIR *handle;
    String base;
    DirEntry entry;
};

    An open directory: fs.openDir(path), next() until it gives null, then close() (defer d.close();, or declare it with ad). "." and ".." are left out. Its fields are its own: use ok(), next() and close().

    fs.openDir function
    Dir openDir(u8[] path);

    The directory at path, open; ok() is false when it can't be opened (os.errno() says why), and next() then gives null

    fs.Dir.ok function
    bool Dir.ok();

    Is the directory open?

    fs.Dir.next function
    DirEntry *Dir.next();

    The next entry, null after the last one (or when it isn't open)

    fs.Dir.close function
    void Dir.close();

    Closes it (once is enough; again does nothing)

    fs.Dir.free function
    void Dir.free();

    For ad: the same as close()

    fs.list function
    vec.Vec<String> list(u8[] path, bool *ok = null);

    The names in the directory at path, sorted; *ok (when given) is false when it can't be read. Yours: free it with names.free().

    fs.freeList function
    void freeList(vec.Vec<String> *names);

    Frees what list() gave: the same as names.free(), which frees the names too

    fs.walk function
    i32 walk(u8[] root, fn(DirEntry *, void *) bool visit, void *arg = null);

    Every entry under the directory root, at any depth: visit(entry, arg) for each, a directory before what is in it, without following symlinks (a link to a directory is visited, not entered). visit returns false to stop. 0 when every entry was visited, 1 when visit stopped it, -1 when a directory couldn't be read (os.errno() says why).

    fs.join function
    String join(u8[] a, u8[] b);
String join(u8[] a, u8[] b, u8[] c);

    a/b: one / between them; b alone when it is absolute or a is empty

    a/b/c: join(join(a, b), c)

    fs.exists function
    bool exists(u8[] path);

    Is there something at path (a symlink: is there something where it points)?

    fs.makeDirAll function
    bool makeDirAll(u8[] path, i32 mode = MAKE_DIR_DEFAULT);

    The directory path made, with every missing parent, as makeDir(path, mode, true): true when path is a directory afterwards (also when it already was), false with os.errno() set when not

    fs.copyFile function
    bool copyFile(u8[] from, u8[] to);

    The regular file from copied to to (made, or emptied first), with from's permission bits. true, or false with os.errno(): from isn't a regular file, the two are the same file, a read or a write failed (to is then removed).

    fs.rename function
    bool rename(u8[] from, u8[] to);

    from renamed to to (replacing a file there), on one filesystem: true, or false with os.errno() (EXDEV across filesystems: see move)

    fs.move function
    bool move(u8[] from, u8[] to);

    As rename(), and across filesystems a regular file is copied, then removed: true, or false with os.errno() (a directory can't move across filesystems)

    fs.readAll function
    String readAll(u8[] path);

    The whole file at path, a String that is yours (defer s.free();), with a NUL after it; its ptr is null when the file can't be read (os.errno() says why). An empty file gives an empty String that has a ptr.

    fs.writeAll function
    bool writeAll(u8[] path, u8[] data, i64 flags=libc.O_CREAT|libc.O_WRONLY|libc.O_TRUNC);

    data into the file at path (made with 0644 when flags create it); false on an error

    fs.currentDir function
    String currentDir();

    The working directory, a String that is yours; its ptr is null on an error (getcwd's own block is libc malloc'd, which a String can't own)

    fs.stat function
    i32 stat(FileStat *fst, u8[] path);

    What is at path (fst filled; a symlink is followed to what it points to): 0, or -1 with errno set

    fs.lstat function
    i32 lstat(FileStat *fst, u8[] path);

    As stat, but a symlink is described itself (kind() is FileKind.link), not what it points to

    fs.fstat function
    i32 fstat(FileStat *fst, i32 fd);

    As stat, for the file open as fd

    fs.FileStat.kind function
    FileKind FileStat.kind();

    What it is: a regular file, a directory, a symlink (only from lstat), or something else (a FIFO, socket or device)

    fs.FileStat.isFile function
    bool FileStat.isFile();
    fs.FileStat.isDir function
    bool FileStat.isDir();
    fs.FileStat.isLink function
    bool FileStat.isLink();
    fs.realPath function
    String realPath(u8[] path);

    The absolute path of path with every symlink, "." and ".." resolved (realpath(3)), a String that is yours; its ptr is null, with errno set, when a part of it doesn't exist or can't be read

    fs.pread function
    i64 pread(i32 fd, u8[] buf, i64 off);

    Up to buf.len bytes of fd from offset off into buf, without moving fd's offset (pread(2)): the bytes read, 0 at end of file, -1 with errno set

    fs.pwrite function
    i64 pwrite(i32 fd, u8[] data, i64 off);

    data written to fd at offset off, without moving fd's offset (pwrite(2)): the bytes written, or -1 with errno set

    fs.changeDir function
    bool changeDir(u8[] path);

    The working directory changed to path (~ and ~/... are under $HOME): true, or false with os.errno() set

    fs.removeDir function
    bool removeDir(u8[] path, i64 flags=0);

    The directory path removed (with REMOVE_RECURSIVE, everything in it too): true, or false with os.errno() set

    Coroutines#

    Functions that pause and resume on their own stacks. import coro; How to use it

    coro.waitChild function
    i32 waitChild(i32 pid, i64 ms=-1);

    In a loop coroutine: pause until child pid (from fork, posix_spawn or proc.spawn: then give p.pid and pass the result to proc.setStatus) exits, reap it, and return its wait status (>= 0; proc.exitCode, proc.signaled and the others read it). -1 when ms milliseconds passed first (ms < 0: no limit; the child still runs, os.errno() is ETIMEDOUT) or pid is not a child of ours (ECHILD). The other coroutines run meanwhile; any number of them can each wait for a child. Waits on proc.exitFd(pid) (a pidfd on Linux, a kqueue on macOS), or by checking every few ms where the system has neither. Like coro.wait, coro.stop() doesn't end it.

    coro.spawn function
    Coroutine *spawn(fn(void *arg) void *body, void *arg=null, i64 stackSize=0);

    A new coroutine that will run fn(arg) on its own stack of stack_size bytes (0 = 256 KiB; rounded up to whole pages, at least 4), with an inaccessible guard page below it so an overflow crashes instead of writing over other memory. Nothing runs until the first coro.next. null if the stack can't be mapped.

    coro.next function
    void *next(Coroutine *c, void *send=null);

    Run c until it yields or returns, and return the value it yielded or, once its function has returned (coro.done(c) is then true), the function's return value. send becomes the return value of the coro.yield that c is paused in; the first coro.next ignores it (the function gets its arg). If c's function throws, the throw goes on from here. null if c is already done.

    coro.yield function
    void *yield(void *value=null);

    Inside a coroutine: pause it and hand value to the coro.next that resumed it. Returns the send of the coro.next that resumes it again.

    coro.done function
    bool done(Coroutine *c);

    true once c's function has returned or thrown (also for null).

    coro.current function
    Coroutine *current();

    The coroutine that is running, null on a thread's own stack.

    coro.release function
    void release(Coroutine *c);

    Free c. Its stack goes to the calling thread's cache for the next coro.spawn of the same size (at most CORO_CACHE_MAX stacks), otherwise it is unmapped. A coroutine paused in coro.yield is dropped where it is: whatever it allocated is not freed. c must not be running. null is ignored.

    coro.dial function
    i32 dial(u8[] addr, i32 port, i64 ms=-1);

    In a loop coroutine: a TCP connection to addr (a host name, or an IPv4 or IPv6 address) on port, as a non-blocking fd ready for coro.read and coro.write; -1 with os.errno() set (ECONNREFUSED, ETIMEDOUT, ...) when no address the name resolves to accepts. Connecting pauses only the coroutine. Every address is tried in turn, within ms milliseconds in all (ms < 0: no limit). Looking up a name still waits for the system's resolver: give a numeric address where that matters. Close the fd with coro.close.

    coro.go function
    Coroutine *go(fn(void *arg) void *body, void *arg=null, i64 stackSize=0);

    Start body(arg) as a coroutine of this thread's loop: it first runs in the next turn of coro.run (or when coro.run is called), and the loop releases it when its function returns. If it throws, coro.run throws that error on (see coro.run). stackSize as for coro.spawn. Returns the coroutine (only valid until it ends), null if its stack can't be mapped. Can be called inside a loop coroutine, or before coro.run.

    coro.backend function
    u8[] backend();

    The backend of the calling thread's loop (made now if there is none): "uring" (io_uring, Linux), "epoll" (Linux), "kqueue" (macOS) or "poll" (poll(2), when no queue could be made or KTM_CORO_BACKEND=poll).

    coro.inLoop function
    bool inLoop();

    Is the caller a loop coroutine (coro.go, coro.serve)? Then coro.read, coro.write and coro.wait park it instead of blocking the thread: libraries use it to pick their I/O.

    coro.wait function
    i64 wait(i32 fd, i16 events, i64 ms=-1);

    In a loop coroutine: pause until fd is ready for events (POLLIN, POLLOUT, ...) and return its revents (> 0; POLLHUP, POLLERR and POLLNVAL count), or 0 once ms milliseconds passed (ms < 0: no limit). stop() doesn't end it, so work in flight finishes.

    coro.park function
    i64 park(i64 ms=-1);

    In a loop coroutine: pause until another coroutine (of this loop, or of another thread's: see coro.unpark) calls coro.unpark(this one), or ms milliseconds pass (ms < 0: no limit). Returns 1 when unparked, 0 on the time limit, -1 when coro.stop() was called (before or during the wait). An unpark that came while this coroutine wasn't parked makes its next park return 1 at once, so a wake-up between "nothing to do" and park isn't lost. No syscall: for handing work or a resource from one coroutine to another.

    coro.unpark function
    void unpark(Coroutine *c);

    Wake c from coro.park (it returns 1); if it isn't parked, its next coro.park returns 1 at once. c is a coro.go coroutine of this thread's loop or of another thread's: from another thread the unpark goes through that loop's mailbox and its thread applies it (a write(2) to wake it; the same loop needs no syscall). c must not have ended (its Coroutine is freed then). Throws ERR_LOOP for a coroutine coro.go didn't start.

    coro.waitIdle function
    i64 waitIdle(i32 fd, i16 events, i64 ms=-1);

    coro.wait for "waiting for more work" (the next request, the next client): the same, but -1 at once when coro.stop() was called, and -1 when it is called during the wait.

    coro.read function
    i64 read(i32 fd, u8[] buf, i64 ms=-1);

    In a loop coroutine: read what is there from the non-blocking fd into buf, pausing the coroutine until there is something (or ms passed; ms < 0: no limit). Returns the bytes read (at most buf.len), 0 at end of file or when the peer closed, -1 on an error or the timeout (os.errno() ETIMEDOUT). It reads at once when the last read filled its buffer (more is likely waiting, as in a stream), and waits first otherwise (the next request isn't there yet): either way a coroutine per connection costs no more system calls than it must. Reads skip the wait for 4 ms at most (LOOP_READ_BUDGET_NS), then wait once, so the loop's other coroutines get their turn.

    coro.write function
    i64 write(i32 fd, u8[] data, i64 ms=-1);

    In a loop coroutine: write all of data to the non-blocking fd, pausing the coroutine while the fd is full (until ms passed; ms < 0: no limit): first for a turn or two of the loop (the peer is usually reading already), then until the fd is writable. Returns data.len, or -1 on an error (EPIPE for a peer that closed: never a SIGPIPE) or the timeout (ETIMEDOUT); the bytes sent before that are gone.

    coro.sleep function
    void sleep(i64 ms);

    In a loop coroutine: pause for ms milliseconds while the others run (0: just let them have a turn).

    coro.accept function
    i32 accept(i32 lfd, i64 ms=-1);

    In a loop coroutine: the next client of listening socket lfd, as a non-blocking fd (lfd is made non-blocking too); -1 when ms passed (ms < 0: no limit), on coro.stop(), or when lfd can't accept (EBADF, EINVAL: os.errno() says which). Out of fds or memory (EMFILE, ENFILE, ENOBUFS, ENOMEM) it neither spins nor retries at once: every coro.accept of the loop rests until coro.close() frees an fd, or 2 s passed. For 10 s after that it checks with dup(lfd) before each accept() that two fds are free (one for the client, one for its work) and rests again if not: on macOS a failed accept() has already taken the client off the queue and resets it.

    coro.close function
    i32 close(i32 fd);

    close(2) fd, and let a coro.accept resting out of fds try again. Can be called anywhere.

    coro.stop function
    void stop();

    Ask the loop to wind down: every coro.waitIdle and coro.accept, now and later, returns -1; plain waits and sleeps go on, so the work in flight finishes, and coro.run returns once every coroutine has ended. Can be called anywhere, also before coro.run.

    coro.stopping function
    bool stopping();

    true once coro.stop() was called (until coro.run returns).

    coro.run function
    void run();

    Run this thread's loop until every coroutine coro.go started has ended, then free the loop (a later coro.go starts afresh, not stopping). Called on the thread's own stack: inside a coroutine it throws ERR_LOOP. When a loop coroutine throws, that coroutine is released and coro.run throws the error on; the others stay, and another coro.run carries on with them.

    coro.serveStop function
    void serveStop();

    Stop every coro.serve running in the process, from any thread, a loop coroutine or a signal coroutine (not from inside a signal handler): each loop stops taking clients, the handlers in flight finish, and each serve call returns 0 then.

    coro.serve function
    i32 serve(i32 port, fn(i32 fd, void *arg) void handler, void *arg = null, i64 threads = 0, u8[] bindaddr = "*");

    A TCP server on port of bindaddr ("*": every IPv4 address, "::*": every IPv6 one, or a numeric address) that runs handler(fd, arg) as a coroutine for each client, on threads coroutine loops (0: one per CPU the process may use), the calling thread's included. The client's fd is non-blocking with TCP_NODELAY set: wait on it with coro.wait, and don't close it, serve closes it with coro.close when the handler returns. A handler that throws is reported on stderr; the server goes on. Handlers run on several threads at once: a global they share needs the atomic module or a lock.

    Returns 0 once serveStop() or a coro.stop() in one of its loops (from a coroutine started before serve, e.g. on signal.stopInit()'s fd) stopped it and every handler has finished; -1 with os.errno() set if the listeners can't be made (a bad port or address, the port in use) or a listener broke later. Call it from a thread, not a coroutine.
