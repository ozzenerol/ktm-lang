    `size` uninitialised bytes; NULL when out of memory or when `size` is too large (such as a negative number passed as a U64).

    Free function
    U0 Free(U0 *ptr);

    Free a block from MAlloc, CAlloc or ReAlloc. NULL is ignored.

    MSize function
    U64 MSize(U0 *ptr);

    The size the block was asked for (not the capacity malloc rounded it up to); 0 for NULL.

    MemSet function
    U0 *MemSet(U0 *dst, I32 ch, U64 len);

    Set `len` bytes at `dst` to the low byte of `ch`; returns `dst`.

    MemCpy function
    U0 *MemCpy(U0 *dst, U0 *src, U64 len);

    Copy `len` bytes from `src` to `dst`, front to back; returns `dst`. Overlapping buffers are not supported: use memmove for those.

    CAlloc function
    U0 *CAlloc(U64 new_size);

    `new_size` zeroed bytes. One argument, the total size, unlike C's calloc(count, size). NULL when out of memory.

    ReAlloc function
    U0 *ReAlloc(U0 *ptr, U64 new_size);

    A new block of `new_size` bytes holding the start of `ptr` (as much as fits); `ptr` is freed and the result is always a different pointer. ReAlloc(NULL, n) is MAlloc(n). When out of memory it returns NULL and leaves `ptr` as it was, still yours to free.

    StrHash function

    A 64-bit hash of str's bytes: h = h * 31 + c from 0, then a final mix (murmur3's), so similar keys spread over the low bits; "" hashes to 0. The same value on every target.

    Atoi function

    A new string with at most the first len bytes of buf, stopping at its NUL (like C's strndup), always NUL terminated. A negative len is 0 and a NULL buf gives "".

    StrTrimEnd function

    Remove the whitespace at the end, in place, by writing a NUL; only the first str_len bytes are looked at (all of it if str_len < 0). Sets *_new_len and returns str. NULL returns NULL.

    Remove every character in `chars` from the end, in place, by writing a NUL: StrCleanEnd(line, "\r\n") drops a line ending. Returns the new length. NULL str returns 0; NULL or "" chars removes nothing.

    StrPrint function
    U8 *StrPrint(U8 *dst=NULL, U8 *fmt, ...);

    Format like printf (see the library guide for the conversions). With dst NULL it returns a new string to Free; otherwise it writes into dst, which must be big enough - nothing checks, see StrNPrint - and returns it.

    StrNPrint function
    U8 *StrNPrint(U8 *dst, I64 size, U8 *fmt, ...);

    Format into `dst`, which has room for `size` bytes, like C's snprintf: at most size-1 characters are written, always followed by a '\0' (size <= 0 writes nothing), and longer output is cut short. Returns dst. StrPrint(dst, ...) has no bound, so use this for a fixed buffer.

    Print function
    U0 Print(U8 *fmt, ...);

    StrPrint to stdout. A print statement whose format is a literal using %Q, %D, %T, %C or %F ("%Q\n", s;) is a call to this; others go to C's printf directly. Output stays in order with printf.

    CatPrint function
    U8 *CatPrint(U8 *_dst, U8 *fmt, ...);

    Append the formatted text to the heap string _dst (or start one if it is NULL) and return it: write s = CatPrint(s, ...), it may move. Each call measures _dst, so long loops are O(n^2): use CatLenPrint there.

    CatLenPrint function
    U8 *CatLenPrint(U8 *_dst, I64 *_len, U8 *fmt, ...);

    CatPrint that keeps the length in *_len (start it at 0 with a NULL _dst), so appending doesn't rescan the string.

    Str2CDateStruct function

    Parse strdate with a strptime-like format: %Y %m %d %H %M %s (or %S) %a/%b (day/month name, full or three letters) %p %z %%. Unset date fields are -1, time fields 0 and zone_diff CDATE_NO_ZONE. FALSE for empty, short or mismatching input, an unknown conversion or a field out of range.

    WildMatch function

    StrToCDate function

    Str2CDateStruct into a CDate; 0 if parsing fails or the format has no year, month and day.

    FileRead function
    U8 *FileRead(U8 *path, I64 *_size = NULL);

    Read the whole file at path into a new NUL-terminated buffer (Free it) and set *_size to its length. A regular file is read up to its size; a FIFO, pipe, device or a file that reports size 0 (/proc) is read until end of file, so FileRead waits for a FIFO's writer and never finishes on an endless device such as /dev/zero. Returns NULL, with *_size 0, if path is NULL, can't be opened, is a directory, or can't be read completely.

    FileWrite function
    Bool FileWrite(U8 *filename, U8 *buf, I64 size, I64 flags = O_CREAT | O_WRONLY | O_TRUNC);

    Write size bytes of buf to filename. The default flags create the file (mode 0644 minus the umask) or truncate it first, so it holds exactly buf; pass O_CREAT|O_WRONLY|O_APPEND to add to the end instead. Returns FALSE, without creating anything, for a NULL filename or buf or a negative size, and FALSE if the file can't be opened or written.

    Cd function
    I32 Cd(U8 *path);

    Change the working directory; "~" and "~/..." start at $HOME. 0 on success, -1 on failure.

    Stat function
    I32 Stat(Fstat *fst, U8 *pathname);

    Fill fst with the status of pathname, following symlinks (statx on Linux, stat on macOS; st_btim is the creation time where the filesystem records it). 0 on success, -1 on failure.

    Dir function
    I64 Dir(U8 *pathname = "./");

    List the entries of the directory pathname (not "." and ".."), one per line, coloured like ls when stdout is a terminal. Names that both start with a number are ordered by that number, however long, and everything else, ties included, by name (byte order). Entries Stat can't follow, like dangling symlinks, are listed too. Returns the number of entries, or -1 for NULL or a path that can't be opened as a directory.

    Pwd function
    U8 *Pwd(U8 *buf=NULL, U64 buf_size=0);

    The working directory: written into buf (buf_size bytes, NULL if it doesn't fit) and buf returned, or with no buf a new string to Free. NULL on error.

    File status#

    Portable file metadata. Defined in src/std/stat.ktm.

    RmDir function
    I32 RmDir(U8 *path, I64 flags=0);

    Remove the directory path: without RM_RECURSE only if it is empty (rmdir), with RM_RECURSE everything in it first. Symlinks inside are removed, never followed, and path itself must not be a symlink. Prints what it removes or fails to remove only with RM_VERBOSE. 0 on success, -1 on failure (also for NULL).

    Rm function
    I32 Rm(U8 *path, I64 flags=0);

    DANGER: remove path, whatever flags are given. A file, symlink (never what it points to), socket or FIFO is unlinked; a directory goes to RmDir(path, flags), so it must be empty unless RM_RECURSE is given. RM_VERBOSE prints what is removed, RM_FORCE makes a path that doesn't exist a success. 0 on success, -1 on failure (also for NULL).

    MkDir function
    I32 MkDir(U8 *path, I32 mode=MKDIR_DEFAULT, Bool recurse=FALSE);

    Make the directory path with mode (minus the umask), and with recurse every missing parent too. Returns 0 if path is a directory afterwards, made now or already there, and -1 if not (NULL or "", a file in the way, a missing parent without recurse, no permission).

    System#

    Process exit, shell commands and raw output. Defined in src/std/system.ktm.

    Exit function
    U0 Exit(I64 exit_code = EXIT_FAIL);
    System function
    I64 System(U8 *command);

    Run `command` with the shell (`sh -c`). Returns the command's exit code (0-255), or -1 if it was killed by a signal or the shell could not be run (also for a NULL command). The shell itself gives 127 for a command it can't find.

    Write function
    I64 Write(I64 fd, U8 *buf, I64 len);

    write(2) len bytes of buf to fd: the number written, or -1.

    Errno function
    I32 Errno();

    The calling thread's C errno: the reason the last failing libc call (socket, connect, read, ...) gave, to compare with the E* names above. Only meaningful right after a call that returned its error value.

    SetErrno function
    U0 SetErrno(I32 err);

    Set the calling thread's C errno, e.g. to 0 before a call that only reports errors through errno.

    Sh function
    I32 Sh(U8 *fmt, ...);

    Call the shell with `printf`-like formatting. fmt is always formatted, also without arguments, so write %% for a literal %. Returns what System returns: the exit code (0-255), or -1 if the command was killed by a signal, could not be run, or fmt is NULL.

    Shlurp function
    U8 *Shlurp(U8 *fmt, ...);

    Run a shell command, built with `printf`-like formatting (always formatted: %% for a literal %), and return what it printed to stdout in a heap allocated string (Free it). One trailing newline is removed. The exit status is not returned: a failing command gives whatever it printed, often "". stderr is not captured. It returns when the shell exits: what a background job (`cmd &`) prints later is not waited for. Returns NULL if fmt is NULL or the shell can't be started.

    ShQuote function
    U8 *ShQuote(U8 *s);

    s in single quotes for sh, as a new string to Free: each ' becomes '\'' and NULL gives ''. The shell expands nothing in it, so use it for any text that goes into a command: q = ShQuote(s); Sh("ls %s", q); Free(q).

    Lists#

    Circular doubly linked lists of U0 * values. Defined in src/std/list.ktm.

    List class
    class List
{
  U0 *value;
  List *next, *prev;
};

    A circular doubly linked list of U0 * values. The list itself is a head node (value unused) that links to itself when the list is empty; walk it with `for (List *it = l->next; it != l; it = it->next)`. Values are borrowed: the list never frees them unless you pass a free function.

    ListInit function
    U0 ListInit(List *l);

    Make `l` (usually a head on the stack or inside a class) an empty list. Such a head must be emptied with ListClear, never ListRelease.

    ListNew function
    List *ListNew();

    A new empty list (a heap-allocated head); free it with ListRelease.

    ListPrepend function
    U0 ListPrepend(List *head, U0 *value);

    Add `value` at the front.

    ListAppend function
    U0 ListAppend(List *head, U0 *value);

    Add `value` at the end.

    ListEmpty function
    Bool ListEmpty(List *l);

    TRUE if the list has no values (also for NULL).

    ListDeque function
    U0 *ListDeque(List *l);

    Remove the first value and return it (a queue's shift): NULL when the list is empty or NULL - a stored NULL looks the same, so check ListEmpty first if you store NULLs.

    ListInsertBefore function
    U0 ListInsertBefore(List *ll, List *new_node);

    Link `new_node` (not in any list) in before `ll`; with `ll` the head, that is the end of the list.

    ListInsertValueBefore function
    U0 ListInsertValueBefore(List *ll, U0 *value);

    Insert `value` before the node `ll` (before the head = at the end).

    ListPop function
    U0 *ListPop(List *l);

    Remove the last value and return it: NULL when the list is empty or NULL (a stored NULL looks the same, see ListDeque).

    ListRelease function
    U0 ListRelease(List *ll, U0 (*FreeValue)(U0 *arg));

    Free every node, calling FreeValue on each value if it is not NULL, and then the head itself - so only for ListNew lists (use ListClear on a ListInit head). NULL is ignored.

    ListCount function
    I64 ListCount(List *ll);

    The number of values. O(n): it walks the list. 0 for NULL.

    ListClear function
    U0 ListClear(List *l, U0 (*free_value)(U0 *value) = NULL);

    Free every node (calling free_value on each value, if given) but keep the head, now empty; works on a ListInit (stack) head. NULL is ignored.

    ListRemove function
    U0 *ListRemove(List *node);

    Unlink `node` from its list, free it and return its value. Must not be given the list's head (an empty head is left alone, returning NULL). NULL returns NULL.

    FzF function

    Match text against an fzf-style pattern: terms separated by spaces must all match (an escaped space, `\ `, is part of a term), and `a | b` matches either term.     Signals#

    sigaction-based handlers and a clean-shutdown helper for poll loops. Defined in src/std/signals.ktm.

    SigAct class
    class SigAct
{
  I64 handler;
  U64 mask;
  I32 flags;
};

    sigaction(2) (signals.ktm). A handler runs in the middle of whatever the program was doing, on whichever thread the signal reached, so it may only: store to a global (I64, Bool), call write(2), _exit, kill or raise, and save/restore Errno() around them. Not MAlloc/Free, printing, StrPrint, throw, mutexes or anything else that takes a lock: the interrupted code may hold it. Actions are per process (every thread); a signal sent to the process goes to one thread that doesn't block it (pthread_sigmask, not wrapped here, blocks it per thread). signal() sets the same action as SigHandle(sig, handler, SA_RESTART) on Linux and macOS, and the two can be mixed.

    The bit for signal sig in SigAct.mask (0 outside 1..64).

    Set the action for sig to *act (unless act is NULL) and store the previous one in *old (unless old is NULL). FALSE on failure, Errno() says why (EINVAL: a bad number, SIGKILL or SIGSTOP). Without SA_RESTART a blocking read, write, accept, ... interrupted by the handler returns -1 with Errno() EINTR; poll() always does.

    SigHandle function

    SqlCtxNew function
    SqlCtx *SqlCtxNew(U8 *dbname, Bool printerror=FALSE);

    Open (or create) the database file dbname, ":memory:" for a private in-memory one. NULL on failure, printing sqlite's message first when printerror is TRUE. dbname is kept, not copied.

    SqlCtxRelease function
    U0 SqlCtxRelease(SqlCtx *ctx);

    Close the database and free ctx. Statements not finalized yet keep the connection open until SqlFinalizePrepared. NULL is ignored.

    SqlPrepare function
    SqlPreparedStmt *SqlPrepare(SqlCtx *ctx, U8 *Sql);

    Compile one SQL statement with `?` parameters, to run many times with SqlExecPrepared. Only whitespace and comments may follow it. NULL on an error; free it with SqlFinalizePrepared.

    SqlFinalizePrepared function
    U0 SqlFinalizePrepared(SqlPreparedStmt *pstmt);

    Free a statement of SqlPrepare. NULL is ignored.

    SqlExecRaw function
    U8 *SqlExecRaw(SqlCtx *ctx, U8 *sql);

    Run every statement in sql, with no parameters (so never with values from outside the program). NULL on success, otherwise an error message to Free.

    SqlExecPrepared function
    I32 SqlExecPrepared(SqlPreparedStmt *pstmt, SqlRow *row, SqlParam *params);

    Run a prepared statement with params[0] .. params[n - 1] for its n parameters (NULL params binds them all to NULL). Returns sqlite's code: SQLITE_ROW when row now holds the first row (read the rest with SqlIterPrepared), SQLITE_DONE when there are no rows, or an error: SQLITE_MISUSE for a NULL pstmt, SQLITE_MISMATCH for a parameter type other than SQL_INT/FLOAT/TEXT/BLOB/NULL, or the code of a failed bind (e.g. SQLITE_TOOBIG). On an error the statement does not run and row holds no row. The row belongs to the statement: it is valid until the next SqlExecPrepared or SqlFinalizePrepared.

    SqlSelect function
    Bool SqlSelect(SqlCtx *ctx, SqlRow *row, U8 *sql, SqlParam *params=NULL, I32 param_count=0);

    Run one SQL statement with param_count parameters and point row at its first row, if any; read the rows with SqlIter. TRUE if the statement ran (also with no rows), FALSE on an error, an unknown parameter type or anything but whitespace and comments after the statement. The row owns the statement: SqlIter frees it after the last row, SqlRowRelease when you stop early.

    SqlQuery function
    Bool SqlQuery(SqlCtx *ctx, U8 *sql, SqlParam *params=NULL, I32 param_count=0);

    Like SqlSelect, for a statement whose rows you don't need (INSERT, UPDATE, CREATE, ...).

    SqlIter function
    I32 SqlIter(SqlRow *row);

    Move row to its next row (the first one on the first call): TRUE while there is one, FALSE after the last, when the row is released.

    SqlIterPrepared function
    I64 SqlIterPrepared(SqlRow *row);

    SqlIter for a row of SqlExecPrepared (the same, but returns I64).

    SqlRowRelease function
    U0 SqlRowRelease(SqlRow *row);

    Release a row before its last row was read: free its columns and, for a row of SqlSelect, its statement. A row of SqlExecPrepared leaves its statement to SqlFinalizePrepared. Calling it again does nothing.
