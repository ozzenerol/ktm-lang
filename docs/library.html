    Library guide

    How to use the standard library for everyday tasks. Every program can use it without an #include. For every function and struct, see the library reference.

    Memory#

    FunctionDoes
    mem.alloc(size)Allocate size bytes
    mem.allocZero(size)Allocate size zeroed bytes
    mem.realloc(ptr, size)Resize an allocation
    mem.free(ptr)Release it (null is fine)
    mem.size(ptr)The size an allocation was asked for (0 for null)
    mem.copy(dst, src, n), mem.set(dst, byte, n)Copy and fill; both return dst

    mem.allocZero takes one argument, the total size, unlike C's calloc(count, size). mem.alloc, mem.allocZero and mem.realloc return null when out of memory or when the size is too large (a negative size passed as a u64, say). mem.realloc always moves the block and copies as much of it as fits; mem.realloc(null, size) is mem.alloc(size), and when it fails the old block is left as it was, so keep the old pointer until you know it worked. Each block carries its size in a hidden header, so only pointers from these functions can go to mem.free, mem.size and mem.realloc. mem.copy copies front to back: for overlapping buffers use memmove.

    import cstr, mem;

struct Player
{
  u8 *name;
  i64 score;
};

void main()
{
  Player *team = mem.allocZero(3 * sizeof(Player));
  team[0].name = "ada";
  team[0].score = 10;
  team = mem.realloc(team, 4 * sizeof(Player));
  team[3].name = "linus";
  printf("%s %d, %s\n", team[0].name, team[0].score, team[3].name);
  mem.free(team);
}

    ada 10, linus

    Run a program with ktm -jit -Memsafe file.ktm to have double frees and wild frees reported (and skipped) as they happen, and leaks reported at exit, each with the line that allocated or freed the block, in any thread. Only blocks your code gets from mem.alloc, mem.allocZero and mem.realloc are tracked: a string or container the standard library allocates for you (cstr.dup, cstr.formatTo, vec.ptrNew, ...) is not, so leaking one goes unreported, and a block of yours that the library resizes (cstr.appendFormat, cstr.appendFormatLen) is reported as never freed.

    Strings#

    Text is two modules. str is what code works with: String, a string you own that grows as you add to it, and the functions that read text given as a u8[], so a literal, a slice or a String. cstr is C's strings: a NUL-terminated u8 *, for C functions and the data they give you. A String's bytes are always followed by a NUL, so s.cstr() passes one to C for free, and cstr.view(p) is a C string's bytes as a u8[], so str.from(cstr.view(p)) makes a String of them. Case conversion and the case-insensitive compares only know ASCII letters.

    String#

    A String is yours: free it, and the way to do that is defer right where you make it. str.new() makes an empty one (nothing is allocated until something is added; a declared String s; is empty too), str.from(t) a copy of t, str.withCap(n) one with room for n bytes and str.format(fmt, ...) the formatted text. Its methods change it in place: append, appendByte, appendFormat, insert, remove, replace, clear, reserve, toLower, toUpper, reverse; clone() gives a copy of your own. s.len is its length in bytes and s[i], s[a:b] its bytes (checked); its fields are read-only. Copying a String (String b = a;) shares its bytes, so free only one of them: -Memsafe reports a double free or a String never freed.

    import str;

void main()
{
  String s = str.format("%d files", 3);
  defer s.free();
  s.insert(0, "found ");
  s.append(" in /tmp");
  s.replace("files", "logs");
  printf("%s (%d bytes)\n", s, s.len);

  String path = str.from("/var/log");
  defer path.free();
  path.appendFormat("/%s.%d", "app", 2);
  path.toUpper();
  printf("%s %s %c\n", path, path[1:4], path[5]);
  printf("%s\n", path.cstr());
}

    Reading text#

    These take a u8[], so any text, and are called as functions or as methods of it (s.find("x") is str.find(s, "x")). find and findLast give the index of a part or -1, contains, startsWith, endsWith and equals say whether it is there, compare orders two texts. The trims and splits return views, parts of what you gave them with nothing copied: trim, trimStart, trimEnd (of whitespace, or of the bytes you give it), splitFirst and splitLast (around a separator), and split, a list of views that is allocated: defer parts.free();.

    import str;

void main()
{
  u8[] line = "  name = ktm, lang  \r\n";
  u8[] t = line.trimEnd("\r\n").trim();
  u8[] key, value;
  if (str.splitFirst(t, " = ", &key, &value)) {
    printf("[%s] [%s]\n", key, value);
  }
  u8[][] parts = value.split(", ");
  defer parts.free();
  for (auto p : parts) { printf("<%s>", p); }
  printf("\n%d %d %d %d\n", t.find("ktm"), t.startsWith("name"), "abc".equals("abc"),
         str.compare("a", "b") < 0);
  printf("%c%c %d\n", str.toUpper('q'), str.toLower('Q'), str.isSpace('\t'));
}

    s.len and s[i] count bytes. For characters, UTF-8: str.decodeRune(s, &at) gives the code point at byte at and moves at past it (U+FFFD for bytes that aren't UTF-8, -1 at the end), str.runeCount(s) counts them and str.validUtf8(s) checks a text.

    Format conversions#

    str.format, a String's appendFormat, cstr.format, cstr.formatTo and the other formatting functions share one format language with print statements. Integers are always 64-bit, and the C length modifiers l, ll, h, hh, z and j are accepted and ignored, so C formats can be pasted in.

    ConversionPrints
    %d %ia signed integer
    %uan unsigned integer
    %x %X %ohexadecimal (lower / upper case), octal
    %f %e %gan f64, as C's printf prints it
    %sa C string; in a literal format also a u8[] or a String (passed as its length and bytes)
    %c %Ca character, %C in upper case; a wider integer prints its bytes as characters, low byte first (up to 8); the value 0 prints nothing
    %pa pointer as 0x and 16 hex digits
    %Qa string escaped for a C literal (cstr.quote)
    %%a % (a width on it is ignored)

    A date is formatted with date.format(d, fmt) (%Y %m %d %H %M %S, %a %b %p) and a file read with fs.readAll; %D, %T and %F are an error, with the way to do it in the message.

    Between the % and the letter come, in order: the flags - (left justify), 0 (pad with zeros), + (always a sign), a space (a space where a plus sign would go) and # (0x / 0 prefix for hex and octal); a width; and a precision after a ., which is the number of decimals for floats, the maximum length for %s and the minimum number of digits for integers (%.3d of 7 is 007). Width and precision can be *, taken from the arguments. An unknown conversion is printed as it was written, with a warning on stderr, and still uses up its argument, so the ones after it stay in place.

    cstr.formatTo(buf, fmt, ...) writes into buf with no bound. For a fixed-size buffer use cstr.formatToSize(buf, size, fmt, ...), which works like C's snprintf: it writes at most size - 1 characters and always ends them with a '\0', cutting longer output short. It returns buf.

    import cstr, mem;

void main()
{
  u8 *s = cstr.formatTo(null, "%+d|% d|%#x|%#o|%.3d|%ld|%-4s|%5.1f", 7, 7, 255, 8, 7,
                   5000000000, "ab", 2.25);
  printf("%s\n", s);
  mem.free(s);

  u8 small[8];
  cstr.formatToSize(small, sizeof(small), "%s-%d", "overflow", 12345);
  printf("[%s] %d\n", small, cstr.len(small));
}

    C strings#

    cstr works on NUL-terminated strings, as C does. Functions that make one (cstr.dup, cstr.format, cstr.formatTo(null, ...), cstr.concat, cstr.dupLen, cstr.quote) return a new block that you mem.free.

    Building C strings#

    cstr.formatTo(null, fmt, ...) returns a newly allocated formatted string, and cstr.appendFormat(s, fmt, ...) appends the formatted text to the heap string s and returns it, so write s = cstr.appendFormat(s, fmt, ...): when s is full it is grown, which may move it and frees the old block. s must come from mem.alloc, cstr.dup, cstr.formatTo(null, ...) or an earlier cstr.appendFormat, or be null to start a new string; never pass a string literal or a stack buffer. cstr.appendFormat measures s on every call, so appending in a long loop is quadratic; cstr.appendFormatLen(s, &len, fmt, ...) keeps the length in len and doesn't. cstr.concat("a", "b", ...) joins strings and cstr.format(fmt, ...) is cstr.formatTo into an exactly sized block.

    import cstr, mem;

void main()
{
  u8 *s = cstr.formatTo(null, "%d|%05d|%s|%.2f", 5000000000, 42, "x", 3.14159);
  printf("%s\n", s);

  u8 *csv = cstr.dup("id");
  for (i64 i = 1; i <= 3; i++) {
    csv = cstr.appendFormat(csv, ",%d", i);
  }
  printf("%s\n", csv);

  i64 len = 0;
  u8 *log = null;
  for (i64 i = 0; i < 3; i++) {
    log = cstr.appendFormatLen(log, &len, "[%d]", i * i);
  }
  printf("%s (%d)\n", log, len);

  u8 *joined = cstr.concat("con", "cat", "enate");
  printf("%s\n", joined);
  mem.free(s);
  mem.free(csv);
  mem.free(log);
  mem.free(joined);
}

    Inspecting C strings#

    cstr.cmp, cstr.cmpLen and cstr.cmpLenNoCase return a negative, zero or positive number like C's strcmp, comparing bytes as unsigned, and sort a null before every string. cstr.firstOf and cstr.lastOf find the first or last character of the first string that is any of the characters in the second. cstr.globMatch matches a whole string against a pattern where * is any run of characters and ? any one character. cstr.hash gives a well mixed 64-bit hash of a string.

    import cstr, fs, str;

void main()
{
  printf("%d %d\n", cstr.len("hello"), cstr.cmp("abc", "abc") == 0);
  printf("%d\n", cstr.cmpLen("prefix-rest", "prefix", 6) == 0);
  printf("%d %d\n", cstr.cmp("abc", "abd") < 0, cstr.cmpLenNoCase("ABC", "abc", 3) == 0);
  printf("%d\n", cstr.count("banana", 'a'));               // count a character
  printf("%s\n", cstr.firstOf("key=value", "="));       // from the first match
  printf("%s\n", cstr.lastOf("a/b/libc.ktm", "/"));         // from the last match
  printf("%s\n", fs.ext("archive.tar.gz"));
  printf("%d %d %d\n", cstr.globMatch("main.ktm", "*.ktm"), cstr.globMatch("main.c", "*.ktm"),
    cstr.globMatch("banana", "b?n*a"));
  printf("%d\n", cstr.toInt("1234") + 1);
  printf("%c %c %d\n", str.toUpper('q'), str.toLower('Q'), str.isSpace(' '));
}

    Copying C strings#

    cstr.dup copies a whole string and cstr.dupLen(s, n) at most the first n bytes of it, like C's strndup (a negative n is 0). cstr.copy copies into a buffer you provide.

    import cstr, mem;

void main()
{
  u8 *copy = cstr.dup("a copy");
  printf("[%s]\n", copy);

  u8 *part = cstr.dupLen("truncate me", 8);
  printf("[%s]\n", part);

  u8 buf[16];
  cstr.copy(buf, "fixed");
  printf("%s\n", buf);
  mem.free(copy);
  mem.free(part);
}

    Splitting paths and names#

    fs.ext(name) is a file name's extension, from its first . that isn't followed by / or ., and fs.cutExt(name) the name without it; both are views of the name. str.splitLast splits a path at its last /.

    import fs, str;

void main()
{
  u8[] dir, file;
  str.splitLast("usr/lib/libktm.tar.gz", "/", &dir, &file);
  printf("%s + %s\n", dir, file);
  printf("%s + %s\n", fs.cutExt(file), fs.ext(file));
}

    Files#

    Paths are a u8[] (a literal, a slice or a String; a C string through cstr.view(p)). fs.writeAll(path, data) writes data, a u8[], to a file and returns whether it worked. fs.readAll(path) reads a whole file into a String that is yours, with a NUL after it; its ptr is null when the file can't be read (os.errno() says why), and an empty file gives an empty String that has one.

    import fs;

void main()
{
  u8[] path = "/tmp/ktm_docs_example.txt";
  if (!fs.writeAll(path, "first line\nsecond line\n")) {
    printf("could not write %s\n", path);
    return;
  }

  String contents = fs.readAll(path);
  defer contents.free();
  printf("%d bytes\n%s", contents.len, contents);

  String missing = fs.readAll("/no/such/file");
  if (!missing.ptr) {
    printf("a missing file gives a String without a ptr\n");
  }
}

    fs.writeAll replaces the file's contents: by default it opens with O_CREAT | O_WRONLY | O_TRUNC (a new file gets mode 0644 minus the umask). Pass the flags yourself to do something else, O_CREAT | O_WRONLY | O_APPEND to add to the end. A path that can't be opened gives false and creates nothing. fs.readAll reads a regular file up to its size, and a FIFO, a pipe (/dev/fd/N, /dev/stdin), a device or a /proc file (which reports size 0) until end of file, so it waits for a FIFO's writer and never finishes on an endless device like /dev/zero. For a directory it gives a String without a ptr. A path longer than 4095 bytes fails in every function here, with ENAMETOOLONG.

    Directories: fs.makeDir(path) makes one directory and fs.makeDir(path,, true) the missing parents too; both return 0 if the path is a directory afterwards (made now or already there) and -1 if not, the convention fs.remove and fs.removeDir use too. fs.remove(path) removes a file, a symlink (never what it points to) or an empty directory; with fs.REMOVE_RECURSE a directory and everything in it, with fs.REMOVE_FORCE a path that doesn't exist is not an error. fs.removeDir is the directory half of it. fs.stat(&fst, path) fills an fs.FileStat (size, mode, times), fs.changeDir changes directory (~ is $HOME) and fs.currentDir() returns the working directory as a String.

    import cstr, fs, libc, mem, str;

extern "c" u8 *mkdtemp(u8 *template);

void main()
{
  u8 dir[32];
  mem.copy(dir, "/tmp/ktm_docs_XXXXXX", 21);
  if (!mkdtemp(dir)) { return; }    // a fresh directory to work in
  u8[] root = cstr.view(dir);

  String path = str.format("%s/a/b", root);
  defer path.free();
  printf("fs.makeDir: %d\n", fs.makeDir(path,, true));

  String notes = str.format("%s/a/notes.txt", root);
  defer notes.free();
  fs.writeAll(notes, "a long first version\n");
  fs.writeAll(notes, "short\n");                  // replaces it
  fs.writeAll(notes, "more\n", libc.O_CREAT | libc.O_WRONLY | libc.O_APPEND);
  String text = fs.readAll(notes);
  defer text.free();
  printf("%d bytes:\n%s", text.len, text);

  String a = str.format("%s/a", root);
  defer a.free();
  String what = fs.readAll(a);
  printf("fs.readAll of a directory: %d\n", what.ptr == null);

  fs.FileStat fst;
  if (fs.stat(&fst, notes) == 0) { printf("notes.txt: %d bytes\n", fst.st_size); }

  printf("fs.remove: %d\n", fs.remove(root, fs.REMOVE_RECURSE));
  printf("fs.remove again with fs.REMOVE_FORCE: %d\n", fs.remove(root, fs.REMOVE_FORCE));
}

    CSV#

    csv.next walks a CSV text without copying it: each call gives the next field (csv.FIELD), then the whole row (csv.ROW), and csv.EOF at the end. A csv.Item has its number (idx, the field in its row or the row) and its text, a u8[] view of the input. The views are the raw text: a quoted field keeps its quotes and its doubled "", commas and newlines inside quotes don't split, and a row's text includes its \n or \r\n. Unquoting is up to you. csv.init takes any u8[], so text[0:n] parses part of a buffer; the input must outlive the parser.

    import csv;

void main()
{
  u8[] text = "name,quote\r\nann,\"say \"\"hi\"\", ok\"\nbob,\n";
  csv.Parser p;
  csv.Item it;
  i64 kind;
  csv.init(&p, text);
  while ((kind = csv.next(&p, &it)) != csv.EOF) {
    if (kind == csv.FIELD) { printf("field %d: [%s]\n", it.idx, it.text); }
    else                   { printf("row %d: %d bytes\n", it.idx, it.text.len); }
  }
}

    Running commands#

    import proc;

void main()
{
  i64 status = proc.shell("echo from the shell");
  proc.shellf("echo %s has %d files", "/tmp", 3);       // printf-style
  String out = proc.shellOutput("echo %s", "captured");  // capture stdout
  defer out.free();

  printf("exit code %d\n", status);
  printf("[%s]\n", out);
}

    Print statements are buffered, while commands write straight to the terminal. When output goes to a pipe or file, a command's output can appear before text you printed earlier.

    proc.shell (a u8[]) and proc.shellf (a format) run the command with sh -c and return its exit code, 0 to 255: proc.shell("exit 3") gives 3, and a command the shell can't find gives 127. They return -1 if the command was killed by a signal or the shell couldn't be run.

    proc.shellOutput returns what the command printed to stdout, minus one trailing newline, as a new String; format arguments are optional, and %s takes a String or a slice as well. It doesn't capture stderr or return the exit status: a failing command gives whatever it printed, often "", and a shell that couldn't be started an empty String with a null ptr. It returns once the shell exits, without waiting for a background job (cmd &) the command started. os.exit(code) ends the program.

    The commands get the program's stdin, stdout and stderr, but none of the files or sockets the library opened: those (the net sockets and accepted connections, fs.readAll/fs.writeAll's file, proc.shellOutput's pipe) are close-on-exec. An fd you open yourself with open or socket is inherited unless you pass O_CLOEXEC (Linux also has SOCK_CLOEXEC) or set FD_CLOEXEC with fcntl(fd, F_SETFD, FD_CLOEXEC).

    The command is shell text, so a string from elsewhere (a file name, user input) must not be pasted in as it is: a space splits it and $, `, ; or * run or expand things. proc.shellQuote(s) returns s in single quotes as a new String, with each ' written as '\'' (and '' for an empty one), so the shell gets it as one word, unchanged.

    import proc;

void main()
{
  String q = proc.shellQuote("it's $HOME; *");
  defer q.free();
  String out = proc.shellOutput("printf '%%s' %s", q);
  defer out.free();
  printf("[%s]\n", out);
}

    [it's $HOME; *]

    Running programs without a shell#

    proc.run(argv, &code) runs a program with the arguments in argv, a null-terminated array of C strings, and returns what it printed to stdout (minus one trailing newline) as a new String, with its exit code in code. No shell is involved: every argument reaches the program exactly as written, so nothing needs quoting. The program is looked up in $PATH; an empty String with a null ptr means it couldn't be started, and os.errno() says why (2, ENOENT, for a program that doesn't exist).

    import proc;

void main()
{
  u8 *argv[] = {"printf", "%s|", "it's $HOME", "a b", null};
  i64 code;
  String out = proc.run(argv, &code);
  defer out.free();
  printf("[%s] exit %d\n", out, code);
}

    [it's $HOME|a b|] exit 0

    For more control, proc.spawn(argv, &opts) starts the program and returns a proc.Proc. In proc.Opts (zero it first: its fields are all optional) each of in, out and err is proc.INHERIT (ours, the default), proc.PIPE (our end is p.inFd, outFd or errFd), proc.DEVNULL (/dev/null) or, for err, proc.STDOUT (2>&1); cwd and env (a null-terminated "NAME=value" list that replaces the environment) are optional. proc.communicate(p, input, &out, &err) writes the input (a u8[]), reads both outputs to the end into Strings and waits, all in one poll() loop, so a program that writes a lot to both, or echoes its input, can't block; pass null for an output you don't want (it is still read, and dropped). proc.wait(p) returns the exit code, or -1 when a signal killed the program (p.termSignal says which); proc.done(p) checks without waiting, proc.kill(p, sig) signals it (the whole group with newGroup), and proc.release(p) closes the pipes and frees it, waiting for a program that is still running.

    import mem, proc;

void main()
{
  u8 *argv[] = {"sh", "-c", "tr a-z A-Z; echo done >&2; exit 3", null};
  proc.Opts opts;
  mem.set(&opts, 0, sizeof(proc.Opts));
  opts.in = proc.PIPE;
  opts.out = proc.PIPE;
  opts.err = proc.PIPE;
  proc.Proc *p = proc.spawn(argv, &opts);
  String out, err;
  i64 code = proc.communicate(p, "hello\n", &out, &err);
  printf("out=%s err=%s exit=%d\n", out, err, code);
  out.free();
  err.free();
  proc.release(p);
}

    The program starts with default signal handlers and only stdin, stdout and stderr open: it inherits none of your sockets or files. proc.shell, proc.shellf and proc.shellOutput are still the tools for shell pipelines, globs and redirections; use the proc.Proc functions whenever an argument comes from a file name or user input.

    Signals#

    signal.handle(sig, handler, flags, mask, &old) sets what happens when a signal arrives: SIG_DFL, SIG_IGN, or a function void F(i32 sig) passed as (&F)(i64). flags defaults to SA_RESTART, which makes a blocking read, write or accept carry on after the handler; pass 0 to have it return -1 with os.errno() == EINTR instead (poll always does). mask (signal.bit(SIGUSR2) | ...) holds other signals back while the handler runs, and old, if given, receives the previous action, so it can be put back with signal.action(sig, &old). signal(sig, handler) is the same as signal.handle with SA_RESTART, and the two can be mixed.

    import cstr, libc, signal;

i64 hits = 0;
void onUsr1(i32 sig)
{
  hits++;
}

void main()
{
  signal.Action old;
  signal.handle(libc.SIGUSR1, (i64)(&onUsr1), libc.SA_RESTART, 0, &old);
  libc.raise(libc.SIGUSR1);
  libc.raise(libc.SIGUSR1);
  signal.action(libc.SIGUSR1, &old);      // back to what it was
  printf("%d signals, previous handler SIG_DFL: %d\n", hits, old.handler == libc.SIG_DFL);
}

    2 signals, previous handler SIG_DFL: 1

    A handler interrupts the program wherever it is, on whichever thread the signal reached, so it may only set a global variable, call write, _exit, kill or raise, and keep os.errno() as it found it. Allocating, printing, throw or taking a mutex there can deadlock or corrupt memory: the interrupted code may be in the middle of the same thing. Actions are shared by all threads, and a signal sent to the process is handled by one of them, whichever doesn't block it.

    For a server built around poll(), signal.stopInit() does this for SIGINT and SIGTERM: it returns an fd to add to the poll set, which becomes readable when either signal arrives, and from then on signal.stopRequested() is TRUE (signal.stopSignal() says which one came). The loop finishes what it is doing and returns. A second Ctrl-C ends the program as usual, in case the loop never gets there.

    import cstr, libc, signal;

void main()
{
  i32 fd = signal.stopInit();
  libc.pollfd p;
  p.fd = fd;
  p.events = libc.POLLIN;
  libc.raise(libc.SIGTERM);                // as if `kill` had been run on us

    Lists#

    list.List is a circular doubly linked list of void * values. The list is its head node, which links to itself when the list is empty, so iterate from l.next until you get back to l. The list never frees the values it holds unless you hand it a free function.

    import cstr, list;

void main()
{
  list.List *l = list.new();
  l.append("two");
  l.append("three");
  l.prepend("one");

  for (list.List *it = l.next; it != l; it = it.next) {
    printf("%s\n", it.value);
  }
  printf("first %s, last %s\n", l.first(), l.last());
  printf("popped %s, %d left\n", l.pop(), l.count());
  l.release(null);
}

    • Making one. list.new() allocates a head; free it with list.release. list.init(&head) turns a head you own (on the stack, or inside a struct) into an empty list; empty that one with list.clear, because list.release also frees the head.
    • Adding. list.append and list.prepend add at the end and the front; list.insertBefore(node, value) inserts before any node (before the head is the end), and list.insertNodeBefore(node, new_node) links in a node you made yourself.
    • Removing. list.shift removes and returns the first value and list.pop the last, so list.append with list.shift is a first-in first-out queue and list.append with list.pop a stack. list.remove(node) unlinks one node while you walk the list (take it.next first) and returns its value; never pass it the head.
    • Looking. list.first and list.last return a value without removing it, list.isEmpty tells whether there are any, and list.count counts them by walking the list, so it is O(n).
    • Emptying. list.clear(l, free_value) frees every node and keeps the head; list.release(l, free_value) frees the nodes and the head. Both call free_value on each value when it isn't null.
    • Joining. list.mergeAppend(l1, l2) and list.mergePrepend(l1, l2) move all of l2's values to the end or the front of l1 and free l2's head, so l2 (which must come from list.new) can't be used afterwards.

    list.shift, list.pop, list.first and list.last return null for an empty list, which looks the same as a stored null: check list.isEmpty first if you store them. The functions that remove, look or free accept a null list and do nothing (returning null, 0 from list.count, true from list.isEmpty); the ones that add need a real list.

    import cstr, list, mem, str;

void main()
{
  list.List todo;              // a head on the stack
  todo.init();
  todo.append(cstr.dup("write"));
  todo.append(cstr.dup("test"));
  todo.append(cstr.dup("ship"));

  list.List *it = todo.next;
  while (it != &todo) {   // drop "test" while walking
    list.List *next = it.next;
    if (!cstr.cmp(it.value, "test")) { mem.free(it.remove()); }
    it = next;
  }

  list.List *later = list.new();
  later.append(cstr.dup("rest"));
  todo.mergeAppend(later);   // `later` is freed

  for (it = todo.next; it != &todo; it = it.next) { printf("%s ", it.value); }
  printf("(%d)\n", todo.count());
  todo.clear(&mem.free);         // keeps the stack head
  printf("empty: %d\n", todo.isEmpty());
}

    Vectors#

    Growable arrays: vec.IntVec of i64, vec.FloatVec of f64 and vec.PtrVec of pointers. Each has size and entries fields, so a range-based for works on them. They have the same methods:

    • vec.intNew(size = 32) makes an empty vector with room for size values (its initial capacity); a size below 1 is taken as 1. v.capacity() says how many values fit before the storage has to grow, and v.push(value) appends, doubling the storage when it is full.
    • v.get(i) and v.set(i, value) read and replace an entry. The index is always checked: outside 0 to size - 1 they print IntVec.get: index 5 out of range (size 3) on stderr and exit with status 1. Reading v.entries[i] directly is not checked.
    • v.pop(&ok) removes and returns the last entry and v.last(&ok) returns it without removing it. On an empty vector they return -1 (-1.0 for vec.FloatVec, null for vec.PtrVec) and set ok to false; the ok argument is optional.
    • v.clear() sets the size to 0 and keeps the storage for reuse; v.release() frees it. A vec.PtrVec's v.release(free_value) first calls free_value (for example &mem.free) on every value.
    • sort() of a vec.IntVec or vec.FloatVec sorts ascending. A vec.PtrVec's sort takes a comparison that returns true when its first argument should come first. That's a "less than" test, not a C-style negative, zero or positive result, which leaves the vector unsorted. The sorts are O(n log n), also for sorted or all-equal input, and not stable: equal values may change order.

    Sets and trees#

    set.IntSet is a sorted set of i64 values. add, delete and has are O(log n); adding a value that is there, or deleting one that isn't, changes nothing. unionWith, intersection, diff (in the first set, not the second) and symDiff (in exactly one) return a new set and leave their arguments alone; eq compares two sets. An iterator, toVec and toStr (a String) give the values in ascending order. Don't add or delete values while iterating: once one is added or deleted, set.intIterNext returns null and the loop ends early, so collect the changes and apply them after it. The functions that only read a set, and release, treat null as the empty set.

    import cstr, mem, set;

void main()
{
  set.IntSet *evens = set.intNew();
  set.IntSet *threes = set.intNew();
  i64 i;
  for (i = 1; i <= 6; i++) { evens.add(i * 2); }
  for (i = 1; i <= 4; i++) { threes.add(i * 3); }
  evens.add(4);
  evens.delete(10);
  printf("has 4: %d, has 5: %d, size %d\n",
    evens.has(4), evens.has(5), evens.size());

  set.IntSet *both = evens.intersection(threes);
  String text = both.toStr();
  printf("both: %s\n", text);
  text.free();

  set.IntSet *either = evens.unionWith(threes);
  set.IntSetIter *it = either.iterNew();
  set.IntSetEntry *e;
  while ((e = set.intIterNext(it))) { printf("%d ", e.key); }
  printf("\n");
  set.intIterRelease(it);

  either.release();
  both.release();
  threes.release();
  evens.release();
}

    map.RBTree, which set.IntSet is built on, maps void * keys to void * values in the order of a comparison function you pass to map.rbNew(free_key, free_value, key_cmp): key_cmp(a, b) returns less than 0 when a comes first, 0 when they are equal and more than 0 otherwise. The two free functions may be null; when set, the tree frees keys and values with them on delete, release and when an insert replaces a value (an insert of an existing key keeps the stored key). get returns null for a missing key, the same as a stored null, so ask has to tell them apart. iterNew and forEach visit the entries in key order; don't insert or delete while they run. Once a new key is added or one is deleted, map.rbIterNext returns null and forEach returns after that callback; replacing the value of a key that is there is fine.

    Hash tables#

    map.StrMap maps text keys to void * values and map.IntMap maps i64 keys. Values are pointers, so cast integers when storing them: count(void *). Setting an existing key replaces its value.

    A StrMap key is a u8[]: a literal, a String or a view into a buffer, matched on all its bytes. A null map is safe everywhere: get and has give null and false, set and delete false, and release and clear do nothing. An empty u8[] is the key "".

    Parsing and selecting#

    json.parse(text) parses text, a u8[], into a tree of json.Value nodes and returns its root; the text can be any one JSON value (an object, array, string, number, boolean or null). It always returns a root: check json.ok before using it, and free it with json.release either way. json.select(node, path) walks a path from any node: .key for an object member, [n] for an array item, and a type check that must match: :s string, :i integer, :f float, :b boolean, :a array, :o object, :! null. It returns null if the path doesn't match or is malformed ([1x], ..a, a trailing .).

    import json;

void main()
{
  u8[] text = "{\"name\": \"ktm\", \"version\": 15, \"ratio\": 0.75, \"tags\": [\"jit\", \"repl\"], \"stable\": false, \"owner\": null}";
  json.Value *doc = json.parse(text);
  if (!json.ok(doc)) {
    json.printError(doc);
    json.release(doc);
    return;
  }

  printf("%s v%d\n", json.select(doc, ".name:s").str, json.select(doc, ".version:i").intVal);
  printf("second tag: %s\n", json.select(doc, ".tags[1]:s").str);
  printf("stable: %d, owner is null: %d\n", json.select(doc, ".stable:b").boolean,
    json.select(doc, ".owner:!") != null);
  printf("missing: %d, wrong type: %d\n", json.select(doc, ".author") == null,
    json.select(doc, ".version:s") == null);

  json.Value *tags = json.select(doc, ".tags:a");
  for (json.Value *t = tags.array; t; t = t.next) {
    printf("tag %s\n", t.str);
  }

  String out = json.toStr(doc);
  defer out.free();
  printf("%s\n", out);
  json.release(doc);
}

    Each node has a type and its value in the matching field: json.STRING in str (a u8[]), json.INT in intVal, json.FLOAT in floatVal, json.BOOL in boolean, json.NULL, json.STRNUM in strnum (see below), and json.ARRAY / json.OBJECT, whose array / object points at the first item or member - or is null when the array or object is empty.     Wildcards and getters#

    A * in a path takes the next argument: an i64 inside [], a string after ., and it can be part of a name (.price_*). Each part of a path is at most 256 bytes, and a key that contains . [ ] : or * can't be written in a path. json.objectGet(obj, key) (any u8[], all its bytes) and json.arrayGet(arr, i) take any key or index directly (null if it isn't there or the node has the wrong type), and json.len counts the items of an array or object (0 for anything else). If a key appears twice, both members are kept; selecting it finds the first.

    Writing JSON and freeing#

    json.toStr(node) returns the JSON text of that node's value as a String that is yours: for an inner node just its value, without its key or the nodes after it. Members are written as "key": value and items are separated by , without a space. Floats get 15, 16 or 17 significant digits, the fewest that read back as the same value, always with a decimal point (0.75, 2.0, 1.0e+21); infinity and NaN, which JSON lacks, are written as null. Strings are escaped (\", \\, \n, \t, ..., \u00XX for other control characters), so the output parses back to the same values.

    The nodes inside a document - whatever json.select, the getters and next give you - are views into it: don't free or keep them after the root is released. json.release frees a whole document, and only does something when given a root; on null or an inner node it does nothing.

    import json;

void main()
{
  json.Value *doc = json.parse("{\"user\": {\"id\": 7, \"roles\": [\"admin\"]}, \"n\": 1e400}");
  json.Value *user = json.select(doc, ".user");
  String s = json.toStr(user);      // just this node's value
  printf("%s\n", s);
  s.free();
  json.release(user);               // a view: ignored
  s = json.toStr(doc);              // 1e400 is too big for an f64: null
  printf("%s\n", s);
  s.free();
  json.release(doc);                // frees everything
}

    Building JSON with a Writer#

    A json.Writer builds a document into a String without a tree: open arrays and objects with beginArray() / beginObject() and close the innermost one with end(), give each member's name with key(k), and add values with int(i64), float(f64), bool(b), nil() (JSON's null: null is a keyword), str(s) (any u8[]: a literal, a slice or a String) and raw(text) (JSON text made elsewhere, checked to be one value). Commas, quotes and escapes are written for you, the same escapes and float digits as json.toStr. w.take() returns the finished document as a String that is yours and leaves the Writer empty for the next one; w.free() frees what it holds. Make one with json.writerNew() (a declared Writer isn't zeroed); json.writerNew(2) puts each member and item on its own line, indented 2 spaces per level.

    A call out of order throws json.ERR_WRITER, and so does a value JSON can't hold: a value where a key is expected, key() outside an object, end() with nothing open, a second top-level value, take() with something still open or nothing written, a NaN or infinite float, a string that isn't UTF-8. The message says which, and the Writer is left as it was.

    import json;

void main()
{
  json.Writer w = json.writerNew();
  defer w.free();
  w.beginObject();
  w.key("id");    w.int(5);
  w.key("name");  w.str("Ada \"the\" first");
  w.key("tags");  w.beginArray(); w.str("a"); w.float(1.5); w.bool(true); w.nil(); w.end();
  w.end();
  String text = w.take();
  printf("%s\n", text);
  text.free();

  try {
    w.beginArray();
    w.key("oops");
  } catch (Error e) {
    printf("%s\n", e.message);
  }
}

    Errors and strictness#

    The parser follows RFC 8259 strictly. It rejects trailing commas, anything after the top-level value, numbers like 01, +1, .5, 1., 1e or hex, raw control characters (tab, newline, ...) inside strings, whitespace other than space, tab, newline and carriage return, anything but whitespace between a key and its :, and arrays and objects nested more than json.MAX_DEPTH (512) deep. On an error json.errorStr(root) returns the message as a String (one without a ptr if there was no error) and json.printError prints it; both say where, as a line and a byte column, also found in root->state with the error code (error, line, col, offset).

    Numbers and strings#

    An integer that fits in an i64 becomes a json.INT; a larger one becomes a json.FLOAT, as in JavaScript, and a number with a fraction or exponent is a float (one too big for an f64 is infinity). String escapes are decoded, \uXXXX and surrogate pairs to UTF-8. A string can contain \u0000, which str.len and key.len count; C-style functions and paths see them only up to the first '\0'.

    json.parse's optional argument is the flags (to parse part of a text, give it the part: json.parse(text[0:n])): json.NO_FLAGS or json.STRNUM_FLAG. With json.STRNUM_FLAG numbers are not converted: each one is still checked against the JSON grammar and becomes a json.STRNUM node whose strnum is the number exactly as written, so large integers and decimals keep every digit, and json.toStr writes it back unchanged. The :i and :f checks don't match these nodes; select them without one.

    import json;

void main()
{
  json.Value *doc = json.parse("[9007199254740993, 99999999999999999999, 2.50, \"a\\u0000b\"]");
  json.Value *big = json.arrayGet(doc, 1);
  printf("%d %d %d\n", json.isInt(json.arrayGet(doc, 0)), json.isFloat(big), json.arrayGet(doc, 3).str.len);
  String s = json.toStr(doc);
  printf("%s\n", s);
  s.free();
  json.release(doc);

  doc = json.parse("{\"id\": 123456789012345678901234567890, \"price\": 9.90}",
                  json.STRNUM_FLAG);
  printf("id %s\n", json.select(doc, ".id").strnum);
  printf("price %s\n", json.select(doc, ".price").strnum);
  s = json.toStr(doc);
  printf("%s\n", s);
  s.free();
  json.release(doc);
}

    Sockets#

    net.listen(port, bindaddr, backlog) returns a listening TCP socket, net.accept(server) the next connection on it and net.dial(addr, port) a connected socket. All three return the socket as an i32, or -1 on failure (0 is a valid socket number). Read and write them with read/write or recv/send, and close them when done. Addresses, like all text here, are a u8[] (a literal, a slice, a String). net.dial takes a host name or an IPv4 or IPv6 address and tries every address the name resolves to. The server's bind address must be numeric ("127.0.0.1", "::1"), "*" for any IPv4 address or "::*" for any IPv6 address; port 0 lets the kernel pick one. Ports outside 0..65535 give -1. net.dial(addr, port, non_blocking, timeout_ms) gives up after timeout_ms milliseconds (shared by all the addresses the name resolves to; the name lookup itself isn't timed) with -1 and os.errno() ETIMEDOUT; 0, the default, waits as long as the system does. net.setRecvTimeout(sock, ms) and net.setSendTimeout(sock, ms) make a read or a write on a connected socket give up after ms milliseconds with -1 and os.errno() EAGAIN (a write returns the bytes it got out first, if any). Writing to a socket whose peer has closed raises SIGPIPE, which ends the program, as in C. net.send(sock, data), with data a u8[] (a literal, a String, buf[0:n]), is a send that adds MSG_NOSIGNAL to its optional flags: it returns -1 with os.errno() EPIPE (or ECONNRESET) instead; signal(SIGPIPE, SIG_IGN) does the same for every write and send in the program. signal takes SIG_DFL, SIG_IGN or a handler void F(i32 sig) passed as (&F)(i64), and returns the previous one or SIG_ERR. SIGHUP, SIGINT, SIGQUIT, SIGKILL, SIGUSR1, SIGUSR2, SIGPIPE, SIGALRM, SIGTERM, SIGCHLD and the job-control signals SIGCONT, SIGSTOP, SIGTSTP, SIGTTIN and SIGTTOU are defined, with each platform's numbers.

    Coroutines#

    A coroutine runs a function on its own stack and can pause in the middle. coro.spawn(&Fn, arg) makes one (nothing runs yet; NULL if its stack can't be mapped), coro.next(c) runs it until it calls coro.yield(value) and returns that value, and the next coro.next carries on after the yield. When the function returns, coro.done(c) becomes TRUE and that last coro.next returns the function's return value; after that it returns NULL. A yielded NULL is a value like any other, so loops test coro.done. Values also go the other way: coro.next(c, send) makes the paused coro.yield return send (the first coro.next just starts the function with its arg). coro.release(c) frees it, also while it is paused.

    The function is void *Fn(void *arg). Coroutines can resume other coroutines (coro.current() is the running one, NULL outside), every thread can have its own, and a try may span a yield. A throw that leaves the coroutine's function goes on from the coro.next that resumed it. Each stack is 256 KiB unless coro.spawn's third argument says otherwise, with a guard page below it: running past it crashes the program instead of overwriting memory. coro.release keeps up to 16 stacks per thread for the next coro.spawn of the same size, so short-lived coroutines (one per request) don't map and unmap a stack each time; they are unmapped when the thread ends. coro.yield outside a coroutine, or resuming one that is running, prints a message and exits with 1.

    import coro, cstr;

void *fib(void *max)
{
  i64 a = 0, b = 1, t;
  while (a < (i64)max) {
    coro.yield((void *)a);
    t = a + b;
    a = b;
    b = t;
  }
  return null;
}

void *sum(void *unused)
{// a running total of whatever CoroutineNext sends
  i64 total = 0;
  while (true) { total += (i64)coro.yield((void *)total); }
  return null;
}

void main()
{
  coro.Coroutine *f = coro.spawn(&fib, (void *)50);
  for (void *v = coro.next(f); !coro.done(f); v = coro.next(f)) {
    printf("%d ", v);
  }
  printf("\n");
  coro.release(f);

  coro.Coroutine *s = coro.spawn(&sum);
  coro.next(s);                 // runs to the first yield
  printf("%d\n", coro.next(s, (void *)5));
  printf("%d\n", coro.next(s, (void *)7));
  coro.release(s);
}

    Fuzzy matching#

    fzf.match(text, pattern) matches text the way the fzf tool does and returns the score and the matched byte offsets, or NULL when it doesn't match. Terms separated by spaces must all match, a | b takes either. A plain term is fuzzy: its characters in order, with gaps. 'term is an exact substring, ^term a prefix, term$ a suffix, ^term$ the whole text and !term must not occur; \ is a space inside a term. With the default fzf.CASE_SMART a term is case-sensitive only when it has an upper-case letter; fzf.CASE_IGNORE and fzf.CASE_RESPECT force it. Passing false as the last argument makes plain terms exact (and 'term fuzzy). The offsets come term after term, so they are only sorted for a single term, and the matcher is fzf's greedy one: it finds a match, not always the best-scoring placement. The pattern is not modified, so a string literal is fine. fzf.match keeps no shared state, so threads can call it at the same time.

    import cstr, fzf;

void show(u8 *text, u8 *pattern)
{
  fzf.Position *m = fzf.match(text, pattern);
  printf("%-12s %-11s ", text, pattern);
  if (!m) {
    printf("no match\n");
    return;
  }
  printf("score %d at", m.score);
  for (i64 i = 0; i < m.size; i++) { printf(" %d", m.data[i]); }
  printf("\n");
  fzf.release(m);
}

void main()
{
  show("src/main.ktm", "smkm");
  show("src/main.ktm", "smKM");
  show("src/main.ktm", "ktm$ main");
  show("src/main.ktm", "^src 'main");
  show("src/main.ktm", "!test main");
  show("my file.txt", "my\\ file");
}

    SQLite#

    The SQLite functions exist when ktm and the library are built with ./build.sh --sqlite (they are under #ifdef __KTM_LINK_SQLITE3__). sql.open(path) opens a database (":memory:" for a private one; the sql.Db keeps its own copy of the name) and sql.close closes it. sql.execRaw runs a script of statements and returns its error as a new String, empty when it ran. sql.exec and sql.select run one statement with ? parameters from an array of sql.Param (sql.INT, sql.FLOAT, sql.TEXT with str a u8[], sql.BLOB, sql.NULL_TYPE); text and blobs are copied, so they can be freed right away, and an empty text binds ''. The SQL is a u8[] too, so script[0:n] runs part of a buffer. A text with a second statement is an error rather than half-run. sql.next steps through the rows of sql.select and frees the row after the last one; call sql.rowRelease if you stop early. A column's str (a u8[] view) and blob are only valid until the next row.

    import sql;

void main()
{
  sql.Db *db = sql.open(":memory:");
  String err = sql.execRaw(db, "CREATE TABLE users(id INTEGER, name TEXT);");
  if (err.len) {
    printf("%s\n", err);
  }
  err.free();

  sql.Param p[2];
  p[0].type = sql.INT;
  p[0].intVal = 1;
  p[1].type = sql.TEXT;
  p[1].str = "ann";
  sql.exec(db, "INSERT INTO users VALUES(?, ?);", p, 2);

  sql.Row row;
  if (sql.select(db, &row, "SELECT id, name FROM users;")) {
    while (sql.next(&row)) { printf("%d %s\n", row.col[0].intVal, row.col[1].str); }
  }
  sql.close(db);
}

    sql.prepare compiles a statement once (null on an error) and sql.execPrepared(stmt, &row, params) runs it with new parameters, returning SQLITE_ROW, SQLITE_DONE or an error code; read its rows with sql.nextPrepared. A parameter it can't bind (an unknown type gives SQLITE_MISMATCH, a string over sqlite's length limit SQLITE_TOOBIG) returns that error without running the statement. Such a row belongs to the statement, which sql.finalize frees.
