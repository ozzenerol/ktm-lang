    Library

    The standard library

    The library is a set of modules. Import the ones a file uses and call their names with the module in front: import fs, str; then fs.readAll(path). Each topic below has its own page with examples; every declaration is in the library reference.

    import fs, str;

void main()
{
  fs.writeAll("/tmp/ktm_docs_hub.txt", "modules are imported by name\n");
  ad String text = fs.readAll("/tmp/ktm_docs_hub.txt");
  ad u8[][] words = str.split(text.trim(), " ");
  printf("%d words, the last is %s\n", words.len, words[words.len - 1]);
  fs.remove("/tmp/ktm_docs_hub.txt");
}

    5 words, the last is name

Serving on every corecoro.serve. HTTP serversnet.http: a mux, JSON handlers. TLSnet.tls: encrypted connections, client and server. Threads and atomicspthreads, a pool, atomic.

    Always there#

    • The prelude needs no import: Error, EXIT_OK, EXIT_FAIL, the integer limits, ERR_BOUNDS.
    • printf needs no import either.
    • libc has the C library by its C names: import libc; then libc.open(...).
    • libktm is linked automatically.
