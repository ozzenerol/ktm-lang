    LibraryReference: date

    Dates

    Calendar dates and times of day: date.Date, its parts, formatting and parsing. For clocks, timeouts and Unix time see Clocks and sleeping.

    At a glance

    date.Date d = date.now();                       // local time
date.Parts p;  date.toParts(&p, d);              // year, mon, dayOfMon, hour, ...
date.Date d2 = date.fromParts(&p);
String s = date.format(d, "%Y-%m-%d %H:%M");
date.Date d3 = date.parse("2024-03-05", "%Y-%m-%d");

    Building a date from parts#

    A date.Parts has year, mon (1-12), dayOfMon, hour, min, sec, dayOfWeek (0 is Sunday), sec100, sec10000 and zoneDiff. Zero it first: fromParts reads every field.

    import date, mem;

void main()
{
  date.Parts p;
  mem.set(&p, 0, sizeof(date.Parts));
  p.year = 2024;
  p.mon = 2;
  p.dayOfMon = 29;
  p.hour = 12;
  p.min = 34;
  date.Date leap = date.fromParts(&p);

  ad String s = date.format(leap, "%a %d %b %Y, %H:%M");
  printf("%s\n", s);

  date.Parts back;
  date.toParts(&back, leap);
  printf("%d-%02d-%02d, day of week %d\n", back.year, back.mon, back.dayOfMon, back.dayOfWeek);
}

    Thu 29 Feb 2024, 12:34
2024-02-29, day of week 4

    Out-of-range parts carry over#

    Day 32 of January is February 1; month 13 is January of the next year; hour 24 is midnight the next day. That makes date arithmetic easy:

    import date, mem;

date.Date addDays(date.Date d, i64 n)
{
  date.Parts p;
  date.toParts(&p, d);
  p.dayOfMon += n;
  return date.fromParts(&p);
}

void main()
{
  date.Parts p;
  mem.set(&p, 0, sizeof(date.Parts));
  p.year = 2024;
  p.mon = 13;
  p.dayOfMon = 32;
  ad String a = date.format(date.fromParts(&p), "%Y-%m-%d");
  printf("month 13, day 32 of 2024: %s\n", a);

  date.Date d = date.parse("2024-12-30", "%Y-%m-%d");
  ad String b = date.format(addDays(d, 5), "%Y-%m-%d");
  printf("5 days after 2024-12-30: %s\n", b);
}

    month 13, day 32 of 2024: 2025-02-01
5 days after 2024-12-30: 2025-01-04

    Formatting#

    CallGives
    date.format(d, fmt)With %Y %m %d %H %M %S %a %b %p %%
    date.formatDate(d)MM/DD/YYYY
    date.formatTime(d)HH:MM:SS
    date.timestampNow()Now as YYYY-MM-DD HH:MM:SS
     
    import date;

void main()
{
  date.Date d = date.parse("2024-03-05 13:30", "%Y-%m-%d %H:%M");
  ad String a = date.format(d, "%Y-%m-%d %H:%M:%S");
  ad String b = date.format(d, "%a, %b %d at %H:%M %p");
  ad String c = date.formatDate(d);
  ad String t = date.formatTime(d);
  printf("%s\n%s\n%s %s\n", a, b, c, t);

  ad String now = date.timestampNow();
  printf("timestamp is %d characters\n", now.len);
}

    2024-03-05 13:30:00
Tue, Mar 05 at 13:30 PM
03/05/2024 13:30:00
timestamp is 19 characters

    All return a String that is yours. In a printf format, %D and %T are errors that point here.

    Parsing#

    date.parse(text, fmt) returns a Date, or 0 when the text doesn't match. date.parseParts(text, fmt, &p) fills Parts and returns whether it worked.

    import date;

void main()
{
  date.Date d = date.parse("Mar 5 2024 1:30 PM", "%b %d %Y %H:%M %p");
  ad String s = date.format(d, "%Y-%m-%d %H:%M");
  printf("%s\n", s);

  date.Parts p;
  printf("%d %d %d\n", date.parseParts("2023-02-29", "%Y-%m-%d", &p),
         date.parse("2024-03", "%Y-%m-%d") == 0,
         date.parseParts("2024-02-29T10:00+0200", "%Y-%m-%dT%H:%M%z", &p));
  printf("zone %d, hour %d\n", p.zoneDiff, p.hour);
}

    2024-03-05 13:30
0 1 1
zone 200, hour 10
    • Conversions: %Y %m %d %H %M, %S or %s, %a and %b (full or three letters, any case), %p, %z (a zone offset) and %%.
    • A space in the format matches any run of spaces; other characters must match exactly.
    • Impossible values fail: month 13, February 30, hour 24.
    • Without %z, zoneDiff is date.NO_ZONE; with it, it is the offset as ±hhmm (200 for +02:00).

    Now#

    import date;

void main()
{
  date.Date today = date.now();
  date.Parts p;
  date.toParts(&p, today);
  date.Parts q;
  date.nowParts(&q);
  printf("year looks right: %d, same year: %d\n", p.year >= 2024, p.year == q.year);
}

    year looks right: 1, same year: 1

    date.now() and date.nowParts are local time (the TZ zone); nowParts also sets zoneDiff.

    What a Date is#

    • A date.Date is an integer underneath: date.Date d = 5; and i64 x = d; need no cast.
    • The calendar is the proleptic Gregorian one, with year 0 a leap year as in ISO 8601.
    • date.isoFromTimespec(&ts) formats a file time as UTC ISO 8601: 2026-07-05T14:30:00.123456789Z.
