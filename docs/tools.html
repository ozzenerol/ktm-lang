    The compiler

    One binary, ktm, compiles, runs, serves your editor and shows you what it generated.

    Everyday commands#

    ktm main.ktm -o app          # build ./app
ktm main.ktm                 # build ./a.out
ktm -run main.ktm a b        # build to a temporary binary, run it with args a b, delete it
ktm -jit main.ktm a b        # compile in memory and run, no files written
ktm -repl                    # an interactive session
ktm -DDEBUG main.ktm         # define a macro
ktm -Werror main.ktm         # warnings are errors

    Only the main file is named: the modules it imports are found and compiled with it.

    -run and -jit#

    -run-jit
    CodeCompiled to a binary, like a normal buildAssembled into memory by ktm itself
    Needs a C compilerYes (to assemble and link)No
    Exit codeThe program'sThe program's
    Extra-Memsafe leak and double-free reports

    Use #ifjit / #ifaot for code that should differ between them. See JIT and REPL.

    Object files and C#

    ktm -c util.ktm -o util.o            # an object file
ktm main.ktm util.o -o app           # link object files in
ktm -c -fPIC util.ktm -o util.o      # for a shared library
ktm game.ktm -clibs="-lSDL2 -lm"     # link C libraries

    In the source, #link <sqlite3> does what -clibs="-lsqlite3" does: see Calling C.

    Without installing#

    A program needs the standard library to compile. If ktm isn't installed, point it at a local build:

    ./ktm --install-dir=build/prefix hello.ktm -o hello

    Cross-compiling#

    ktm --target=aarch64-apple-darwin -S main.ktm -o main.s
ktm --target=x86_64-unknown-linux-gnu -S main.ktm -o main.s

    With -S this checks the other platform's #if branches without its machine.

    All flags#

    FlagWhat it does
    -o <file>Output file name
    -runCompile to a temporary binary, run it and delete it; arguments after the file go to the program
    -jitCompile in memory and run (x86_64 and arm64)
    -MemsafeWith -jit: report double frees, wild frees and leaks
    -replInteractive session
    -lspLanguage server over stdio
    -S, -o-Emit assembly only; to stdout
    -cEmit an object file
    -fPICPosition-independent code
    -lib <name>Build a static and a shared library (Building libraries)
    -clibs="..."Extra linker flags
    -D<NAME>Define a macro (no value)
    -WerrorWarnings are errors
    --install-dir <dir>Use <dir> instead of the install prefix
    --target <triple>x86_64-unknown-linux-gnu, x86_64-apple-darwin, aarch64-apple-darwin, ...
    --expandPrint the code @json/@yaml made, on stderr
    -tokens, -ast, --dump-irPrint the tokens, the syntax tree, the IR
    -cfg, -cfg-png, -cfg-svgA Graphviz control flow graph
    --mem-statsThe compiler's own memory use
    -vPrint the commands that build a library
    --version, --helpVersion and build details; all flags

    How it builds#

    ktm parses to a syntax tree, lowers it to an SSA IR and emits x86_64 or AArch64 assembly. The system C compiler assembles and links that, through a temporary file in $TMPDIR (one per compile, so several can run at once). The JIT skips that step with its own assembler.
