    LibraryReference: net

    UDP sockets

    Datagrams: net.udpSocket to bind, net.sendTo and net.recvFrom to talk. net.Addr keeps a sender's address without text in between.

    Send and answer#

    import libc, net;

void main()
{
  i32 srv = net.udpSocket(0, "127.0.0.1");
  i32 cli = net.udpSocket(0, "127.0.0.1");
  u8 buf[64];
  ad String from;
  i32 port;

  net.sendTo(cli, "ping", "127.0.0.1", net.localPort(srv));
  i64 n = net.recvFrom(srv, buf, &from, &port);
  printf("server got %s from %s\n", buf[0:n], from);
  net.sendTo(srv, "pong", from, port);       // answer the sender

  net.setRecvTimeout(cli, 1000);
  n = net.recvFrom(cli, buf);
  printf("client got %s\n", buf[0:n]);
  libc.close(srv);
  libc.close(cli);
}

    server got ping from 127.0.0.1
client got pong
    • net.udpSocket(port, bindaddr) takes the same bind addresses as net.listen; port 0 picks one.
    • recvFrom receives one datagram into a u8[]; one longer than the buffer is cut.
    • Both work with IPv4 and IPv6 and return -1 on failure.
    • net.setRecvTimeout(sock, ms) makes reads give up with -1 after ms.

    net.Addr: answering many clients#

    A server that answers many senders keeps each address as the kernel gives it: no text, no name lookup.

    import libc, net;

void main()
{
  i32 srv = net.udpSocket(0, "127.0.0.1");
  i32 cli = net.udpSocket(0, "127.0.0.1");
  net.setRecvTimeout(srv, 1000);
  net.setRecvTimeout(cli, 1000);

  net.Addr server;
  net.makeAddr("127.0.0.1", net.localPort(srv), &server);
  net.sendToAddr(cli, "\x00\x2Aquery", &server);     // a 2-byte id, then the question

  u8 buf[512];
  net.Addr from;
  i64 n = net.recvFromAddr(srv, buf, &from);
  ad String ip = from.ip();
  printf("%d bytes from %s, the client's port: %d\n", n, ip, from.port() == net.localPort(cli));
  buf[2] = '!';
  net.sendToAddr(srv, buf[0:3], &from);              // the id and the answer, straight back

  net.Addr back;
  n = net.recvFromAddr(cli, buf, &back);
  printf("answer to id %d: %c, from the server: %d\n", buf[1], buf[2], back.equals(&server));
  libc.close(srv);
  libc.close(cli);
}

    7 bytes from 127.0.0.1, the client's port: 1
answer to id 42: !, from the server: 1
    CallDoes
    net.makeAddr(ip, port, &a)Makes one from a numeric address (false for anything else)
    a.ip(), a.port(), a.family()Its parts (libc.AF_INET, AF_INET6, or 0 when empty)
    a.equals(&b), a.sameIp(&b)Compare address and port, or just the address
    net.localAddr(sock, &a), net.remoteAddr(sock, &a)A socket's own end and its peer's

    IPv6#

    import libc, net;

void main()
{
  net.Addr a;
  printf("%d %d\n", net.makeAddr("::1", 53, &a), a.family() == libc.AF_INET6);
  ad String ip = a.ip();
  printf("%s port %d\n", ip, a.port());
  printf("host names aren't addresses: %d\n", net.makeAddr("localhost", 53, &a));
}

::1 port 53
host names aren't addresses: 0
