    The ktm language

    One page per topic, each with examples you can run. If you know C, start with Coming from C, then read the topics that are new to you.

    Basics#

    Program basicsmain, comments, printf, exit codes. Types and literalsi64, u8, f64, bool; numbers, characters, strings. Variables and constantsauto, static, const, globals. Operators and castsChained comparisons, typeof, precedence. Control flowif, loops, range-based for, goto. switchNo fall-through, ranges, fallthrough.

    Functions#

    FunctionsPrototypes, default arguments, inlining. Variable argumentsi64 ...nums as a slice. OverloadingOne name, several parameter lists. Function pointersfn(i64) i64, tables, callbacks.

    Data#

    Pointers and arraysInitialiser lists, heap memory. SlicesT[]: a pointer and a length, bounds-checked. StringsString, u8[] and C strings. Structs and unionsValues, layout, initialisers. Methods and inheritancevoid User.greet(), struct Admin : User. EnumsScoped constants, flags, names at run time. Type aliasestype Text = u8[]; GenericsStack<T>, max<T>.

    Structure and safety#

    Modulesimport, pub, private fields. Exceptionsthrow, try, catch. defer and adClean-up that always runs.

    Advanced#

    ReflectionTypes and fields at run time. Attributes@json, @key, @skip. The preprocessor#define, #if, platform macros. Calling C and assemblyextern "c", #link, asm.

    Keywords#

    These can't name a variable, a parameter or a declaration:

    if else for while do switch case default break continue return goto fallthrough
try catch throw defer struct union enum fn module import pub private static const
extern inline asm sizeof alignof typeof self true false null

    type and ad are keywords only where they start a declaration, so a variable can still be called type or ad.
