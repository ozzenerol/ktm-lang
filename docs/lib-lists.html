    LibraryReference: list

    Lists

    list.List<T> is a doubly linked list. Keep the node an insert gives you, and remove it later in O(1).

    At a glance

    ad list.List<i64> l = list.new<i64>();
list.Node<i64> *n = l.append(5);      // or prepend, insertBefore, insertAfter
l.remove(n);                          // O(1), returns the value
l.shift();  l.pop();                  // from the front / the back
for (auto n = l.head; n; n = n.next) { n.value; }

    Adding and walking#

    import list;

void main()
{
  ad list.List<u8 *> todo = list.new<u8 *>();
  todo.append("write");
  todo.append("ship");
  todo.prepend("plan");
  list.Node<u8 *> *w = todo.head.next;
  todo.insertAfter(w, "test");

  for (auto n = todo.head; n; n = n.next) { printf("%s,", n.value); }
  printf(" %d items\n", todo.len);
  for (auto n = todo.tail; n; n = n.prev) { printf("%s,", n.value); }
  printf("\n");
}

    plan,write,test,ship, 4 items
ship,test,write,plan,

    head and tail are null when the list is empty. A node has value, next and prev.

    Removing a node you kept#

    Keep the node append returned (a timer, a client) and remove it later without searching.

    import list;

void main()
{
  ad list.List<i64> clients = list.new<i64>();
  clients.append(10);
  list.Node<i64> *mine = clients.append(20);
  clients.append(30);

  i64 v = clients.remove(mine);
  printf("removed %d, %d left: %d %d\n", v, clients.len, clients.first(), clients.last());
}

    removed 20, 2 left: 10 30

    While walking, read n.next before removing n:

    import list;

void main()
{
  ad list.List<i64> l = list.new<i64>();
  for (i64 i = 1; i <= 6; i++) { l.append(i); }
  auto n = l.head;
  while (n) {
    auto next = n.next;
    if (n.value % 2 == 0) { l.remove(n); }
    n = next;
  }
  for (auto m = l.head; m; m = m.next) { printf("%d,", m.value); }
  printf("\n");
}

    1,3,5,

    Queues and stacks#

    append with shift is a first-in first-out queue; append with pop is a stack.

    import list;

void main()
{
  ad list.List<i64> q = list.new<i64>();
  q.append(1);
  q.append(2);
  q.append(3);
  printf("queue: %d %d\n", q.shift(), q.shift());
  printf("stack: %d\n", q.pop());

  bool ok;
  i64 v = q.shift(&ok);
  printf("empty: %d, ok %d\n", v, ok);
}

    queue: 1 2
stack: 3
empty: 0, ok 0

    On an empty list, shift, pop, first and last return a zeroed value and set the optional ok to false.

    Joining and emptying#

    import list;

void main()
{
  ad list.List<i64> a = list.new<i64>();
  ad list.List<i64> b = list.new<i64>();
  a.append(1);
  b.append(2);
  b.append(3);
  a.mergeAppend(&b);          // b's nodes move to the end of a
  printf("%d %d\n", a.len, b.len);
  a.clear();
  printf("%d %d\n", a.len, a.head == null);
}

    3 0
0 1
    • mergeAppend(&other) and mergePrepend(&other) move every node and leave other empty.
    • clear() frees every node and leaves the list usable. free() does the same, for ad.
    • Both free String values; remove, shift and pop hand a value back to you. Other values are yours: neither frees what they point to.
