    JIT and REPL

    Run code without a build step: ktm -jit for files and scripts, ktm -repl to type it in.

    The JIT#

    ktm -jit file.ktm assembles machine code into memory with ktm's own assembler and runs it. No C compiler, linker or files are involved, so it starts fast. Arguments after the file go to the program.

    $ cat args.ktm
i32 main(i32 argc, u8 **argv)
{
  printf("%d %s\n", argc, argv[argc - 1]);
  return 3;
}
$ ktm -jit args.ktm x y; echo "exit $?"
3 y
exit 3
    • Programs behave the same compiled and in the JIT: every example in these docs is checked both ways.
    • A file with no main has nothing to run: -jit says so and exits with 1.
    • #link libraries are loaded as shared objects.

    Telling them apart#

    Compiled, this prints the lines below; in the JIT, JIT instead of compiled.

    void main()
{
#ifjit
  printf("JIT\n");
#endif
#ifaot
  printf("compiled\n");
#endif
  printf("either way\n");
}

    compiled
either way

    Scripts#

    ktm skips a first line that starts with #!:

    #!/usr/bin/env -S ktm -jit
import proc;

void main()
{
  ad String user = proc.getenv("USER");
  printf("hello, %s\n", user);
}
    chmod +x hello.ktm
./hello.ktm

    The REPL#

    $ ktm -repl
&gt; i64 sq(i64 x) { return x * x; }
&gt; sq(7);
49
&gt; printf("hello %d\n", sq(3));
hello 9
    • Functions, structs, globals and #defines accumulate across the session.
    • The value of a trailing expression is printed.
    • Line editing, history (~/.ktm_repl_history) and tab completion are built in.
    • Allocations are tracked, so leaks and bad frees are reported.
    • ~/.ktm_rc.ktm is included at start-up; #define KTM_NO_REPL_HELLO there hides the welcome message.

    REPL commands#

    CommandDoes
    replDisasm("name");Disassembles a function
    replDel("name");Forgets a definition so you can redefine it
    replListFn();, replFindFn("part");Lists functions, all or by name
    replListGVars();Lists the globals
    replClassRep("name");Prints a struct or union
    replHeap();The live allocations, biggest first
    replEval("code");Runs a string as REPL input
    replReloadRc();Reads ~/.ktm_rc.ktm again
    @ ls -laRuns a shell command (through system(): @ cd doesn't move the REPL)
