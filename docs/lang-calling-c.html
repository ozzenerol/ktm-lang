    LanguageReference: libc

    Calling C and assembly

    Declare a C function with extern "c" and call it. Most of the C library is already declared in the libc module.

    The libc module#

    libc is always linked, and import libc; gives its functions, structs and constants by their C names.

    import libc;

void main()
{
  printf("%.4f %.0f\n", libc.sqrt(2.0), libc.pow(2.0, 10.0));
  printf("%d\n", libc.getenv("PATH") != null);
  printf("%d\n", libc.getpid() > 0);
}

    1.4142 1024
1
1

    Streams and exit codes#

    libc.stdin, libc.stdout and libc.stderr are C's streams, for libc.fprintf and libc.fflush. printf writes to libc.stdout, so the two stay in order. libc.EXIT_SUCCESS and libc.EXIT_FAILURE are exit's statuses, as in C.

    import libc;

i32 main(i32 argc, u8 **argv)
{
  printf("checking %d files\n", 2);
  libc.fprintf(libc.stdout, "%s: ok\n", "a.txt");
  if (argc > 5) {
    libc.fprintf(libc.stderr, "usage: %s [file]\n", argv[0]);
    libc.exit(libc.EXIT_FAILURE);
  }
  libc.exit(libc.EXIT_SUCCESS);
  return 0;
}

    checking 2 files
a.txt: ok
    • libc.fprintf's format is checked against its arguments as printf's is.
    • os.eprintf and os.exit do the same in ktm's own style; see Environment.

    Declaring a C function#

    For anything libc doesn't declare, write the prototype yourself with extern "c".

    extern "c" i32 abs(i32 x);
extern "c" i64 strtol(u8 *s, u8 **end, i32 base);

void main()
{
  u8 *end;
  printf("%d %d\n", abs(-5), strtol("ff zz", &end, 16));
  printf("[%s]\n", end);
}

    5 255
[ zz]

    C data#

    A C global is declared the same way, by its C name:

    extern "c" u8 **environ;

void main()
{
  i64 n = 0;
  while (environ[n]) { n++; }
  printf("%d\n", n > 0);
}

    1

    When the symbol isn't the name you want, or differs between systems, _extern gives the symbol as the assembly spells it, then the declaration. libc declares stderr this way, because macOS calls it __stderrp (with Mach-O's leading _):

    #ifdef IS_MACOS
pub _extern ___stderrp FILE *stderr;
#else
pub _extern stderr FILE *stderr;
#endif

    In a module, the name is the module's like any other: libc.stderr.

    C structs#

    Declare the struct with the same fields in the same order: the layout is C's.

    struct tm
{
  i32 tm_sec, tm_min, tm_hour, tm_mday, tm_mon, tm_year, tm_wday, tm_yday, tm_isdst;
  i64 tm_gmtoff;
  u8 *tm_zone;
};

extern "c" tm *gmtime_r(i64 *t, tm *out);

void main()
{
  i64 t = 0;
  tm out;
  gmtime_r(&t, &out);
  printf("%d-%02d-%02d\n", out.tm_year + 1900, out.tm_mon + 1, out.tm_mday);
}

    1970-01-01

    Callbacks into ktm#

    A ktm function can be passed where C wants a function pointer: the calling convention is C's.

    extern "c" void qsort(void *base, u64 n, u64 size, fn(void *, void *) i32 cmp);

i32 byValue(i64 *a, i64 *b) { return (i32)(*a - *b); }

void main()
{
  i64 nums[] = {42, 7, 19, 3};
  qsort(nums, 4, sizeof(i64), &byValue);
  for (auto n : nums) { printf("%d,", n); }
  printf("\n");
}

    3,7,19,42,

    To sort in ktm, sort.slice and vec.Vec.sort are simpler.

    Other C libraries#

    Name the library in the source with #link, or on the command line with -clibs:

    #link <sqlite3>          // like -lsqlite3
#link "./libmine.so"     // a path, relative to the working directory

extern "c" i32 sqlite3_libversion_number();

void main()
{
  printf("%d\n", sqlite3_libversion_number());
}
    ktm app.ktm -clibs="-lcurl -lm" -o app

    #link works for compiled programs, the JIT and the REPL alike.

    Names stay apart#

    • Your functions and globals have symbols of their own: your read() or free() doesn't replace C's.
    • A prototype without extern "c" is a ktm function, which must be defined in the program or a ktm library.
    • In a module, an extern "c" declaration is the module's name (private unless pub) but keeps its C symbol.
    • An extern "c" function can't be overloaded.

    Inline assembly#

    An asm block defines labelled routines; _extern binds one to a ktm prototype. Arguments arrive in the platform's C calling convention.

    #ifdef IS_X86_64
asm {
_ADD_ONE::
  MOV RAX, RDI
  INC RAX
  RET
}
#endif

#ifdef IS_ARM_64
asm {
_ADD_ONE::
  ADD X0, X0, 1
  RET
}
#endif

_extern _ADD_ONE i64 addOne(i64 x);

void main()
{
  printf("%d\n", addOne(41));
}

    42
