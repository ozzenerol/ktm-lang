    LibraryReference: proc

    Shell commands

    Run a command line through sh -c: for pipelines, globs and redirections. To run a program with arguments that come from users or files, use proc.run instead.

    CallReturns
    proc.shell(cmd)The exit code, 0 to 255 (-1 if killed or the shell couldn't run)
    proc.shellf(fmt, ...)The same, with a format
    proc.shellOutput(fmt, ...)What it printed to stdout, minus one trailing newline, as a String
    proc.shellQuote(s)s as one safe shell word, a String

    Running and capturing#

    import os, proc;

void main()
{
  i64 status = proc.shell("echo from the shell");
  proc.shellf("echo %s has %d files", "/tmp", 3);
  ad String out = proc.shellOutput("echo %s | tr a-z A-Z", "captured");
  os.flush();
  printf("exit code %d, output [%s]\n", status, out);
  printf("%d %d\n", proc.shell("exit 3"), proc.shell("no-such-command 2>/dev/null"));
}

    from the shell
/tmp has 3 files
exit code 0, output [CAPTURED]
3 127

    Output order. printf is buffered; commands write straight to the terminal. Call os.flush() before a command so your earlier output comes first.

    shellOutput#

    • The command is a format: write %% for a % the shell should see. Arguments are optional, and %s takes a String or a slice too.
    • stderr isn't captured and the exit status isn't returned: a failing command gives whatever it printed, often "".
    • A shell that couldn't start gives a String with a null ptr.
    • It returns when the shell exits, without waiting for a background job (cmd &).
    import proc, str;

void main()
{
  ad String n = proc.shellOutput("printf 'a\\nb\\nc\\n' | wc -l");
  ad String files = proc.shellOutput("printf '%%s\\n' one two three");   // %% : the command is a format
  ad u8[][] names = str.split(files, "\n");
  printf("[%s] %d names, the last is %s\n", n.trim(), names.len, names[2]);
}

    [3] 3 names, the last is three

    Quoting what you paste in#

    A command is shell text: a file name or user input must never go in as it is. A space splits it, and $, `, ; or * run or expand things. proc.shellQuote makes it one word, unchanged.

    import proc;

void main()
{
  u8[] name = "it's $HOME; rm *";
  ad String q = proc.shellQuote(name);
  ad String out = proc.shellOutput("printf '%%s' %s", q);
  printf("%s\n[%s]\n", q, out);
}

    'it'\''s $HOME; rm *'
[it's $HOME; rm *]

    What the command inherits#

    • It gets the program's stdin, stdout and stderr.
    • It gets none of the files and sockets the library opened: those are close-on-exec.
    • An fd you open yourself is inherited unless you pass O_CLOEXEC (or set FD_CLOEXEC).
