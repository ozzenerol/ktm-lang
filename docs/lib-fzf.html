    LibraryReference: fzf

    Fuzzy matching

    fzf.match(text, pattern) matches the way the fzf tool does: it returns a score and the matched offsets, or null.

    Matching#

    import fzf;

void show(u8 *text, u8 *pattern)
{
  fzf.Position *m = fzf.match(text, pattern);
  printf("%-12s %-11s ", text, pattern);
  if (!m) {
    printf("no match\n");
    return;
  }
  printf("score %d at", m.score);
  for (i64 i = 0; i < m.size; i++) { printf(" %d", m.data[i]); }
  printf("\n");
  fzf.release(m);
}

void main()
{
  show("src/main.ktm", "smkm");
  show("src/main.ktm", "smKM");
  show("src/main.ktm", "ktm$ main");
  show("src/main.ktm", "^src 'main");
  show("src/main.ktm", "!test main");
  show("my file.txt", "my\\ file");
}

    src/main.ktm smkm        score 82 at 0 4 9 11
src/main.ktm smKM        no match
src/main.ktm ktm$ main   score 184 at 9 10 11 4 5 6 7
src/main.ktm ^src 'main  score 184 at 0 1 2 4 5 6 7
src/main.ktm !test main  score 104 at 4 5 6 7
my file.txt  my\ file    score 176 at 0 1 2 3 4 5 6

    Pattern syntax#

    Terms separated by spaces must all match; a | b takes either.

    TermMatches
    termFuzzy: its characters in order, with gaps
    'termAn exact substring
    ^termA prefix
    term$A suffix
    ^term$The whole text
    !termMust not occur
    \ A space inside a term

    Ranking a list#

    import fzf, sort;

struct Hit { u8 *text; i64 score; };

i64 byScore(Hit *a, Hit *b) { return b.score - a.score; }

void main()
{
  u8 *files[] = {"docs/index.html", "src/main.ktm", "src/std/str/string.ktm", "README.md"};
  Hit hits[4];
  i64 n = 0;
  for (auto f : files) {
    fzf.Position *m = fzf.match(f, "sm");
    if (m) {
      Hit h = {f, m.score};
      hits[n++] = h;
      fzf.release(m);
    }
  }
  sort.slice(hits[0:n], &byScore);
  for (i64 i = 0; i < n; i++) { printf("%d %s\n", hits[i].score, hits[i].text); }
}

    51 src/main.ktm
38 src/std/str/string.ktm
21 docs/index.html

    Options#

    • Case: with the default fzf.CASE_SMART a term is case-sensitive only when it has an upper-case letter. fzf.CASE_IGNORE and fzf.CASE_RESPECT force it.
    • Passing false as the last argument makes plain terms exact (and 'term fuzzy).
    • The offsets come term after term, so they are sorted only for a single term.
    • The matcher is fzf's greedy one: it finds a match, not always the best-scoring one.
    • The pattern isn't modified (a literal is fine), and there is no shared state: threads can match at the same time.
