    LibraryReference: bytes

    Byte buffers

    The bytes module is for binary data that comes and goes in pieces: what a socket delivers, or a message being put together.

    At a glance

    bytes.Buffer b = bytes.bufferNew();  defer b.free();
b.append(data)  b.appendByte(x)  b.appendBe32(n)  b.appendLe16(n)
b.data()      // a view of the unread bytes
b.consume(n)  // drop the first n
b.readFrom(fd)  b.writeTo(fd)       // one read / one write
bytes.be32(s, at)  bytes.putLe16(s, at, v)   // integers in a u8[]

    A queue of bytes#

    Add at the end, read from the front with data(), drop what you used with consume(n).

    import bytes;

void main()
{
  // a message: a 2-byte type and a 4-byte length (network order), then the body
  bytes.Buffer b = bytes.bufferNew();
  defer b.free();
  b.appendBe16(7);
  b.appendBe32(5);
  b.append("hello");
  b.append("\x00\x08\x00\x00\x00\x02hi");   // a second message, already here

  while (b.len >= 6) {
    u8[] d = b.data();
    i64 len = bytes.be32(d, 2);
    if (b.len < 6 + len) { break; }         // the rest hasn't arrived yet
    printf("type %d: %s\n", bytes.be16(d), d[6:6 + len]);
    b.consume(6 + len);
  }
  printf("%d bytes left\n", b.len);
}

    type 7: hello
type 8: hi
0 bytes left
    • Make one with bytes.bufferNew(): a declared Buffer isn't zeroed.
    • The space in front is reused, so a buffer filled and drained all the time doesn't keep growing.
    • b.take() gives the unread bytes as a String that is yours.

    Reading into it#

    room(n) gives at least n writable bytes after the data; commit(k) counts the k you wrote. readFrom(fd) does one read that way.

    import bytes, libc;

void main()
{
  i32 fds[2];
  libc.pipe(fds);
  libc.write(fds[1], "chunk one|chunk two", 19);
  libc.close(fds[1]);

  bytes.Buffer b = bytes.bufferNew();
  defer b.free();
  i64 n;
  while ((n = b.readFrom(fds[0])) > 0) { }
  libc.close(fds[0]);
  printf("%d bytes: %s\n", b.len, b.data());

  u8[] room = b.room(4);
  room[0] = '!';
  b.commit(1);
  ad String all = b.take();
  printf("%s\n", all);
}

    19 bytes: chunk one|chunk two
chunk one|chunk two!

    readFrom and writeTo return what the system call did: -1 with EAGAIN on a non-blocking fd that has to wait. writeTo consumes what went out.

    Integers in a slice#

    Read and write fixed-size integers at an offset, big-endian (network order) or little-endian.

    ReadWrite
    bytes.be16(s, at), be32, be64bytes.putBe16(s, at, v), putBe32, putBe64
    bytes.le16(s, at), le32, le64bytes.putLe16(s, at, v), putLe32, putLe64
     
    import bytes;

void main()
{
  u8 header[8];
  bytes.putBe16(header, 0, 0xCAFE);
  bytes.putLe32(header, 2, 1000);
  bytes.putBe16(header, 6, 2);
  printf("%x %x | %X %d %d\n", header[0], header[1], bytes.be16(header), bytes.le32(header, 2),
         bytes.be16(header, 6));
  try {
    bytes.be32(header, 6);         // 4 bytes from 6: past the end
  } catch (Error e) {
    printf("%s\n", e.message);
  }
}

    ca fe | CAFE 1000 2
bytes.be32: 4 bytes at 6 of a 8-byte slice

    Past the end throws ERR_BOUNDS, like consume or commit past the data.
