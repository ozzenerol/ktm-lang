    LibraryReference: map

    Hash maps

    map.Map<K, V> maps keys to values. Iteration goes in insertion order. For keys kept sorted, see Ordered maps.

    At a glance

    ad map.Map<u8[], i64> m = map.new<u8[], i64>();
m.set("a", 1);                 // add or replace
m.get("a", &v)                 // true and v filled, or false
m.getOr("a", 0)                // the value or a default
*m.ref("a") += 1;              // change in place
m.has("a")  m.delete("a")  m.len
i64 it = 0; while (m.next(&it, &k, &v)) { ... }

    The basics#

    import map;

void main()
{
  ad map.Map<u8[], i64> stock = map.new<u8[], i64>();
  stock.set("apples", 3);
  stock.set("pears", 5);
  stock.set("apples", 4);         // replaces
  stock.set("plums", 7);
  stock.delete("plums");
  *stock.ref("pears") += 1;

  printf("%d apples, has kiwis: %d, %d keys\n",
         stock.getOr("apples", 0), stock.has("kiwis"), stock.len);

  i64 n;
  if (stock.get("pears", &n)) { printf("pears: %d\n", n); }
  if (!stock.get("kiwis", &n)) { printf("no kiwis\n"); }
}

    4 apples, has kiwis: 0, 2 keys
pears: 6
no kiwis

    Iterating#

    next(&it, &k, &v) steps through keys and values in insertion order; start it at 0. Either pointer may be null.

    import map, vec;

void main()
{
  ad map.Map<u8[], i64> ages = map.new<u8[], i64>();
  ages.set("ann", 41);
  ages.set("bob", 29);
  ages.set("cy", 35);

  i64 it = 0;
  u8[] name;
  i64 age;
  while (ages.next(&it, &name, &age)) { printf("%s=%d,", name, age); }
  printf("\n");

  ad vec.Vec<u8[]> keys = ages.keys();
  ad vec.Vec<i64> values = ages.values();
  printf("%d keys, first %s, last value %d\n", keys.len, keys.get(0), values.last());
}

    ann=41,bob=29,cy=35,
3 keys, first ann, last value 35

    Counting#

    import map, str;

void main()
{
  ad map.Map<u8[], i64> counts = map.new<u8[], i64>();
  ad u8[][] words = str.split("the cat and the hat and the bat", " ");
  for (auto w : words) {
    i64 *c = counts.ref(w);
    if (c) { *c += 1; } else { counts.set(w, 1); }
  }
  printf("the=%d and=%d cat=%d, %d distinct\n",
         counts.getOr("the", 0), counts.getOr("and", 0), counts.getOr("cat", 0), counts.len);
}

    the=3 and=2 cat=1, 5 distinct

    Key types#

    • i64, u64, i32, u32, pointers, u8[] and String have their own hash and compare.
    • Any other type (a struct) is hashed and compared by its bytes: set every field of a struct key, padding included (start from {0}).
    • A u8[] or String key is copied: you can pass a reused buffer, and the map frees its copies.
    • A String value is the map's: freed with the map, by delete, and when set replaces it. Other values are stored as they are: free what they point to yourself before free().
    import map;

struct Point { i64 x, y; };

void main()
{
  ad map.Map<i64, u8 *> status = map.new<i64, u8 *>();
  status.set(404, "not found");
  status.set(200, "ok");
  printf("%s\n", status.getOr(404, "?"));

  ad map.Map<Point, u8 *> grid = map.new<Point, u8 *>();
  Point p = {2, 3};
  grid.set(p, "treasure");
  Point q = {2, 3};
  printf("%s\n", grid.getOr(q, "nothing"));
}

    not found
treasure

    A cache of Strings#

    String values belong to the map: free(), clear(), delete and a set that replaces one free them. keys() and values() give copies of their own.

    import map, str;

void main()
{
  map.Map<i64, String> cache = map.new<i64, String>();
  for (i64 i = 1; i <= 3; i++) { cache.set(i, str.format("value %d", i * i)); }
  printf("%s\n", cache.getOr(3, str.new()));
  cache.set(3, str.from("replaced"));   // the old "value 9" is freed
  cache.free();                         // and every value with it
}

    value 9

    Sharing between threads#

    A Map is not thread-safe. In coro.serve handlers or threads, guard a shared one with a lock.
