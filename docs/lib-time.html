    LibraryReference: date

    Clocks and sleeping

    Measure time, sleep, work with Unix time, and read and write HTTP dates.

    CallGivesUse it for
    date.monoMs(), date.monoNs()A clock that only goes forwardTimeouts, deadlines, measuring
    date.nowMs()Milliseconds since the Unix epochTimestamps (it jumps when the clock is set)
    date.unixNow()Seconds since the Unix epochUnix time
    date.sleepMs(ms)Sleeps, even through signalsWaiting

    Measuring#

    import date;

i64 slowSum(i64 n)
{
  i64 t = 0;
  for (i64 i = 0; i < n; i++) { t += i % 7; }
  return t;
}

void main()
{
  i64 start = date.monoNs();
  i64 r = slowSum(1000000);
  i64 took = date.monoNs() - start;
  printf("result %d, took more than 0 ns: %d\n", r, took > 0);

  i64 t0 = date.monoMs();
  date.sleepMs(20);
  printf("slept at least 20 ms: %d\n", date.monoMs() - t0 >= 20);
}

    result 2999997, took more than 0 ns: 1
slept at least 20 ms: 1

    A deadline#

    import date;

void main()
{
  i64 deadline = date.monoMs() + 50;
  i64 tries = 0;
  while (date.monoMs() < deadline) {
    tries++;
    date.sleepMs(10);
  }
  printf("tried more than once: %d\n", tries > 1);
}

    tried more than once: 1

    Use monoMs, not nowMs, for deadlines: the time of day can jump back when the clock is set.

    Unix time#

    date.formatUnix(t, fmt) writes a Unix time with strftime's format, in UTC; pass false as the third argument for local time.

    import date;

void main()
{
  ad String a = date.formatUnix(0, "%Y-%m-%d %H:%M:%S");
  ad String b = date.formatUnix(784111777, "%A %d %B %Y, day %j");
  printf("%s\n%s\n", a, b);
  printf("now is after 2024: %d\n", date.unixNow() > 1704067200);
}

    1970-01-01 00:00:00
Sunday 06 November 1994, day 310
now is after 2024: 1

    HTTP dates#

    date.httpDate(t) is the form HTTP headers use (Date, Last-Modified), always English and UTC. date.parseHttpDate(text, &t) reads it back, and the two older forms clients may still send. date.httpDateTo(t, buf) writes the same text into a buffer of date.HTTP_DATE_LEN (29) bytes, with no allocation and no NUL, and returns its length: for a server writing one per reply.

    import date;

void main()
{
  ad String h = date.httpDate(784111777);
  printf("%s\n", h);
  u8 buf[date.HTTP_DATE_LEN];
  printf("%s\n", buf[0:date.httpDateTo(784111777, buf)]);

  u8[] forms[] = {"Sun, 06 Nov 1994 08:49:37 GMT", "Sunday, 06-Nov-94 08:49:37 GMT",
                  "Sun Nov  6 08:49:37 1994", "yesterday"};
  for (auto f : forms) {
    i64 t = -1;
    bool ok = date.parseHttpDate(f, &t);
    printf("%d %d\n", ok, t);
  }
}

    Sun, 06 Nov 1994 08:49:37 GMT
Sun, 06 Nov 1994 08:49:37 GMT
1 784111777
1 784111777
1 784111777
0 -1

    On failure it returns false and leaves t alone.
