    ktm

    A compiled language for systems programming and networking: REST microservices, network daemons and system tools, on Linux and macOS.

    C-like, with classes, default arguments and exceptions; an ahead-of-time compiler, a JIT, a REPL and a language server in one binary.

    Get started Language tour Library reference

    ktm is a C-like language with classes, default arguments, a print-a-string statement and a JIT at its heart, made for REST microservices, network daemons and systems tools. ktm runs on Linux (x86_64 and arm64) and macOS (Apple Silicon) as an ahead-of-time compiler, a JIT, a REPL and a language server.

    U0 Main()
{
  "Hello world\n";
}

    Hello world

    A string on its own is a print statement, U0 is void, and Main is called for you. Save it as hello.ktm and run it either way:

    ktm hello.ktm -o hello && ./hello   # compile to a native binary
ktm -jit hello.ktm                    # or compile in memory and run straight away

    What it looks like#

    A request and a reply#

    A server and a client on loopback in one program: the sockets library speaks TCP, UDP and Unix sockets, IPv4 and IPv6.

    U0 Main()
{
  I32 srv = NetCreateServer(0, "127.0.0.1", 4);
  I32 cli = NetConnect("127.0.0.1", NetGetSocketPort(srv));
  I32 conn = NetAccept(srv);
  U8 req[256], resp[256];
  I64 n;

  NetSend(cli, "GET /hello HTTP/1.0\r\n\r\n", 23);

  n = recv(conn, req, sizeof(req) - 1, 0);   // the server side
  req[n] = '\0';
  U8 *path = req + 4;                          // after "GET "
  *StrFirstOcc(path, " ") = '\0';
  U8 *reply = MStrPrint("HTTP/1.0 200 OK\r\n\r\nyou asked for %s\n", path);
  NetSend(conn, reply, StrLen(reply));
  close(conn);

  n = recv(cli, resp, sizeof(resp) - 1, MSG_WAITALL);  // the client side
  resp[n] = '\0';
  "%s", strstr(resp, "\r\n\r\n") + 4;
  Free(reply);
  close(cli);
  close(srv);
}

    you asked for /hello

    Running a program#

    ProcRun runs a command and returns what it printed; ProcSpawn gives you its pipes.

    U0 Main()
{
  U8 *argv[] = {"echo", "hello from a child process", NULL};
  I64 code;
  U8 *out = ProcRun(argv, &code);
  "%s\n", out;
  "exit code %d\n", code;
  Free(out);
}

    hello from a child process
exit code 0

    Threads#

    POSIX threads directly, or a thread pool from the library.

    I64 sums[4];

U0 *Sum(U0 *arg)
{
  I64 part = arg(I64), total = 0;
  for (I64 i = part * 250 + 1; i <= (part + 1) * 250; i++) total += i;
  sums[part] = total;
  return NULL;
}

U0 Main()
{
  pthread_t *th[4];
  I64 i, total = 0;
  for (i = 0; i < 4; i++) pthread_create(&th[i], NULL, &Sum, i(U0 *));
  for (i = 0; i < 4; i++) {
    pthread_join(th[i]);
    total += sums[i];
  }
  "1 + 2 + ... + 1000 = %d\n", total;
}

    1 + 2 + ... + 1000 = 500500

    A taste of the language#

    Classes with inheritance, default arguments and ranges in case.

    class Animal
{
  U8 *name;
  I64 legs;
};

class Bird : Animal
{
  Bool can_fly;
};

U0 Describe(Animal *a, U8 *sound = "...")
{
  "%s has %d legs and says %s\n", a->name, a->legs, sound;
}

U0 Main()
{
  Bird b;
  b.name = "Tweety";
  b.legs = 2;
  b.can_fly = TRUE;

  Describe(&b, "tweet");   // a Bird is an Animal
  Describe(&b);            // default argument

  for (I64 i = 1; i <= 3; i++) {
    switch (i) {
      case 1: "one"; break;
      case 2 ... 3: ", more"; break;
    }
  }
  "\n";
}

    Tweety has 2 legs and says tweet
Tweety has 2 legs and says ...
one, more, more

    What ktm is#

    • A native compiler. ktm is parsed to an AST, lowered to an SSA IR and emitted as x86_64 or AArch64 assembly, which the system C compiler assembles and links.
    • A JIT. ktm -jit assembles machine code in memory with a built-in assembler and runs it, with no files written.
    • A REPL. ktm -repl runs ktm interactively.
    • A language server. ktm -lsp gives editors diagnostics, hover, completion, go-to-definition, references and rename.
    • A standard library. Strings, files, hash tables, vectors, JSON, dates, threads, sockets and more, available in every program without an include.

    It runs on Linux on x86_64 and arm64 and on macOS on Apple Silicon. On Windows, use WSL2.

    History and credits#

    ktm started as a fork of Jamesbarford/holyc-lang (BSD-2-Clause), a compiler for HolyC, the language Terry A. Davis created for TempleOS. Thanks to both: to Terry A. The fork was called hcc until v0.19.3 and was renamed ktm at v0.1.0; the hcc releases are in the holyc-lang repository.
