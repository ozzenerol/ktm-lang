Functions

Defining and calling functions, prototypes, default arguments, and how names stay out of each other's way.

At a glance

i64 square(i64 n) { return n * n; }
i64 later(i64 x);                       // a prototype
void box(i64 w = 2, i64 h = 3);         // defaults, on any parameter
box(, 9);                               // skip an argument: w is 2
i64 sum(i64 ...nums);                   // variable arguments
inline i64 twice(i64 x);                // a hint only

Defining and calling


i64 square(i64 n)
{
  return n * n;
}

f64 average(f64 a, f64 b)
{
  return (a + b) / 2;
}

void greet(u8 *who)
{
  printf("hello, %s\n", who);
}

void main()
{
  printf("%d %.1f\n", square(12), average(3, 4));
  greet("ktm");
}

144 3.5
hello, ktm

Arguments are converted to the parameter types: average(3, 4) passes two f64s. The return value is converted to the return type the same way.

Prototypes

Declare a function before its definition to call it earlier in the file.


bool isEven(i64 n);   // a prototype: defined below

bool isOdd(i64 n)
{
  if (n == 0) { return false; }
  return isEven(n - 1);
}

bool isEven(i64 n)
{
  if (n == 0) { return true; }
  return isOdd(n - 1);
}

void main()
{
  printf("%d %d\n", isEven(10), isOdd(7));
}

1 1
  • Every prototype and the definition must have the same return and parameter types: a mismatch is the error conflicting types.
  • A prototype that is never defined is a link error. A C function is declared with extern "c" instead.
  • Functions in a module need no prototypes at all: they see each other in any order.

Default arguments

Any parameter can have a default, not only the last ones. Leave an argument empty to use it.


void box(i64 w = 2, i64 h = 3, u8 *fill = "#")
{
  printf("%dx%d of %s\n", w, h, fill);
}

void main()
{
  box(5, 1, "*");
  box(5);          // h and fill default
  box(, 9);        // w defaults
  box(, , "@");    // only fill given
  box();
}

5x1 of *
5x3 of #
2x9 of #
2x3 of @
2x3 of #

Defaults given on a prototype carry over to the definition:


void connect(u8 *host, i64 port = 80);

void main()
{
  connect("example.com");
  connect("example.com", 8080);
}

void connect(u8 *host, i64 port)    // no need to repeat = 80
{
  printf("%s:%d\n", host, port);
}

example.com:80
example.com:8080

Repeating a default with the same value is fine. A different value is an error.

Where a call comes from

A parameter marked @caller("file"), @caller("line") or @caller("func") is filled in by every call with where that call is written. Callers never pass it, so a logging or checking function can say where it was called from.


void trace(@caller("file") u8 *file, @caller("line") i64 line,
           @caller("func") u8 *func, u8 *what)
{
  printf("%s:%d in %s: %s\n", file, line, func, what);
}

void load()
{
  trace("loading");
}

void main()
{
  trace("start");
  load();
}

example.ktm:14 in main: start
example.ktm:9 in load: loading
  • "file" is the source file's path as ktm was given it, "func" the function the call is in (Type.method for a method, module.name in a module, "" outside any function). Both are u8 *. "line" is an integer.
  • They can go anywhere in the list, before ...args too, as in void info(@caller("line") i64 line, u8 *fmt, ...args).
  • A @caller parameter has no default, and a function with one can't be overloaded.
  • A call through auto p = &trace fills them in too. A call through an fn(...) type passes them like any other argument.

Returning values


struct Point { i64 x, y; };

Point origin() { Point p = {0, 0}; return p; }   // structs return by value

f64 half(i64 n) { return n; }                    // the i64 becomes an f64

void main()
{
  Point p = origin();
  printf("%d %d %.1f\n", p.x, p.y, half(3) / 2);
}

In a void function, return expr; is a warning. The expression still runs.

Several results

Return a struct, or write through pointer parameters:


bool divide(i64 a, i64 b, i64 *quot, i64 *rem)
{
  if (b == 0) { return false; }
  *quot = a / b;
  *rem = a % b;
  return true;
}

void main()
{
  i64 q, r;
  if (divide(17, 5, &q, &r)) {
    printf("17 = 5 * %d + %d\n", q, r);
  }
  printf("ok: %d\n", divide(1, 0, &q, &r));
}

ok: 0

Recursion


i64 fib(i64 n)
{
  if (n < 2) { return n; }
  return fib(n - 1) + fib(n - 2);
}

void main()
{
  for (i64 i = 0; i < 10; i++) { printf("%d,", fib(i)); }
  printf("\n");
}

Inlining

The compiler inlines small functions by itself, with exactly the behaviour of a call. inline is accepted as a hint only: an inline function is still an ordinary function that can recurse and have its address taken.


inline i64 twice(i64 x)
{
  return x * 2;
}

void main()
{
  fn(i64 x) i64 fp = &twice;
  printf("%d %d\n", twice(21), fp(4));
}

42 8

Names don't clash with libraries

Your functions can use any name. The standard library lives in modules, and the C library's symbols are separate from yours.


import date;

i64 now() { return 42; }          // yours
void free(u8 *what) { printf("my free(%s)\n", what); }

void main()
{
  printf("%d %d\n", now(), date.now() > 0);   // date.now() is the library's
  free("thing");                                // the library keeps using C's free
}

my free(thing)
