Vectors and sorting

vec.Vec<T> is a growable array of any type. sort sorts any slice in place.

At a glance

ad vec.Vec v = vec.new();   // freed at the end of the scope
v.push(3);  v.get(0);  v.set(0, 4);  v.pop();
v.len   v.items()   v.contains(3)       // count; a T[] view; bool
for (auto x : v) { ... }
v.sortAsc();  v.sort(&cmp);
sort.asc(slice);  sort.slice(slice, &cmp);

The basics


import vec;

void main()
{
  ad vec.Vec nums = vec.new();
  for (i64 i = 1; i <= 5; i++) { nums.push(i * 10); }
  nums.set(0, 15);
  printf("len %d, first %d, last %d\n", nums.len, nums.get(0), nums.last());
  printf("popped %d, len %d\n", nums.pop(), nums.len);
  for (auto n : nums) { printf("%d,", n); }
  printf("\n");
}

len 5, first 15, last 50
popped 50, len 4
15,20,30,40,

A Vec is a value with data, len and cap fields. free() frees its array, not what the items point to.

Methods

MethodDoes
push(x)Appends, growing as needed
get(i), set(i, x)Reads or writes item i (checked)
at(i)A pointer to item i, to change it in place (checked)
pop(&ok), last(&ok)Removes / reads the last item
insert(i, x), removeAt(i)Inserts or removes, keeping the order
items()A T[] view (valid until the Vec grows)
contains(x)bool: whether x is one of the items; a String or u8[] by its text, anything else by its value
sort(cmp), sortAsc()Sorts in place
reserve(n), clear(), free()Room for n more; empty it, keeping the room; free it

Checked access

An index outside 0 to len - 1 throws ERR_BOUNDS. pop and last on an empty Vec throw too, unless you pass &ok.


import vec;

void main()
{
  ad vec.Vec v = vec.new();
  bool ok;
  i64 x = v.pop(&ok);
  printf("empty pop: %d, ok %d\n", x, ok);
  try {
    v.get(3);
  } catch (Error e) {
    printf("%s\n", e.message);
  }
}

empty pop: 0, ok 0
vec.Vec.get: index 3 of 0

Changing items in place


import vec;

struct Player { u8 *name; i64 score; };

void main()
{
  ad vec.Vec team = vec.new();
  Player a = {"ada", 10}, b = {"bob", 5}, c = {"cy", 1};
  team.push(a);
  team.push(b);
  team.at(1).score += 20;          // bob: through a pointer into the Vec
  team.insert(0, c);               // cy, ada, bob
  team.removeAt(1);                // cy, bob
  for (auto p : team) { printf("%s %d\n", p.name, p.score); }
}

cy 1
bob 25

Sorting

sortAsc() sorts anything < compares. sort(cmp) takes a comparator given pointers to two items: negative when a goes first, 0 when equal, positive when b does.


import vec;

struct User { u8 *name; i64 age; };

i64 byAge(User *a, User *b) { return a.age - b.age; }

void main()
{
  ad vec.Vec temps = vec.new();
  temps.push(21.5);
  temps.push(18.0);
  temps.push(19.25);
  temps.sortAsc();
  for (auto t : temps) { printf("%.2f,", t); }
  printf("\n");

  ad vec.Vec users = vec.new();
  User ann = {"ann", 41}, bob = {"bob", 29}, cy = {"cy", 35};
  users.push(ann);
  users.push(bob);
  users.push(cy);
  users.sort(&byAge);
  for (auto u : users) { printf("%s %d\n", u.name, u.age); }
}

18.00,19.25,21.50,
bob 29
cy 35
ann 41

Both are O(n log n) on any input, and not stable.

Sorting any slice

The sort module sorts arrays and slices in place.


import sort;

i64 byLength(u8[] *a, u8[] *b) { return a.len - b.len; }

void main()
{
  i64 nums[] = {5, 2, 9, 1};
  sort.asc(nums);
  printf("%d %d %d %d\n", nums[0], nums[1], nums[2], nums[3]);

  u8[] words[] = {"pear", "fig", "banana"};
  sort.slice(words, &byLength);
  printf("%s %s %s\n", words[0], words[1], words[2]);

  i64 part[] = {9, 8, 7, 6, 5};
  sort.asc(part[1:4]);               // only the middle three
  printf("%d %d %d %d %d\n", part[0], part[1], part[2], part[3], part[4]);
}

1 2 5 9
fig pear banana
9 6 7 8 5

Passing a Vec as a slice


import vec;

i64 sum(i64[] xs) { i64 t = 0; for (auto x : xs) { t += x; } return t; }

void main()
{
  ad vec.Vec v = vec.new();
  for (i64 i = 1; i <= 4; i++) { v.push(i); }
  printf("%d %d\n", sum(v.items()), sum(v.items()[2:]));
}

10 7

Returning a Vec

Make it without ad, return it, and let the caller free it:


import vec;

vec.Vec evens(i64 upTo)
{
  vec.Vec v = vec.new();
  for (i64 i = 0; i <= upTo; i += 2) { v.push(i); }
  return v;
}

void main()
{
  ad vec.Vec e = evens(8);
  printf("%d evens, the last %d\n", e.len, e.last());
}

5 evens, the last 8

Bit vectors

vec.BitVec is a set of numbered bits, all 0 at first. set grows it to fit any index.


import vec;

void main()
{
  vec.BitVec *seen = vec.bitNew();
  i64 primes[] = {2, 3, 5, 7, 1000003};
  for (auto p : primes) { seen.set(p); }
  seen.unset(5);

  for (i64 n = 0; n < 10; n++) {
    if (seen.test(n)) { printf("%d,", n); }
  }
  printf(" 1000003: %d, 99999999: %d\n", seen.test(1000003), seen.test(99999999));
  seen.release();
}

2,3,7, 1000003: 1, 99999999: 0
  • test and unset treat bits past the end as 0.
  • set returns false when it can't grow; clear zeroes every bit.
