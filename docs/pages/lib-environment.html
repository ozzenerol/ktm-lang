Environment and exit

Environment variables, the program's own path, exit codes, errno and stderr.

Environment variables

CallDoes
proc.getenv(name)The value as a String; empty when unset
proc.hasEnv(name)Tells an empty value from a missing one
proc.setenv(name, value), proc.unsetenv(name)Change it for this program and the ones it starts
 

import proc;

void main()
{
  proc.setenv("GREETING", "hello");
  ad String g = proc.getenv("GREETING");
  printf("GREETING=%s\n", g);

  proc.setenv("EMPTY", "");
  proc.unsetenv("GREETING");
  printf("GREETING set: %d, EMPTY set: %d\n", proc.hasEnv("GREETING"), proc.hasEnv("EMPTY"));

  ad String port = proc.getenv("PORT_THAT_IS_NOT_SET");
  printf("default port: %s\n", port.len ? port.cstr() : "8080");
}

GREETING=hello
GREETING set: 0, EMPTY set: 1
default port: 8080

Exiting


import os;

void main()
{
  printf("before\n");
  os.exit(EXIT_OK);       // EXIT_OK and EXIT_FAIL come from the prelude
  printf("never\n");
}

before

os.exit writes out what printf holds, but runs no defers.

stderr and flushing

  • os.eprintf(fmt, ...) is printf to stderr, checked the same way.
  • os.flush() writes out what printf still holds for stdout. Do it before starting a command that writes to the same place.
import os;

void main()
{
  printf("result: 42\n");                 // stdout: what a pipe gets
  os.eprintf("took %d ms\n", 17);         // stderr: what the user sees
}

errno

os.errno() is the C errno of the calling thread; os.setErrno(0) clears it. The codes are in libc, with each platform's numbers.


import libc, os;

void main()
{
  if (libc.close(-1) == -1 && os.errno() == libc.EBADF) {
    printf("close(-1): EBADF\n");
  }
  i32 fd = libc.open("/no/such/file", libc.O_RDONLY);
  printf("%d %d\n", fd, os.errno() == libc.ENOENT);
}

close(-1): EBADF
-1 1

Read os.errno() straight after the call that failed: anything in between may change it.

Wait statuses

A status from libc.waitpid or libc.system is read with these:

CallSays
proc.exited(st), proc.exitCode(st)Whether it exited, and with what
proc.signaled(st), proc.termSignal(st)Whether a signal killed it, and which
proc.stopped(st), proc.stopSignal(st)Whether it is stopped, and by which signal
proc.statusCode(st)What a shell puts in $?: the exit code, or 128 plus the signal
 

import libc, proc;

void main()
{
  i32 st = libc.system("exit 3");
  printf("exited %d with %d, $? %d\n", proc.exited(st), proc.exitCode(st), proc.statusCode(st));
  st = libc.system("kill -KILL $$");
  printf("signal %d, $? %d\n", proc.termSignal(st), proc.statusCode(st));
}

exited 1 with 3, $? 3
signal 9, $? 137
