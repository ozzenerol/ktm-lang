Slices

A slice T[] is a pointer and a length: a view of some Ts that knows how many there are. Every index is checked.

At a glance

i64 nums[6] = {1, 2, 3, 4, 5, 6};
i64[] all = nums;          // an array converts: len 6
i64[] mid = all[1:4];      // elements 1, 2, 3: a view, nothing copied
all[:2]   all[4:]          // from the start, to the end
s.len   s.ptr   s[i]       // length, pointer, an element (checked)
u8[] word = "hello";       // a literal is a u8[] of its bytes
p[0:n]                     // a raw pointer becomes a slice: you vouch for n

Making and viewing


void main()
{
  i64 nums[6] = {1, 2, 3, 4, 5, 6};
  i64[] all = nums;
  i64[] mid = all[1:4];
  printf("%d %d | %d %d %d\n", all.len, mid.len, mid[0], mid[1], mid[2]);
  printf("%d %d\n", all[:2].len, all[4:][0]);
  printf("%s\n", typeof(mid));
}

s[a:b] runs from a up to, not including, b.

A view writes into what it views


void main()
{
  i64 nums[4] = {1, 2, 3, 4};
  i64[] tail = nums[2:];
  tail[0] = 30;              // writes nums[2]
  printf("%d %d %d %d\n", nums[0], nums[1], nums[2], nums[3]);
}

Passing arrays as slices

A function that takes a slice accepts an array, a slice, or part of one.


i64 sum(i64[] xs)
{
  i64 total = 0;
  for (auto x : xs) { total += x; }
  return total;
}

i64 maxOf(i64[] xs)
{
  i64 best = xs[0];
  for (i64 i = 1; i < xs.len; i++) {
    if (xs[i] > best) { best = xs[i]; }
  }
  return best;
}

void main()
{
  i64 nums[6] = {4, 8, 15, 16, 23, 42};
  printf("%d %d %d\n", sum(nums), sum(nums[:3]), maxOf(nums[1:4]));
}

Text is a u8[]

A string literal converts to a u8[] of its bytes, without the NUL. So does a String.


void main()
{
  u8[] word = "hello";
  printf("%s %d %c %s\n", word, word.len, word[1], word[1:4]);
}

hello 5 e ell

A u8 buffer is all its bytes. A u8 buf[64] passed as a u8[] has length 64, not the length of the text in it. Use cstr.view(buf) for the text up to its NUL, or buf[0:n] when you know n.


import cstr;

void main()
{
  u8 buf[64];
  cstr.copy(buf, "hi");
  u8[] whole = buf;
  printf("%d %d %d\n", whole.len, cstr.view(buf).len, buf[0:2].len);
}

Bounds checks

Every index and sub-slice is checked, compiled and in the JIT. Out of range throws ERR_BOUNDS, which you can catch.


void main()
{
  i64 nums[3] = {1, 2, 3};
  i64[] s = nums;
  try {
    printf("%d\n", s[3]);
  } catch (Error e) {
    printf("caught: %s\n", e.message);
  }
  try {
    i64[] t = s[2:5];
  } catch (Error e) {
    printf("caught: %s\n", e.message);
  }
}

caught: index 3 out of range for length 3
caught: slice 2:5 out of range for length 3
  • A check costs one compare and a branch.
  • The compiler drops it where it can't fail: s[i] inside for (i64 i = 0; i < s.len; i++) when the body doesn't change i or s.
  • s.ptr[i] is the unchecked way, for loops that checked their range themselves.

From a pointer

p[0:n] turns a raw pointer into a slice. It can't be checked: you vouch for n. The other way, s.ptr is the pointer.


import mem;

void main()
{
  i64 *raw = mem.allocZero(4 * sizeof(i64));
  i64[] s = raw[0:4];
  s[3] = 9;
  printf("%d %d %d\n", s.len, raw[3], s.ptr == raw);
  mem.free(raw);
}

Comparing and freeing

  • a == b on slices is an error. Compare text with a.equals(b), identity with a.ptr == b.ptr.
  • A slice a function allocated for you (like the parts str.split returns) is freed with s.free().
  • A slice of an array, or of someone else's memory, is not yours to free.
  • s.len and s.ptr are read-only: assign the whole slice instead.

import str;

void main()
{
  u8[] a = "abc";
  u8 buf[3] = {'a', 'b', 'c'};
  u8[] b = buf;
  printf("%d %d\n", a.equals(b), a.ptr == b.ptr);

  u8[][] parts = str.split("x,y,z", ",");   // allocated: ours to free
  defer parts.free();
  printf("%d parts, the last is %s\n", parts.len, parts[2]);
}

Slices of anything

Slices of structs, slice fields, slices of slices (u8[][]) and slices in function types all work.


struct User { u8[] name; i64[] scores; };

i64 best(User[] users, fn(i64[]) i64 score)
{
  i64 top = 0;
  for (auto u : users) {
    if (score(u.scores) > top) { top = score(u.scores); }
  }
  return top;
}

i64 total(i64[] xs) { i64 t = 0; for (auto x : xs) { t += x; } return t; }

void main()
{
  i64 a[] = {3, 4}, b[] = {10};
  User users[2] = {{"ann", a}, {"bob", b}};
  printf("%d\n", best(users, &total));
}
