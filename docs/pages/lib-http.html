HTTP servers

net.http serves REST APIs the way Go's net/http does: a Mux sends each request to a handler by method and path, and a handler writes the reply. It runs on coro.serve, a coroutine per connection on every core.

A first API


import json, net.http, reflect;

@json struct User { i64 id; String name; };

void getUser(http.Writer *w, http.Request *r)
{
  User u = {7, str.from(r.param("id"))};
  defer u.name.free();
  w.json(200, reflect.of(u));
}

void createUser(http.Writer *w, http.Request *r)
{
  User u = http.decode(r);    // bad JSON: the server answers 400 itself
  u.id = 42;
  w.json(201, reflect.of(u));        // u is freed when the handler returns
}

i32 main()
{
  http.Mux mux;
  mux.handle("GET /users/{id}", &getUser);
  mux.handle("POST /users", &createUser);
  return http.listen(8080, &mux);    // Ctrl-C: finishes the requests in progress, returns 0
}

$ curl -d '{"name":"Ada"}' localhost:8080/users
{"id":42,"name":"Ada"}
$ curl -d '{"name":' localhost:8080/users
{"error":"1:9: name: expected a string, got the end of the input"}

Routing

An http.Mux sends each request to the handler of the pattern that matches it, the way Go 1.22's ServeMux does. Declare one (http.Mux mux;: no setup call) and add routes with mux.handle(pattern, &handler). A pattern is [METHOD ]/path:

PatternMatches
/health/health, any method
GET /users/{id}/users/7 by GET or HEAD; r.param("id") is "7"
/files/{path...}/files/a/b.txt: path is the rest, "a/b.txt" (it may be empty)
/static/a trailing slash: /static/ and everything under it
/{$}only / (/ alone matches every path)

import net.http;

void user(http.Writer *w, http.Request *r)  { w.text(200, "user %s", r.param("id")); }
void me(http.Writer *w, http.Request *r)    { w.text(200, "it's you"); }
void file(http.Writer *w, http.Request *r)  { w.text(200, "file %s", r.param("path")); }
void create(http.Writer *w, http.Request *r) { w.text(201, "created"); }
void home(http.Writer *w, http.Request *r)  { w.text(200, "home"); }

void show(http.Mux *mux, u8[] method, u8[] target)
{
  http.Request r = http.testRequest(method, target);
  http.Writer w = http.recorder();
  mux.serve(&w, &r);
  printf("%-6s %-18s %d %s%s\n", method, target, w.code, w.body, w.getHeader("Location"));
  w.free();
  r.free();
}

void main()
{
  http.Mux mux;
  mux.handle("GET /users/{id}", &user);
  mux.handle("GET /users/me", &me);       // more specific: wins for /users/me
  mux.handle("POST /users", &create);
  mux.handle("/files/{path...}", &file);
  mux.handle("/{$}", &home);

  show(&mux, "GET", "/users/42");
  show(&mux, "GET", "/users/me");
  show(&mux, "GET", "/files/a%20b/c.txt");
  show(&mux, "GET", "/");
  show(&mux, "GET", "/files");
  show(&mux, "DELETE", "/users/42");
  show(&mux, "GET", "/nope");
  mux.free();
}

GET    /users/42          200 user 42
GET    /users/me          200 it's you
GET    /files/a%20b/c.txt 200 file a b/c.txt
GET    /                  200 home
GET    /files             301 /files/
DELETE /users/42          405 {"error":"method not allowed"}
GET    /nope              404 {"error":"not found"}

Which pattern wins

When several patterns match, the most specific one wins, whatever order they were added in: one pattern is more specific than another when it matches a strict subset of its requests. So a literal segment beats {name}, {name} beats {name...}, a longer subtree beats a shorter one, and GET /x beats /x.

Two patterns that both match some request where neither is more specific are refused at handle(), and so is the same pattern twice: it throws http.ERR_PATTERN with both patterns in the message. For example /users/{id} and /{kind}/new both match /users/new, and GET / and /health both match GET /health (the first takes fewer methods, the second fewer paths). A pattern that isn't one (no leading /, a host, { inside a segment, {name...} or {$} not at the end, a name used twice) throws the same.


import net.http;

void h(http.Writer *w, http.Request *r) { }

void main()
{
  http.Mux mux;
  mux.handle("/users/{id}", &h);
  try {
    mux.handle("/{kind}/new", &h);
  } catch (Error e) {
    printf("%d: %s\n", e.code == http.ERR_PATTERN, e.message);
  }
  mux.free();
}

1: http.Mux.handle: pattern "/{kind}/new" conflicts with pattern "/users/{id}": some requests match both and neither is more specific

The details

  • Methods: a pattern without one takes every method; GET takes HEAD too (the server sends no body for HEAD). HEAD /x is more specific than GET /x.
  • No route: 404 {"error":"not found"}. A path that a route for other methods matches gets 405 {"error":"method not allowed"} with an Allow header listing them (DELETE, GET, HEAD).
  • Escapes: the path is split at its /s first, then each segment is unescaped, so /a%2Fb is one segment, a/b. Literal segments of a pattern are unescaped too, and r.param gives values unescaped (a segment with a bad % escape is used as it is).
  • Redirects (301, the query kept): /dir goes to /dir/ when it doesn't match a route itself but /dir/ matches a subtree /dir/ (or /dir/{rest...}); a path with //, /./ or /../ goes to its clean form (/a/../b to /b).
  • Speed: patterns are parsed once, at handle(). Matching allocates nothing (a parameter that needs unescaping is copied into the request's arena) and rejects most routes by their segment count and first byte.
  • mux.free() frees the routes and leaves the Mux empty; http.listen calls it when it returns.

Handlers

A handler is void name(http.Writer *w, http.Request *r) (the type http.Handler). What the request hands it is valid until it returns, and the module frees it then: the path, headers, query values, path parameters, the body and what http.decode made. Copy what must live longer (str.from). Only what the handler allocates itself is its own to free.

  • A handler that throws gets a 500 reply with {"error":"internal server error"}, and the error goes to the log with its file and line. The server carries on.
  • A json.ERR_DECODE (bad JSON in http.decode) gets a 400 with the decode message.
  • Handlers run on several threads at once: what they share needs the atomic module or a lock.

The request

r.method, r.path"GET", "/users/7" (the path before the ?, as sent)

r.header("Authorization"), r.hasHeader(name)a header by name, any case

r.alloc(n), r.unescape(s)memory that lives until the reply; %XX decoding

The reply

The reply is sent in one piece when the handler returns, with Date and Content-Length. A handler that writes nothing sends 200 with an empty body.

MethodWhat it does
w.json(code, reflect.of(x))x as JSON, Content-Type: application/json
w.text(code, "fmt %s", ...)formatted text, text/plain; charset=utf-8
w.error(code, "msg"){"error":"msg"}, replacing a body already started
w.status(code), w.write(bytes)the status (200 by default) and raw body bytes
w.header(name, value)adds a header; a Content-Type replaces the default one
w.jsonText(code, text), w.redirect(url, 302)JSON that is text already; a redirect

Running the server

http.listen(port, &mux, app, &opts) serves until SIGINT or SIGTERM (or http.shutdown()), lets the requests in progress finish, frees the mux and returns 0; -1 with os.errno() set when the port can't be used. app and opts are optional. Every http.Options field left 0 means its default:

FieldDefault
threadsa coroutine loop per CPU
bindaddrevery IPv4 address ("::*" for IPv6, or a numeric address)
maxHeaderBytes64 KiB for the request line and headers, else 431
maxBodyBytes10 MiB, else 413
readTimeoutMs, idleTimeoutMs30 s for a request that started, 120 s idle between requests
noSignalsfalse: SIGINT and SIGTERM stop the server

HTTP/1.1 with keep-alive and pipelining, chunked request bodies, Expect: 100-continue, and HTTP/1.0. A request with both Content-Length and chunked encoding is refused (400). There is no TLS: put the server behind a proxy such as nginx or Caddy for HTTPS.

Testing handlers

http.testRequest and http.recorder() run a handler or a whole mux without a socket.


import net.http;

void hello(http.Writer *w, http.Request *r)
{
  w.text(200, "hello %s", r.query("name"));
}

void main()
{
  http.Mux mux;
  defer mux.free();
  mux.handle("GET /hello", &hello);

  http.Request r = http.testRequest("GET", "/hello?name=Ada%20L");
  defer r.free();
  http.Writer w = http.recorder();
  defer w.free();
  mux.serve(&w, &r);
  printf("%d %s: %s\n", w.code, w.getHeader("Content-Type"), w.body);
}

200 text/plain; charset=utf-8: hello Ada L
