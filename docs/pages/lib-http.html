HTTP servers

net.http serves REST APIs the way Go's net/http does: a Mux sends each request to a handler by method and path, and a handler writes the reply. It runs on coro.serve, a coroutine per connection on every core.

A first API


import json, net.http, reflect;

@json struct User { i64 id; String name; };

void getUser(http.Writer *w, http.Request *r)
{
  User u = {7, str.from(r.param("id"))};
  defer u.name.free();
  w.json(200, reflect.of(u));
}

void createUser(http.Writer *w, http.Request *r)
{
  User u = http.decode(r);    // bad JSON: the server answers 400 itself
  u.id = 42;
  w.json(201, reflect.of(u));        // u is freed when the handler returns
}

i32 main()
{
  http.Mux mux;
  mux.handle("GET /users/{id}", &getUser);
  mux.handle("POST /users", &createUser);
  return http.listen(8080, &mux);    // Ctrl-C: finishes the requests in progress, returns 0
}

$ curl -d '{"name":"Ada"}' localhost:8080/users
{"id":42,"name":"Ada"}
$ curl -d '{"name":' localhost:8080/users
{"error":"1:9: name: expected a string, got the end of the input"}

Handlers

A handler is void name(http.Writer *w, http.Request *r) (the type http.Handler). What the request hands it is valid until it returns, and the module frees it then: the path, headers, query values, path parameters, the body and what http.decode made. Copy what must live longer (str.from). Only what the handler allocates itself is its own to free.

  • A handler that throws gets a 500 reply with {"error":"internal server error"}, and the error goes to the log with its file and line. The server carries on.
  • A json.ERR_DECODE (bad JSON in http.decode) gets a 400 with the decode message.
  • Handlers run on several threads at once: what they share needs the atomic module or a lock.

The request

Field or methodWhat it is
r.method, r.path"GET", "/users/7" (the path before the ?, as sent)
r.rawQuery, r.bodyafter the ?, not unescaped; the whole body (a chunked one already joined)
r.param("id")a path parameter of the pattern, unescaped; "" if none
r.query("page"), r.hasQuery("x")the first value of a query parameter, unescaped (+ is a space)
r.header("Authorization"), r.hasHeader(name)a header by name, any case
http.decode<T>(r)the body as JSON in a T, freed after the reply
r.appwhat http.listen was given as app: the program's own state
r.alloc(n), r.unescape(s)memory that lives until the reply; %XX decoding

The reply

The reply is sent in one piece when the handler returns, with Date and Content-Length. A handler that writes nothing sends 200 with an empty body.

MethodWhat it does
w.json(code, reflect.of(x))x as JSON, Content-Type: application/json
w.text(code, "fmt %s", ...)formatted text, text/plain; charset=utf-8
w.error(code, "msg"){"error":"msg"}, replacing a body already started
w.status(code), w.write(bytes)the status (200 by default) and raw body bytes
w.header(name, value)adds a header; a Content-Type replaces the default one
w.jsonText(code, text), w.redirect(url, 302)JSON that is text already; a redirect

Running the server

http.listen(port, &mux, app, &opts) serves until SIGINT or SIGTERM (or http.shutdown()), lets the requests in progress finish, frees the mux and returns 0; -1 with os.errno() set when the port can't be used. app and opts are optional. Every http.Options field left 0 means its default:

FieldDefault
threadsa coroutine loop per CPU
bindaddrevery IPv4 address ("::*" for IPv6, or a numeric address)
maxHeaderBytes64 KiB for the request line and headers, else 431
maxBodyBytes10 MiB, else 413
readTimeoutMs, idleTimeoutMs30 s for a request that started, 120 s idle between requests
noSignalsfalse: SIGINT and SIGTERM stop the server

HTTP/1.1 with keep-alive and pipelining, chunked request bodies, Expect: 100-continue, and HTTP/1.0. A request with both Content-Length and chunked encoding is refused (400). There is no TLS: put the server behind a proxy such as nginx or Caddy for HTTPS.

Testing handlers

http.testRequest and http.recorder() run a handler or a whole mux without a socket.


import net.http;

void hello(http.Writer *w, http.Request *r)
{
  w.text(200, "hello %s", r.query("name"));
}

void main()
{
  http.Mux mux;
  defer mux.free();
  mux.handle("GET /hello", &hello);

  http.Request r = http.testRequest("GET", "/hello?name=Ada%20L");
  defer r.free();
  http.Writer w = http.recorder();
  defer w.free();
  mux.serve(&w, &r);
  printf("%d %s: %s\n", w.code, w.getHeader("Content-Type"), w.body);
}

200 text/plain; charset=utf-8: hello Ada L
