Logging

log writes one short line per call to stderr or a file: the time, the level, and optionally where the call is. Files rotate by size, and a Logger can be shared by threads.

A first log


import log;

void main()
{
  log.Options o = log.options();   // stderr, INFO and up
  log.Logger *lg = log.open(&o);
  defer lg.close();

  lg.info("listening on :%d", 8080);
  lg.warn("slow request: %d ms", 950);
  lg.error("db: %s", "connection refused");
  lg.debug("not written: below INFO");
}

2026-10-13T14:02:11.482Z INFO listening on :8080
2026-10-13T14:02:11.483Z WARN slow request: 950 ms
2026-10-13T14:02:11.483Z ERROR db: connection refused
  • Each line is the time in UTC with milliseconds, the level's name, then the message.
  • debug, info, warn and error take a printf format and its arguments.
  • A newline in a message is written as \n, so one call is always one line.

Options

Start from log.options() and change the fields you need. log.open copies them.

FieldDefaultDoes
pathnullThe file to append to; null writes to stderr
threadSafefalseA mutex around each line, for a Logger several threads share
maxBytes0Rotate before a line would take the file past this size; 0 never rotates
keep0How many rotated files to keep: path.1 (newest) to path.<keep>
showFilefalseThe call's file name and line
showFuncfalseThe function the call is in
levellog.Level.infoThe least important level written

Where a line comes from


import log;

void serve(log.Logger *lg)
{
  lg.warn("slow request: %d ms", 950);
}

void main()
{
  log.Options o = log.options();
  o.path = "app.log";
  o.showFile = true;
  o.showFunc = true;
  log.Logger *lg = log.open(&o);
  defer lg.close();

  lg.info("listening on :%d", 8080);
  serve(lg);
}

app.log:

2026-10-13T14:02:11.482Z INFO main.ktm:17 main: listening on :8080
2026-10-13T14:02:11.483Z WARN main.ktm:5 serve: slow request: 950 ms

The compiler fills in the file, line and function at each call, with @caller parameters. Nothing is looked up while the program runs.

Levels

LevelWritten as
log.Level.debugDEBUG
log.Level.infoINFO
log.Level.warnWARN
log.Level.errorERROR

A Logger writes its level and everything after it. lg.level can be changed at any time, for example to log.Level.debug while chasing a bug. A call below the level returns before it formats anything.

Rotating a file

With maxBytes set, the file is rotated before a line would take it past that size: app.log becomes app.log.1, app.log.1 becomes app.log.2, and so on up to keep, and the oldest is dropped.


import fs, log;

void report(u8[] name)
{
  printf("%s: %s\n", name, fs.exists(name) ? "kept" : "none");
  fs.remove(name);
}

void main()
{
  log.Options o = log.options();
  o.path = "app.log";
  o.maxBytes = 200;     // about four lines
  o.keep = 2;
  log.Logger *lg = log.open(&o);
  for (i64 i = 1; i <= 20; i++) {
    lg.info("request number %d", i);
  }
  lg.close();

  report("app.log");
  report("app.log.1");
  report("app.log.2");
  report("app.log.3");
}

app.log: kept
app.log.1: kept
app.log.2: kept
app.log.3: none
  • A line is never split: if one line is bigger than maxBytes, it gets a file of its own.
  • With keep 0 the file is emptied and started again.
  • Reopening an existing file appends to it and counts its size towards maxBytes.
  • Rotation is for one process. Several programs writing to one file should each have their own.

Threads

With threadSafe, one mutex covers taking the time, rotating and writing, so the lines of different threads never mix and come out in time order. Without it there is no locking at all, which suits a single-threaded program or one Logger per thread.


import fs, libc, log;

log.Logger *gLog;

void *work(void *arg)
{
  for (i64 i = 0; i < 100; i++) {
    gLog.info("worker %d step %d", (i64)arg, i);
  }
  return null;
}

void main()
{
  log.Options o = log.options();
  o.path = "threads.log";
  o.threadSafe = true;
  gLog = log.open(&o);
  libc.pthread_t *th[4];
  for (i64 i = 0; i < 4; i++) { libc.pthread_create(&th[i], null, &work, (void *)i); }
  for (i64 i = 0; i < 4; i++) { libc.pthread_join(th[i]); }
  gLog.close();

  String text = fs.readAll("threads.log");
  i64 lines = 0;
  for (i64 i = 0; i < text.len; i++) { if (text.ptr[i] == '\n') { lines++; } }
  printf("%d lines\n", lines);
  text.free();
  fs.remove("threads.log");
}

400 lines

Errors

  • log.open throws log.ERR_LOG when the file can't be opened. The message says why.
  • After that, a log call never throws. A line a failed write drops (a full disk, say) is counted in lg.failed.
  • Each line is one write to a file opened for appending, with nothing buffered, so a crash loses nothing already logged.
  • lg.close() closes the file (never stderr) and frees the Logger.
