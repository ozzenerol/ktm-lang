C strings

The cstr module works on NUL-terminated u8 * strings, for C code and the data it gives you. For your own text, prefer String.

Who frees what. Functions that make a C string (cstr.dup, cstr.format, cstr.formatTo(null, ...), cstr.concat, cstr.dupLen, cstr.quote) return a new block that you mem.free.

Between String and u8 *


import cstr, mem, str;

void main()
{
  u8 *fromC = cstr.dup("from C");
  ad String s = str.from(cstr.view(fromC));   // a C string to a String: copy
  mem.free(fromC);

  u8 *forC = s.cstr();                        // a String to C: no copy
  printf("%s %d\n", forC, cstr.len(forC));

  u8 *mine = s.take();                        // the bytes are now ours
  printf("%s, String empty: %d\n", mine, s.len == 0);
  mem.free(mine);
}

Building

FunctionGives
cstr.format(fmt, ...)A new, exactly sized formatted string
cstr.formatTo(null, fmt, ...)The same into a new block; with a buffer, into it (no bound)
cstr.formatToSize(buf, n, fmt, ...)At most n - 1 characters and a NUL, like snprintf
cstr.concat(a, b, ...)The strings joined
cstr.appendFormat(s, fmt, ...)Appends to a heap string and returns it (it may move)
cstr.appendFormatLen(s, &len, fmt, ...)The same, keeping the length, so loops stay linear
 

import cstr, mem;

void main()
{
  u8 *s = cstr.formatTo(null, "%d|%05d|%s|%.2f", 5000000000, 42, "x", 3.14159);
  printf("%s\n", s);

  u8 *csv = cstr.dup("id");
  for (i64 i = 1; i <= 3; i++) {
    csv = cstr.appendFormat(csv, ",%d", i);   // always reassign
  }
  printf("%s\n", csv);

  i64 len = 0;
  u8 *log = null;                              // null starts a new string
  for (i64 i = 0; i < 3; i++) {
    log = cstr.appendFormatLen(log, &len, "[%d]", i * i);
  }
  printf("%s (%d)\n", log, len);

  u8 *joined = cstr.concat("con", "cat", "enate");
  printf("%s\n", joined);
  mem.free(s);
  mem.free(csv);
  mem.free(log);
  mem.free(joined);
}

concatenate

cstr.appendFormat grows its string, which may move and free the old block. Pass only heap strings from these functions (or null), never a literal or a stack buffer.

Inspecting


import cstr;

void main()
{
  printf("%d %d %d\n", cstr.len("hello"), cstr.cmp("abc", "abc"), cstr.cmp("abc", "abd") < 0);
  printf("%d %d\n", cstr.cmpLen("prefix-rest", "prefix", 6), cstr.cmpLenNoCase("ABC", "abc", 3));
  printf("%d\n", cstr.count("banana", 'a'));
  printf("%s %s\n", cstr.firstOf("key=value", "="), cstr.lastOf("a/b/c.ktm", "/"));
  printf("%d\n", cstr.toInt("1234") + 1);
}

  • The compares return negative, zero or positive like strcmp, comparing bytes as unsigned.
  • firstOf and lastOf find the first or last character that is any of the second string's.
  • null is safe: compares sort it first, the finders return null, count and toInt 0.

Copying


import cstr, mem;

void main()
{
  u8 *copy = cstr.dup("a copy");
  u8 *part = cstr.dupLen("truncate me", 8);    // like strndup
  u8 buf[16];
  cstr.copy(buf, "fixed");                      // into your buffer
  printf("[%s] [%s] [%s]\n", copy, part, buf);
  mem.free(copy);
  mem.free(part);
}

[a copy] [truncate] [fixed]

Walking bytes


import cstr;

void main()
{
  u8 *text = "hello world";
  i64 vowels = 0;
  for (u8 *c = text; *c; c++) {
    if (*c == 'e' || *c == 'o') { vowels++; }
  }
  printf("%d vowels, %d as a slice\n", vowels, cstr.view(text).len);
}

3 vowels, 11 as a slice
