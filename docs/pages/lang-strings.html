Strings

Text you own is a String. Text you only read is a u8[]. C strings (u8 *) are there for C.

TypeWhat it isUse it for
StringPointer, length, capacity (24 bytes). Owned, growable, always NUL-terminatedText you build or keep
u8[]Pointer and length (16 bytes). A viewParameters, parts of text, literals
u8 *A pointer to NUL-terminated bytesC functions

String: make it, free it

A String you get is yours. Free it where you made it, with defer:


import str;

void main()
{
  String s = str.from("Hello");
  defer s.free();
  s.append(", world");
  s.appendFormat(" %d", 2026);
  printf("%s (%d bytes)\n", s, s.len);
}

Hello, world 2026 (17 bytes)

Or declare it with ad, which frees it at the end of the scope:


import str;

void main()
{
  ad String name = str.format("user-%03d", 7);
  name.toUpper();
  printf("%s\n", name);
}

USER-007

Ways to make one


import str;

void main()
{
  ad String a = str.new();             // empty, nothing allocated yet
  ad String b = str.from("copied");    // a copy of any u8[]
  ad String c = str.withCap(64);       // empty, room for 64 bytes
  ad String d = str.format("%d-%s", 42, "x");
  String e;                            // a declared String is empty too
  a.append("grown");
  printf("[%s] [%s] [%s] [%s] [%d]\n", a, b, c, d, e.len);
}

[grown] [copied] [] [42-x] [0]

Changing it


import str;

void main()
{
  ad String s = str.from("found 3 files");
  s.insert(0, "> ");
  s.replace("files", "logs");
  s.append(" in /tmp");
  s.appendByte('!');
  printf("%s\n", s);
  s.remove(0, 2);                // bytes 0 up to 2
  s.toUpper();
  printf("%s\n", s);
  s.reverse();
  printf("%s\n", s);
  s.clear();
  printf("[%s] %d\n", s, s.len);
}

> found 3 logs in /tmp!
FOUND 3 LOGS IN /TMP!
!PMT/ NI SGOL 3 DNUOF
[] 0

Reading it

A String converts to a u8[], so every function that reads text takes a literal, a slice or a String.


import str;

void main()
{
  ad String s = str.from("Hello, world");
  u8[] hello = s[0:5];           // a view into s
  printf("%s %c %d\n", hello, s[7], s.len);
  printf("%d %d %d\n", s.startsWith("Hell"), s.find("world"), s.contains("xyz"));
  printf("%d\n", s.equals("Hello, world"));
}

Hello w 12
1 7 0
1

All the reading functions (find, trim, split, ...) are on the Strings library page.

Copies share bytes

Assigning a String copies its three fields, so both names point at the same bytes. Only one of them may free it. Use clone() for a copy of its own.


import str;

void main()
{
  ad String a = str.from("shared");
  String alias = a;           // the same bytes: don't free both
  ad String own = a.clone();  // a copy of its own
  own.toUpper();
  printf("%s %s %s\n", a, alias, own);
}

shared shared SHARED
  • free() empties the String it is called on, so freeing the same variable twice does nothing.
  • A double free through a copy is caught by -Memsafe.
  • A view (s[a:b]) is valid until the String changes or is freed.
  • A String's fields are read-only outside the str module.

Bytes, not characters

s.len and s[i] count bytes. The bytes are UTF-8 by convention.


import str;

void main()
{
  u8[] word = "naïve";
  printf("%d bytes, %d characters\n", word.len, str.runeCount(word));
}

6 bytes, 5 characters

Literals are read-only

A write the compiler can see is an error. One it can't see crashes at run time. Copy first:

Error

u8[] a = "abc";
a[0] = 'x';

Fine

String a = str.from("abc");
a[0] = 'x';

The message says it: "`a` is a string literal, which is read-only: copy it with str.from(...)".

C strings

A NUL-terminated u8 * is what C functions take and return.


import cstr, str;

void main()
{
  ad String s = str.from("for C");
  u8 *c = s.cstr();               // a String as a C string: free
  u8[] back = cstr.view(c);       // a C string as a u8[]: measured once
  printf("%s %d\n", c, back.len);
}

for C 5

A u8 array initialised from a string gets its own writable copy:


void main()
{
  u8 buf[] = "abc";        // 4 bytes: a, b, c, NUL
  u8 name[8] = "hi";       // the 6 bytes after "hi" are zero
  buf[0] = 'X';
  printf("%s %d %s %d\n", buf, sizeof(buf), name, sizeof(name));
}

Xbc 4 hi 8

The cstr module has the classic C string helpers: C strings.

printf and %s

In a literal format, %s takes a C string, a slice or a String. A width works (%-10s); a precision doesn't (the length is the slice's).


import str;

void main()
{
  ad String s = str.from("ktm");
  u8[] part = "language"[0:4];
  printf("[%-6s][%6s][%s]\n", s, part, "c string");
}

[ktm   ][  lang][c string]

A format that isn't a literal can't take a slice: pass s.cstr().
