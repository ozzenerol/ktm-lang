Processes

Run a program by its argument list, with no shell: every argument arrives exactly as written, so nothing needs quoting. Then talk to it through pipes.

At a glance

u8 *argv[] = {"ls", "-l", path, null};       // null-terminated
String out = proc.run(argv, &code);          // run, capture stdout, get the exit code

proc.Opts o;  mem.set(&o, 0, sizeof(proc.Opts));
o.in = proc.PIPE;  o.out = proc.PIPE;
proc.Proc *p = proc.spawn(argv, &o);
proc.communicate(p, input, &out, &err);      // write, read both, wait
proc.release(p);

proc.run

Runs a program found in $PATH, returns what it printed (minus one trailing newline) and its exit code.


import proc;

void main()
{
  u8 *argv[] = {"printf", "%s|", "it's $HOME", "a b", null};
  i64 code;
  ad String out = proc.run(argv, &code);
  printf("[%s] exit %d\n", out, code);
}

[it's $HOME|a b|] exit 0

No shell saw $HOME or the space: the program got them as they are.

import os, proc;

void main()

proc.spawn and pipes

For more control, proc.spawn(argv, &opts) starts the program and returns a proc.Proc. Zero the proc.Opts first: every field is optional.

Opts fieldValues
in, out, errproc.INHERIT (ours, the default), proc.PIPE, proc.DEVNULL, proc.FD; err also proc.STDOUT (2>&1)
inFd, outFd, errFdYour fd, with proc.FD
cwdThe directory to start in
envA null-terminated "NAME=value" list that replaces the environment
newGroup, pgidA new process group, or an existing one
dups, ndupsMore fds for the child, as pairs {from, to, ...}
 

import mem, proc;

void main()
{
  u8 *argv[] = {"sh", "-c", "tr a-z A-Z; echo done >&2; exit 3", null};
  proc.Opts opts;
  mem.set(&opts, 0, sizeof(proc.Opts));
  opts.in = proc.PIPE;
  opts.out = proc.PIPE;
  opts.err = proc.PIPE;
  proc.Proc *p = proc.spawn(argv, &opts);
  ad String out, err;
  i64 code = proc.communicate(p, "hello\n", &out, &err);
  printf("out=[%s] err=[%s] exit=%d\n", out.trimEnd(), err.trimEnd(), code);
  proc.release(p);
}

out=[HELLO] err=[done] exit=3

Working with a Proc

CallDoes
proc.communicate(p, input, &out, &err)Writes the input, reads both outputs to the end, waits. One poll() loop, so it can't deadlock. null drops an output
proc.wait(p)The exit code, or -1 if a signal killed it (p.termSignal)
proc.done(p)Whether it has ended, without waiting
proc.kill(p, sig)Sends a signal (SIGTERM by default)
proc.release(p)Closes the pipes and frees it, waiting if it still runs
proc.disown(p)Frees it without waiting, when you reap children yourself
 

import libc, proc;

void main()
{
  u8 *argv[] = {"sleep", "10", null};
  proc.Proc *p = proc.spawn(argv);
  printf("done yet: %d\n", proc.done(p));
  proc.kill(p);
  printf("exit %d, signal %d\n", proc.wait(p), p.termSignal == libc.SIGTERM);
  proc.release(p);
}

done yet: 0
exit -1, signal 1

Options: directory and environment


import mem, proc;

void main()
{
  u8 *argv[] = {"sh", "-c", "echo $GREETING from $(pwd)", null};
  u8 *env[] = {"GREETING=hello", "PATH=/usr/bin:/bin", null};
  proc.Opts o;
  mem.set(&o, 0, sizeof(proc.Opts));
  o.out = proc.PIPE;
  o.cwd = "/";
  o.env = env;
  proc.Proc *p = proc.spawn(argv, &o);
  ad String out;
  proc.communicate(p, "", &out);
  printf("%s", out);
  proc.release(p);
}

hello from /

Pipelines

Connect programs the way a shell's a | b | c does: proc.pipe(fds) makes a pipe, each stage gets the read end before it and the write end after it, and you close your copies once all are started.


import libc, mem, proc;

proc.Proc *stage(u8 *script, i32 in, i32 out, i32 pgid)
{
  u8 *argv[] = {"sh", "-c", script, null};
  proc.Opts o;
  mem.set(&o, 0, sizeof(proc.Opts));
  if (in >= 0) { o.in = proc.FD; o.inFd = in; }
  if (out >= 0) { o.out = proc.FD; o.outFd = out; } else { o.out = proc.PIPE; }
  if (pgid) { o.pgid = pgid; } else { o.newGroup = true; }
  return proc.spawn(argv, &o);
}

void main()
{
  i32 ab[2], bc[2];
  proc.pipe(ab);
  proc.pipe(bc);
  proc.Proc *a = stage("printf 'pear\napple\npear\n'", -1, ab[1], 0);
  proc.Proc *b = stage("sort", ab[0], bc[1], a.pgid);
  proc.Proc *c = stage("uniq -c | tr -s ' '", bc[0], -1, a.pgid);
  libc.close(ab[0]);
  libc.close(ab[1]);
  libc.close(bc[0]);
  libc.close(bc[1]);

  ad String out;
  proc.communicate(c, "", &out);
  printf("%s", out);
  printf("one group: %d\n", b.pgid == a.pid && c.pgid == a.pid);
  proc.release(a);
  proc.release(b);
  proc.release(c);
}

 1 apple
 2 pear
one group: 1
  • The later stages join the first one's group (p.pgid), so proc.kill on any stage, or Ctrl-C with the group in the foreground, reaches all of them.
  • The child starts with default signal handlers and only stdin, stdout, stderr (and dups) open.

Waiting in a coroutine loop

In a coroutine loop, coro.waitChild(p.pid, ms) waits for a child without blocking the thread; proc.setStatus(p, st) then fills in p.exitCode. Outside a loop, proc.exitFd(pid) is an fd that polls readable when the child exits.
