1. Hello, Shelf

A project with one file and a server that answers on /. Ten lines, and already a real HTTP/1.1 server that uses every core.

The project

$ mkdir shelf && cd shelf
$ ktm mod init example.com/shelf
ktm: created ktm.mod for example.com/shelf

ktm.mod names the project and the ktm version it needs. Later chapters add the packages it uses there.

main.ktm

import net.http;

void hello(http.Writer *w, http.Request *r)
{
    w.text(200, "Hello from Shelf!\n");
}

i32 main()
{
    http.Mux mux;
    mux.handle("GET /{$}", &hello);
    printf("Shelf listening on http://localhost:8080\n");
    return http.listen(8080, &mux);
}
  • import net.http; brings in the HTTP module; its names are used as http.X.
  • A handler is a function that takes the reply being built (http.Writer *w) and the request (http.Request *r). w.text(200, ...) sets the status and a plain-text body, with printf's formatting.
  • http.Mux routes requests to handlers. A pattern is a method and a path, as in Go: "GET /{$}" is GET on exactly / (a plain "GET /" would match every path).
  • http.listen serves until the program gets Ctrl-C or SIGTERM, then finishes the requests in flight and returns.

Run it

$ ktm run .
Shelf listening on http://localhost:8080

In another terminal:

$ curl -i localhost:8080/
HTTP/1.1 200 OK
Date: Wed, 14 Oct 2026 15:19:45 GMT
Content-Length: 18
Content-Type: text/plain; charset=utf-8

Hello from Shelf!

$ curl -i localhost:8080/nope
HTTP/1.1 404 Not Found
...
$ curl -i -X POST localhost:8080/
HTTP/1.1 405 Method Not Allowed
Allow: GET, HEAD
...

The mux answers what has no route by itself: 404 for a path it doesn't know, 405 (with the methods it would take) for a known path with the wrong method. HEAD works wherever GET does.

What you have

ktm run . compiles main.ktm and runs it; ktm build makes a binary, ./shelf, to copy anywhere. The server runs one event loop per CPU core, each handling thousands of connections with coroutines, so this is already the server Shelf keeps: the next chapters only add routes.
