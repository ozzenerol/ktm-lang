Example projects

Three complete programs in docs/examples/, each with the exact output it should produce. They double as tests: docs/examples/run.sh builds every project, runs it both compiled and in the JIT, and compares the output with its expected.txt.

docs/examples/run.sh          # all projects
docs/examples/run.sh life     # just one

Word frequency

Reads a text file and prints its most common words. It shows reading a file, scanning characters, counting with a map.StrMap, ranking with a vec.PtrVec's sort, and reading command-line arguments.

cd docs/examples/wordfreq
ktm main.ktm -o wordfreq && ./wordfreq sample.txt

Bank

Accounts with monthly interest and a transaction log. A savings account inherits from Account and swaps in its own interest function through a function pointer. Errors are exceptions, and a failed transfer rolls itself back. Money is kept in integer cents, so no rounding errors creep in.

cd docs/examples/bank
ktm main.ktm -o bank && ./bank

Game of Life

Conway's Game of Life on a small board that wraps at the edges, with a glider and a blinker. It shows 2D arrays, nested loops, % for wrap-around and mem.copy on whole arrays.

cd docs/examples/life
ktm main.ktm -o life && ./life

More examples in the repository

The compiler's own test suite, src/tests/, has more than 300 small programs, one per feature or fixed bug: threads, sockets, JSON, SQLite, fuzzy matching and more. The standard library in src/std/ is all ktm too, and worth reading.
