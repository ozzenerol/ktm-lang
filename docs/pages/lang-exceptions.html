Exceptions

throw an error, catch it any number of calls up. Every throw carries an Error.

At a glance

throw(MyErr.full);                          // a code, empty message
throw(MyErr.full, "need %d bytes", n);      // a code and a formatted message
try { ... } catch (Error e) { e.code; e.message; e.file; e.line; }
try { ... } catch { ... }                   // without the error
throw(e);                                   // rethrow, unchanged

The Error struct

Every program has it, from the prelude:

struct Error { i64 code; u8 *message; u8 *file; i32 line; };

The code is usually an enum member. The compiler fills in the file and line of the throw.

Throwing and catching


enum BankError { funds, locked };

void withdraw(i64 balance, i64 amount)
{
  if (amount > balance) {
    throw(BankError.funds, "need %d, have %d", amount, balance);
  }
  printf("withdrew %d\n", amount);
}

void main()
{
  try {
    withdraw(100, 30);
    withdraw(100, 500);
    printf("never printed\n");
  } catch (Error e) {
    if (e.code == BankError.funds) {
      printf("insufficient funds: %s\n", e.message);
    }
  }
  printf("carrying on\n");
}

withdrew 30
insufficient funds: need 500, have 100
carrying on
  • The message format and its arguments are checked like printf's.
  • e.message is never null: it is "" without a message.
  • e.message is freed when the catch block ends. Keep it with cstr.dup(e.message).

Through any number of calls

A throw unwinds to the nearest enclosing try, running the defers on the way.


enum Err { bad };

void level3() { throw(Err.bad, "deep down"); }
void level2() { defer printf("level2 cleans up\n"); level3(); }
void level1() { level2(); printf("not printed\n"); }

void main()
{
  try {
    level1();
  } catch (Error e) {
    printf("caught: %s (line %d)\n", e.message, e.line);
  }
}

level2 cleans up
caught: deep down (line 3)

Rethrowing

throw(e) throws the same error again, with its original message, file and line.


enum Err { notFound, denied };

void open(u8 *path)
{
  if (path[0] != '/') { throw(Err.notFound, "%s: no such file", path); }
  throw(Err.denied, "%s: permission denied", path);
}

void openOrSkip(u8 *path)
{
  try {
    open(path);
  } catch (Error e) {
    if (e.code == Err.notFound) {
      printf("skipping: %s\n", e.message);
      return;
    }
    throw(e);           // not ours to handle
  }
}

void main()
{
  try {
    openOrSkip("notes.txt");
    openOrSkip("/etc/shadow");
  } catch (Error e) {
    printf("fatal: %s\n", e.message);
  }
}

skipping: notes.txt: no such file
fatal: /etc/shadow: permission denied

Catching without the error


enum Err { any };

void main()
{
  try {
    throw(Err.any);
  } catch {
    printf("something went wrong\n");
  }
}

something went wrong

Leaving a try early

return, break, continue and goto may leave a try at any depth. The tries left behind stop catching.


enum Err { late };

i64 find(i64[] items, i64 want)
{
  for (i64 i = 0; i < items.len; i++) {
    try {
      if (items[i] == want) { return i; }
      if (items[i] < 0) { break; }
    } catch {
    }
  }
  return -1;
}

void main()
{
  i64 items[4] = {3, 7, -1, 9};
  try {
    printf("%d %d\n", find(items, 7), find(items, 9));
    throw(Err.late);
  } catch {
    printf("caught here, not in find\n");
  }
}

1 -1
caught here, not in find

The library throws too

Bounds checks, JSON decoding and others throw. ERR_BOUNDS is in the prelude; the others are module constants.


import json, vec;

struct Config { i64 port; };

void main()
{
  ad vec.Vec v = vec.new();
  try {
    v.get(5);
  } catch (Error e) {
    printf("%d: %s\n", e.code == ERR_BOUNDS, e.message);
  }
  try {
    Config c = json.decode("{\"port\": \"eighty\"}");
  } catch (Error e) {
    printf("%d: %s\n", e.code == json.ERR_DECODE, e.message);
  }
}

1: vec.Vec.get: index 5 of 0
1: 1:10: port: expected an integer, got a string

Uncaught errors

An error no try catches, in any thread, is printed on stderr with the calls that led to the throw, and ends the program with exit code 1:

i64 balance = 100;

void withdraw(i64 amount)
{
  if (amount > balance) {
    throw(0, "need %d, have %d", amount, balance);
  }
  balance -= amount;
}

void main()
{
  withdraw(30);
  withdraw(500);
}
uncaught error 0: need 500, have 70 (bank.ktm:6)
  at bank.ktm:6 in withdraw
  called from bank.ktm:14 in main
  • The calls are those of the last throw: an error caught and thrown on with throw(e) (a coroutine's, which coro.run throws on) shows where it was thrown on. The first line keeps the file and line of its first throw.
  • The calls are listed as a crash lists them (see Crashes), in compiled programs and -jit alike.

Details

  • The code converts like an argument to an integer parameter: throw(42.75) throws 42.
  • A throw inside a catch block goes to the next enclosing try.
  • Each thread has its own chain: a throw is caught only by a try of its own thread.
  • A try may span a coroutine's yield.
  • A try costs no system call: it saves registers, not the signal mask. So a throw out of a signal handler leaves that signal blocked.
