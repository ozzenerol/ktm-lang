ktm

A compiled language for systems programming and networking: REST microservices, network daemons and system tools, on Linux and macOS.

C-like, with modules, methods, default arguments and exceptions; an ahead-of-time compiler, a JIT, a REPL and a language server in one binary.

Why ktm

C, minus the sharp edgesSlices with checked indexes, owned Strings, defer, exceptions, modules. No headers, no macros with arguments. Made for serversSockets, a coroutine loop on io_uring, epoll or kqueue, and coro.serve on every core. Fast to tryA JIT and a REPL in the same binary as the compiler: run a file or a script with no build step. Batteries includedJSON, YAML, CSV, processes, hashing, dates, generic containers. C is one line awayextern "c" and #link; the C library is already declared. Editor supportA language server with completion, hover, rename and inlay hints.

What it looks like

A request and a reply

A server and a client on loopback in one program: the sockets library speaks TCP, UDP and Unix sockets, IPv4 and IPv6.


import libc, net, str;

void main()
{
  i32 srv = net.listen(0, "127.0.0.1", 4);
  i32 cli = net.dial("127.0.0.1", net.localPort(srv));
  i32 conn = net.accept(srv);
  u8 buf[256];

  net.send(cli, "GET /hello HTTP/1.0\r\n\r\n");

  i64 n = libc.recv(conn, buf, sizeof(buf), 0);      // the server side
  u8[] line, rest, path, version;
  str.splitFirst(buf[0:n], "\r\n", &line, &rest);
  str.splitFirst(line[4:], " ", &path, &version);     // after "GET "
  String reply = str.format("HTTP/1.0 200 OK\r\n\r\nyou asked for %s\n", path);
  defer reply.free();
  net.send(conn, reply);
  libc.close(conn);

  n = libc.recv(cli, buf, sizeof(buf), libc.MSG_WAITALL);  // the client side
  u8[] head, body;
  str.splitFirst(buf[0:n], "\r\n\r\n", &head, &body);
  printf("%s", body);
  libc.close(cli);
  libc.close(srv);
}

you asked for /hello

Running a program

proc.run runs a command and returns what it printed; proc.spawn gives you its pipes.


import proc;

void main()
{
  u8 *argv[] = {"echo", "hello from a child process", null};
  i64 code;
  String out = proc.run(argv, &code);
  defer out.free();
  printf("%s\n", out);
  printf("exit code %d\n", code);
}

Threads

POSIX threads directly, or a thread pool from the library.


import libc;

i64 sums[4];

void *sum(void *arg)
{
  i64 part = (i64)arg, total = 0;
  for (i64 i = part * 250 + 1; i <= (part + 1) * 250; i++) { total += i; }
  sums[part] = total;
  return null;
}

void main()
{
  libc.pthread_t *th[4];
  i64 i, total = 0;
  for (i = 0; i < 4; i++) { libc.pthread_create(&th[i], null, &sum, (void *)i); }
  for (i = 0; i < 4; i++) {
    libc.pthread_join(th[i]);
    total += sums[i];
  }
  printf("1 + 2 + ... + 1000 = %d\n", total);
}

A taste of the language

Structs with inheritance, default arguments and ranges in case.


struct Animal
{
  u8 *name;
  i64 legs;
};

struct Bird : Animal
{
  bool canFly;
};

void describe(Animal *a, u8 *sound = "...")
{
  printf("%s has %d legs and says %s\n", a.name, a.legs, sound);
}

void main()
{
  Bird b;
  b.name = "Tweety";
  b.legs = 2;
  b.canFly = true;

  describe(&b, "tweet");   // a Bird is an Animal
  describe(&b);            // default argument

  for (i64 i = 1; i <= 3; i++) {
    switch (i) {
      case 1: printf("one"); break;
      case 2 ... 3: printf(", more"); break;
    }
  }
  printf("\n");
}

What ktm is

  • A native compiler. ktm is parsed to an AST, lowered to an SSA IR and emitted as x86_64 or AArch64 assembly, which the system C compiler assembles and links.
  • A JIT. ktm -jit assembles machine code in memory with a built-in assembler and runs it, with no files written.
  • A REPL. ktm -repl runs ktm interactively.
  • A language server. ktm -lsp gives editors diagnostics, hover, completion, go-to-definition, references and rename.
  • A standard library. Strings, files, hash tables, vectors, JSON, dates, threads, sockets and more, in modules you import (import net, str;).

It runs on Linux on x86_64 and arm64 and on macOS on Apple Silicon. On Windows, use WSL2.

History and credits

ktm started as a fork of Jamesbarford/holyc-lang (BSD-2-Clause), a compiler for HolyC, the language Terry A. Davis created for TempleOS. Thanks to both: to Terry A.
