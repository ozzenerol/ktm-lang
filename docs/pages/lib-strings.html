Strings

The str module: String, the text you own, and the functions that read any text (u8[]). The language side is on Strings.

Making a String

CallGives
str.new()Empty; nothing allocated until something is added
str.from(t)A copy of any text
str.withCap(n)Empty, with room for n bytes
str.format(fmt, ...)Formatted text (format strings)
str.adopt(p, len)Takes over a mem.alloc'd block with a NUL after len bytes, without copying

Changing a String

MethodDoes
append(t), appendByte(b), appendFormat(fmt, ...)Adds at the end
insert(at, t)Inserts at a byte index
remove(a, b)Removes bytes a up to b
replace(old, new)Replaces every occurrence
toLower(), toUpper(), reverse()In place (ASCII letters)
clear(), reserve(n)Empty it (keeping its memory), make room

import str;

void main()
{
  ad String s = str.format("%d files", 3);
  s.insert(0, "found ");
  s.append(" in /tmp");
  s.replace("files", "logs");
  printf("%s (%d bytes)\n", s, s.len);

  ad String path = str.from("/var/log");
  path.appendFormat("/%s.%d", "app", 2);
  path.toUpper();
  printf("%s %s %c\n", path, path[1:4], path[5]);
}

Reading text

These take a u8[]: a literal, a slice or a String. Call them as functions or as methods: s.find("x") is str.find(s, "x").

FunctionReturns
find(s, part), findLast(s, part)The byte index, or -1
contains, startsWith, endsWithbool
equals(a, b)bool: the same bytes
compare(a, b)Negative, 0 or positive, for sorting
trim(s), trimStart(s), trimEnd(s, chars)A view without the whitespace (or the given bytes)
splitFirst(s, sep, &a, &b), splitLastbool; the views before and after
split(s, sep)A u8[][] of views, allocated: free it
 

import str;

void main()
{
  u8[] text = "the cat sat on the mat";
  printf("%d %d %d\n", text.find("the"), text.findLast("the"), text.find("dog"));
  printf("%d %d %d\n", text.contains("sat"), text.startsWith("the"), text.endsWith("hat"));
  printf("%d %d\n", str.equals("abc", "abc"), str.compare("apple", "banana") < 0);
}

0 15 -1
1 1 0
1 1

Trimming and splitting

Trimming and splitFirst return views: parts of the text you gave, nothing copied.


import str;

void main()
{
  u8[] line = "  name = ktm, lang  \r\n";
  u8[] t = line.trimEnd("\r\n").trim();
  u8[] key, value;
  if (str.splitFirst(t, " = ", &key, &value)) {
    printf("[%s] [%s]\n", key, value);
  }
  ad u8[][] parts = value.split(", ");
  for (auto p : parts) { printf("<%s>", p); }
  printf("\n");
}

[name] [ktm, lang]

split keeps empty parts:


import str;

void main()
{
  ad u8[][] parts = str.split("a,b,,c", ",");
  for (auto p : parts) { printf("[%s]", p); }
  printf(" %d parts\n", parts.len);
}

Parsing a line


import str;

void main()
{
  u8[] request = "GET /index.html HTTP/1.1";
  u8[] method, rest, path, version;
  str.splitFirst(request, " ", &method, &rest);
  str.splitFirst(rest, " ", &path, &version);
  u8[] dir, file;
  str.splitLast(path, "/", &dir, &file);
  printf("%s | %s | %s | file %s\n", method, path, version, file);
}

GET | /index.html | HTTP/1.1 | file index.html

Characters

str.toUpper(c), str.toLower(c) and str.isSpace(c) work on one byte (ASCII).


import str;

void main()
{
  printf("%c%c %d %d\n", str.toUpper('q'), str.toLower('Q'), str.isSpace('\t'), str.isSpace('x'));
}

Qq 1 0

UTF-8

len and s[i] count bytes. For characters:

  • str.decodeRune(s, &at): the code point at byte at, moving at past it. U+FFFD for bytes that aren't UTF-8, -1 at the end.
  • str.runeCount(s): the number of code points.
  • str.validUtf8(s): whether the text is valid UTF-8.

import str;

void main()
{
  u8[] s = "añb€";
  printf("%d bytes, %d runes, valid %d\n", s.len, str.runeCount(s), str.validUtf8(s));
  i64 at = 0;
  i32 r;
  while ((r = str.decodeRune(s, &at)) >= 0) { printf("[U+%04X]", r); }
  printf("\n%d\n", str.validUtf8("\xff"));
}
