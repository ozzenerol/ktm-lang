switch

Like C's switch, but cases don't fall through, a case can be a range, and you can switch on a string.

At a glance

switch (x) {
  case 1:          ...           // no break needed
  case 10 ... 19:  ...           // a range, both ends included
  case 20:
  case 21:         ...           // stacked labels share the code
  case 30:         ...; fallthrough;   // run on into the next case
  default:         ...
}

No fall-through

A case ends where the next one starts. No break is needed.


void describe(i64 n)
{
  switch (n) {
    case 0: printf("zero\n");
    case 1: printf("one\n");
    default: printf("many\n");
  }
}

void main()
{
  describe(0);
  describe(1);
  describe(7);
}

zero
one
many

break still works: it leaves the switch early.


void main()
{
  i64 n = -3;
  switch (n) {
    default:
      if (n < 0) {
        printf("negative, stop here\n");
        break;
      }
      printf("not printed\n");
  }
}

negative, stop here

Ranges

case lo ... hi: matches every value from lo to hi, both included.


void grade(i64 score)
{
  switch (score) {
    case 90 ... 100: printf("%d: A\n", score);
    case 80 ... 89:  printf("%d: B\n", score);
    case 0:          printf("%d: no score\n", score);
    default:         printf("%d: C or below\n", score);
  }
}

void main()
{
  grade(95);
  grade(83);
  grade(0);
  grade(42);
}

95: A
83: B
0: no score
42: C or below

It works on characters too:


u8 *kind(u8 c)
{
  switch (c) {
    case 'a' ... 'z': return "lower";
    case 'A' ... 'Z': return "upper";
    case '0' ... '9': return "digit";
    default:          return "other";
  }
}

void main()
{
  printf("%s %s %s %s\n", kind('q'), kind('Q'), kind('7'), kind('!'));
}

lower upper digit other

Several values, one body

Labels stacked with nothing between them share the code that follows.


u8 *dayType(i64 day)
{
  switch (day) {
    case 0:
    case 6:
      return "weekend";
    default:
      return "weekday";
  }
}

void main()
{
  printf("%s %s %s\n", dayType(0), dayType(3), dayType(6));
}

weekend weekday weekend

fallthrough

fallthrough; as the last statement of a case runs on into the next case.


void main()
{
  for (i64 i = 1; i <= 3; i++) {
    switch (i) {
      case 1: printf("one, "); fallthrough;
      case 2: printf("two or after one\n");
      default: printf("three\n");
    }
  }
}

one, two or after one
two or after one
three

It is an error anywhere else:

  • outside a switch, or before other statements of its case;
  • inside an if or a loop;
  • in the last case, where there is no next one;
  • into or out of a default that isn't the last label.

Each case is a block

A case can declare variables without braces. Two cases can use the same name.


void main()
{
  for (i64 i = 0; i < 2; i++) {
    switch (i) {
      case 0:
        i64 doubled = i * 2;
        printf("case 0: %d\n", doubled);
      case 1:
        i64 doubled = i * 2;      // another variable
        printf("case 1: %d\n", doubled);
    }
  }
}

case 0: 0
case 1: 2

A defer in a case runs at the end of that case. It needs braces: case 1: { defer ...; }.

Switching on enums


enum Color { red, green, blue };

u8 *hex(Color c)
{
  switch (c) {
    case Color.red:   return "#f00";
    case Color.green: return "#0f0";
    case Color.blue:  return "#00f";
  }
  return "?";
}

void main()
{
  printf("%s %s\n", hex(Color.green), hex(Color.blue));
}

#0f0 #00f

Switching on strings

A u8[] or a String can be switched on, with string literals as the cases. A case matches when the value has exactly its bytes: same length, case-sensitive, no trimming.


i64 run(u8[] cmd)
{
  switch (cmd) {
    case "GET":  return 1;
    case "SET":  return 2;
    case "DEL":
    case "REMOVE": return 3;
    default:     return 0;
  }
}

void main()
{
  u8[] line = "SET name ktm";
  printf("%d %d %d %d\n", run("GET"), run(line[0:3]), run("REMOVE"), run("get"));
}

1 2 3 0
  • every case is a string literal: no ranges, no bare case:, no integers;
  • a string given twice is an error (duplicate case value "GET");
  • the value is read once, so switch (readCommand()) calls the function once;
  • default, stacked labels and fallthrough work as in an integer switch.

For a case-insensitive match, switch on a lowercased copy: a String made with str.from, then s.toLower().

Two extras

Implicit case values

A bare case: is the previous case's value plus one (starting from 0).


void main()
{
  for (i64 i = 0; i < 4; i++) {
    switch (i) {
      case 0: printf("zero,");
      case:   printf("one,");      // 1
      case:   printf("two,");      // 2
      default: printf("other\n");
    }
  }
}

zero,one,two,other

Unchecked switch

switch [x] skips the range check on x. Use it only when you know x matches a case: anything else is undefined. A switch on strings always checks.


void main()
{
  for (i64 i = 0; i < 3; i++) {
    switch [i] {
      case 0: printf("a");
      case 1: printf("b");
      case 2: printf("c\n");
    }
  }
}
