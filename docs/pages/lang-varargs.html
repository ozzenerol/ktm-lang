Variable arguments

A function can take any number of extra arguments. Inside, they are a slice: no va_list.

At a glance

i64 sum(i64 ...nums)         // typed: nums is an i64[]
{ for (auto n : nums) ... }
sum();  sum(1, 2, 3);        // zero or more
f(...nums);                  // pass them all on
void log(u8 *fmt, ...args)   // untyped: 64-bit slots, for formats
void exec(u8 *sql, any ...args)  // any type: each a reflect.Value

Typed extras

T ...name as the last parameter takes any number of Ts, each checked and converted like a normal argument. Inside, name is a T[].


i64 sum(i64 ...nums)
{
  i64 total = 0;
  for (auto n : nums) { total += n; }
  return total;
}

void main()
{
  printf("%d %d %d\n", sum(), sum(5), sum(1, 2, 3, 4));
}

0 5 10

Using the slice

  • name.len is how many were passed, name[i] is one of them (bounds-checked).
  • It can be sliced and passed to a T[] parameter.
  • name itself can't be assigned.

f64 avg(f64 ...xs)
{
  if (!xs.len) { return 0; }
  f64 total = 0;
  for (i64 i = 0; i < xs.len; i++) { total += xs[i]; }
  return total / xs.len;
}

f64 first(f64[] xs) { return xs[0]; }

f64 restAvg(f64 ...xs)
{
  return avg(...xs[1:]);    // everything but the first
}

void main()
{
  printf("%.2f %.2f\n", avg(1, 2, 4), avg());   // 1, 2 and 4 become f64
  printf("%.2f\n", restAvg(100, 1, 2));
}

2.33 0.00

Fixed and default parameters first


void tag(u8 *label, u8 *sep = ", ", u8 * ...items)
{
  printf("%s:", label);
  for (i64 i = 0; i < items.len; i++) {
    printf("%s", i ? sep : " ");
    printf("%s", items[i]);
  }
  printf("\n");
}

void main()
{
  tag("fruit", , "apple", "pear");
  tag("path", "/", "usr", "lib", "ktm");
  tag("empty");
}

Passing them on

...name as the last argument of a call passes the extras on, to a function that takes the same kind. It must be the only extra argument.


i64 sum(i64 ...nums)
{
  i64 t = 0;
  for (auto n : nums) { t += n; }
  return t;
}

i64 sumTwice(i64 ...nums)
{
  return 2 * sum(...nums);
}

void main()
{
  printf("%d\n", sumTwice(1, 2, 3));
}

12

Spreading costs nothing: the extras are passed as a count and a pointer to an array the caller built.

Extras of any type

any ...name takes extras of any type, as Go's ...any. Inside, name is a reflect.Value[]: each extra's type, and the address of a copy made at the call (it lives until the calling function returns). A string literal or another array comes as a slice. It needs import reflect;.


import reflect;

struct Point { i64 x, y; };

void show(any ...args)
{
  for (auto v : args) {
    printf("%.*s", v.type.name.len, v.type.name.ptr);
    if (v.type.kind == reflect.Kind.int) { printf(" %d", *(i64 *)v.ptr); }
    printf("\n");
  }
}

void main()
{
  Point p = {1, 2};
  show(42, "text", 2.5, p, &p);
}

  • ...args passes them on to another any function.
  • A String from a call is refused (nobody would free it): put it in a variable first.
  • Libraries take it where Go takes ...any: SQL parameters, log fields.

Untyped extras, for formats

...name without a type takes each extra as a 64-bit slot, the way format functions want them. name is a u64[]: a number as is, a float as its bits, a pointer as its address.


import cstr, mem;

void logf(u8 *fmt, ...args)
{
  u8 *msg = cstr.formatArgs(null, fmt, args);   // format the extras
  printf("[log] %s\n", msg);
  mem.free(msg);
}

void main()
{
  logf("%d files in %s, %.1f%% full", 3, "/tmp", 42.5);
}

[log] 3 files in /tmp, 42.5% full

A String or a u8[] goes to such a function as it goes to printf, when its format parameter is called fmt (right before ...args): with a literal format each one's %s prints its bytes (a u8[] view only its own, no NUL needed). Anywhere else a String is passed as its C string (s.cstr()), so it works with a computed format too; a u8[] needs the literal format.


import cstr, mem, str;

void reply(u8 *fmt, ...args)
{
  u8 *msg = cstr.formatArgs(null, fmt, args);
  printf("> %s\n", msg);
  mem.free(msg);
}

void main()
{
  String user = str.from("ada");
  u8[] cmd = "GET key";
  reply("%s ran %s", user, cmd[0:3]);
  user.free();
}

> ada ran GET

Read a float back from a slot with *(f64 *)&args[i]:


void show(...args)
{
  printf("%d slots: %d and %.2f\n", args.len, args[0], *(f64 *)&args[1]);
}

void main()
{
  show(7, 2.5);
}

2 slots: 7 and 2.50

A plain ... with no name, as in extern "c" i32 printf(u8 *fmt, ...);, is C's variadic convention, for declaring C functions.
