Attributes

An attribute, @name or @name("text"), before a struct, a field or a parameter tells the compiler to write code for it.

AttributeGoes beforeDoes
@jsona structWrites toJson, fromJson, freeDecoded
@yamla structWrites toYaml, fromYaml (and freeDecoded)
@key("name")a fieldThe field's key in the text
@skipa fieldLeaves it out
@omitEmptya fieldLeaves it out when it is 0, empty or null
@caller("file"), ("line"), ("func")a parameterEvery call fills it with where the call is written: Where a call comes from

An example

The struct's file must import json (or yaml).


import json;

@json
struct User {
  i64 id;
  @key("e-mail") String email;
  @omitEmpty String nickname;
  @skip i64 cacheHits;
};

void main()
{
  User u = json.decode("{\"id\": 7, \"e-mail\": \"ada@example.com\"}");
  defer u.freeDecoded();
  u.cacheHits = 99;

  json.Writer w = json.writerNew();
  defer w.free();
  u.toJson(&w);
  String text = w.take();
  defer text.free();
  printf("%s\n", text);
}

{"id":7,"e-mail":"ada@example.com"}

Attributes in reflection

Field.key is the key a field is written under: its @key, or its name.


import json, reflect;

@json
struct Item {
  @key("item-id") i64 id;
  @skip i64 internal;
};

void main()
{
  reflect.Type *t = reflect.typeOf(Item);
  printf("json: %d\n", t.json);
  for (auto f : t.fields) {
    printf("%s key=[%s] skip=%d\n", f.name, f.key, f.skip);
  }
}

json: 1
id key=[item-id] skip=0
internal key=[internal] skip=1

Rules

  • @json and @yaml go before the struct, and before pub: @json pub struct User { ... }.
  • They go on the definition, not on a declaration ahead (struct User;).
  • An unknown attribute, or one in the wrong place, is a compile error.
  • A field type that can't be written (a union, a function, a struct without @json) is an error at that field: mark it @skip.
