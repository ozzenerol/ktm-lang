defer and ad

defer runs a statement when its block is left, however it is left. ad frees a variable at the end of its scope. Clean-up stays next to the code that needs it.

At a glance

u8 *buf = mem.alloc(64);
defer mem.free(buf);              // runs when this block ends
defer { a(); b(); }               // a block works too

ad String s = str.from("x");      // = String s = ...; defer s.free();
ad vec.Vec v = vec.new();

defer


import mem;

void work()
{
  u8 *buf = mem.alloc(64);
  defer { mem.free(buf); printf("freed\n"); }
  printf("working\n");
}

void main()
{
  work();
}

freed

Every way out

A defer runs at the end of the block, on return, break, continue, a goto out, and when a throw passes through.


enum Err { neg };

i64 check(i64 n)
{
  defer printf("  check(%d) done\n", n);
  if (n < 0) { throw(Err.neg); }
  if (n == 0) { return 0; }
  return n * 2;
}

void main()
{
  printf("%d\n", check(5));
  printf("%d\n", check(0));
  try {
    check(-1);
  } catch {
    printf("caught\n");
  }
}

  check(5) done
10
  check(0) done
0
  check(-1) done
caught

Order

Several defers in a block run last first. Inner blocks finish before outer ones.


void main()
{
  defer printf("outer\n");
  {
    defer printf("1st registered, runs last\n");
    defer printf("2nd registered, runs first\n");
  }
  printf("between\n");
}

2nd registered, runs first
1st registered, runs last
between
outer

The scope is the block

Not the function: in a loop body, it runs at the end of every iteration.


void main()
{
  for (i64 i = 0; i < 3; i++) {
    defer printf("end of %d\n", i);
    if (i == 1) { continue; }
    printf("body %d\n", i);
  }
}

body 0
end of 0
end of 1
body 2
end of 2

It runs as written, later

The statement sees the values variables have when the block ends. return evaluates its value first.


import mem;

i64 first(i64 n)
{
  i64 *buf = mem.alloc(n * sizeof(i64));
  defer mem.free(buf);
  buf[0] = 42;
  return buf[0];          // read before the free
}

void main()
{
  i64 x = 1;
  {
    defer printf("x is %d\n", x);
    x = 2;
  }
  printf("%d\n", first(4));
}

x is 2
42

Only if reached

A defer written after an early return doesn't run on that return.


void f(bool early)
{
  if (early) { return; }
  defer printf("deferred\n");
  printf("late part\n");
}

void main()
{
  f(true);
  f(false);
}

late part
deferred

ad

ad in front of a declaration means defer name.free(); right after it. It works for a String, any slice, and any struct with a free() method that takes no arguments (or a pointer to one). An @json or @yaml struct with no free() of its own is freed with its freeDecoded().


import str;

struct Conn { i64 fd; };
void Conn.free() { printf("closing %d\n", self.fd); }

void main()
{
  ad String name = str.from("Lorenzo");
  ad u8[][] words = str.split("a b c", " ");
  ad Conn c = {7};
  printf("%s has %d words\n", name, words.len);
}

Lorenzo has 3 words
closing 7

The library's containers all have free(), so ad is the usual way to hold them:


import map, set, vec;

void main()
{
  ad vec.Vec v = vec.new();
  ad map.Map m = map.new();
  ad set.Set s = set.new();
  v.push(1);
  m.set("a", 1);
  s.add(1);
  printf("%d %d %d\n", v.len, m.len, s.len);
}

1 1 1

The variable can be declared first and filled in later, as when it is decoded into:


import json;

@json struct User { String name; i64 age; };

void main()
{
  ad User u;                  // empty for now, u.freeDecoded() at the end
  u = json.decode("{\"name\": \"ada\", \"age\": 36}");
  printf("%s is %d\n", u.name, u.age);
}

ada is 36

ad rules

  • Returning an ad variable is an error: it would be freed. Declare it without ad to hand it to the caller.
  • A type with no such free() is an error.
  • Without a value an ad variable starts zeroed, as every local does: an empty String, slice or container, freed by its free() like any other (the library's all take an empty value). An ad pointer with no value is null and is freed only if it holds something by the end of its block.
  • A copy of an ad variable shares what it points to, and is freed with the original.
  • ad goes on a local variable, not a field. It is not reserved: a variable can be called ad.

import str;

String greeting(u8[] who)
{
  String s = str.format("hello, %s", who);   // no ad: the caller frees it
  return s;
}

void main()
{
  ad String g = greeting("ada");             // the caller's ad
  printf("%s\n", g);
}

hello, ada

Rules for defer

  • A defer must be a statement of a { } block: directly after a case label, add braces.
  • A deferred statement can't return, break, continue or goto out of itself, or contain a label. A loop inside it keeps its own break.
  • A goto can't jump past a defer into the rest of its block.
  • A throw from a deferred statement goes on like any other throw.
  • Returning from main runs its defers. os.exit() and a crash don't.
  • Switching coroutines doesn't leave a block, so it runs no defers.
  • Only functions that use defer pay for it.
