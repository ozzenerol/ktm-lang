Validation

validate checks a struct's values against rules written on its fields: @required, @min, @max, @email, @url and @oneOf. Every broken rule is one error naming its field, ready to show a user or send back from an API.


import reflect, str, validate;

struct Signup {
  @required @email u8[] email;
  @required @min(3) @max(20) String name;
  @min(18) i64 age;
  @oneOf("free", "pro") u8[] plan;
};

void main()
{
  Signup s;
  s.email = "ann@example";
  s.name = str.from("an");
  s.age = 17;
  s.plan = "gold";

  validate.Errors errs;
  if (!validate.check(reflect.of(s), &errs)) {
    for (auto e : errs.items) {
      printf("%s: %s\n", e.field, e.message);
    }
  }
  errs.free();

  s.email = "ann@example.com";
  s.name.free();
  s.name = str.from("Ann");
  s.age = 30;
  s.plan = "";                   /* empty and not @required: fine */
  printf("valid: %d\n", validate.check(reflect.of(s), &errs));
  errs.free();
  s.name.free();
}

email: not an email address
name: must have at least 3 characters
age: must be at least 18
plan: must be one of free, pro
valid: 1

validate.check(reflect.of(x), &errs) answers true when every rule holds. It replaces what errs held, so one Errors can serve several checks; free it once at the end.

The rules

AttributeOnHolds when
@requiredany fieldThe value isn't 0, false, "", an empty slice or null
@min(n), @max(n)a numberIts value is at least / at most n (@min(-10), @max(0.5) work too)
String, u8[]Its length in characters (UTF-8 code points, not bytes) is at least / at most n
a sliceIt has at least / at most n items
@emailString, u8[]It looks like name@example.com: one @, a domain with a dot, no spaces
@urlString, u8[]It is an absolute URL with a host: https://example.com/a
@oneOf("a", "b")String, u8[]It is exactly one of the values
  • A text or slice that is empty and not @required passes its other rules: they check a value when there is one. A number is always checked (0 with @min(1) fails).
  • Nested structs are checked too, and so are the structs a pointer field points to and the items of a slice of structs. A null pointer is skipped unless it is @required.
  • @skip fields and private ones are left alone.
  • A rule on a field it can't check (@email on an i64) is a mistake in the program: check throws validate.ERR_VALIDATE.
  • The rules go on any struct, with or without @json; @required is the same attribute config reads.

Errors

Each error is a validate.FieldError with a field and a message (both Strings), in the order of the struct's fields. The field is named the way a client sent it: its JSON key (@key("e-mail")'s when it has one), with the path for nested values: address.city, tags[2].name.

CallWhat it gives
errs.itemsThe errors (a vec.Vec: errs.items.len, for (auto e : errs.items))
errs.message()One line: email: not an email address; age: must be at least 18 (a String to free)
errs.toJson(){"error":"invalid request","fields":[{"field":"age","message":"must be at least 18"}]} (a String to free)
errs.add(field, fmt, ...)Adds an error of your own, for a check the rules can't express
errs.free()Frees them all
validate.isEmail(s), validate.isUrl(s)The @email and @url checks on their own

In an HTTP handler

http.decodeValid<T>(r) decodes the request's body as JSON (as http.decode does) and checks it. A body that breaks a rule never reaches the rest of the handler: the server answers 422 with errs.toJson()'s list, and bad JSON gets the usual 400.


@json struct NewBookmark {
  @required @url String url;
  @required @max(200) String title;
  @max(10) u8[][] tags;
};

void createBookmark(http.Writer *w, http.Request *r)
{
  NewBookmark b = http.decodeValid(r);
  ...                                  // b is valid here
}

POST /bookmarks {"url":"nope","title":"ktm"}
422 {"error":"invalid request","fields":[{"field":"url","message":"not a URL"}]}

The same answer comes from a Mux in a test (http.testRequest and http.recorder()), so the 422 can be checked without a server. For a check of your own on top of the rules, call validate.check yourself, errs.add what else is wrong, and reply with w.jsonText(422, ...) of errs.toJson().
