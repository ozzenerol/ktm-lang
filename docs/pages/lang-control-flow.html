Control flow

if, loops, range-based for and goto. switch has its own page.

At a glance

if (x > 0) { ... } else if (x < 0) { ... } else { ... }
if (i64 n = count(); n > 5) { ... }    // n lives only in the if
while (cond) { ... }
do { ... } while (cond);
for (i64 i = 0; i < n; i++) { ... }
for (i = 0, j = n; i < j; i++, j--) { ... }   // several, comma-separated
for (auto x : items) { ... }           // arrays, slices, vectors
if x > 0 { ... }                       // the parentheses are optional
for i64 i = 0; i < n; i++ { ... }

Braces are required

The body of if, else, for, while and do is always a { } block. else if is the one exception.

Error

if (x) y = 1;

ktm

if (x) { y = 1; }

Parentheses are optional

The condition of if, while, do ... while, for and switch can be written with or without parentheses, as in C or as in Go. Both mean the same, and one program can mix them. Without parentheses the condition runs up to the { of the body. for also has Go's for cond { } (a while) and for { } (for ever).


void main()
{
  i64 a = 1, b = 2;
  if a < b { printf("a is smaller\n"); }
  if (a + b) * 2 > 5 { printf("a parenthesised start is fine\n"); }

  i64 n = 0, xs[2] = {4, 5};
  while n < 3 { n++; }
  for i64 i = 0; i < 2; i++ { printf("i=%d ", i); }
  for auto x : xs { printf("x=%d ", x); }
  for n > 0 { n--; }
  for {
    n++;
    if n == 2 { break; }
  }
  printf("\nn=%d\n", n);
  switch n {
    case 2: printf("two\n"); break;
    default: printf("other\n");
  }
}

An initialiser in the if

A declaration can come before the condition. It is visible only in the if and its else.


i64 lookup(u8 *key) { return key[0] == 'a' ? 42 : -1; }

void main()
{
  if (i64 v = lookup("apple"); v >= 0) {
    printf("found %d\n", v);
  } else {
    printf("missing\n");
  }
  if (i64 v = lookup("kiwi"); v >= 0) {
    printf("found %d\n", v);
  } else {
    printf("missing (v is %d)\n", v);
  }
}

found 42
missing (v is -1)

Loops


void main()
{
  i64 i = 0;
  while (i < 3) {
    printf("w%d,", i);
    i++;
  }
  do {
    printf("d%d,", i);
    i--;
  } while (i > 0);
  printf("\n");

  for (i64 j = 0; j < 10; j++) {
    if (j == 2) { continue; }   // skip 2
    if (j == 5) { break; }      // stop at 5
    printf("f%d,", j);
  }
  printf("\n");
}

Nested loops

break and continue act on the innermost loop. To leave several at once, use goto or a function and return.


void main()
{
  for (i64 row = 0; row < 3; row++) {
    for (i64 col = 0; col < 3; col++) {
      if (col > row) { break; }
      printf("(%d,%d)", row, col);
    }
  }
  printf("\n");
}

(0,0)(1,0)(1,1)(2,0)(2,1)(2,2)

Range-based for

for (T x : items) runs once per element. It works on:

  • fixed-size arrays,
  • slices (T[]), Strings included,
  • any struct with data and len fields (or entries and size), such as vec.Vec.

import vec;

void main()
{
  i64 primes[] = {2, 3, 5, 7, 11};
  i64 sum = 0;
  for (auto p : primes) { sum += p; }
  printf("sum = %d\n", sum);

  u8[] word = "ktm";
  for (u8 c : word) { printf("[%c]", c); }
  printf("\n");

  ad vec.Vec v = vec.new();
  v.push(1.5);
  v.push(2.5);
  for (f64 x : v) { printf("<%.1f>", x); }
  printf("\n");
}

The loop variable is a copy. To change the elements, loop over the index:


void main()
{
  i64 nums[] = {1, 2, 3};
  for (auto n : nums) { n *= 10; }          // changes the copy only
  printf("%d %d %d\n", nums[0], nums[1], nums[2]);
  for (i64 i = 0; i < 3; i++) { nums[i] *= 10; }
  printf("%d %d %d\n", nums[0], nums[1], nums[2]);
}

10 20 30

goto

Labels end with :. Useful for retry loops and leaving nested loops.


void main()
{
  i64 tries = 0;
retry:
  tries++;
  if (tries < 3) { goto retry; }
  printf("gave up after %d tries\n", tries);

  for (i64 i = 0; i < 10; i++) {
    for (i64 j = 0; j < 10; j++) {
      if (i * j == 12) {
        printf("found %d x %d\n", i, j);
        goto done;
      }
    }
  }
done:
  printf("out of both loops\n");
}

gave up after 3 tries
found 2 x 6
out of both loops
