SQLite

The sql module wraps SQLite: open a database, run statements with ? parameters, step through rows.

Build with SQLite. The module exists when ktm is built with ./build.sh --sqlite (it needs the SQLite development package). Code can check #ifdef __KTM_LINK_SQLITE3__.

A first database

import sql;

void main()
{
  sql.Db *db = sql.open(":memory:");
  defer sql.close(db);

  ad String err = sql.execRaw(db, "CREATE TABLE users(id INTEGER, name TEXT);");
  if (err.len) { printf("%s\n", err); return; }

  sql.Param p[2];
  p[0].type = sql.INT;   p[0].intVal = 1;
  p[1].type = sql.TEXT;  p[1].str = "ann";
  sql.exec(db, "INSERT INTO users VALUES(?, ?);", p, 2);

  sql.Row row;
  if (sql.select(db, &row, "SELECT id, name FROM users;")) {
    while (sql.next(&row)) { printf("%d %s\n", row.col[0].intVal, row.col[1].str); }
  }
}

The calls

CallDoes
sql.open(path)Opens a database; ":memory:" for a private one
sql.close(db)Closes it
sql.execRaw(db, script)Runs a script of statements; returns the error as a String, empty when it ran
sql.exec(db, sql, params, n)Runs one statement whose rows you don't need
sql.select(db, &row, sql, params, n)Runs one statement; read rows with sql.next
sql.next(&row)The next row; frees it after the last
sql.rowRelease(&row)Frees a row when you stop early

Parameters

An sql.Param has a type and the value in the matching field:

typeField
sql.INTintVal
sql.FLOATfloatVal
sql.TEXTstr, a u8[]
sql.BLOBblob and blobLen
sql.NULL_TYPE(nothing)
  • Text and blobs are copied, so they can be freed right after the call. An empty text binds ''.
  • The SQL is a u8[]: script[0:n] runs part of a buffer.
  • Text with a second statement is an error, rather than half-run.
  • Always use parameters for values: never format user input into SQL.

Rows

A row has cols and col[i], each with a type and intVal, floatVal, str or blob. A column's str and blob are valid only until the next row.

sql.Row row;
sql.Param min[1];
min[0].type = sql.INT;
min[0].intVal = 18;
if (sql.select(db, &row, "SELECT name, age FROM users WHERE age >= ?;", min, 1)) {
  while (sql.next(&row)) {
    ad String name = str.from(row.col[0].str);    // keep a copy past this row
    printf("%s is %d\n", name, row.col[1].intVal);
  }
}

Prepared statements

Compile a statement once and run it many times with new parameters.

sql.Stmt *ins = sql.prepare(db, "INSERT INTO users VALUES(?, ?);");   // null on an error
defer sql.finalize(ins);
sql.Row row;
for (i64 i = 0; i < 3; i++) {
  sql.Param p[2];
  p[0].type = sql.INT;   p[0].intVal = i;
  p[1].type = sql.TEXT;  p[1].str = "user";
  i32 rc = sql.execPrepared(ins, &row, p);         // SQLITE_DONE, SQLITE_ROW or an error
}
  • sql.execPrepared returns sql.SQLITE_ROW, sql.SQLITE_DONE or an error code; read rows with sql.nextPrepared.
  • A parameter it can't bind returns that error without running the statement (SQLITE_MISMATCH, SQLITE_TOOBIG).
  • The row belongs to the statement, which sql.finalize frees.
