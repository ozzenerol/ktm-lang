Variables and constants

Declaring locals and globals, letting the compiler pick the type, and constants.

At a glance

i64 a = 1, b, c = 3;       // several in one line
u8 *name = "ktm", letter;  // each * belongs to the name after it
auto count = 3;            // i64, from the initialiser
static i64 calls = 0;      // keeps its value between calls
const i64 MAX = 64;        // read-only, a compile-time constant

Declaring variables

Declare a local anywhere in a block. Several can share one declaration.


void main()
{
  i64 a = 1, b = 2, c;
  c = a + b;
  f64 ratio = 0.25;
  u8 *name = "ktm", letter = 'h';   // name is a u8 *, letter a u8
  printf("%d %.2f %s %c\n", c, ratio, name, letter);
}

3 0.25 ktm h

Globals

A global is declared at file scope and seen by everything below it. Uninitialised globals are 0.


i64 gTotal = 100, gCount;
u8 *gName = "server";

void bump() { gCount++; }

void main()
{
  bump();
  bump();
  printf("%s: %d of %d\n", gName, gCount, gTotal);
}

server: 2 of 100

Locals are not zeroed. Only String locals start empty. Give every other local a value before you read it.

auto

auto takes its type from the initialiser.


void main()
{
  auto count = 3;
  auto price = 9.99;
  auto label = "total";
  auto half = count / 2.0;
  printf("%s %s %s %s\n", typeof(count), typeof(price), typeof(label), typeof(half));
}

i64 f64 u8[6] f64

It is most useful with long type names, and in range-based for:


import map;

void main()
{
  auto ages = map.new();     // map.Map
  defer ages.free();
  ages.set("ada", 36);
  i64 nums[] = {1, 2, 3};
  for (auto x : nums) { printf("%d ", x); }
  printf("%d\n", ages.getOr("ada", 0));
}

1 2 3 36

static

A static local keeps its value between calls.


i64 nextId()
{
  static i64 id = 0;
  id++;
  return id;
}

void main()
{
  nextId();
  nextId();
  printf("%d\n", nextId());
}

3

On a function or a global, static keeps it private to its file.

const

const marks a declaration read-only. With a constant initialiser it is a compile-time constant: usable as an array size, a case label, or in another const.


const i64 MAX_USERS = 4;
const i64 DOUBLE_MAX = MAX_USERS * 2;   // built from another const
const f64 RATE = 0.5;
i64 gUsers[MAX_USERS];                 // as an array size

i64 classify(i64 n)
{
  switch (n) {
    case MAX_USERS: return 1;           // as a case label
    default:        return 0;
  }
}

void main()
{
  printf("%d %d %.1f %d %d\n", MAX_USERS, DOUBLE_MAX, RATE, classify(4), sizeof(gUsers));
}

4 8 0.5 1 32

const parameters


i64 twice(const i64 n)    // n can't be assigned inside twice
{
  return n * 2;
}

void main()
{
  printf("%d\n", twice(21));
}

42

Rules

  • A const needs an initialiser (a parameter doesn't).
  • Assigning to it, with =, += or ++, is a compile error.
  • const is not a type qualifier as in C: it goes only at the start of a declaration. u8 const *p, a const field, a const return type or a cast to const are errors.

Prefer const to #define for numbers: it has a type and the editor knows it.

Shadowing a module

A local may have the name of an imported module. For its scope, the name means the local.


import str;

void main()
{
  u8[] str = "a local called str";
  printf("%s, %d bytes\n", str, str.len);
}

a local called str, 18 bytes

A global can't: i64 str; at file scope would hide the module, and is an error.
