Base64 and hex

encoding.base64 and encoding.hex turn bytes into text and back, as Go's packages of the same names do. Decoding answers false on bad input instead of throwing.


import encoding.base64, encoding.hex;

void main()
{
  String b = base64.encode("hello, ktm");
  String u = base64.encodeUrl("\xfb\xff\xbf");
  String h = hex.encode("ktm");
  printf("%s %s %s\n", b, u, h);

  String raw;
  if (base64.decode(b, &raw)) { printf("%s\n", raw); }
  printf("%d\n", hex.decode("not hex", &raw));
  b.free(); u.free(); h.free(); raw.free();
}

CallWhat it does
base64.encode(data)The standard alphabet (+ /), padded with =: MIME, Basic auth, PEM
base64.encodeUrl(data)The URL-safe alphabet (- _), no padding: JWTs, tokens, URLs
base64.decode(text, &out)Either alphabet, padded or not, skipping blanks and line breaks; false (and out empty) on anything else
base64.encodedLen(n)The length encode gives n bytes
hex.encode(data)Two lowercase digits a byte
hex.decode(text, &out)Digits in either case, an even number of them; false otherwise

What encode returns and what decode fills in are yours to free; decode replaces what out held.
