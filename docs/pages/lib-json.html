JSON: reading

Three ways to read JSON. Pick by what you need:

WayUse it whenPage
json.decode<T>(text)The JSON has a known shape: fill a structJSON: structs
json.parse + json.selectYou want a few values from a document, or its shape variesThis page
json.ReaderLarge input, or you want full control with no treeThis page

Parsing and selecting

json.parse(text) builds a tree and returns its root. Check json.ok, and free it with json.release either way. json.select(node, path) walks a path from any node.


import json;

void main()
{
  u8[] text = "{\"name\": \"ktm\", \"version\": 14, \"tags\": [\"jit\", \"repl\"],"
              " \"stable\": false, \"owner\": null}";
  json.Value *doc = json.parse(text);
  defer json.release(doc);
  if (!json.ok(doc)) {
    json.printError(doc);
    return;
  }
  printf("%s v%d\n", json.select(doc, ".name:s").str, json.select(doc, ".version:i").intVal);
  printf("second tag: %s\n", json.select(doc, ".tags[1]:s").str);
  printf("stable: %d, owner is null: %d\n", json.select(doc, ".stable:b").boolean,
         json.select(doc, ".owner:!") != null);
  printf("missing: %d, wrong type: %d\n", json.select(doc, ".author") == null,
         json.select(doc, ".version:s") == null);
}

missing: 1, wrong type: 1

Paths

In a pathMeans
.keyAn object member
[n]An array item
:s :i :f :bMust be a string, integer, float, boolean
:a :o :!Must be an array, object, null
*Takes the next argument: an i64 in [], a string after .

select returns null when the path doesn't match or is malformed.

Nodes

Each node has a type and its value in the matching field.

typeValue in
json.STRINGstr, a u8[]
json.INT / json.FLOATintVal / floatVal
json.BOOLboolean
json.NULL(nothing)
json.ARRAY / json.OBJECTarray / object: the first child, or null
json.STRNUMstrnum, the number as written (see Numbers)

Children are linked by next; an object member has its name in key. That is how you iterate:


import json;

void main()
{
  json.Value *doc = json.parse("{\"prices\": {\"eur\": 9.5, \"usd\": 10.25}, \"tags\": [\"a\", \"b\"]}");
  defer json.release(doc);

  for (json.Value *t = json.select(doc, ".tags:a").array; t; t = t.next) {
    printf("tag %s\n", t.str);
  }
  for (json.Value *p = json.select(doc, ".prices:o").object; p; p = p.next) {
    printf("%s = %.2f\n", p.key, p.floatVal);
  }
}

tag b
eur = 9.50
usd = 10.25

Nodes are views into the document: don't keep them after the root is released.

Wildcards and getters


import json;

void main()
{
  json.Value *doc = json.parse("{\"prices\": {\"eur\": 9.5, \"usd\": 10.25}, \"rows\": [[1, 2], [3]],"
                               " \"a.b\": \"dotted\", \"dup\": 1, \"dup\": 2}");
  defer json.release(doc);
  for (i64 i = 0; i < 2; i++) {
    printf("row %d has %d items\n", i, json.len(json.select(doc, ".rows[*]", i)));
  }
  u8 *currency = "usd";
  printf("%s: %.2f\n", currency, json.select(doc, ".prices.*:f", currency).floatVal);

  printf("%s, dup = %d, members %d\n", json.objectGet(doc, "a.b").str,
         json.objectGet(doc, "dup").intVal, json.len(doc));
  json.Value *rows = json.objectGet(doc, "rows");
  printf("rows[1][0] = %d, rows[5] missing: %d\n", json.arrayGet(json.arrayGet(rows, 1), 0).intVal,
         json.arrayGet(rows, 5) == null);
}

usd: 10.25

  • json.objectGet(obj, key) takes any key, even one with . or [ in it.
  • json.arrayGet(arr, i) takes an index. Both return null when it isn't there.
  • json.len counts an array's or object's children (0 for anything else).
  • A key that appears twice is kept twice; selecting it finds the first.
  • json.isInt, isFloat, isString, isBool, isNull, isArray, isObject test a node's type.

Errors

The parser follows RFC 8259 strictly. On an error, json.errorStr(root) is the message and root.state has the code, line and column.


import json;

void main()
{
  json.Value *doc = json.parse("{\n  \"a\": [1, 2],\n  \"b\" 3\n}");
  if (!json.ok(doc)) {
    ad String msg = json.errorStr(doc);
    printf("%s\n", msg);
    printf("code %d, line %d, column %d\n", doc.state.error, doc.state.line, doc.state.col);
  }
  json.release(doc);

  u8[] bad[] = {"[1, 2,]", "[1] x", "[01]", "{\"a\": tru}", "[\"tab\there\"]", ""};
  for (auto b : bad) {
    doc = json.parse(b);
    printf("%d,", doc.state.error);
    json.release(doc);
  }
  printf("\n");
}

Numbers

An integer that fits an i64 is json.INT; a larger one, or one with a fraction or exponent, is json.FLOAT. With json.STRNUM_FLAG, numbers are kept as written, every digit.


import json;

void main()
{
  json.Value *doc = json.parse("[9007199254740993, 99999999999999999999, 2.50]");
  printf("%d %d\n", json.isInt(json.arrayGet(doc, 0)), json.isFloat(json.arrayGet(doc, 1)));
  ad String s = json.toStr(doc);
  printf("%s\n", s);
  json.release(doc);

  doc = json.parse("{\"id\": 123456789012345678901234567890, \"price\": 9.90}", json.STRNUM_FLAG);
  printf("id %s, price %s\n", json.select(doc, ".id").strnum, json.select(doc, ".price").strnum);
  json.release(doc);
}

1 1
[9007199254740993,1.0e+20,2.5]
id 123456789012345678901234567890, price 9.90
  • A STRNUM is still checked against the JSON grammar; json.toStr writes it back unchanged.
  • The :i and :f checks don't match STRNUM nodes: select them without one.
  • Strings are decoded, \uXXXX and surrogate pairs to UTF-8. \u0000 is kept and counted in str.len.

Streaming: json.Reader

A Reader reads the text front to back and builds no tree. Open an object and loop on nextKey(); open an array and loop on nextItem(). Errors throw json.ERR_DECODE with the line and column.


import json;

void main()
{
  u8[] text = "{\"service\": \"api\", \"ports\": [80, 443], \"debug\": true, \"extra\": {\"x\": 1}}";
  json.Reader r = json.readerNew(text);
  defer r.free();
  r.beginObject();
  while (r.nextKey()) {
    u8[] k = r.key();
    if (k.equals("service")) {
      printf("service %s\n", r.readStr());
    } else if (k.equals("ports")) {
      r.beginArray();
      while (r.nextItem()) { printf("port %d\n", r.readInt()); }
    } else if (k.equals("debug")) {
      printf("debug %d\n", r.readBool());
    } else {
      r.skipValue();                  // anything we don't know
    }
  }
  r.finish();                         // nothing left over
}

Reader callDoes
readStr(), readString(&s)A string as a view, or into a String
readInt(), readUint(), readFloat(), readBool()A value of that type, or an error
isNull()Reads a null if there is one
peek()What comes next: json.STRING, INT, ARRAY, ...
skipValue(), finish()Skip one value; check the text was all read
 

import json;

void main()
{
  json.Reader r = json.readerNew("{\"n\": \"seven\"}");
  defer r.free();
  try {
    r.beginObject();
    r.nextKey();
    r.readInt();
  } catch (Error e) {
    printf("%s\n", e.message);
  }
}
