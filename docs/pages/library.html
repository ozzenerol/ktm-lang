Library guide

How to use the standard library for everyday tasks. Every program can use it without an #include. For every function and struct, see the library reference.

Memory

FunctionDoes
mem.alloc(size)Allocate size bytes
mem.allocZero(size)Allocate size zeroed bytes
mem.realloc(ptr, size)Resize an allocation
mem.free(ptr)Release it (null is fine)
mem.size(ptr)The size an allocation was asked for (0 for null)
mem.copy(dst, src, n), mem.set(dst, byte, n)Copy and fill; both return dst

Where they differ from C:

  • mem.allocZero takes one argument, the total size, unlike C's calloc(count, size).
  • mem.alloc, mem.allocZero and mem.realloc return null when out of memory or when the size is too large (a negative size passed as a u64, say).
  • mem.realloc always moves the block and copies as much of it as fits; mem.realloc(null, size) is mem.alloc(size). When it fails the old block is left as it was, so keep the old pointer until you know it worked.
  • Each block carries its size in a hidden header, so only pointers from these functions can go to mem.free, mem.size and mem.realloc.
  • mem.copy copies front to back: for overlapping buffers use memmove.

import cstr, mem;

struct Player
{
  u8 *name;
  i64 score;
};

void main()
{
  Player *team = mem.allocZero(3 * sizeof(Player));
  team[0].name = "ada";
  team[0].score = 10;
  team = mem.realloc(team, 4 * sizeof(Player));
  team[3].name = "linus";
  printf("%s %d, %s\n", team[0].name, team[0].score, team[3].name);
  mem.free(team);
}

Finding memory bugs. Run a program with ktm -jit -Memsafe file.ktm to have double frees and wild frees reported (and skipped) as they happen, and leaks reported at exit, each with the line that allocated or freed the block, in any thread.

Only blocks your code gets from mem.alloc, mem.allocZero and mem.realloc are tracked. A string or container the standard library allocates for you (cstr.dup, cstr.formatTo, vec.new, ...) is not, so leaking one goes unreported, and a block of yours that the library resizes (cstr.appendFormat, cstr.appendFormatLen) is reported as never freed.

Strings

Text is two modules:

  • str is what code works with: String, a string you own that grows as you add to it, and the functions that read text given as a u8[], so a literal, a slice or a String.
  • cstr is C's strings: a NUL-terminated u8 *, for C functions and the data they give you.

Going between them is cheap. A String's bytes are always followed by a NUL, so s.cstr() passes one to C for free, and cstr.view(p) is a C string's bytes as a u8[], so str.from(cstr.view(p)) makes a String of them. Case conversion and the case-insensitive compares only know ASCII letters.

String

A String is yours: free it, and the way to do that is defer right where you make it.

  • Its methods change it in place: append, appendByte, appendFormat, insert, remove, replace, clear, reserve, toLower, toUpper, reverse. clone() gives a copy of your own.

Reading text

These take a u8[], so any text, and are called as functions or as methods of it (s.find("x") is str.find(s, "x")).

  • Searching: find and findLast give the index of a part or -1; contains, startsWith, endsWith and equals say whether it is there; compare orders two texts.
  • Trimming and splitting return views, parts of what you gave them with nothing copied: trim, trimStart, trimEnd (of whitespace, or of the bytes you give it), splitFirst and splitLast (around a separator), and split, a list of views that is allocated: defer parts.free();.

import str;

void main()
{
  u8[] line = "  name = ktm, lang  \r\n";
  u8[] t = line.trimEnd("\r\n").trim();
  u8[] key, value;
  if (str.splitFirst(t, " = ", &key, &value)) {
    printf("[%s] [%s]\n", key, value);
  }
  u8[][] parts = value.split(", ");
  defer parts.free();
  for (auto p : parts) { printf("<%s>", p); }
  printf("\n%d %d %d %d\n", t.find("ktm"), t.startsWith("name"), "abc".equals("abc"),
         str.compare("a", "b") < 0);
  printf("%c%c %d\n", str.toUpper('q'), str.toLower('Q'), str.isSpace('\t'));
}

s.len and s[i] count bytes. For characters, UTF-8: str.decodeRune(s, &at) gives the code point at byte at and moves at past it (U+FFFD for bytes that aren't UTF-8, -1 at the end), str.runeCount(s) counts them and str.validUtf8(s) checks a text.

Ignoring case

str.equalsFold(a, b), compareFold, findFold, containsFold, startsWithFold and endsWithFold work as the functions without Fold, with A-Z equal to a-z. Only ASCII letters fold: every other byte, UTF-8 included, has to match exactly, so "\xc3\xa9" (é) does not equal "\xc3\x89" (É). That is what protocol text wants: HTTP header names and values like keep-alive, MIME types, file extensions, hex.

URLs and HTML

str.urlEncode(s) percent-encodes one URL component (a query value, a path segment): every byte but A-Z a-z 0-9 - _ . ~ becomes %XX, a space %20. str.urlEncodePath(s) also keeps /, for a whole path, and str.formEncode(s) writes a space as +, as HTML forms send it (application/x-www-form-urlencoded). Each gives a new String that is yours.

str.urlDecode(s, &out) turns each %XX back into its byte and leaves + alone; str.formDecode also turns + into a space. The result goes into a String you pass (cleared first, its memory reused; free it when done). They return false, with out empty, when a % isn't followed by two hex digits. A decoded value can hold any byte, %00 and %2F included, so check it before using it as a file name.

str.htmlEscape(s) replaces & < > " ' with &amp; &lt; &gt; &quot; &#39;, which makes any text safe in HTML content and in a quoted attribute value.


import str;

void main()
{
  u8[] header = "Connection: Keep-Alive";
  u8[] name, value;
  str.splitFirst(header, ": ", &name, &value);
  printf("%d %d\n", name.equalsFold("connection"), value.containsFold("keep-alive"));

  String q = str.urlEncode("tom & jerry/2");
  defer q.free();
  String path = str.urlEncodePath("/docs/read me.txt");
  defer path.free();
  printf("%s?q=%s\n", path, q);

  String got;
  defer got.free();
  if (str.formDecode("q=tom+%26+jerry%2F2", &got)) { printf("%s\n", got); }
  printf("%d\n", str.urlDecode("100%", &got));

  String html = str.htmlEscape("\"5 < 6\"");
  defer html.free();
  printf("%s\n", html);
}

Format conversions

str.format, a String's appendFormat, cstr.format, cstr.formatTo and the other formatting functions share one format language with print statements. Integers are always 64-bit, and the C length modifiers l, ll, h, hh, z and j are accepted and ignored, so C formats can be pasted in.

ConversionPrints
%d %ia signed integer
%uan unsigned integer
%x %X %ohexadecimal (lower / upper case), octal
%f %e %gan f64, as C's printf prints it
%sa C string; in a literal format also a u8[] or a String (passed as its length and bytes)
%c %Ca character, %C in upper case; a wider integer prints its bytes as characters, low byte first (up to 8); the value 0 prints nothing
%pa pointer as 0x and 16 hex digits
%Qa string escaped for a C literal (cstr.quote)
%%a % (a width on it is ignored)

A date is formatted with date.format(d, fmt) (%Y %m %d %H %M %S, %a %b %p) and a file read with fs.readAll; %D, %T and %F are an error, with the way to do it in the message.

Between the % and the letter come, in order:

  1. The flags: - (left justify), 0 (pad with zeros), + (always a sign), a space (a space where a plus sign would go) and # (0x / 0 prefix for hex and octal).
  2. A width.
  3. A precision after a .: the number of decimals for floats, the maximum length for %s and the minimum number of digits for integers (%.3d of 7 is 007).

Width and precision can be *, taken from the arguments. An unknown conversion is printed as it was written, with a warning on stderr, and still uses up its argument, so the ones after it stay in place.

cstr.formatTo(buf, fmt, ...) writes into buf with no bound. For a fixed-size buffer use cstr.formatToSize(buf, size, fmt, ...), which works like C's snprintf: it writes at most size - 1 characters and always ends them with a '\0', cutting longer output short. It returns buf.


import cstr, mem;

void main()
{
  u8 *s = cstr.formatTo(null, "%+d|% d|%#x|%#o|%.3d|%ld|%-4s|%5.1f", 7, 7, 255, 8, 7,
                   5000000000, "ab", 2.25);
  printf("%s\n", s);
  mem.free(s);

  u8 small[8];
  cstr.formatToSize(small, sizeof(small), "%s-%d", "overflow", 12345);
  printf("[%s] %d\n", small, cstr.len(small));
}

C strings

cstr works on NUL-terminated strings, as C does. Functions that make one (cstr.dup, cstr.format, cstr.formatTo(null, ...), cstr.concat, cstr.dupLen, cstr.quote) return a new block that you mem.free.

Building C strings

  • cstr.formatTo(null, fmt, ...) returns a newly allocated formatted string, and cstr.format(fmt, ...) is the same into an exactly sized block.
  • cstr.concat("a", "b", ...) joins strings.
  • cstr.appendFormat(s, fmt, ...) appends the formatted text to the heap string s and returns it, so write s = cstr.appendFormat(s, fmt, ...): when s is full it is grown, which may move it and frees the old block. s must come from mem.alloc, cstr.dup, cstr.formatTo(null, ...) or an earlier cstr.appendFormat, or be null to start a new string; never pass a string literal or a stack buffer.
  • cstr.appendFormat measures s on every call, so appending in a long loop is quadratic; cstr.appendFormatLen(s, &len, fmt, ...) keeps the length in len and doesn't.

import cstr, mem;

void main()
{
  u8 *s = cstr.formatTo(null, "%d|%05d|%s|%.2f", 5000000000, 42, "x", 3.14159);
  printf("%s\n", s);

  u8 *csv = cstr.dup("id");
  for (i64 i = 1; i <= 3; i++) {
    csv = cstr.appendFormat(csv, ",%d", i);
  }
  printf("%s\n", csv);

  i64 len = 0;
  u8 *log = null;
  for (i64 i = 0; i < 3; i++) {
    log = cstr.appendFormatLen(log, &len, "[%d]", i * i);
  }
  printf("%s (%d)\n", log, len);

  u8 *joined = cstr.concat("con", "cat", "enate");
  printf("%s\n", joined);
  mem.free(s);
  mem.free(csv);
  mem.free(log);
  mem.free(joined);
}

Inspecting C strings

cstr.cmp, cstr.cmpLen and cstr.cmpLenNoCase return a negative, zero or positive number like C's strcmp, comparing bytes as unsigned, and sort a null before every string. cstr.firstOf and cstr.lastOf find the first or last character of the first string that is any of the characters in the second. cstr.globMatch matches a whole string against a pattern where * is any run of characters and ? any one character. cstr.hash gives a well mixed 64-bit hash of a string.


import cstr, fs, str;

void main()
{
  printf("%d %d\n", cstr.len("hello"), cstr.cmp("abc", "abc") == 0);
  printf("%d\n", cstr.cmpLen("prefix-rest", "prefix", 6) == 0);
  printf("%d %d\n", cstr.cmp("abc", "abd") < 0, cstr.cmpLenNoCase("ABC", "abc", 3) == 0);
  printf("%d\n", cstr.count("banana", 'a'));               // count a character
  printf("%s\n", cstr.firstOf("key=value", "="));       // from the first match
  printf("%s\n", cstr.lastOf("a/b/libc.ktm", "/"));         // from the last match
  printf("%s\n", fs.ext("archive.tar.gz"));
  printf("%d %d %d\n", cstr.globMatch("main.ktm", "*.ktm"), cstr.globMatch("main.c", "*.ktm"),
    cstr.globMatch("banana", "b?n*a"));
  printf("%d\n", cstr.toInt("1234") + 1);
  printf("%c %c %d\n", str.toUpper('q'), str.toLower('Q'), str.isSpace(' '));
}

Copying C strings

cstr.dup copies a whole string and cstr.dupLen(s, n) at most the first n bytes of it, like C's strndup (a negative n is 0). cstr.copy copies into a buffer you provide.

  u8 *copy = cstr.dup("a copy");

  cstr.copy(buf, "fixed");

Splitting paths and names

fs.ext(name) is a file name's extension, from its first . that isn't followed by / or ., and fs.cutExt(name) the name without it; both are views of the name. str.splitLast splits a path at its last /.


import fs, str;

void main()
{
  u8[] dir, file;

  printf("%s + %s\n", dir, file);
  printf("%s + %s\n", fs.cutExt(file), fs.ext(file));

Files

Paths are a u8[] (a literal, a slice or a String; a C string through cstr.view(p)). fs.writeAll(path, data) writes data, a u8[], to a file and returns whether it worked. fs.readAll(path) reads a whole file into a String that is yours, with a NUL after it; its ptr is null when the file can't be read (os.errno() says why), and an empty file gives an empty String that has one.


import fs;

void main()
{
  u8[] path = "/tmp/ktm_docs_example.txt";
  if (!fs.writeAll(path, "first line\nsecond line\n")) {
    printf("could not write %s\n", path);
    return;
  }

  String contents = fs.readAll(path);
  defer contents.free();
  printf("%d bytes\n%s", contents.len, contents);

  String missing = fs.readAll("/no/such/file");
  if (!missing.ptr) {
    printf("a missing file gives a String without a ptr\n");
  }
}

  • fs.writeAll replaces the file's contents: by default it opens with O_CREAT | O_WRONLY | O_TRUNC (a new file gets mode 0644 minus the umask). Pass the flags yourself to do something else, O_CREAT | O_WRONLY | O_APPEND to add to the end. A path that can't be opened gives false and creates nothing.
  • fs.readAll reads a regular file up to its size, and a FIFO, a pipe (/dev/fd/N, /dev/stdin), a device or a /proc file (which reports size 0) until end of file, so it waits for a FIFO's writer and never finishes on an endless device like /dev/zero. For a directory it gives a String without a ptr.
  • A path longer than 4095 bytes fails in every function here, with ENAMETOOLONG.

Making, removing and moving between directories:

  • fs.makeDir(path) makes one directory and fs.makeDir(path,, true) the missing parents too. Both return 0 if the path is a directory afterwards (made now or already there) and -1 if not, the convention fs.remove and fs.removeDir use too.
  • fs.remove(path) removes a file, a symlink (never what it points to) or an empty directory; with fs.REMOVE_RECURSE a directory and everything in it, with fs.REMOVE_FORCE a path that doesn't exist is not an error. fs.removeDir is the directory half of it.
  • fs.stat(&fst, path) fills an fs.FileStat (size, mode, times; see File status).
  • fs.changeDir changes directory (~ is $HOME) and fs.currentDir() returns the working directory as a String.

import cstr, fs, libc, mem, str;

void main()

  u8 dir[32];

  u8[] root = cstr.view(dir);

Reading directories, copying and moving

fs.openDir(path) opens a directory; d.next() gives each entry as an fs.DirEntry * and null after the last, leaving out . and ...

  • An entry has its name, its kind (an fs.FileKind; a symlink is link, never what it points to, and a filesystem that doesn't report types is asked with lstat) and its path, the directory's path joined with the name.
  • The name and path belong to the fs.Dir and stay valid until its next next(): copy them (str.from(e.name), e.path.clone()) to keep them.
  • Close it with d.close(), usually right away as defer d.close();, or declare it with ad fs.Dir d = fs.openDir(path);.
  • A directory that can't be opened gives a Dir whose d.ok() is false (os.errno() says why) and whose next() gives null at once.

fs.list(path) is the names of a directory as a sorted vec.Vec<String> (fs.list(path, &ok) also says whether it could be read); free it with fs.freeList(&names). fs.walk(root, &visit, arg) calls bool visit(fs.DirEntry *e, void *arg) for every entry under root at any depth, a directory before what is in it, and never enters a symlink, as fs.remove with fs.REMOVE_RECURSE never does; visit returns false to stop. It returns 0 when every entry was visited, 1 when visit stopped it and -1 when a directory couldn't be read.

File status

fs.stat(&fst, path) fills an fs.FileStat, the same struct on every platform, so a program never needs libc.cStat, whose layout differs between Linux x86_64, Linux arm64 and macOS.

  • Its fields: st_size, st_mode (type and permission bits), st_ino, st_dev, st_nlink, st_uid, st_gid, and the times st_mtim, st_atim, st_ctim and st_btim (creation), each with tv_sec and tv_nsec.
  • fst.kind() says what it is: fs.FileKind.file, dir, link or other (a FIFO, a socket, a device), and fst.isFile(), isDir() and isLink() ask for one.
  • fs.stat follows a symlink to what it points to; fs.lstat describes the link itself, the only way to get link, and fs.fstat(&fst, fd) describes an open file. All three return 0, or -1 with errno set.

fs.realPath(path) is the absolute path with every symlink, . and .. resolved, a String that is yours; its ptr is null (with errno set) when a part of the path doesn't exist. fs.pread(fd, buf, off) reads into a u8[] from an offset and fs.pwrite(fd, data, off) writes at one, neither moving the file's offset, so threads can share one fd.

CSV

csv.next walks a CSV text without copying it: each call gives the next field (csv.FIELD), then the whole row (csv.ROW), and csv.EOF at the end.

  • A csv.Item has its number (idx, the field in its row or the row) and its text, a u8[] view of the input.
  • The views are the raw text: a quoted field keeps its quotes and its doubled "", commas and newlines inside quotes don't split, and a row's text includes its \n or \r\n. Unquoting is up to you.
  • csv.init takes any u8[], so text[0:n] parses part of a buffer; the input must outlive the parser.

import csv;

void main()
{
  u8[] text = "name,quote\r\nann,\"say \"\"hi\"\", ok\"\nbob,\n";
  csv.Parser p;
  csv.Item it;
  i64 kind;
  csv.init(&p, text);
  while ((kind = csv.next(&p, &it)) != csv.EOF) {
    if (kind == csv.FIELD) { printf("field %d: [%s]\n", it.idx, it.text); }
    else                   { printf("row %d: %d bytes\n", it.idx, it.text.len); }
  }
}

Print statements are buffered, while commands write straight to the terminal. When output goes to a pipe or file, a command's output can appear before text you printed earlier.

proc.shell (a u8[]) and proc.shellf (a format) run the command with sh -c and return its exit code, 0 to 255: proc.shell("exit 3") gives 3, and a command the shell can't find gives 127. They return -1 if the command was killed by a signal or the shell couldn't be run.

proc.shellOutput returns what the command printed to stdout, minus one trailing newline, as a new String; format arguments are optional, and %s takes a String or a slice as well.

  • It doesn't capture stderr or return the exit status: a failing command gives whatever it printed, often "", and a shell that couldn't be started an empty String with a null ptr.
  • It returns once the shell exits, without waiting for a background job (cmd &) the command started.

Related, in os:

  • os.exit(code) ends the program.
  • os.eprintf(fmt, ...) is printf to stderr (checked against its format the same way), for messages that must not mix into a program's output.
  • os.flush() writes out what printf still holds for stdout: do it before starting a command that writes to the same terminal or file.

The commands get the program's stdin, stdout and stderr, but none of the files or sockets the library opened: those (the net sockets and accepted connections, fs.readAll/fs.writeAll's file, proc.shellOutput's pipe) are close-on-exec. An fd you open yourself with open or socket is inherited unless you pass O_CLOEXEC (Linux also has SOCK_CLOEXEC) or set FD_CLOEXEC with fcntl(fd, F_SETFD, FD_CLOEXEC).

The command is shell text, so a string from elsewhere (a file name, user input) must not be pasted in as it is: a space splits it and $, `, ; or * run or expand things. proc.shellQuote(s) returns s in single quotes as a new String, with each ' written as '\'' (and '' for an empty one), so the shell gets it as one word, unchanged.


import proc;

void main()
{
  String q = proc.shellQuote("it's $HOME; *");
  defer q.free();
  String out = proc.shellOutput("printf '%%s' %s", q);
  defer out.free();
  printf("[%s]\n", out);
}

Running programs without a shell

proc.run(argv, &code) runs a program with the arguments in argv, a null-terminated array of C strings, and returns what it printed to stdout (minus one trailing newline) as a new String, with its exit code in code. No shell is involved: every argument reaches the program exactly as written, so nothing needs quoting. The program is looked up in $PATH; an empty String with a null ptr means it couldn't be started, and os.errno() says why (2, ENOENT, for a program that doesn't exist).


import proc;

void main()
{
  u8 *argv[] = {"printf", "%s|", "it's $HOME", "a b", null};
  i64 code;
  String out = proc.run(argv, &code);
  defer out.free();
  printf("[%s] exit %d\n", out, code);
}

For more control, proc.spawn(argv, &opts) starts the program and returns a proc.Proc. In proc.Opts (zero it first: its fields are all optional):

  • Each of in, out and err is proc.INHERIT (ours, the default), proc.PIPE (our end is p.inFd, outFd or errFd), proc.DEVNULL (/dev/null) or, for err, proc.STDOUT (2>&1), or proc.FD (below).
  • cwd and env (a null-terminated "NAME=value" list that replaces the environment) are optional.

Pipelines and process groups

Pipelines, process groups and more fds:

  • proc.FD gives the program an fd of yours as its stdin, stdout or stderr: set opts.in = proc.FD and opts.inFd (likewise out/outFd and err/errFd).
  • With proc.pipe(fds) (a pipe whose ends are close-on-exec and above 2) that connects processes the way a shell's a | b | c does: each stage gets the read end of the pipe before it and the write end of the pipe after it, and you close your copies of both once it is started, so the last reader sees end of input.
  • opts.newGroup starts the program in a new process group that it leads, and opts.pgid puts it into an existing one: the later stages of a pipeline join the first one's (p.pgid), so proc.kill on any stage, or a terminal's Ctrl-C with the group in the foreground (libc.tcsetpgrp), reaches all of them.
  • opts.dups lists more fds for the child as pairs {from, to, ...} (opts.ndups pairs), applied in order after stdin, stdout and stderr like a shell's 3>file or 2>&1.
  • A program that reaps its children itself (a shell's waitpid(-1), coro.waitChild) frees a Proc with proc.disown(p), which doesn't wait.

import libc, mem, proc;

proc.Proc *stage(u8 *script, i32 in, i32 out, i32 pgid)
{// sh -c script, reading in (-1: a PIPE from us) and writing out (-1: a PIPE to us)
  u8 *argv[] = {"sh", "-c", script, null};
  proc.Opts o;
  mem.set(&o, 0, sizeof(proc.Opts));
  if (in >= 0) { o.in = proc.FD; o.inFd = in; }
  if (out >= 0) { o.out = proc.FD; o.outFd = out; } else { o.out = proc.PIPE; }
  if (pgid) { o.pgid = pgid; } else { o.newGroup = true; }
  return proc.spawn(argv, &o);
}

void main()
{
  i32 ab[2], bc[2];
  proc.pipe(ab);
  proc.pipe(bc);
  proc.Proc *a = stage("printf 'pear\napple\npear\n'", -1, ab[1], 0);
  proc.Proc *b = stage("sort", ab[0], bc[1], a.pgid);
  proc.Proc *c = stage("uniq -c | tr -s ' '", bc[0], -1, a.pgid);
  libc.close(ab[0]);
  libc.close(ab[1]);
  libc.close(bc[0]);
  libc.close(bc[1]);

  String out;
  proc.communicate(c, "", &out);
  printf("%s", out);
  printf("one group: %d\n", b.pgid == a.pid && c.pgid == a.pid);
  out.free();
  proc.release(a);
  proc.release(b);
  proc.release(c);
}

The environment, the program's path, wait statuses

proc.getenv(name) gives a variable's value as a String (empty when it isn't set; proc.hasEnv(name) tells an empty value from a missing one), proc.setenv(name, value) and proc.unsetenv(name) change it for this program and the ones it starts. proc.selfPath() is the running executable's absolute path (under ktm -jit, ktm's own), and proc.cpuCount() the CPUs online.

  • A status from libc.waitpid or libc.system is read with proc.exited(st) and proc.exitCode(st), proc.signaled(st) and proc.termSignal(st), proc.stopped(st) and proc.stopSignal(st). proc.statusCode(st) is what a shell puts in $?: the exit code, or 128 plus the signal.
  • proc.exitFd(pid) is a file descriptor that polls readable once child pid has exited (a pidfd on Linux, a kqueue on macOS; -1 where the system can't make one, so check with waitpid and WNOHANG then). Put it in your own poll loop instead of waking up every so often to reap, then waitpid or proc.done the child and close the fd. In a coroutine loop, coro.waitChild does all of that.
  • The libc module also declares what shells and daemons call directly: dup, dup2, setpgid, tcsetpgrp, getpid, setsid, readlink, realpath, pread, setrlimit and more, with the common errno codes (EEXIST, EMFILE, ENOTEMPTY, ...) for each platform.

Signals

signal.handle(sig, handler, flags, mask, &old) sets what happens when a signal arrives: SIG_DFL, SIG_IGN, or a function void F(i32 sig) passed as (&F)(i64).

  • flags defaults to SA_RESTART, which makes a blocking read, write or accept carry on after the handler; pass 0 to have it return -1 with os.errno() == EINTR instead (poll always does).
  • mask (signal.bit(SIGUSR2) | ...) holds other signals back while the handler runs.
  • old, if given, receives the previous action, so it can be put back with signal.action(sig, &old).

libc.signal(sig, handler), C's signal, is the same as signal.handle with SA_RESTART, and the two can be mixed.


import cstr, libc, signal;

i64 hits = 0;
void onUsr1(i32 sig)
{
  hits++;
}

void main()
{
  signal.Action old;
  signal.handle(libc.SIGUSR1, (i64)(&onUsr1), libc.SA_RESTART, 0, &old);
  libc.raise(libc.SIGUSR1);
  libc.raise(libc.SIGUSR1);
  signal.action(libc.SIGUSR1, &old);      // back to what it was
  printf("%d signals, previous handler SIG_DFL: %d\n", hits, old.handler == libc.SIG_DFL);
}

What a handler may do. A handler interrupts the program wherever it is, on whichever thread the signal reached, so it may only set a global variable, call write, _exit, kill or raise, and keep os.errno() as it found it. Allocating, printing, throw or taking a mutex there can deadlock or corrupt memory: the interrupted code may be in the middle of the same thing.

Actions are shared by all threads, and a signal sent to the process is handled by one of them, whichever doesn't block it.

For a server built around poll(), signal.stopInit() does this for SIGINT and SIGTERM: it returns an fd to add to the poll set, which becomes readable when either signal arrives, and from then on signal.stopRequested() is TRUE (signal.stopSignal() says which one came). The loop finishes what it is doing and returns. A second Ctrl-C ends the program as usual, in case the loop never gets there.


import cstr, libc, signal;

void main()
{
  i32 fd = signal.stopInit();
  libc.pollfd p;
  p.fd = fd;
  p.events = libc.POLLIN;
  libc.raise(libc.SIGTERM);                // as if `kill` had been run on us
  if (libc.poll(&p, 1, 1000) == 1 && signal.stopRequested()) {
    printf("stopping cleanly after signal %d\n", signal.stopSignal());
  }
}

Lists

list.List<T> is a doubly linked list of T. It is a value: make one with list.new<T>() (nothing is allocated until the first value) and free it with l.free(), or let ad do that at the end of the scope. Its nodes are list.Node<T>, with value, next and prev; l.head and l.tail are the first and last (null when it is empty) and l.len counts them, so walk it with for (auto n = l.head; n; n = n.next).

  • Adding. l.append(v) and l.prepend(v) add at the end and the front, l.insertBefore(node, v) and l.insertAfter(node, v) next to a node. Each returns the new node.
  • Removing. l.remove(node) takes that node out in O(1) and returns its value: keep the node append gave you (a timer, a client) and remove it later without searching. During a walk, read n.next before removing n. l.shift() removes the first value and l.pop() the last, so append with shift is a first-in first-out queue and append with pop a stack.
  • Looking. l.first() and l.last() return a value without removing it. On an empty list shift, pop, first and last return a zeroed T (0, null) and set the optional bool *ok to false, for when a stored zero must be told apart.
  • Joining and emptying. l.mergeAppend(&other) and l.mergePrepend(&other) move all of other's nodes to the end or the front, leaving other empty. l.clear() frees every node and leaves the list empty and usable; l.free() is the same, for ad. Neither frees what the values point to: that is yours.

import cstr, list, mem;

void main()
{
  ad list.List todo = list.new();
  todo.append(cstr.dup("write"));
  list.Node *test = todo.append(cstr.dup("test"));
  todo.append(cstr.dup("ship"));
  todo.prepend(cstr.dup("plan"));

  mem.free(todo.remove(test));            // the node append gave back: O(1)

  ad list.List later = list.new();
  later.append(cstr.dup("rest"));
  todo.mergeAppend(&later);               // `later` is empty now

  for (auto n = todo.head; n; n = n.next) { printf("%s ", n.value); }
  printf("(%d)\n", todo.len);
  u8 *first = todo.shift();
  printf("first %s, last %s\n", first, todo.last());
  mem.free(first);
  for (auto n = todo.head; n; n = n.next) { mem.free(n.value); }   // the values are ours
}

Vectors

vec.Vec<T> is a growable array of any type, held by value like a String: make one with vec.new<T>(cap = 8) and free it with free(), or declare it with ad. It has data, len and cap fields; for (auto x : v) goes through the items, and v.items() is a T[] view of them (valid until the Vec grows), for anything that takes a slice. free() frees the array, not what its items point to.

  • push(x) appends, growing the array as needed; reserve(n) makes room for n items at once.
  • get(i), set(i, x) and at(i) (a pointer to the item, to change it in place) check the index: outside 0 to len - 1 they throw ERR_BOUNDS, as a slice index does.
  • pop(&ok) removes and returns the last item and last(&ok) returns it. On an empty Vec they set ok to false and return a zeroed T; without ok they throw ERR_BOUNDS.
  • insert(i, x) (i from 0 to len) and removeAt(i) move the items after i, so the order is kept.
  • sort(cmp) sorts with cmp(a, b), given pointers to two items: negative when a goes first, 0 when equal, positive when b does. sortAsc() sorts numbers (anything < compares) smallest first. Both are O(n log n), also for sorted, reversed or all-equal input, and not stable.
  • clear() empties it and keeps the room for reuse.

import str, vec;

struct User { u8 *name; i64 age; };

i64 byAge(User **a, User **b) { return (*a).age - (*b).age; }

void main()
{
  ad vec.Vec nums = vec.new();
  nums.push(30);
  nums.push(10);
  nums.push(20);
  nums.sortAsc();
  for (auto n : nums) { printf("%d ", n); }
  nums.set(0, 15);
  printf("| popped %d, len %d, first %d\n", nums.pop(), nums.len, nums.get(0));

  User ann = {"ann", 41}, bob = {"bob", 29};
  ad vec.Vec users = vec.new();
  users.push(&ann);
  users.push(&bob);
  users.sort(&byAge);
  for (auto u : users) { printf("%s %d\n", u.name, u.age); }

  bool ok;
  nums.clear();
  i64 last = nums.last(&ok);
  printf("after clear: len %d, last %d, ok %d\n", nums.len, last, ok);
}

Sets and trees

set.Set<T> is a hash set of T. It is a value: make one with set.new<T>() and free it with s.free(), or with ad.

  • s.add(v) returns true when v is new, s.delete(v) true when it was there, s.has(v) tells, s.len counts and s.clear() empties it; all are O(1) on average.
  • unionWith, intersection, diff (in the first set, not the second) and symDiff (in exactly one) take a pointer to the other set and return a new one, leaving both alone; isSubset and equals compare two sets.
  • Walk it in the order values were added with i64 it = 0; while (s.next(&it, &v)) { ... }; s.items() gives the values as a vec.Vec<T> (yours to free), which sortAsc() puts in order.
  • Values are hashed and compared like map.Map's keys (the integer types, pointers, u8[] and String, and any other type byte by byte), and u8[] and String values are copied into the set.

For a set kept in order, use a map.Tree.


import set, vec;

void main()
{
  ad set.Set evens = set.new();
  ad set.Set threes = set.new();
  for (i64 i = 1; i <= 6; i++) { evens.add(i * 2); }
  for (i64 i = 1; i <= 4; i++) { threes.add(i * 3); }
  printf("add 4 again: %d, delete 10: %d\n", evens.add(4), evens.delete(10));
  printf("has 4: %d, has 5: %d, %d values\n", evens.has(4), evens.has(5), evens.len);

  ad set.Set both = evens.intersection(&threes);
  i64 it = 0, v;
  while (both.next(&it, &v)) { printf("both %d\n", v); }

  ad set.Set either = evens.unionWith(&threes);
  ad vec.Vec sorted = either.items();
  sorted.sortAsc();
  for (auto x : sorted.items()) { printf("%d ", x); }
  printf("\n");

  ad set.Set seen = set.new();
  seen.add("apple");
  printf("seen apple before: %d\n", !seen.add("apple"));
}

Ordered maps: map.Tree

map.Tree<K, V> maps keys to values in key order (a red-black tree). It is a value: make one with map.treeNew<K, V>() and free it with t.free(), so ad map.Tree<u8[], i64> t = map.treeNew<u8[], i64>(); frees it at the end of the scope.

  • t.set(k, v) adds a key or replaces its value.
  • t.get(k, &v) fills v and returns true (false for a missing key, v untouched); t.getOr(k, def) returns the value or def.
  • t.has(k), t.delete(k) (true if the key was there), t.len and t.clear().
  • Walk it in key order with for (auto n = t.first(); n; n = t.after(n)), reading n.key and n.value, or backwards with t.last() and t.before(n). A delete leaves the other nodes where they are, so during a walk take t.after(n) before deleting n.

Keys are ordered by map.compare(a, b), an overloaded function returning less than 0, 0 or more than 0: there are overloads for the integer types, f64 and u8[] (bytes, then length, which covers String). For a key type of your own, add one: i64 map.compare(Version a, Version b) { ... }. u8[] and String keys are copied into the tree and freed with it, so the key you pass can be a reused buffer; other keys and every value are stored as they are, and what a value points to is yours to free.


import map;

void main()
{
  ad map.Tree ages = map.treeNew();
  ages.set("linus", 55);
  ages.set("ada", 36);
  ages.set("grace", 85);
  ages.set("ada", 37);
  ages.delete("grace");
  i64 ada;
  ages.get("ada", &ada);
  printf("ada %d, has grace: %d, %d entries, bob %d\n",
    ada, ages.has("grace"), ages.len, ages.getOr("bob", -1));
  for (auto n = ages.first(); n; n = ages.after(n)) { printf("%s = %d\n", n.key, n.value); }
}

Hash tables

map.Map<K, V> is a hash map, held by value: make one with map.new<K, V>() and free it with free(), or declare it with ad. Setting an existing key replaces its value; iteration goes in insertion order.

  • set(k, v); get(k, &v) fills v and returns whether k is there; getOr(k, default); ref(k) is a pointer to the value, to change it in place (*m.ref(k) += 1), or null; has(k); delete(k) returns whether it was there; len counts the keys; clear().
  • next(&it, &k, &v) steps through the keys and values (start it at 0; either pointer may be null); keys() and values() return them as a vec.Vec.
  • Keys are hashed with map.hashOf and compared with map.keyEq: i64, u64, i32, u32, pointers, u8[] and String have their own; any other type (a struct) is hashed and compared by its bytes, so set every field of a struct key.
  • A u8[] or String key is copied: the key you pass can be a reused buffer or a String you free right after, and the map frees its copies. The values are yours (free what they point to before free()).

import map, str;

void main()
{

  stock.set("apples", 4);

  u8[] fruit;
  i64 n;
  while (stock.next(&it, &fruit, &n)) {

  names.set(404, "not found");

Bit vectors

A vec.BitVec is a set of numbered bits, all 0 to begin with. set grows it to fit any index (a u64), test and unset treat bits past the end as 0, and clear zeroes every bit. set returns false when it runs out of memory growing. release of a null BitVec does nothing.


import cstr, vec;

  seen.unset(5);

    if (seen.test(n)) { printf("%d ", n); }
  }
  printf("\n1000003: %d, 1000004: %d, 99999999: %d\n",

  seen.release();

Byte buffers

Module bytes is for binary data that comes and goes in pieces: what a socket or a pipe delivers, or a message being put together. A bytes.Buffer is a queue of bytes:

  • append(u8[]), appendByte(b) and appendBe16/32/64 / appendLe16/32/64 add at the end.
  • data() is a view of the unread bytes, and consume(n) drops the first n once they are used. The space in front is reused, so a buffer that is filled and drained all the time doesn't keep growing.
  • Make one with bytes.bufferNew() (a declared Buffer isn't zeroed) and free it with b.free(); b.take() gives the unread bytes as a String that is yours.

To read into one, room(n) gives at least n writable bytes after the data and commit(k) counts the k you wrote; b.readFrom(fd) does one read that way and b.writeTo(fd) one write of the unread bytes, consuming what went out. Both return what the system call did (-1 with errno EAGAIN on a non-blocking fd that has to wait).

The integer helpers read and write a u8[] at an offset: bytes.be16(s, at), be32, be64 (big-endian, network order), le16, le32, le64, and putBe16(s, at, v) and the others to write. Past the end, like consume or commit past the data, throws ERR_BOUNDS.


import bytes;

void main()
{
  /* a message: a 2-byte type and a 4-byte length (network order), then the body */
  bytes.Buffer b = bytes.bufferNew();
  defer b.free();
  b.appendBe16(7);
  b.appendBe32(5);
  b.append("hello");
  b.append("\x00\x08\x00\x00\x00\x02hi");   /* a second message, already here */

  /* read them back the way a server reads what arrived */
  while (b.len >= 6) {
    u8[] d = b.data();
    i64 len = bytes.be32(d, 2);
    if (b.len < 6 + len) { break; }        /* the rest hasn't arrived yet */
    printf("type %d: %s\n", bytes.be16(d), d[6:6 + len]);
    b.consume(6 + len);
  }
  printf("%d bytes left\n", b.len);

Hashing

Module hash has SHA-256, CRC-32, FNV-1a and a constant-time compare.

  • hash.sha256(data, out) writes the 32-byte digest of a u8[] into out (hash.SHA256_SIZE bytes; a shorter out throws ERR_BOUNDS).
  • For data that comes in pieces (a file read in blocks, a body off a socket), make a hash.Sha256 with hash.sha256New(), give it each piece with h.update(piece) and finish with h.final(out), which also starts it over for the next message (h.reset() drops what was fed without finishing). A Sha256 holds no memory, so there is nothing to free.
  • hash.hex(bytes) gives the lowercase hex of any bytes as a String that is yours.

hash.crc32(data) is the IEEE CRC-32 that zip, gzip and PNG use. It chains: hash.crc32(b, hash.crc32(a)) is the CRC of a followed by b. hash.fnv1a(data) is a fast 64-bit hash for tables, sharding and cache keys (the one map.Map uses for text keys), not for anything security-related.

hash.equalCt(a, b) compares two byte strings in a time that depends only on their length, not on where they differ: use it for digests, MACs and tokens, where str.equals would tell an attacker how many leading bytes were right. Strings of different lengths return false at once, so the length itself is not kept secret.


import hash;

void main()
{
  u8 d[hash.SHA256_SIZE];
  hash.sha256("abc", d);
  String hex = hash.hex(d);
  defer hex.free();
  printf("%s\n", hex);

  /* the same digest, fed in pieces */
  hash.Sha256 h = hash.sha256New();
  h.update("a");
  h.update("bc");
  u8 again[hash.SHA256_SIZE];
  h.final(again);
  printf("same: %d\n", hash.equalCt(d, again));

  printf("crc32 %x, chained %x\n", hash.crc32("123456789"),
         hash.crc32("56789", hash.crc32("1234")));
}

Parsing and selecting

json.parse(text) parses text, a u8[], into a tree of json.Value nodes and returns its root; the text can be any one JSON value (an object, array, string, number, boolean or null). It always returns a root: check json.ok before using it, and free it with json.release either way.

json.select(node, path) walks a path from any node:

In a pathMeans
.keyAn object member
[n]An array item
:s :i :f :bA type check that must match: string, integer, float, boolean
:a :o :!Array, object, null

It returns null if the path doesn't match or is malformed ([1x], ..a, a trailing .).


import json;

void main()
{
  u8[] text = "{\"name\": \"ktm\", \"version\": 15, \"ratio\": 0.75, \"tags\": [\"jit\", \"repl\"], \"stable\": false, \"owner\": null}";
  json.Value *doc = json.parse(text);
  if (!json.ok(doc)) {
    json.printError(doc);
    json.release(doc);
    return;
  }

  printf("%s v%d\n", json.select(doc, ".name:s").str, json.select(doc, ".version:i").intVal);
  printf("second tag: %s\n", json.select(doc, ".tags[1]:s").str);
  printf("stable: %d, owner is null: %d\n", json.select(doc, ".stable:b").boolean,
    json.select(doc, ".owner:!") != null);
  printf("missing: %d, wrong type: %d\n", json.select(doc, ".author") == null,
    json.select(doc, ".version:s") == null);

  json.Value *tags = json.select(doc, ".tags:a");
  for (json.Value *t = tags.array; t; t = t.next) {
    printf("tag %s\n", t.str);
  }

  String out = json.toStr(doc);
  defer out.free();
  printf("%s\n", out);
  json.release(doc);
}

Wildcards and getters

  • A * in a path takes the next argument: an i64 inside [], a string after ., and it can be part of a name (.price_*).
  • Each part of a path is at most 256 bytes, and a key that contains . [ ] : or * can't be written in a path. json.objectGet(obj, key) (any u8[], all its bytes) and json.arrayGet(arr, i) take any key or index directly (null if it isn't there or the node has the wrong type).
  • json.len counts the items of an array or object (0 for anything else).
  • If a key appears twice, both members are kept; selecting it finds the first.

Writing JSON and freeing

json.toStr(node) returns the JSON text of that node's value as a String that is yours: for an inner node just its value, without its key or the nodes after it.

  • Members are written as "key": value and items are separated by , without a space.
  • Floats get 15, 16 or 17 significant digits, the fewest that read back as the same value, always with a decimal point (0.75, 2.0, 1.0e+21); infinity and NaN, which JSON lacks, are written as null.

Strings are escaped (\", \\, \n, \t, ..., \u00XX for other control characters), so the output parses back to the same values.

The nodes inside a document - whatever json.select, the getters and next give you - are views into it: don't free or keep them after the root is released. json.release frees a whole document, and only does something when given a root; on null or an inner node it does nothing.


import json;

void main()
{
  json.Value *doc = json.parse("{\"user\": {\"id\": 7, \"roles\": [\"admin\"]}, \"n\": 1e400}");
  json.Value *user = json.select(doc, ".user");
  String s = json.toStr(user);      // just this node's value
  printf("%s\n", s);
  s.free();
  json.release(user);               // a view: ignored
  s = json.toStr(doc);              // 1e400 is too big for an f64: null
  printf("%s\n", s);
  s.free();
  json.release(doc);                // frees everything
}

Errors and strictness

The parser follows RFC 8259 strictly. It rejects:

  • trailing commas, and anything after the top-level value;
  • numbers like 01, +1, .5, 1., 1e or hex;
  • raw control characters (tab, newline, ...) inside strings;
  • whitespace other than space, tab, newline and carriage return, and anything but whitespace between a key and its :;
  • arrays and objects nested more than json.MAX_DEPTH (512) deep.

On an error json.errorStr(root) returns the message as a String (one without a ptr if there was no error) and json.printError prints it; both say where, as a line and a byte column, also found in root->state with the error code (error, line, col, offset).


import cstr, json;

Numbers and strings

An integer that fits in an i64 becomes a json.INT; a larger one becomes a json.FLOAT, as in JavaScript, and a number with a fraction or exponent is a float (one too big for an f64 is infinity). String escapes are decoded, \uXXXX and surrogate pairs to UTF-8. A string can contain \u0000, which str.len and key.len count; C-style functions and paths see them only up to the first '\0'.

json.parse's optional argument is the flags (to parse part of a text, give it the part: json.parse(text[0:n])): json.NO_FLAGS or json.STRNUM_FLAG. With json.STRNUM_FLAG numbers are not converted: each one is still checked against the JSON grammar and becomes a json.STRNUM node whose strnum is the number exactly as written, so large integers and decimals keep every digit, and json.toStr writes it back unchanged. The :i and :f checks don't match these nodes; select them without one.

Faster: @json and @yaml

Mark a struct @json (or @yaml, or both) and the compiler writes its encoder and decoder as ordinary methods, so nothing is looked up at run time. The struct's file has to import json (or yaml).

  • u.toJson(&w) writes it to a json.Writer, u.fromJson(&r) reads it from a json.Reader, and u.freeDecoded() frees what fromJson allocated. @yaml adds toYaml and fromYaml the same way.
  • json.encode, json.decode and json.free call these methods by themselves for a @json struct, also one nested in a struct without @json, so code that uses them gets faster without changes. With json.STRICT, decode keeps the reflection path.
  • A Reader made with json.readerNew(text, json.STRICT) (or yaml.readerNew(text, yaml.STRICT)) makes fromJson and fromYaml strict: a key with no field and a missing key are errors ("1:27: ship.city: missing"). @skip fields are never required.
  • On a field: @key("e-mail") gives its key in the text, @skip leaves it out, and @omitEmpty leaves it out when it is 0, empty or null.
  • A field that can't be written, such as a union, a function or a struct without @json, is a compile error at that field. Mark it @skip to leave it out.
  • ktm --expand file.ktm prints the methods the compiler made.

YAML

yaml.Reader reads a YAML document front to back and yaml.Writer writes one in block style. The Reader has the same calls as json.Reader, so one decoder can read both formats.

  • yaml.readerNew(text) views the text (keep it alive), r.free() frees the Reader. Open a mapping with r.beginObject() and loop on r.nextKey() (the key is r.key()); open a sequence with r.beginArray() and loop on r.nextItem(). Both return false at the end.
  • Read values with readString(&s), readStr() (a view), readBytes(), readInt(), readUint(), readFloat() and readBool(). isNull() reads a null if there is one, peek() says what comes next (yaml.STRING, INT, FLOAT, BOOL, NULL, ARRAY, OBJECT), skipValue() drops one, and finish() checks the whole document was read.
  • A plain (unquoted) scalar is typed by its form: true/false (also True, TRUE ...), null, ~ or nothing for null, integers (also 0x1F and 0o17) and floats (also .inf and .nan). A quoted or block scalar is always a string, and readString takes any scalar as the text it is written as.
  • Supported: block mappings and sequences, [] and {}, plain, single- and double-quoted scalars, | and > block scalars, comments, --- and .... Anchors and aliases, tags, << merge keys and several documents in one text are errors that say they are not supported.
  • Errors throw yaml.ERR_DECODE with the line, column and path: 4:10: lines[0].qty: expected an integer, got a string.

date.parse(text, format) parses a date with a strptime-like format and date.parseParts(text, format, &ds) fills a date.Parts.

  • The conversions are %Y, %m, %d, %H, %M, %s (or %S) for seconds, %a and %b for day and month names (full or three letters, any case), %p for AM/PM, %z for a zone offset and %%.
  • A space in the format matches any run of spaces; other characters must match exactly.
  • Missing time fields are 0, and without %z zone_diff is date.NO_ZONE (a value no ±hhmm offset can have).

date.monoMs() (and date.monoNs()) read a clock that only goes forward, which is what timeouts and deadlines want: date.nowMs() is the time of day and jumps when the system clock is set. date.sleepMs(ms) sleeps that long, even when a signal arrives in between. date.unixNow() is the Unix time in seconds.

All three return the socket as an i32, or -1 on failure (0 is a valid socket number). Read and write them with read/write or recv/send, and close them when done.

Addresses, like all text here, are a u8[] (a literal, a slice, a String).

  • net.dial takes a host name or an IPv4 or IPv6 address and tries every address the name resolves to.
  • The server's bind address must be numeric ("127.0.0.1", "::1"), "*" for any IPv4 address or "::*" for any IPv6 address; port 0 lets the kernel pick one.
  • Ports outside 0..65535 give -1.

Timeouts:

  • net.dial(addr, port, non_blocking, timeout_ms) gives up after timeout_ms milliseconds (shared by all the addresses the name resolves to; the name lookup itself isn't timed) with -1 and os.errno() ETIMEDOUT; 0, the default, waits as long as the system does. net.dial waits in connect either way, and non_blocking only makes the connected socket non-blocking: in a loop coroutine use coro.dial, which pauses only the coroutine (see A coroutine server).
  • net.setRecvTimeout(sock, ms) and net.setSendTimeout(sock, ms) make a read or a write on a connected socket give up after ms milliseconds with -1 and os.errno() EAGAIN (a write returns the bytes it got out first, if any).

A closed peer. Writing to a socket whose peer has closed raises SIGPIPE, which ends the program, as in C. Two ways to get an error instead:

  • net.send(sock, data), with data a u8[] (a literal, a String, buf[0:n]), is a send that adds MSG_NOSIGNAL to its optional flags: it returns -1 with os.errno() EPIPE (or ECONNRESET) instead.
  • signal.handle(libc.SIGPIPE, libc.SIG_IGN) does the same for every write and send in the program (see Signals). libc.signal(libc.SIGPIPE, libc.SIG_IGN), C's signal, works too: it takes libc.SIG_DFL, libc.SIG_IGN or a handler void F(i32 sig) passed as (&F)(i64), and returns the previous one or libc.SIG_ERR.

SIGHUP, SIGINT, SIGQUIT, SIGKILL, SIGUSR1, SIGUSR2, SIGPIPE, SIGALRM, SIGTERM, SIGCHLD and the job-control signals SIGCONT, SIGSTOP, SIGTSTP, SIGTTIN and SIGTTOU are defined in libc, with each platform's numbers.

Coroutines

A coroutine runs a function on its own stack and can pause in the middle.

  • coro.spawn(&Fn, arg) makes one (nothing runs yet; NULL if its stack can't be mapped).
  • coro.next(c) runs it until it calls coro.yield(value) and returns that value, and the next coro.next carries on after the yield.
  • When the function returns, coro.done(c) becomes TRUE and that last coro.next returns the function's return value; after that it returns NULL. A yielded NULL is a value like any other, so loops test coro.done.
  • Values also go the other way: coro.next(c, send) makes the paused coro.yield return send (the first coro.next just starts the function with its arg).
  • coro.release(c) frees it, also while it is paused.

The function is void *Fn(void *arg).

  • Coroutines can resume other coroutines (coro.current() is the running one, NULL outside), and every thread can have its own.
  • A try may span a yield. A throw that leaves the coroutine's function goes on from the coro.next that resumed it.
  • Each stack is 256 KiB unless coro.spawn's third argument says otherwise, with a guard page below it: running past it crashes the program instead of overwriting memory.
  • coro.release keeps up to 16 stacks per thread for the next coro.spawn of the same size, so short-lived coroutines (one per request) don't map and unmap a stack each time; they are unmapped when the thread ends. A cached stack behind the 4 most recently released ones gives the memory its coroutine used back to the system, keeping only its top pages, so a burst of finished coroutines doesn't stay resident.
  • coro.yield outside a coroutine, or resuming one that is running, prints a message and exits with 1.

import coro, cstr;

void *fib(void *max)
{
  i64 a = 0, b = 1, t;
  while (a < (i64)max) {
    coro.yield((void *)a);
    t = a + b;
    a = b;
    b = t;
  }
  return null;
}

A coroutine server

A server with one coroutine per connection needs a scheduler: something that knows what each coroutine waits for, polls all those fds at once and resumes the ready ones. Module coro has one. coro.go(&Fn, arg) starts a coroutine in the calling thread's loop (it first runs in coro.run; NULL if its stack can't be mapped), and coro.run() runs the loop until every such coroutine has ended; the loop releases each one when its function returns. Inside them these pause the coroutine instead of blocking the thread:

  • coro.wait(fd, events, ms) waits until fd is ready for events (libc.POLLIN, libc.POLLOUT) and returns its revents (above 0; POLLHUP and POLLERR count), or 0 once ms milliseconds passed (leave it out to wait without a limit).
  • coro.waitIdle(fd, events, ms) is the same for waiting on more work (the next request, the next client), but returns -1 when coro.stop() is called, and at once when it was called before.
  • coro.read(fd, buf, ms) reads what is there into the u8[] buf, pausing until there is something, and returns the bytes read, 0 at end of file, or -1 on an error or the timeout (ETIMEDOUT). coro.write(fd, data, ms) writes all of data, pausing while the fd is full, and returns data.len or -1 (EPIPE for a peer that closed, never a SIGPIPE). Both work on sockets and pipes, and they are the fastest way to talk to a connection: a read waits first only when nothing is likely to be there yet, and goes straight on while a stream keeps coming, for 4 ms at most before it lets the loop's other coroutines have a turn. So a coroutine that shares its loop with a saturating stream waits about 8 ms at worst, less than Go's 10 ms preemption tick, while the stream moves 12-14% more data than Go's (measured on 64 KiB streams; a shorter bound cost up to a third of that).
  • coro.sleep(ms) lets the others run for ms milliseconds; a plain coro.yield() lets them have a turn.
  • coro.dial(addr, port, ms) connects to addr (a host name or an address) and returns the connection as a non-blocking fd, pausing only the coroutine while the connection is made; every address the name resolves to is tried in turn, within ms milliseconds in all. -1 with os.errno() (ECONNREFUSED, ETIMEDOUT) when none accepts. Looking up a name still waits for the system's resolver, so give a numeric address where that matters.
  • coro.accept(listener, ms) returns the next client as a non-blocking fd (it makes the listener non-blocking too), or -1 on its timeout, on coro.stop(), or when the listener can't accept (os.errno() says why). Out of fds (EMFILE, ENFILE, or ENOBUFS/ENOMEM) it doesn't spin or try again at once (on macOS a failed accept has already dropped that client): every coro.accept of the loop rests until coro.close(fd) closes an fd, or 2 s passed. For 10 s after that it checks (with dup) before each accept that two fds are free, one for the client and one for its work, and rests again if not, so no further client is dropped. So close connections with coro.close.
  • coro.waitChild(pid, ms) waits for a child process to exit, reaps it and returns its wait status (0 or more: read it with proc.exitCode, proc.signaled and the others), or -1 when ms passed first (the child still runs; os.errno() is ETIMEDOUT) or pid isn't a child of this process (ECHILD). Any number of coroutines can each wait for a child. For a proc.spawned child give p.pid and pass the status to proc.setStatus(p, st), so p.exitCode and p.termSignal are set as proc.wait sets them.

Backends. On Linux the loop uses io_uring where the kernel allows it (6.1 or later, and not blocked: Docker's default seccomp profile blocks it, for one). coro.read, coro.write and coro.accept then go to the kernel as operations that complete when there is something to do, a wait on an fd becomes one such operation too, and one system call per turn of the loop submits them all and takes their results. A coroutine resumes only when its operation has completed, also after a timeout, coro.stop or coro.close cancelled it, so the kernel never writes into a buffer the coroutine has left. Elsewhere the loop uses the kernel's event queue, epoll on Linux and kqueue on macOS, and poll when it can't make one. Every backend behaves the same.

  • coro.backend() says which one the calling thread's loop uses: "uring", "epoll", "kqueue" or "poll".
  • KTM_CORO_BACKEND=uring, epoll (or kqueue) or poll in the environment picks one, when a thread's loop is made; one the system can't give falls back to the next one down, and an unknown value is ignored.

Each turn of the loop asks the kernel which of the waited-on fds are ready, with the nearest deadline as its timeout, so a turn costs the fds that are ready, not every fd that is open, and ten thousand idle connections cost nothing. Ready fds resume first, then the waits that timed out, earliest deadline first; new coroutines run in the order they were started. Every thread that calls coro.run has its own loop, kept with the thread's coroutine state. Each fd stays registered with the kernel between waits, and the kernel forgets an fd when it is closed, so close the fds you wait on with coro.close (it tells the loop); a program that has run out of fds when its loop starts gets poll instead, which needs none.

coro.stop() winds the loop down: coro.waitIdle and coro.accept return -1 from then on, while plain waits and sleeps go on, so the work in flight finishes and coro.run returns when it has. coro.stopping() tells whether it was called (a server sends Connection: close then). After coro.run returns, the next loop starts afresh. A SIGINT/SIGTERM stop fits as one more coroutine waiting on signal.stopInit()'s fd, as below.

The loop calls throw coro.ERR_LOOP when they can't work: coro.run inside a coroutine, coro.wait and the others outside a coroutine that coro.go started, a loop where every coroutine waits with no fd and no time limit. When a loop coroutine throws, the loop releases it and coro.run throws the error on; the other coroutines stay, and calling coro.run again carries on with them.


import coro, cstr, libc, net, signal;

i32 gListen;

void *serve(void *arg)
{// one coroutine per client: sends its line back in capitals
  i32 fd = (i32)(i64)arg;
  u8 buf[64];
  if (coro.wait(fd, libc.POLLIN, 5000) > 0) {
    i64 n = libc.recv(fd, buf, sizeof(buf), 0);
    for (i64 i = 0; i < n; i++) {
      if (buf[i] >= 'a' && buf[i] <= 'z') { buf[i] -= 'a' - 'A'; }
    }
    if (n > 0) { net.send(fd, buf[0:n]); }
  }
  coro.close(fd);
  return null;
}

void *acceptor(void *unused)
{// a coroutine per client, until coro.stop()
  i32 fd;
  while ((fd = coro.accept(gListen)) != -1) { coro.go(&serve, (void *)(i64)fd); }
  return null;
}

void *onSignal(void *unused)
{// Ctrl-C or SIGTERM: stop taking clients, finish the rest
  if (coro.waitIdle(signal.stopInit(), libc.POLLIN) > 0) { coro.stop(); }
  return null;
}

void ask(u8 *word)
{
  u8 buf[64];
  i32 fd = net.dial("127.0.0.1", net.localPort(gListen), true);
  coro.wait(fd, libc.POLLOUT, 5000);
  net.send(fd, cstr.view(word));
  if (coro.wait(fd, libc.POLLIN, 5000) > 0) {
    i64 n = libc.recv(fd, buf, sizeof(buf) - 1, 0);
    if (n > 0) {
      buf[n] = 0;
      printf("%s -> %s\n", word, buf);
    }
  }
  libc.close(fd);
}

void *clients(void *unused)
{// the server's clients, in the same loop; then it stops
  ask("ping");
  ask("hello");
  coro.stop();
  return null;
}

void main()
{
  gListen = net.listen(0, "127.0.0.1", 16);
  coro.go(&acceptor);
  coro.go(&onSignal);
  coro.go(&clients);
  coro.run();
  libc.close(gListen);
  printf("stopped\n");
}

import coro, proc;

void *job(void *arg)
{
  u8 *script = arg;
  u8 *argv[4] = {"/bin/sh", "-c", script, null};

  i32 st = coro.waitChild(p.pid, 5000);
  proc.setStatus(p, st);
  printf("[%s] exit %d\n", script, p.exitCode);
  proc.release(p);
  return null;
}

{
  for (i64 i = 0; i < 3; i++) {
    printf("still working\n");

  }
  return null;
}

Serving on every core

coro.serve(port, &handler, arg, threads, bindaddr) is a whole TCP server in one call: it runs void handler(i32 fd, void *arg) as a coroutine for each client, on one coroutine loop per thread, so the work spreads over the machine's cores.

i32 r = coro.serve(8080, &handle);   // every IPv4 address, one loop per CPU
  • threads 0, the default, is one loop per CPU the process may use (its affinity mask on Linux, the CPUs online on macOS). The calling thread runs one of the loops, so serve returns only when the server has stopped; call it from a thread, not from a coroutine (that throws coro.ERR_LOOP).
  • bindaddr is "*" (every IPv4 address, the default), "::*" (every IPv6 address) or a numeric address, as for net.listen.
  • The client's fd is non-blocking with TCP_NODELAY set: read and write it with coro.read and coro.write as in any loop coroutine, and don't close it, serve closes it with coro.close when the handler returns. A handler that throws is reported on stderr and the server goes on.
  • It returns 0 once stopped and every handler has finished, or -1 with os.errno() when the listeners can't be made (a port outside 0..65535, a bad address, the port in use) or a listener breaks later.

Handlers run on several threads at once. Two clients' handlers may run at the same moment on different cores, so a global they share (a counter, a cache, a map) needs the atomic module or a lock. Everything else about a handler is as in a single loop: it pauses in coro.wait, coro.sleep and the others, and the coroutines of one loop never run at the same time.

Stopping. coro.serveStop() stops every running coro.serve, from any thread or any coroutine (not from a signal handler itself): each loop stops taking clients, the handlers in flight finish, then serve returns 0. A coro.stop() in one of its loops stops the whole server the same way, so the SIGINT/SIGTERM coroutine of the previous section works unchanged: start it with coro.go before calling serve, and it runs in the calling thread's loop. Give it coro.waitIdle, as there, so it doesn't keep its loop running once the server has stopped some other way.

How the clients are spread. On Linux each loop has a listener of its own on the same port (SO_REUSEPORT), and the kernel shares the connections out between them. macOS gives every connection to just one of several such listeners, so there the loops share one listener and each takes the clients it wins the accept for: correct, and still on every core, but a busy loop accepts as eagerly as an idle one.

Fuzzy matching

fzf.match(text, pattern) matches text the way the fzf tool does and returns the score and the matched byte offsets, or NULL when it doesn't match. Terms separated by spaces must all match, a | b takes either.

TermMatches
termFuzzy: its characters in order, with gaps
'termAn exact substring
^termA prefix
term$A suffix
^term$The whole text
!termMust not occur
  • \ is a space inside a term.
  • With the default fzf.CASE_SMART a term is case-sensitive only when it has an upper-case letter; fzf.CASE_IGNORE and fzf.CASE_RESPECT force it.
  • Passing false as the last argument makes plain terms exact (and 'term fuzzy).
  • The offsets come term after term, so they are only sorted for a single term, and the matcher is fzf's greedy one: it finds a match, not always the best-scoring placement.
  • The pattern is not modified, so a string literal is fine. fzf.match keeps no shared state, so threads can call it at the same time.

import cstr, fzf;

void show(u8 *text, u8 *pattern)
{
  fzf.Position *m = fzf.match(text, pattern);
  printf("%-12s %-11s ", text, pattern);
  if (!m) {
    printf("no match\n");
    return;
  }
  printf("score %d at", m.score);
  for (i64 i = 0; i < m.size; i++) { printf(" %d", m.data[i]); }
  printf("\n");
  fzf.release(m);
}

void main()
{
  show("src/main.ktm", "smkm");
  show("src/main.ktm", "smKM");
  show("src/main.ktm", "ktm$ main");
  show("src/main.ktm", "^src 'main");
  show("src/main.ktm", "!test main");
  show("my file.txt", "my\\ file");
}

SQLite

The SQLite functions exist when ktm and the library are built with ./build.sh --sqlite (they are under #ifdef __KTM_LINK_SQLITE3__).

  • sql.open(path) opens a database (":memory:" for a private one; the sql.Db keeps its own copy of the name) and sql.close closes it.
  • sql.execRaw runs a script of statements and returns its error as a new String, empty when it ran.
  • sql.exec and sql.select run one statement with ? parameters from an array of sql.Param (sql.INT, sql.FLOAT, sql.TEXT with str a u8[], sql.BLOB, sql.NULL_TYPE); text and blobs are copied, so they can be freed right away, and an empty text binds ''. The SQL is a u8[] too, so script[0:n] runs part of a buffer. A text with a second statement is an error rather than half-run.
  • sql.next steps through the rows of sql.select and frees the row after the last one; call sql.rowRelease if you stop early. A column's str (a u8[] view) and blob are only valid until the next row.

import sql;

void main()
{
  sql.Db *db = sql.open(":memory:");
  String err = sql.execRaw(db, "CREATE TABLE users(id INTEGER, name TEXT);");
  if (err.len) {
    printf("%s\n", err);
  }
  err.free();

  sql.Param p[2];
  p[0].type = sql.INT;
  p[0].intVal = 1;
  p[1].type = sql.TEXT;
  p[1].str = "ann";
  sql.exec(db, "INSERT INTO users VALUES(?, ?);", p, 2);

  sql.Row row;
  if (sql.select(db, &row, "SELECT id, name FROM users;")) {
    while (sql.next(&row)) { printf("%d %s\n", row.col[0].intVal, row.col[1].str); }
  }
  sql.close(db);
}

sql.prepare compiles a statement once (null on an error) and sql.execPrepared(stmt, &row, params) runs it with new parameters, returning SQLITE_ROW, SQLITE_DONE or an error code; read its rows with sql.nextPrepared. A parameter it can't bind (an unknown type gives SQLITE_MISMATCH, a string over sqlite's length limit SQLITE_TOOBIG) returns that error without running the statement. Such a row belongs to the statement, which sql.finalize frees.

Atomics

Module atomic changes an integer that several threads share without a mutex: a counter they all add to, a flag one thread sets and others read, a lock-free swap.

FunctionDoes
atomic.add(&n, v), subAdds (subtracts) and returns the value from before
swap(&n, v)Stores and returns the old value
and, or, xorApply a bit operation and return the old value
load(&n), store(&n, v)Reads, writes
cas(&n, expected, desired)Stores desired only if n still holds expected, and says whether it did
loadPtr, storePtr, swapPtr, casPtrThe same for a void *
atomic.fence()A full memory barrier

Each takes an i64 *, i32 *, u64 * or u32 *, and the pointer picks the width (the values are passed as i64).

  • Every operation is sequentially consistent: all threads see all of them in one order, and no other load or store moves across one, so a value written before store(&flag, 1) is there for a thread that has read the 1 with load.
  • The integer must be aligned to its size, as a variable, a struct field or mem.alloc'd memory always is.

Each operation is one function call (LOCK XADD, XCHG and LOCK CMPXCHG on x86_64; LDAXR/STLXR loops, LDAR and STLR on arm64). Use them only on memory more than one thread touches; for anything bigger than one integer, a mutex is still simpler. atomic used to be a keyword that was accepted and ignored: atomic i64 n; is an error now, with a pointer to this module.


import atomic, libc;

i64 gHits = 0;      // shared by every thread
i64 gPlain = 0;     // the same, without atomics

void *worker(void *unused)
{
  for (i64 i = 0; i < 100000; i++) {
    atomic.add(&gHits, 1);
  }
  return null;
}

void main()
{
  libc.pthread_t *th[4];
  for (i64 i = 0; i < 4; i++) { libc.pthread_create(&th[i], null, &worker, null); }
  for (i64 i = 0; i < 4; i++) { libc.pthread_join(th[i]); }
  printf("%d hits\n", atomic.load(&gHits));

  i64 flags = 0b0101;
  i64 before = atomic.or(&flags, 0b0010);
  printf("or: %d -> %d\n", before, flags);
  bool swapped = atomic.cas(&flags, 7, 0);    // flags is 7: now 0
  bool again = atomic.cas(&flags, 7, 1);      // flags isn't 7 any more
  printf("cas: %d %d, flags %d\n", swapped, again, flags);
}

More modules

These are covered in the library reference:

  • Threads: pthreads (pthread_create, mutexes, condition variables) and a thread pool: thread.poolNew(n) (NULL if n <= 0 or a thread can't start), thread.poolEnqueue(pool, argv, &Fn) runs Fn(pool.priv_data, argv) on a worker, thread.poolWait waits until the queue is empty (never call it from inside a job), thread.poolRelease runs what is left and frees the pool.
  • Networking: sockets, getaddrinfo and friends. net.unixListen(path, backlog) and net.unixDial(path) make Unix domain sockets; they return -1 on failure, also when the path is longer than 107 bytes on Linux or 103 on macOS. The address structs (sockaddr_in, sockaddr_un, addrinfo, ...) have the platform's C layout, and SOL_SOCKET, SO_*, AF_INET6, IPPROTO_*, TCP_* and AI_* the platform's values.
