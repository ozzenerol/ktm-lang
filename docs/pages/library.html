Library guide

How to use the standard library for everyday tasks. Every program can use it without an #include. For every function and class, see the library reference.

Memory

MAlloc(size)Allocate size bytes
CAlloc(size)Allocate size zeroed bytes

Free(ptr)Release it (null is fine)
MSize(ptr)The size an allocation was asked for (0 for null)

CAlloc takes one argument, the total size, unlike C's calloc(count, size). MAlloc, CAlloc and ReAlloc return null when out of memory or when the size is too large (a negative size passed as a u64, say). ReAlloc always moves the block and copies as much of it as fits; ReAlloc(null, size) is MAlloc(size), and when it fails the old block is left as it was, so keep the old pointer until you know it worked. Each block carries its size in a hidden header, so only pointers from these functions can go to Free, MSize and ReAlloc. MemCpy copies front to back: for overlapping buffers use memmove.


import mem;

struct Player
{
  u8 *name;
  i64 score;
};

void main()
{
  Player *team = mem.allocZero(3 * sizeof(Player));
  team[0].name = "ada";
  team[0].score = 10;
  team = mem.realloc(team, 4 * sizeof(Player));
  team[3].name = "linus";
  printf("%s %d, %s\n", team[0].name, team[0].score, team[3].name);
  mem.free(team);
}

Run a program with ktm -jit -Memsafe file.ktm to have double frees and wild frees reported (and skipped) as they happen, and leaks reported at exit, each with the line that allocated or freed the block, in any thread. Only blocks your code gets from MAlloc, CAlloc and ReAlloc are tracked: a string or container the standard library allocates for you (StrNew, StrPrint, PtrVecNew, ...) is not, so leaking one goes unreported, and a block of yours that the library resizes (CatPrint, CatLenPrint) is reported as never freed.

Strings

A string is a NUL-terminated u8 array. Functions that make a string (StrNew, StrPrint(null, ...), MStrPrint, StrMerge, StrNCpy, MPrintQ, MPrintDate, MPrintTime, MPrintTimestampNow) return a new block that you Free. The trimming and ...Rem functions change the string you pass, in place, so give them a copy rather than a literal. Case conversion and the case-insensitive compares only know ASCII letters.

Building strings

StrPrint(null, fmt, ...) returns a newly allocated formatted string, and CatPrint(s, fmt, ...) appends the formatted text to the heap string s and returns it, so write s = CatPrint(s, fmt, ...): when s is full it is grown, which may move it and frees the old block. s must come from MAlloc, StrNew, StrPrint(null, ...) or an earlier CatPrint, or be null to start a new string; never pass a string literal or a stack buffer. CatPrint measures s on every call, so appending in a long loop is quadratic; CatLenPrint(s, &len, fmt, ...) keeps the length in len and doesn't. StrMerge("a", "b", ...) joins strings and MStrPrint(fmt, ...) is StrPrint into an exactly sized block.


import mem, str;

Format conversions

StrPrint, CatPrint and the other formatting functions share one format language with print statements. Integers are always 64-bit, and the C length modifiers l, ll, h, hh, z and j are accepted and ignored, so C formats can be pasted in.

ConversionPrints
%d %ia signed integer
%uan unsigned integer
%x %X %ohexadecimal (lower / upper case), octal
%f %e %gan f64, as C's printf prints it
%sa string
%c %Ca character; a multi-character constant like 'abc' prints all its characters (up to 8), %C in upper case; the value 0 prints nothing
%pa pointer as 0x and 16 hex digits
%D %Ta CDate as MM/DD/YYYY / HH:MM:SS
%Qa string escaped for a C literal (MPrintQ)
%Fthe contents of the file whose name is the argument (nothing if it can't be read)

Between the % and the letter come, in order: the flags - (left justify), 0 (pad with zeros), + (always a sign), a space (a space where a plus sign would go) and # (0x / 0 prefix for hex and octal); a width; and a precision after a ., which is the number of decimals for floats, the maximum length for %s and the minimum number of digits for integers (%.3d of 7 is 007). Width and precision can be *, taken from the arguments. An unknown conversion is printed as it was written, with a warning on stderr, and still uses up its argument, so the ones after it stay in place.

StrPrint(buf, fmt, ...) writes into buf with no bound. For a fixed-size buffer use StrNPrint(buf, size, fmt, ...), which works like C's snprintf: it writes at most size - 1 characters and always ends them with a '\0', cutting longer output short. It returns buf.

Inspecting strings

StrCmp, StrNCmp and StrNICmp return a negative, zero or positive number like C's strcmp, comparing bytes as unsigned, and sort a null before every string. StrFirstOcc and StrLastOcc find the first or last character of the first string that is any of the characters in the second. WildMatch matches a whole string against a pattern where * is any run of characters and ? any one character. StrHash gives a well mixed 64-bit hash of a string.


import fs, str;

void main()
{
  printf("%d %d\n", str.len("hello"), str.cmp("abc", "abc") == 0);
  printf("%d\n", str.cmpLen("prefix-rest", "prefix", 6) == 0);
  printf("%d %d\n", str.cmp("abc", "abd") < 0, str.cmpLenNoCase("ABC", "abc", 3) == 0);
  printf("%d\n", str.count("banana", 'a'));               // count a character
  printf("%s\n", str.firstOf("key=value", "="));       // from the first match
  printf("%s\n", str.lastOf("a/b/c.ktm", "/"));         // from the last match
  printf("%s\n", fs.ext("archive.tar.gz"));
  printf("%d %d %d\n", str.globMatch("main.ktm", "*.ktm"), str.globMatch("main.c", "*.ktm"),
    str.globMatch("banana", "b?n*a"));
  printf("%d\n", str.toInt("1234") + 1);
  printf("%c %c %d\n", str.toUpper('q'), str.toLower('Q'), str.isSpace(' '));
}

Copying and trimming

StrNew copies a whole string and StrNCpy(s, n) at most the first n bytes of it, like C's strndup (a negative n is 0). StrCpy copies into a buffer you provide. StrTrimStart and StrTrimEnd remove whitespace in place and return the same pointer; pass a length as the second argument to look only at that many bytes, or -1 for the whole string.


import mem, str;

void main()
{
  u8 *copy = str.dup("  padded  ");
  i64 len;
  str.trimStart(copy, -1, &len);
  printf("[%s] %d\n", copy, len);
  str.trimEnd(copy, -1, &len);
  printf("[%s] %d\n", copy, len);

  u8 *part = str.dupLen("truncate me", 8);
  printf("[%s]\n", part);

  u8 buf[16];
  str.copy(buf, "fixed");
  printf("%s\n", buf);
  mem.free(copy);
  mem.free(part);
}

Splitting paths and names

These come from the original library. StrFirstRem(s, markers, dst) moves the part before the first marker character into dst and leaves the rest in s; StrLastRem does the same with the part after the last marker. Both change s in place, and dst may be null. FileExtRem(name, dst) cuts the extension off name and puts it, without the dot, in dst. FileExtDot finds the first . that isn't followed by / or ., and IsDotZ / IsDotC are TRUE for names like Doc.ktm.Z: the name must end in .Z / .C and have another dot before it.


import fs, str;

void main()
{
  u8 path[32], first[16], last[16], ext[8];
  str.copy(path, "usr/lib/libktm.a");
  str.splitFirst(path, "/", first);
  printf("%s + %s\n", first, path);
  str.splitLast(path, "/", last);
  printf("%s + %s\n", path, last);
  fs.cutExt(last, ext);
  printf("%s . %s\n", last, ext);
  printf("%d %d\n", IsDotZ("Doc.ktm.Z"), IsDotZ("Doc.Z"));
}

Files

FileWrite writes a buffer to a file and returns whether it worked. FileRead reads a whole file into a new NUL-terminated buffer, or returns null if it can't.


import fs, mem, str;

void main()
{
  u8 *path = "/tmp/ktm_docs_example.txt";
  u8 *text = "first line\nsecond line\n";
  if (!fs.writeAll(path, text, str.len(text))) {
    printf("could not write %s\n", path);
    return;
  }

  i64 size;
  u8 *contents = fs.readAll(path, &size);
  printf("%d bytes\n%s", size, contents);
  mem.free(contents);

  if (fs.readAll("/no/such/file", &size) == null) {
    printf("missing files give NULL\n");
  }
}

FileWrite replaces the file's contents: by default it opens with O_CREAT | O_WRONLY | O_TRUNC (a new file gets mode 0644 minus the umask). Pass the flags yourself to do something else, O_CREAT | O_WRONLY | O_APPEND to add to the end. A null name or buffer or a negative size gives false and creates nothing. FileRead reads a regular file up to its size, and a FIFO, a pipe (/dev/fd/N, /dev/stdin), a device or a /proc file (which reports size 0) until end of file, so it waits for a FIFO's writer and never finishes on an endless device like /dev/zero. For a directory it returns null, and on any failure it sets *_size to 0.

Directories: MkDir(path) makes one directory and MkDir(path,, true) the missing parents too; both return 0 if the path is a directory afterwards (made now or already there) and -1 if not, the convention Rm and RmDir use too. Rm(path) removes a file, a symlink (never what it points to) or an empty directory; with RM_RECURSE a directory and everything in it, with RM_FORCE a path that doesn't exist is not an error, and only RM_VERBOSE makes it print. RmDir is the directory half of it. Dir(path) prints the entries one per line (in colour on a terminal) and returns how many there are, or -1 if it can't open the directory: names that start with a number are ordered by that number, the rest by name. Stat(&fst, path) fills an Fstat (size, mode, times), Cd changes directory (~ is $HOME) and Pwd() returns the working directory as a new string to Free.

CSV

CsvParse walks a CSV buffer without copying it: each call gives the next field (CSV_FIELD), then the whole row (CSV_ROW), and CSV_EOF at the end. A CsvSlice is where that piece is in the buffer (off, len) and its number (idx, the field in its row or the row). The slices are the raw text: a quoted field keeps its quotes and its doubled "", commas and newlines inside quotes don't split, and a row's length includes its \n or \r\n. Unquoting is up to you.


import csv, str;

void main()
{
  u8 *csv = "name,quote\r\nann,\"say \"\"hi\"\", ok\"\nbob,\n";
  csv.Parser p;
  csv.Slice s;
  i64 kind;
  csv.init(&p, csv, str.len(csv));
  while ((kind = csv.next(&p, &s)) != csv.EOF) {
    if (kind == csv.FIELD) { printf("field %d: [%.*s]\n", s.idx, s.len, csv + s.off); }
    else                   { printf("row %d: %d bytes\n", s.idx, s.len); }
  }
}

Print statements are buffered, while commands write straight to the terminal. When output goes to a pipe or file, a command's output can appear before text you printed earlier.

System and Sh run the command with sh -c and return its exit code, 0 to 255: System("exit 3") gives 3, and a command the shell can't find gives 127. They return -1 if the command was killed by a signal or the shell couldn't be run.

Shlurp returns what the command printed to stdout, minus one trailing newline, as a string to Free; format arguments are optional. It doesn't capture stderr or return the exit status: a failing command gives whatever it printed, often "". It returns once the shell exits, without waiting for a background job (cmd &) the command started. Exit(code) ends the program.

The commands get the program's stdin, stdout and stderr, but none of the files or sockets the library opened: those (the Net* sockets and accepted connections, FileRead/FileWrite's file, Shlurp's pipe) are close-on-exec. An fd you open yourself with open or socket is inherited unless you pass O_CLOEXEC (Linux also has SOCK_CLOEXEC) or set FD_CLOEXEC with fcntl(fd, F_SETFD, FD_CLOEXEC).

The command is shell text, so a string from elsewhere (a file name, user input) must not be pasted in as it is: a space splits it and $, `, ; or * run or expand things. ShQuote(s) returns s in single quotes as a new string to Free, with each ' written as '\'' (and '' for null), so the shell gets it as one word, unchanged.


import mem, proc;

void main()
{
  u8 *q = proc.shellQuote("it's $HOME; *");
  u8 *out = proc.shellOutput("printf '%%s' %s", q);
  printf("[%s]\n", out);
  mem.free(out);
  mem.free(q);
}

Running programs without a shell

ProcRun(argv, &code) runs a program with the arguments in argv, a NULL-terminated array, and returns what it printed to stdout (minus one trailing newline, to Free) with its exit code in code. No shell is involved: every argument reaches the program exactly as written, so nothing needs quoting. The program is looked up in $PATH; NULL means it couldn't be started, and Errno() says why (2, ENOENT, for a program that doesn't exist).


import mem, proc;

void main()
{
  u8 *argv[] = {"printf", "%s|", "it's $HOME", "a b", null};
  i64 code;
  u8 *out = proc.run(argv, &code);
  printf("[%s] exit %d
", out, code);
  mem.free(out);
}

For more control, ProcSpawn(argv, &opts) starts the program and returns a Proc. In ProcOpts each of in, out and err is PROC_INHERIT (ours, the default), PROC_PIPE (our end is p->in_fd, out_fd or err_fd), PROC_NULL (/dev/null) or, for err, PROC_STDOUT (2>&1); cwd and env (a NULL-terminated "NAME=value" list that replaces the environment) are optional. ProcCommunicate(p, input, len, &out, &out_len, &err, &err_len) writes the input, reads both outputs to the end and waits, all in one poll() loop, so a program that writes a lot to both, or echoes its input, can't block. ProcWait(p) returns the exit code, or -1 when a signal killed the program (p->term_signal says which); ProcDone(p) checks without waiting, ProcKill(p, sig) signals it (the whole group with new_group), and ProcRelease(p) closes the pipes and frees it, waiting for a program that is still running.


import mem, proc;

void main()
{
  u8 *argv[] = {"sh", "-c", "tr a-z A-Z; echo done >&2; exit 3", null};
  proc.Opts opts;
  mem.set(&opts, 0, sizeof(proc.Opts));
  opts.in = proc.PIPE;
  opts.out = proc.PIPE;
  opts.err = proc.PIPE;
  proc.Proc *p = proc.spawn(argv, &opts);
  u8 *out, *err;
  i64 code = proc.communicate(p, "hello\n", 6, &out, null, &err);
  printf("out=%s err=%s exit=%d\n", out, err, code);
  mem.free(out);
  mem.free(err);
  proc.release(p);
}

The program starts with default signal handlers and only stdin, stdout and stderr open: it inherits none of your sockets or files. System, Sh and Shlurp are still the tools for shell pipelines, globs and redirections; use the Proc functions whenever an argument comes from a file name or user input.

Signals

SigHandle(sig, handler, flags, mask, &old) sets what happens when a signal arrives: SIG_DFL, SIG_IGN, or a function void F(i32 sig) passed as (&F)(i64). flags defaults to SA_RESTART, which makes a blocking read, write or accept carry on after the handler; pass 0 to have it return -1 with Errno() == EINTR instead (poll always does). mask (SigBit(SIGUSR2) | ...) holds other signals back while the handler runs, and old, if given, receives the previous action, so it can be put back with SigAction(sig, &old). signal(sig, handler) is the same as SigHandle with SA_RESTART, and the two can be mixed.


import libc, signal;

i64 hits = 0;
void onUsr1(i32 sig)
{
  hits++;
}

void main()
{
  signal.Action old;
  signal.handle(libc.SIGUSR1, (i64)(&onUsr1), libc.SA_RESTART, 0, &old);
  libc.raise(libc.SIGUSR1);
  libc.raise(libc.SIGUSR1);
  signal.action(libc.SIGUSR1, &old);      // back to what it was
  printf("%d signals, previous handler SIG_DFL: %d\n", hits, old.handler == libc.SIG_DFL);
}

2 signals, previous handler SIG_DFL: 1

A handler interrupts the program wherever it is, on whichever thread the signal reached, so it may only set a global variable, call write, _exit, kill or raise, and keep Errno() as it found it. Allocating, printing, throw or taking a mutex there can deadlock or corrupt memory: the interrupted code may be in the middle of the same thing. Actions are shared by all threads, and a signal sent to the process is handled by one of them, whichever doesn't block it.

For a server built around poll(), SigStopInit() does this for SIGINT and SIGTERM: it returns an fd to add to the poll set, which becomes readable when either signal arrives, and from then on SigStopRequested() is TRUE (SigStopSignal() says which one came). The loop finishes what it is doing and returns. A second Ctrl-C ends the program as usual, in case the loop never gets there.


import libc, signal;

void main()
{
  i32 fd = signal.stopInit();
  libc.pollfd p;
  p.fd = fd;
  p.events = libc.POLLIN;
  libc.raise(libc.SIGTERM);                // as if `kill` had been run on us
  if (libc.poll(&p, 1, 1000) == 1 && signal.stopRequested()) {
    printf("stopping cleanly after signal %d\n", signal.stopSignal());
  }
}

Lists

List is a circular doubly linked list of void * values. The list is its head node, which links to itself when the list is empty, so iterate from l->next until you get back to l. The list never frees the values it holds unless you hand it a free function.


import list;

void main()
{
  list.List *l = list.new();
  l.append("two");
  l.append("three");
  l.prepend("one");

  for (list.List *it = l.next; it != l; it = it.next) {
    printf("%s\n", it.value);
  }
  printf("first %s, last %s\n", l.first(), l.last());
  printf("popped %s, %d left\n", l.pop(), l.count());
  l.release(null);
}

  • Making one. ListNew() allocates a head; free it with ListRelease. ListInit(&head) turns a head you own (on the stack, or inside a class) into an empty list; empty that one with ListClear, because ListRelease also frees the head.
  • Adding. ListAppend and ListPrepend add at the end and the front; ListInsertValueBefore(node, value) inserts before any node (before the head is the end), and ListInsertBefore(node, new_node) links in a node you made yourself.
  • Removing. ListDeque removes and returns the first value and ListPop the last, so ListAppend with ListDeque is a first-in first-out queue and ListAppend with ListPop a stack. ListRemove(node) unlinks one node while you walk the list (take it->next first) and returns its value; never pass it the head.
  • Looking. ListFirst and ListLast return a value without removing it, ListEmpty tells whether there are any, and ListCount counts them by walking the list, so it is O(n).
  • Emptying. ListClear(l, free_value) frees every node and keeps the head; ListRelease(l, free_value) frees the nodes and the head. Both call free_value on each value when it isn't null.
  • Joining. ListMergeAppend(l1, l2) and ListMergePrepend(l1, l2) move all of l2's values to the end or the front of l1 and free l2's head, so l2 (which must come from ListNew) can't be used afterwards.

ListDeque, ListPop, ListFirst and ListLast return null for an empty list, which looks the same as a stored null: check ListEmpty first if you store them. The functions that remove, look or free accept a null list and do nothing (returning null, 0 from ListCount, true from ListEmpty); the ones that add need a real list.


import list, mem, str;

void main()
{
  list.List todo;              // a head on the stack
  todo.init();
  todo.append(str.dup("write"));
  todo.append(str.dup("test"));
  todo.append(str.dup("ship"));

  list.List *it = todo.next;
  while (it != &todo) {   // drop "test" while walking
    list.List *next = it.next;
    if (!str.cmp(it.value, "test")) { mem.free(it.remove()); }
    it = next;
  }

  list.List *later = list.new();
  later.append(str.dup("rest"));
  todo.mergeAppend(later);   // `later` is freed

  printf("(%d)\n", todo.count());

Vectors

Growable arrays: IntVec of i64, FloatVec of f64 and PtrVec of pointers. Each has size and entries fields, so a range-based for works on them. The functions are the same for the three, with the type as prefix:

  • IntVecNew(size = 32) makes an empty vector with room for size values (its initial capacity); a size below 1 is taken as 1. IntVecCapacity says how many values fit before the storage has to grow, and IntVecPush appends, doubling the storage when it is full.
  • IntVecGet(v, i) and IntVecSet(v, i, value) read and replace an entry. The index is always checked: outside 0 to size - 1 they print IntVecGet: index 5 out of range (size 3) on stderr and exit with status 1. Reading v->entries[i] directly is not checked.
  • IntVecPop(v, &ok) removes and returns the last entry and IntVecLast(v, &ok) returns it without removing it. On an empty vector they return -1 (-1.0 for FloatVec, null for PtrVec) and set ok to false; the ok argument is optional.
  • IntVecClear sets the size to 0 and keeps the storage for reuse; IntVecRelease frees it. PtrVecRelease(v, free_value) first calls free_value (for example &Free) on every value.
  • IntVecSort and FloatVecSort sort ascending. PtrVecSort takes a comparison that returns true when its first argument should come first. That's a "less than" test, not a C-style negative, zero or positive result, which leaves the vector unsorted. The sorts are O(n log n), also for sorted or all-equal input, and not stable: equal values may change order.

Sets and trees

IntSet is a sorted set of i64 values. IntSetAdd, IntSetDelete and IntSetHas are O(log n); adding a value that is there, or deleting one that isn't, changes nothing. IntSetUnion, IntSetIntersection, IntSetDiff (in the first set, not the second) and IntSetSymDiff (in exactly one) return a new set and leave their arguments alone; IntSetEq compares two sets. An iterator, IntSetToVec and IntSetToString give the values in ascending order. Don't add or delete values while iterating: once one is added or deleted, IntSetIterNext returns null and the loop ends early, so collect the changes and apply them after it. The functions that only read a set, and IntSetRelease, treat null as the empty set.

Iteration (StrMapIter, StrMapKeyIter, StrMapValueIter and the IntMap ones) follows insertion order. Start the cursor at 0 and call until it returns false; the cursor is opaque, so don't compute with it. Deleting entries while iterating is safe (the loop above could delete node->key); adding entries is not, as an added entry can be skipped or the table rebuilt under the loop. A deleted key can be set again and then comes last. StrMapToString, IntMapToString and the KeysToString versions print a map, in insertion order, into a new string you free.

StrMapNew and IntMapNew take an optional starting capacity (default 32): the number of slots, rounded up to a power of two, at least 8 (a negative request gets 8 and one above 228 gets 228). The table is rebuilt, doubling, when its entries and deleted holes fill 60% of the slots, so a capacity of 1024 holds about 600 entries before it grows. It never shrinks, not on delete and not on clear; release it and make a new one to give the memory back. StrMapResize and IntMapResize double it ahead of time. They and the New functions return false or null when out of memory, as does a Set that needed to grow the table.

StrMapSetFreeKey, StrMapSetFreeValue and IntMapSetFreeValue register destructors. With them the map owns what you give it: they run on Delete, Clear and Release, and when Set replaces a value. Setting a key that is already there keeps the key the map stores and frees the old value and the key you passed (nothing is freed when you pass the stored pointers again). A pointer used as both the key and the value (StrMapSet(m, s, s)) is freed once. Set returns true for a new key and an update alike; check Has first to know which. A null map or key is safe everywhere: Get and Has give null and false, Set and Delete false, and Release and Clear do nothing.

The map keeps the key pointer you pass the first time a key is set, instead of copying it. Use keys that live as long as the map, such as StrNew copies; updating an existing key from a reused buffer is fine. With a key destructor registered, an update frees the key you passed: don't use it after StrMapSet returns.

Parsing and selecting

JsonParse(text) parses text into a tree of Json nodes and returns its root; the text can be any one JSON value (an object, array, string, number, boolean or null). It always returns a root: check JsonOk before using it, and free it with JsonRelease either way. JsonSelect(node, path) walks a path from any node: .key for an object member, [n] for an array item, and a type check that must match: :s string, :i integer, :f float, :b boolean, :a array, :o object, :! null. It returns null if the path doesn't match or is malformed ([1x], ..a, a trailing .).


import json, mem;

void main()
{
  u8 *text = "{\"name\": \"ktm\", \"version\": 15, \"ratio\": 0.75, \"tags\": [\"jit\", \"repl\"], \"stable\": false, \"owner\": null}";
  json.Value *doc = json.parse(text);
  if (!json.ok(doc)) {
    json.printError(doc);
    json.release(doc);
    return;
  }

  printf("%s v%d\n", json.select(doc, ".name:s").str, json.select(doc, ".version:i").intVal);
  printf("second tag: %s\n", json.select(doc, ".tags[1]:s").str);
  printf("stable: %d, owner is null: %d\n", json.select(doc, ".stable:b").boolean,
    json.select(doc, ".owner:!") != null);
  printf("missing: %d, wrong type: %d\n", json.select(doc, ".author") == null,
    json.select(doc, ".version:s") == null);

  json.Value *tags = json.select(doc, ".tags:a");
  for (json.Value *t = tags.array; t; t = t.next) {
    printf("tag %s\n", t.str);
  }

  u8 *out = json.toStr(doc);
  printf("%s\n", out);
  mem.free(out);
  json.release(doc);
}

Each node has a type and its value in the matching field: JSON_STRING in str, JSON_INT in i64, JSON_FLOAT in f64, JSON_BOOL in boolean, JSON_NULL, JSON_STRNUM in strnum (see below), and JSON_ARRAY / JSON_OBJECT, whose array / object points at the first item or member - or is null when the array or object is empty. A member has its name in key, and next leads to the following item or member, so that is how you iterate.

Wildcards and getters

A * in a path takes the next argument: an i64 inside [], a string after ., and it can be part of a name (.price_*). Each part of a path is at most 256 bytes, and a key that contains . [ ] : or * can't be written in a path. JsonObjectGet(obj, key) and JsonArrayGet(arr, i) take any key or index directly (null if it isn't there or the node has the wrong type), and JsonLen counts the items of an array or object (0 for anything else). If a key appears twice, both members are kept; selecting it finds the first.

Writing JSON and freeing

JsonToString(node) returns the JSON text of that node's value as a new string to Free: for an inner node just its value, without its key or the nodes after it. Members are written as "key": value and items are separated by , without a space. Floats get 15, 16 or 17 significant digits, the fewest that read back as the same value, always with a decimal point (0.75, 2.0, 1.0e+21); infinity and NaN, which JSON lacks, are written as null. Strings are escaped (\", \\, \n, \t, ..., \u00XX for other control characters), so the output parses back to the same values.

The nodes inside a document - whatever JsonSelect, the getters and next give you - are views into it: don't free or keep them after the root is released. JsonRelease frees a whole document, and only does something when given a root; on null or an inner node it does nothing.


import json, mem;

void main()
{
  json.Value *doc = json.parse("{\"user\": {\"id\": 7, \"roles\": [\"admin\"]}, \"n\": 1e400}");
  json.Value *user = json.select(doc, ".user");
  u8 *s = json.toStr(user);      // just this node's value
  printf("%s\n", s);
  mem.free(s);
  json.release(user);               // a view: ignored
  s = json.toStr(doc);           // 1e400 is too big for an f64: null
  printf("%s\n", s);
  mem.free(s);
  json.release(doc);                // frees everything
}

Errors and strictness

The parser follows RFC 8259 strictly. It rejects trailing commas, anything after the top-level value, numbers like 01, +1, .5, 1., 1e or hex, raw control characters (tab, newline, ...) inside strings, whitespace other than space, tab, newline and carriage return, anything but whitespace between a key and its :, and arrays and objects nested more than JSON_MAX_DEPTH (512) deep. On an error JsonGetStrerror(root) returns a message to Free (null if there was no error) and JsonPrintError prints it; both say where, as a line and a byte column, also found in root->state with the error code (error, line, col, offset).

Numbers and strings

An integer that fits in an i64 becomes a JSON_INT; a larger one becomes a JSON_FLOAT, as in JavaScript, and a number with a fraction or exponent is a float (one too big for an f64 is infinity). String escapes are decoded, \uXXXX and surrogate pairs to UTF-8. A string can contain \u0000, so str_len and key_len give the full byte length of str and key; C-style functions and paths see them only up to the first '\0'.

JsonParse's optional arguments are the length to parse (-1, the default, reads up to the terminating NUL) and flags: JSON_NO_FLAGS or JSON_STRNUM_FLAG. With JSON_STRNUM_FLAG numbers are not converted: each one is still checked against the JSON grammar and becomes a JSON_STRNUM node whose strnum is the number exactly as written, so large integers and decimals keep every digit, and JsonToString writes it back unchanged. The :i and :f checks don't match these nodes; select them without one.

Now() returns a CDate, and Date2Struct / Struct2Date convert between it and a CDateStruct, which has year, mon, day_of_mon, hour, min, sec and day_of_week (0 is Sunday). MPrintDate and MPrintTime return new strings as MM/DD/YYYY and HH:MM:SS. A CDate is an i64 struct, an integer underneath, so CDate d = 5; and i64 x = d; need no cast, and f64 f = d; converts it to a float like any integer (a float assigned to a CDate is truncated, as it would be for an i64).

Now() and NowDateTimeStruct give local time (the TZ time zone), not UTC; NowDateTimeStruct also sets zone_diff, the offset from UTC as ±hhmm (100 for +01:00), and NowMilliseconds counts from the Unix epoch. Below the seconds a CDateStruct has sec100 (hundredths, 0-99) and sec10000 (the ten-thousandths below those, 0-99). Struct2Date carries fields that are out of range: day 32 of January is February 1, month 13 is January of the next year and month 0 December of the year before; the time carries the same way, so hour 24 is midnight of the next day.

The calendar is the proleptic Gregorian one, with the same leap years before 1582 and for year 0 (a leap year, as in ISO 8601) and the years before it. Day 0 is January 2 of year 0, so a CDate of 0 prints as 01/02/0000. Years 1 to 3999 have the same day numbers whose calendar has no February 29 in years divisible by 4000 and is a day ahead from 4000-03-01. IsoFromTimespec(&ts, buf), which formats a Stat time as UTC ISO 8601 (2026-07-05T14:30:00.123456789Z, 31 bytes with the NUL), uses the same calendar.

StrToCDate(text, format) parses a date with a strptime-like format and Str2CDateStruct(text, format, &ds) fills a CDateStruct. The conversions are %Y, %m, %d, %H, %M, %s (or %S) for seconds, %a and %b for day and month names (full or three letters, any case), %p for AM/PM, %z for a zone offset and %%; a space in the format matches any run of spaces, other characters must match exactly. Missing time fields are 0, and without %z zone_diff is CDATE_NO_ZONE (a value no ±hhmm offset can have). Str2CDateStruct returns false and StrToCDate 0 for empty or short input, text that doesn't match, an unknown conversion or an impossible value (month 13, February 30, hour 24, ...); StrToCDate also needs the year, month and day.

Maths

The C maths library is declared under its usual names (sqrt, pow, sin, floor, fabs, …, all on f64), plus Abs, Gcd and Pow, and the constants M_PI, M_E, M_SQRT2 and the rest of C's M_* set. Gcd ignores signs: Gcd(0, n) is |n| and Gcd(0, 0) is 0. Pow takes an f64 exponent: integral ones use exact repeated squaring (Pow(2, 10) is 1024.0) and the rest go to pow, so Pow(4.0, 0.5) is 2.0. Abs returns an i64; like C's labs, Abs(I64_MIN) is I64_MIN. Use fabs for floats.


import libc, math;

void main()
{
  printf("%.4f %.0f %.1f %.1f\n", libc.sqrt(2.0), libc.pow(2.0, 10.0), libc.floor(2.7), libc.fabs(-1.5));
  printf("%d %d %d %.2f\n", math.abs(-5), math.gcd(12, 18), math.gcd(-4, 0), math.power(1.5, 2));
}

Sockets

NetCreateServer(port, bindaddr, backlog) returns a listening TCP socket, NetAccept(server) the next connection on it and NetConnect(addr, port) a connected socket. All three return the socket as an i32, or -1 on failure (0 is a valid socket number). Read and write them with read/write or recv/send, and close them when done. NetConnect takes a host name or an IPv4 or IPv6 address and tries every address the name resolves to. The server's bind address must be numeric ("127.0.0.1", "::1"), "*" for any IPv4 address or "::*" for any IPv6 address; port 0 lets the kernel pick one. Ports outside 0..65535 give -1. NetConnect(addr, port, non_blocking, timeout_ms) gives up after timeout_ms milliseconds (shared by all the addresses the name resolves to; the name lookup itself isn't timed) with -1 and Errno() ETIMEDOUT; 0, the default, waits as long as the system does. NetSetRecvTimeout(sock, ms) and NetSetSendTimeout(sock, ms) make a read or a write on a connected socket give up after ms milliseconds with -1 and Errno() EAGAIN (a write returns the bytes it got out first, if any). Writing to a socket whose peer has closed raises SIGPIPE, which ends the program, as in C. NetSend(sock, buf, len) (a send that adds MSG_NOSIGNAL to its optional flags) returns -1 with Errno() EPIPE (or ECONNRESET) instead; signal(SIGPIPE, SIG_IGN) does the same for every write and send in the program. signal takes SIG_DFL, SIG_IGN or a handler void F(i32 sig) passed as (&F)(i64), and returns the previous one or SIG_ERR. SIGHUP, SIGINT, SIGQUIT, SIGKILL, SIGUSR1, SIGUSR2, SIGPIPE, SIGALRM, SIGTERM, SIGCHLD and the job-control signals SIGCONT, SIGSTOP, SIGTSTP, SIGTTIN and SIGTTOU are defined, with each platform's numbers.

For UDP, NetCreateUdpSocket(port, bindaddr) returns a bound datagram socket (the same bind addresses as NetCreateServer, port 0 picks one: NetGetSocketPort tells which), NetSendTo(sock, buf, len, addr, port) sends one datagram and NetRecvFrom(sock, buf, len, from, from_size, &port) receives one and says who sent it, so a server answers with NetSendTo(sock, reply, n, from, port). Both work with IPv4 and IPv6 and return -1 on failure. A datagram longer than the buffer is cut. NetSetRecvTimeout(sock, ms) makes reads give up with -1 after ms milliseconds.

Coroutines

A coroutine runs a function on its own stack and can pause in the middle. CoroutineNew(&Fn, arg) makes one (nothing runs yet; NULL if its stack can't be mapped), CoroutineNext(c) runs it until it calls CoroutineYield(value) and returns that value, and the next CoroutineNext carries on after the yield. When the function returns, CoroutineDone(c) becomes TRUE and that last CoroutineNext returns the function's return value; after that it returns NULL. A yielded NULL is a value like any other, so loops test CoroutineDone. Values also go the other way: CoroutineNext(c, send) makes the paused CoroutineYield return send (the first CoroutineNext just starts the function with its arg). CoroutineRelease(c) frees it, also while it is paused.

The function is void *Fn(void *arg). Coroutines can resume other coroutines (CoroutineSelf() is the running one, NULL outside), every thread can have its own, and a try may span a yield. A throw that leaves the coroutine's function goes on from the CoroutineNext that resumed it. Each stack is 256 KiB unless CoroutineNew's third argument says otherwise, with a guard page below it: running past it crashes the program instead of overwriting memory. CoroutineRelease keeps up to 16 stacks per thread for the next CoroutineNew of the same size, so short-lived coroutines (one per request) don't map and unmap a stack each time; they are unmapped when the thread ends. CoroutineYield outside a coroutine, or resuming one that is running, prints a message and exits with 1.


import coro;

void *fib(void *max)
{
  i64 a = 0, b = 1, t;
  while (a < (i64)max) {
    coro.yield((void *)a);
    t = a + b;
    a = b;
    b = t;
  }
  return null;
}

void *sum(void *unused)
{// a running total of whatever CoroutineNext sends
  i64 total = 0;
  while (true) { total += (i64)coro.yield((void *)total); }
  return null;
}

void main()
{
  coro.Coroutine *f = coro.spawn(&fib, (void *)50);
  for (void *v = coro.next(f); !coro.done(f); v = coro.next(f)) {
    printf("%d ", v);
  }
  printf("\n");
  coro.release(f);

  coro.Coroutine *s = coro.spawn(&sum);
  coro.next(s);                 // runs to the first yield
  printf("%d\n", coro.next(s, (void *)5));
  printf("%d\n", coro.next(s, (void *)7));
  coro.release(s);
}

Fuzzy matching

FzF(text, pattern) matches text the way the fzf tool does and returns the score and the matched byte offsets, or NULL when it doesn't match. Terms separated by spaces must all match, a | b takes either. A plain term is fuzzy: its characters in order, with gaps. 'term is an exact substring, ^term a prefix, term$ a suffix, ^term$ the whole text and !term must not occur; \ is a space inside a term. With the default FZF_CASE_SMART a term is case-sensitive only when it has an upper-case letter; FZF_CASE_IGNORE and FZF_CASE_RESPECT force it. Passing false as the last argument makes plain terms exact (and 'term fuzzy). The offsets come term after term, so they are only sorted for a single term, and the matcher is fzf's greedy one: it finds a match, not always the best-scoring placement. The pattern is not modified, so a string literal is fine. FzF keeps no shared state, so threads can call it at the same time.


import fzf;

void show(u8 *text, u8 *pattern)
{
  fzf.Position *m = fzf.match(text, pattern);
  printf("%-12s %-11s ", text, pattern);
  if (!m) {
    printf("no match\n");
    return;
  }
  printf("score %d at", m.score);
  for (i64 i = 0; i < m.size; i++) { printf(" %d", m.data[i]); }
  printf("\n");
  fzf.release(m);
}

void main()
{
  show("src/main.ktm", "smkm");
  show("src/main.ktm", "smKM");
  show("src/main.ktm", "ktm$ main");
  show("src/main.ktm", "^src 'main");
  show("src/main.ktm", "!test main");
  show("my file.txt", "my\\ file");
}

SQLite

The SQLite functions exist when ktm and the library are built with ./build.sh --sqlite (they are under #ifdef __KTM_LINK_SQLITE3__). SqlCtxNew(path) opens a database (":memory:" for a private one) and SqlCtxRelease closes it. SqlExecRaw runs a script of statements and returns NULL or an error message to Free. SqlQuery and SqlSelect run one statement with ? parameters from an array of SqlParam (SQL_INT, SQL_FLOAT, SQL_TEXT, SQL_BLOB, SQL_NULL); text and blobs are copied, so they can be freed right away. A string with a second statement is an error rather than half-run. SqlIter steps through the rows of SqlSelect and frees the row after the last one; call SqlRowRelease if you stop early. A column's str and blob are only valid until the next row.


import mem, sql;

sql.Db *db;
u8 *err;

sql.Param p[2];

sql.Row row;

void main()
{
  db = sql.open(":memory:");
  err = sql.execRaw(db, "CREATE TABLE users(id INTEGER, name TEXT);");
  if (err) {
    printf("%s\n", err);
    mem.free(err);
  }
  p[0].type = sql.INT;
  p[0].intVal = 1;
  p[1].type = sql.TEXT;
  p[1].str = "ann";
  sql.exec(db, "INSERT INTO users VALUES(?, ?);", p, 2);
  if (sql.select(db, &row, "SELECT id, name FROM users;")) {
    while (sql.next(&row)) { printf("%d %s\n", row.col[0].intVal, row.col[1].str); }
  }
  sql.close(db);
}

SqlPrepare compiles a statement once (NULL on an error) and SqlExecPrepared(stmt, &row, params) runs it with new parameters, returning SQLITE_ROW, SQLITE_DONE or an error code; read its rows with SqlIterPrepared. A parameter it can't bind (an unknown type gives SQLITE_MISMATCH, a string over sqlite's length limit SQLITE_TOOBIG) returns that error without running the statement. Such a row belongs to the statement, which SqlFinalizePrepared frees.
