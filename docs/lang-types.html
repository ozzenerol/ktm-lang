    Types and literals

    The built-in types, their sizes, and how to write numbers, characters and strings.

    Built-in types#

    TypeSizeWhat it is
    i8 i16 i32 i641 2 4 8Signed integers. i64 is the default integer type
    u8 u16 u32 u641 2 4 8Unsigned integers. u8 is the character (byte) type
    f64 f328 4Floats. f64 is the default
    bool1true (1) or false (0)
    void0Nothing
    T *8A pointer. null is the null pointer
    T[]16A slice: a pointer and a length
    String24An owned, growable string
     
    void main()
{
  printf("%d %d %d %d\n", sizeof(i8), sizeof(i16), sizeof(i32), sizeof(i64));
  printf("%d %d %d\n", sizeof(f32), sizeof(f64), sizeof(bool));
  printf("%d %d %d\n", sizeof(u8 *), sizeof(u8[]), sizeof(String));
}

    1 2 4 8
4 8 1
8 16 24

    Type names are not keywords: a struct field can be called i64. A variable can't.

    bool#

    Any value becomes a bool by comparing it with 0, wherever the conversion happens: an assignment, an argument, a return, a cast.

    bool isSet(i64 flags, i64 bit) { return flags & bit; }

void main()
{
  bool a = 0x100;          // 1: not just the low byte
  bool b = (bool)0.5;      // 1: not 0.0
  bool c = (bool)(-1);     // 1
  u8 *p = null;
  bool d = p;              // 0: a null pointer
  printf("%d %d %d %d %d\n", a, b, c, d, isSet(0x800, 0x800));
}

    1 1 1 0 1
    • A pointer becomes a bool without a cast.
    • Other integer types warn without a cast when stored into a bool.

    null, true and false#

    • null is 0 as a void *: it can be assigned to any pointer or function pointer.
    • true and false are bool values, 1 and 0.
    void main()
{
  u8 *name = null;
  if (!name) { printf("no name yet\n"); }
  printf("%d %d\n", true, false);
}

    no name yet
1 0

    Integer literals#

    Decimal, hex (0x) or binary (0b). _ between digits groups them.

    void main()
{
  i64 dec = 42, hex = 0xFF, bin = 0b1010;
  i64 million = 1_000_000;
  i64 mask = 0xFF_FF;
  printf("%d %d %d %d %d\n", dec, hex, bin, million, mask);
}

    42 255 10 1000000 65535
    • A literal too big for i64 is a u64.
    • _ is only valid between two digits: _100 is a name, 1__0 and 1_ are errors.
    • A malformed number is an error that says what is wrong: 0x with no digits, 0b102, 12ab, 1e.

    No octal literals. A leading zero doesn't change the base: 0644 is six hundred and forty-four, not octal 420 as in C. The compiler warns at such a literal and suggests the hex spelling (0x1A4).

    Float literals#

    A number with a . or an exponent is an f64.

    void main()
{
  f64 a = 1.5, b = 1.5e3, c = 2e-3, price = 1_000.25;
  printf("%.1f %.1f %.3f %.2f\n", a, b, c, price);
  printf("%s %s\n", typeof(2), typeof(2.0));
}

    1.5 1500.0 0.002 1000.25
i64 f64

    Character literals#

    A character constant is one character and has an integer value. An escape counts as one character.

    void main()
{
  i64 a = 'A', nl = '\n', zero = '0';
  printf("%d %d %d %c\n", a, nl, zero, a + 1);
  u8 c = 'x';
  printf("%c is a letter: %d\n", c, c >= 'a' && c <= 'z');
}

    65 10 48 B
x is a letter: 1

    'ab' is an error: use a string, or an enum for a set of tags.

    String literals#

    A string literal is a u8 * to read-only bytes ending in a NUL. It converts to a u8[] wherever a slice is expected.

    void main()
{
  printf("tab:[\t] quote:[\"] backslash:[\\]\n");
  printf("hex:[\x41\x42] octal:[\101] dollar:[\d]\n");
  printf("%d\n", sizeof("abc"));   // 3 bytes and the NUL
}

    tab:[	] quote:["] backslash:[\]
hex:[AB] octal:[A] dollar:[$]
4
    EscapeMeans
    \n \t \r \b \f \v \aThe C control characters
    \\ \' \"A backslash, a quote
    \xHHA byte in hex, at most two digits: "\x01b" is 1 then b
    \0 to \7Start an octal escape of up to three digits: "\033" is ESC
    \dA $

    Writing into a literal is an error when the compiler can see it, and a crash when it can't. Copy it first: see Strings.

    Asking for a type#

    typeof(x) is the name of an expression's type, as a string, made at compile time. sizeof and alignof give sizes in bytes.

    void main()
{
  u8 small = 1;
  printf("%s %s %s\n", typeof(small), typeof(small + 1), typeof("hi"));
  printf("%d %d\n", sizeof(small), alignof(f64));
}

    u8 i64 u8[3]
1 8
