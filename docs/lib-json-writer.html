    JSON: writing

    Build JSON with a json.Writer, print a parsed tree with json.toStr, or encode a whole struct with json.encode.

    json.Writer#

    A Writer builds a document into a String, without a tree. Commas, quotes and escapes are written for you.

    import json;

void main()
{
  json.Writer w = json.writerNew();
  defer w.free();
  w.beginObject();
  w.key("id");    w.int(5);
  w.key("name");  w.str("Ada \"the\" first");
  w.key("tags");
  w.beginArray(); w.str("a"); w.float(1.5); w.bool(true); w.nil(); w.end();
  w.end();
  ad String text = w.take();
  printf("%s\n", text);
}

    {"id":5,"name":"Ada \"the\" first","tags":["a",1.5,true,null]}
    MethodWrites
    beginObject(), beginArray(), end()Opens and closes
    key(k), rawKey(k)The next member's name (rawKey writes it unescaped)
    int(i64), uint(u64), float(f64), bool(b)Numbers and booleans
    nil()JSON's null
    str(s), cstr(p)A string from a u8[], or a C string (null for a null pointer)
    raw(text)JSON made elsewhere, checked to be one value
    take()The finished document as a String; the Writer is empty again

    Pretty output#

    json.writerNew(2) puts each member and item on its own line, indented 2 spaces per level.

    import json;

void main()
{
  json.Writer w = json.writerNew(2);
  defer w.free();
  w.beginObject();
  w.key("server"); w.beginObject();
  w.key("host"); w.str("localhost");
  w.key("ports"); w.beginArray(); w.int(80); w.int(443); w.end();
  w.end();
  w.end();
  ad String text = w.take();
  printf("%s\n", text);
}

    {
  "server": {
    "host": "localhost",
    "ports": [
      80,
      443
    ]
  }
}

    Writing a list from data#

    import json;

struct Item { u8 *name; i64 qty; f64 price; };

void main()
{
  Item items[] = {{"pen", 3, 1.5}, {"book", 1, 12.0}};
  json.Writer w = json.writerNew();
  defer w.free();
  w.beginArray();
  for (auto it : items) {
    w.beginObject();
    w.key("name");  w.cstr(it.name);
    w.key("total"); w.float(it.qty * it.price);
    w.end();
  }
  w.end();
  ad String text = w.take();
  printf("%s\n", text);
}

    [{"name":"pen","total":4.5},{"name":"book","total":12.0}]

    Floats get the fewest digits (15 to 17) that read back as the same value, always with a decimal point.

    Mistakes throw#

    A call out of order, or a value JSON can't hold, throws json.ERR_WRITER. The Writer is left as it was.

    import json;

void main()
{
  json.Writer w = json.writerNew();
  defer w.free();
  try {
    w.beginArray();
    w.key("oops");
  } catch (Error e) {
    printf("%s\n", e.message);
  }
  try {
    w.float(0.0 / 0.0);
  } catch (Error e) {
    printf("%s\n", e.message);
  }
}

    key(): no object is open
float(): JSON has no NaN or infinity

    Also: a value where a key is expected, end() with nothing open, a second top-level value, take() with something still open, a string that isn't UTF-8.

    Printing a parsed tree#

    json.toStr(node) is the JSON text of a node from json.parse: for an inner node just its value.

    import json;

void main()
{
  json.Value *doc = json.parse("{\"user\": {\"id\": 7, \"roles\": [\"admin\"]}, \"n\": 1e400}");
  defer json.release(doc);
  ad String user = json.toStr(json.select(doc, ".user"));
  ad String all = json.toStr(doc);          // 1e400 is too big for an f64: null
  printf("%s\n%s\n", user, all);
}

    {"id": 7,"roles": ["admin"]}
{"user": {"id": 7,"roles": ["admin"]},"n": null}

    json.release frees a whole document and only does something given a root; on an inner node it does nothing.
