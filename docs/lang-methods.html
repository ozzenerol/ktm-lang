    Methods and inheritance

    A method is a function named Type.name. A struct can extend one other struct. There are no classes, no constructors and no virtual dispatch.

    At a glance

    struct User { u8 *name; i64 age; };
void User.greet() { printf("hi %s\n", self.name); }  // self is a User *
u.greet();  p.greet();                                // on a value or a pointer
struct Admin : User { i64 level; };                   // Admin has User's fields and methods
User.greet(self);                                     // call the base's explicitly
fn(User *) void f = &User.greet;                      // a method is a function

    Methods#

    Write the method outside the struct. Inside, self is a pointer to the object it was called on.

    struct Account
{
  u8 *owner;
  i64 balance;
};

void Account.deposit(i64 amount)
{
  self.balance += amount;        // changes the caller's object
}

bool Account.withdraw(i64 amount)
{
  if (amount > self.balance) { return false; }
  self.balance -= amount;
  return true;
}

void Account.print()
{
  printf("%s: %d\n", self.owner, self.balance);
}

void main()
{
  Account a = {"ann", 0};
  a.deposit(100);
  a.withdraw(30);
  printf("too much: %d\n", a.withdraw(500));
  a.print();

  Account *p = &a;
  p.deposit(5);                  // the same on a pointer
  p->print();
}

    too much: 0
ann: 70
ann: 75
    • self can't be assigned, and no parameter may be called self.
    • Default arguments, T ...name and overloading work as for functions.
    • A prototype, void Account.print();, declares a method defined later.
    • A union can have methods too.

    A constructor is just a function#

    By convention, a module's new or open function makes the value; a free() method releases it.

    import mem;

struct Buffer { u8 *data; i64 len; };

Buffer bufferNew(i64 size)
{
  Buffer b = {mem.allocZero(size), size};
  return b;
}

void Buffer.free()
{
  mem.free(self.data);
  self.data = null;
  printf("freed %d bytes\n", self.len);
}

void main()
{
  ad Buffer b = bufferNew(64);     // ad calls b.free() at the end
  b.data[0] = 'x';
  printf("%c\n", b.data[0]);
}

    x
freed 64 bytes

    Inheritance#

    struct Admin : User starts with all of User's fields, so an Admin * can be used wherever a User * is expected. It also has User's methods.

    struct User  { u8 *name; i64 age; };
struct Admin : User { i64 level; };

void User.describe() { printf("%s is %d\n", self.name, self.age); }
void User.birthday() { self.age++; }

void greet(User *u) { printf("hello %s\n", u.name); }

void main()
{
  Admin a;
  a.name = "bob";
  a.age = 40;
  a.level = 2;
  a.birthday();          // inherited
  a.describe();          // inherited
  greet(&a);             // an Admin * is a User *
  printf("%d\n", sizeof(Admin));
}

    bob is 41
hello bob
24

    Hiding a base method#

    A method of the same name on the derived struct hides the base's. Base.name(self) still calls the base's.

    struct User  { u8 *name; };
struct Admin : User { i64 level; };

void User.describe()  { printf("user %s\n", self.name); }
void Admin.describe()
{
  printf("admin %d, ", self.level);
  User.describe(self);
}

void main()
{
  Admin a;
  a.name = "bob";
  a.level = 2;
  a.describe();

  User *u = &a;
  u.describe();      // the pointer's type decides: User.describe
}

    admin 2, user bob
user bob

    No virtual dispatch. Which method runs is decided by the type the compiler sees, never at run time. For behaviour chosen at run time, store a function pointer in the struct.

    Run-time dispatch with a function pointer#

    struct Shape
{
  u8 *name;
  fn(Shape *) f64 area;
};

struct Circle : Shape { f64 r; };
struct Rect : Shape { f64 w, h; };

f64 circleArea(Shape *s) { Circle *c = s; return 3.14159 * c.r * c.r; }
f64 rectArea(Shape *s)   { Rect *r = s; return r.w * r.h; }

void main()
{
  Circle c;
  c.name = "circle";
  c.area = &circleArea;
  c.r = 1.0;

  Rect r;
  r.name = "rect";
  r.area = &rectArea;
  r.w = 2.0;
  r.h = 3.0;

  Shape *shapes[2] = {&c, &r};
  for (auto s : shapes) {
    printf("%s: %.2f\n", s.name, s.area(s));
  }
}

    circle: 3.14
rect: 6.00

    Methods as function pointers#

    &User.describe is an ordinary function whose first parameter is self.

    struct User { u8 *name; };
void User.hello() { printf("hello %s\n", self.name); }

void each(User[] users, fn(User *) void f)
{
  for (i64 i = 0; i < users.len; i++) { f(&users[i]); }
}

void main()
{
  User all[2] = {{"ann"}, {"bob"}};
  each(all, &User.hello);
}

    hello ann
hello bob

    u.hello without () is an error: there are no bound methods.

    Errors#

    • A method with the name of a field, inherited fields included.
    • The same method defined twice (with the same parameter types).
    • A method of something that isn't a struct or union.
    • A method added to a type of the standard library or another module: only the module that defines a type can add methods.
    • Calling a field as a method: s.len() says "`len` is a field, not a method: read it without `()`".
