    LibraryReference: net.http.middleware

    HTTP middleware

    net.http.middleware has the middleware most APIs want: request IDs, the client's real address behind a proxy, CORS, rate limiting and bearer tokens. Each is one call that adds it to a Mux or a group.

    import net.http, net.http.middleware;

bool checkToken(u8[] token, http.Request *r)
{
  if (!token.equals("s3cret")) { return false; }
  r.setInt("userId", 42);                // for the handlers
  return true;
}

void me(http.Writer *w, http.Request *r) { w.text(200, "user %d", r.getInt("userId")); }

void main()
{
  http.Mux mux;
  middleware.realIp(&mux, "10.0.0.0/8");      // first: the others see the client
  middleware.requestId(&mux);
  middleware.rateLimit(&mux, 100, 60);          // 100 requests a minute per client

  http.Mux *api = mux.group("/api");
  middleware.bearer(api, &checkToken);         // 401 without a good token
  api.handle("GET /me", &me);

  http.Request r = http.testRequest("GET", "/api/me");
  r.addHeader("Authorization", "Bearer s3cret");
  http.Writer w = http.recorder();
  mux.serve(&w, &r);
  printf("%d %s\n", w.code, w.body);
  w.free();
  r.free();
  mux.free();
}

    200 user 42
    CallWhat it does
    middleware.requestId(m)Keeps the client's X-Request-Id when it is sane, else makes a UUIDv7; it goes in the reply's X-Request-Id and middleware.requestIdOf(r), for logs
    middleware.realIp(m, "10.0.0.0/8, ::1")For requests from those proxies, r.remoteAddr() becomes the right-most address in X-Forwarded-For that isn't a proxy; from anywhere else the header is ignored, so it can't be faked
    middleware.cors(m, &opts)CORS for the origins in a middleware.CorsOptions (origins, methods, headers, expose, credentials, maxAge); answers preflights itself. Add it on the Mux the server serves
    middleware.rateLimit(m, requests, seconds)Per client address, a token bucket shared by all the server's threads; past it 429 with Retry-After, and RateLimit-Limit/-Remaining on every reply
    middleware.bearer(m, &check)Authorization: Bearer <token> that check(token, r) accepts, else 401 with WWW-Authenticate; check can r.set the user

    Order and groups#

    Middleware runs in the order it was added, the Mux's before a group's. Put realIp first so the rest see the client, and cors on the Mux the server serves (a preflight is answered before routing). A group gets its own: a strict rateLimit(login, 5, 60) on a login group beside a looser one for the whole API.

    What isn't here#

    • Recovery: a throw in a handler is already a logged 500 (a JSON decode error a 400).
    • Timeouts: a running handler can't be stopped from outside. Limits are per operation: http.Options' read and idle limits, the client's timeoutMs, a database's statement timeout.
    • An access log: http.Options.accessLog.

    Your own, with settings#

    mux.useWith(f, ctx) adds a middleware bool f(http.Writer *w, http.Request *r, void *ctx) that gets ctx on every request, so one function serves several configurations; with true third, the Mux frees ctx with itself. That is how this module's are built.
