    Type aliases

    type Name = T; gives a type a second name. The alias is the type itself, not a new one.

    At a glance

    type Text = u8[];
type Handler = fn(i64, Text) bool;
type Buf = u8[64];
type Ints = vec.Vec<i64>;
pub type Port = u16;          // in a module: exported

    Naming long types#

    type Text = u8[];
type Handler = fn(i64, Text) bool;
type Celsius = f64;
struct Reading { Text place; Celsius temp; };
type Readings = Reading[];

bool show(i64 i, Text place) { printf("%d: %s\n", i, place); return true; }

Celsius warmest(Readings all, Handler each)
{
  Celsius best = -273.15;
  for (i64 i = 0; i < all.len; i++) {
    each(i, all[i].place);
    if (all[i].temp > best) { best = all[i].temp; }
  }
  return best;
}

void main()
{
  Reading r[3] = {{"Iasi", 18.5}, {"Cluj", 21.0}, {"Sibiu", 16.25}};
  printf("warmest %.1f\n", warmest(r, &show));
}

    0: Iasi
1: Cluj
2: Sibiu
warmest 21.0

    An alias is the same type#

    A Celsius and an f64 pass to each other with no conversion. sizeof, typeof and error messages see the real type.

    type Celsius = f64;
type Text = u8[];

void main()
{
  Celsius c = 21.5;
  f64 f = c;
  Text t = "hello";
  u8[] s = t;
  printf("%.1f %s %d %s\n", f, s, sizeof(Text), typeof(c));
}

    21.5 hello 16 f64

    Because an alias is not a new type, it doesn't stop you mixing Celsius and Fahrenheit. For that, wrap the value in a struct.

    Fixed arrays and generics#

    import vec;

type Buf = u8[8];
type Ints = vec.Vec<i64>;

void main()
{
  Buf b;
  b[0] = 'k';
  ad Ints nums = vec.new<i64>();
  nums.push(3);
  printf("%d %c %d\n", sizeof(Buf), b[0], nums.len);
}

    8 k 1

    Rules#

    • Aliases are declared at file scope, not inside a function.
    • In a program, an alias can only name types declared above it. In a module, any order works.
    • Two aliases that name each other are an error.
    • In a module an alias is private unless pub, and is mod.Name outside it.
    • type is a keyword only at the start of such a declaration: a variable or field can still be called type.
