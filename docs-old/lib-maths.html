    LibraryReference: math libc

    Maths

    Integer helpers and bit operations in math; the C maths library (sqrt, sin, ...) in libc.

    Integers#

    CallGives
    math.abs(n)|n| as an i64 (math.abs(I64_MIN) is I64_MIN, as C's labs)
    math.min(a, b), math.max(a, b)The smaller, the larger
    math.clamp(v, lo, hi)v kept between lo and hi
    math.gcd(a, b)The greatest common divisor, ignoring signs
    math.power(x, y)x to the y, an f64; exact for integral y
     
    import math;

void main()
{
  printf("%d %d %d %d\n", math.abs(-5), math.min(3, 9), math.max(3, 9), math.clamp(150, 0, 100));
  printf("%d %d %d\n", math.gcd(12, 18), math.gcd(-4, 0), math.gcd(0, 0));
  printf("%.0f %.2f %.1f\n", math.power(2, 10), math.power(1.5, 2), math.power(4.0, 0.5));
}

    5 3 9 100
6 4 0
1024 2.25 2.0

    Floating point: libc#

    The C maths functions are declared in libc under their usual names, all on f64.

    import libc, math;

void main()
{
  printf("%.4f %.0f %.1f %.1f %.1f\n", libc.sqrt(2.0), libc.pow(2.0, 10.0), libc.floor(2.7),
         libc.ceil(2.1), libc.fabs(-1.5));
  printf("%.4f %.4f %.4f\n", libc.sin(math.PI / 2), libc.cos(0.0), libc.log(math.E));
}

    1.4142 1024 2.0 3.0 1.5
1.0000 1.0000 1.0000

    Constants: math.PI, math.E, math.SQRT2 and the rest of C's M_* set.

    A worked example: distance#

    import libc;

struct Point { f64 x, y; };

f64 dist(Point a, Point b)
{
  f64 dx = a.x - b.x, dy = a.y - b.y;
  return libc.sqrt(dx * dx + dy * dy);
}

void main()
{
  Point a = {0, 0}, b = {3, 4};
  printf("%.1f\n", dist(a, b));
}

    5.0

    Bit operations#

    On a u32 or a u64: the type picks the width, so cast an i64 first. Each is a single machine instruction where it is called.

    CallGives
    math.rotl(x, n), math.rotr(x, n)Rotated by n bits
    math.bswap(x)The bytes reversed (also on a u16)
    math.clz(x), math.ctz(x)Leading / trailing zero bits (the width for 0)
    math.popcount(x)The number of one bits
     
    import math;

void main()
{
  u32 h = 0x80000001;
  printf("%x %x\n", math.rotl(h, 1), math.rotr(h, 1));
  printf("%x\n", math.bswap((u32)0x11223344));
  printf("%d %d %d\n", math.clz((u32)1), math.ctz((u64)8), math.popcount((u64)0xFF));
}

    3 c0000000
44332211
31 3 8

    Next power of two#

    import math;

u64 nextPow2(u64 n)
{
  if (n <= 1) { return 1; }
  return (u64)1 << (64 - math.clz(n - 1));
}

void main()
{
  u64 tests[] = {1, 5, 16, 17, 1000};
  for (auto t : tests) { printf("%d -> %d\n", t, nextPow2(t)); }
}

    1 -> 1
5 -> 8
16 -> 16
17 -> 32
1000 -> 1024
