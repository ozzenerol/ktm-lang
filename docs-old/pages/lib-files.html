Files

Read a whole file, write one, make and remove directories. Paths are a u8[]: a literal, a slice or a String.

At a glance

String text = fs.readAll(path);       // text.ptr == null: couldn't read
bool ok = fs.writeAll(path, data);    // replaces the file
fs.makeDir(path,, true);              // with missing parents
fs.remove(path, fs.REMOVE_RECURSE);   // a directory and everything in it
fs.exists(path)  fs.copyFile(a, b)  fs.move(a, b)

Reading and writing a whole file


import fs;

void main()
{
  u8[] path = "/tmp/ktm_docs_example.txt";
  if (!fs.writeAll(path, "first line\nsecond line\n")) {
    printf("could not write %s\n", path);
    return;
  }

  ad String contents = fs.readAll(path);
  printf("%d bytes\n%s", contents.len, contents);
  fs.remove(path);
}

When it fails

fs.readAll gives a String whose ptr is null; os.errno() says why. An empty file gives an empty String that has a ptr.


import fs, libc, os;

void main()
{
  String missing = fs.readAll("/no/such/file");
  if (!missing.ptr) {
    printf("can't read: ENOENT %d\n", os.errno() == libc.ENOENT);
  }
  printf("write to a bad path: %d\n", fs.writeAll("/no/such/dir/x.txt", "data"));
}

can't read: ENOENT 1
write to a bad path: 0

Lines of a file


import fs, str;

void main()
{
  u8[] path = "/tmp/ktm_docs_lines.txt";
  fs.writeAll(path, "alpha\nbeta\n\ngamma\n");

  ad String text = fs.readAll(path);
  ad u8[][] lines = str.split(text.trimEnd("\n"), "\n");

Appending

fs.writeAll opens with O_CREAT | O_WRONLY | O_TRUNC by default. Pass other flags to append:


import fs, libc;

void main()
{
  u8[] path = "/tmp/ktm_docs_append.log";
  fs.writeAll(path, "one\n");
  for (i64 i = 0; i < 2; i++) {
    fs.writeAll(path, "more\n", libc.O_CREAT | libc.O_WRONLY | libc.O_APPEND);
  }
  ad String text = fs.readAll(path);
  printf("%s", text);
  fs.remove(path);
}

Directories

CallDoes
fs.makeDir(path)Makes one directory
fs.makeDir(path,, true), fs.makeDirAll(path)Also the missing parents
fs.remove(path)A file, a symlink (never what it points to) or an empty directory
fs.remove(path, fs.REMOVE_RECURSE)A directory and everything in it
fs.remove(path, fs.REMOVE_FORCE)A missing path is not an error
fs.changeDir(path), fs.currentDir()Change directory (~ is $HOME); the working directory as a String

They return a bool: true when done, false on failure (with os.errno()), as fs.writeAll and fs.exists do, so if (!fs.makeDir(dir)) { ... } catches the failure. makeDir is true if the path is a directory afterwards, made now or already there.


import cstr, fs, mem;

extern "c" u8 *mkdtemp(u8 *template);

void main()
{
  u8 dir[32];
  mem.copy(dir, "/tmp/ktm_docs_XXXXXX", 21);
  if (!mkdtemp(dir)) { return; }          // a fresh directory to work in
  u8[] root = cstr.view(dir);

  ad String deep = fs.join(root, "a/b/c");
  printf("makeDir: %d %d\n", fs.makeDir(deep), fs.makeDir(deep,, true));
  printf("again: %d, exists: %d\n", fs.makeDirAll(deep), fs.exists(deep));

  printf("remove non-empty: %d\n", fs.remove(root));
  printf("recursive: %d\n", fs.remove(root, fs.REMOVE_RECURSE));
  printf("missing, forced: %d\n", fs.remove(root, fs.REMOVE_FORCE));
}

Copying and moving

CallDoes
fs.copyFile(from, to)Copies a regular file with its permission bits, replacing to. A copy that fails part way is removed
fs.rename(from, to)Renames, on one filesystem
fs.move(from, to)Renames, or across filesystems copies and removes the original

Each returns true when done, false with os.errno() set.


import fs;

void main()
{
  fs.writeAll("/tmp/ktm_docs_a.txt", "payload");
  printf("copy %d\n", fs.copyFile("/tmp/ktm_docs_a.txt", "/tmp/ktm_docs_b.txt"));
  printf("move %d\n", fs.move("/tmp/ktm_docs_b.txt", "/tmp/ktm_docs_c.txt"));
  printf("%d %d %d\n", fs.exists("/tmp/ktm_docs_a.txt"), fs.exists("/tmp/ktm_docs_b.txt"),
         fs.exists("/tmp/ktm_docs_c.txt"));
  ad String c = fs.readAll("/tmp/ktm_docs_c.txt");
  printf("%s\n", c);
  fs.remove("/tmp/ktm_docs_a.txt");
  fs.remove("/tmp/ktm_docs_c.txt");
}

Details

  • fs.readAll reads a regular file up to its size, and a pipe, FIFO, device or /proc file until end of file. It never finishes on an endless device like /dev/zero.
  • For a directory, fs.readAll gives a String without a ptr.
  • A path longer than 4095 bytes fails with ENAMETOOLONG.
  • The files fs opens are close-on-exec: programs you start don't inherit them.
  • The POSIX calls (libc.open, read, write, lseek, ...) are there for lower-level work.
