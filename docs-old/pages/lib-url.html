URLs

net.url parses a URL into its parts and builds one back, reads and writes query strings, and resolves a link against the page it was found on, as Go's net/url does.


import net.url;

void main()
{
  url.URL u;
  if (!url.parse("https://ann:secret@example.com:8443/docs/a%20b?page=2&q=hi+there#top", &u)) { return; }
  printf("%s %s %s %d %s\n", u.scheme, u.user, u.host, u.port, u.path);

  url.Values v;
  url.parseQuery(u.rawQuery, &v);
  printf("page %s, q %s\n", v.get("page"), v.get("q"));

  url.URL next;
  u.resolve("../img/logo.png", &next);
  String s = next.string();
  printf("%s\n", s);
  s.free(); next.free(); v.free(); u.free();
}

The parts

FieldHolds
schemeIn lower case: "https"; empty for a reference such as "/a/b"
user, passwordDecoded; hasUser and hasPassword say whether they were there
host, portThe host in lower case (an IPv6 one without its brackets), the port or 0; u.portOrDefault() gives the scheme's usual one
path, rawQuery, fragmentAs written, percent-encoded: str.urlDecode them for their text

url.parse answers false for what isn't a URL: a bad port, a bad % escape, a space or a control byte, an unclosed [. u.string() builds the text back, escaping the user and password.

Query strings

CallWhat it does
url.parseQuery(raw, &values)a=1&b=two+words into pairs, decoded (+ is a space), in order
values.get(name), values.has(name)The first value of a name ("" if none)
values.add(name, value), values.encode()Adding a pair; the query string, escaped

Resolving links

base.resolve(ref, &out) turns a link found at base ("../c", "/d", "?page=3", "//cdn.example/x", an absolute URL) into an absolute URL, as a browser does (RFC 3986 section 5).

A url.URL and a url.Values own their Strings: free() them. parse, parseQuery and resolve replace what their output held.
