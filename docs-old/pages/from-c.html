Coming from C

ktm reads like C. This page lists every place where it doesn't, side by side.

Types

C

int n; long big; unsigned char c;
double d; float f; _Bool b;
typedef struct Point { int x, y; } Point;
int (*cmp)(const void *, const void *);

ktm

i32 n; i64 big; u8 c;
f64 d; f32 f; bool b;
struct Point { i32 x, y; };     // a type at once
fn(void *, void *) i32 cmp;
  • The default integer is i64; integer literals are i64.
  • 0644 is decimal: there are no octal literals (the compiler warns). Write 0x1A4.
  • _ groups digits: 1_000_000. 0b1010 is binary.

Strings and arrays

C

char *s = strdup("hi");
size_t n = strlen(s);
void sum(int *xs, size_t n);
free(s);

ktm

String s = str.from("hi");
i64 n = s.len;
void sum(i64[] xs);          // a slice knows its length
s.free();                    // or: ad String s = ...
  • Slices (T[]) carry their length, and every index is checked.
  • An array or a string literal converts to a slice where one is expected.
  • String is an owned, growable string. %s prints it.

Statements

C

if (x) y = 1;
switch (c) {
  case 1: a(); break;
  case 2: case 3: b(); break;
}

ktm

if (x) { y = 1; }            // braces required
switch (c) {
  case 1: a();               // no break: no fall-through
  case 2 ... 3: b();         // ranges
}
  • A switch case doesn't fall through; write fallthrough; to.
  • for (auto x : items) loops over arrays, slices and vectors.
  • if (i64 v = f(); v > 0) declares a variable for the if.
  • 1 < x < 10 is a chained comparison, not (1 < x) < 10.

Functions

C

void box(int w, int h);
box(2, 9);   /* no defaults */
int sum(int n, ...);   /* va_list */
#define SQ(x) ((x)*(x))

ktm

void box(i64 w = 2, i64 h = 3);
box(, 9);                    // skip an argument
i64 sum(i64 ...nums);        // nums is an i64[]
i64 sq(i64 x) { return x * x; }   // no function macros
  • Overloading by parameter types.
  • Generics: T max<T>(T a, T b).
  • Your functions never clash with C's: your free() is yours.

Structs

C

void user_greet(User *u);
user_greet(&u);
p->x = 1;
struct Admin { User base; int level; };

ktm

void User.greet();           // self is a User *
u.greet();
p.x = 1;                     // . works through a pointer
struct Admin : User { i64 level; };
  • Methods are dispatched by the static type: no virtual calls.
  • Enum members are scoped: Color.red, never red.

Errors and clean-up

C

FILE *f = fopen(p, "r");
if (!f) goto fail;
...
fclose(f);
return 0;
fail: return -1;

ktm

i32 fd = libc.open(p, libc.O_RDONLY);
if (fd < 0) { throw(Err.open, "%s", p); }
defer libc.close(fd);        // on every way out
...
return 0;

Exceptions unwind through calls and run defers on the way.

Code organisation

C

#include "geo.h"
static int helper(void);
geo_area(5);

ktm

import geo;                  // a directory of files
i64 helper();                // private unless pub
geo.area(5);

No headers: a module is a directory, and its files see each other in any order.

Things that are new

SlicesChecked views with a length. defer and adClean-up that always runs. Exceptionstry, catch, throw. GenericsTypes and functions with type parameters. ReflectionTypes at run time. JIT and REPLRun without a build step.

Where it comes from

ktm started as a fork of a HolyC compiler (see History) and has since replaced that syntax with its own. HolyC's sub-integer access (x.u8[1]), its exponent operator and the TempleOS system calls are not part of ktm.
