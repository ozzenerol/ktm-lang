Editors

ktm -lsp is a language server: any editor that speaks LSP gets errors as you type, completion, hover and navigation.

What the server gives

  • Diagnostics as you type; a module's files are checked as the module they belong to.
  • Hover: the declaration and its doc comment, for functions, methods, fields, enums, modules, aliases and generics, the standard library's included.
  • Completion: names in scope, fields and methods after ., a module's names after its prefix, enum members, the modules an import can name.
  • Signature help, with the parameter you are on and every overload.
  • Go to definition, find references, highlight uses, rename.
  • Outline and workspace symbol search.
  • Semantic highlighting: modules, types, enum members, functions, fields, parameters, locals, constants, macros.
  • Folding and inlay hints with the type of each auto variable.

A doc comment is the comment right above a declaration, or after it on its line.

Neovim

The syntax, filetype and indent files install into <prefix>/share/ktm/vim (in a checkout: src/syntax-highlighting/vim).

With lazy.nvim (Neovim 0.11+)

lazy.nvim resets the runtime path when it starts, so add the directory through its own setting:

require("lazy").setup({
  -- your plugins ...
  performance = { rtp = { paths = { "/usr/local/share/ktm/vim" } } },
})

vim.lsp.config("ktm", { cmd = { "ktm", "-lsp" }, filetypes = { "ktm" }, root_markers = { ".git" } })
vim.lsp.enable("ktm")

Without a plugin manager

vim.opt.rtp:append("/usr/local/share/ktm/vim")

vim.api.nvim_create_autocmd("FileType", {
  pattern = "ktm",
  callback = function(ev)
    vim.lsp.start({
      name = "ktm",
      cmd = { "ktm", "-lsp" },
      root_dir = vim.fs.root(ev.buf, { ".git" })
                 or vim.fs.dirname(vim.api.nvim_buf_get_name(ev.buf)),
    })
    vim.lsp.inlay_hint.enable(true, { bufnr = ev.buf })
  end,
})

Semantic highlighting needs nothing more: Neovim colours the tokens with its @lsp.type.* groups (link @lsp.type.namespace.ktm and the others to change them).

Vim

set runtimepath+=/usr/local/share/ktm/vim
filetype plugin indent on
syntax on

Other editors

  • Point the editor's generic LSP client at ktm -lsp for .ktm and .ktmh files.
  • If ktm isn't installed, add --install-dir=/path/to/build/prefix so it finds the standard library.
  • Set KTM_LSP_LOG=1 in the server's environment to log its traffic to stderr.
