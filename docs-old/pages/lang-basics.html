Program basics

What a ktm file looks like, where a program starts, and how it prints.

At a glance

// a comment              /* a block comment */
import str;               // imports first
i64 gCount = 0;           // globals, types, functions at file scope

i32 main(i32 argc, u8 **argv)
{
  printf("%d args\n", argc);
  return 0;               // the exit code
}

The smallest program

A program starts at main, as in C.


void main()
{
  printf("Hello\n");
}

Hello

Save it as hello.ktm and run it:

ktm hello.ktm -o hello && ./hello   # compile to a binary
ktm -jit hello.ktm                    # or compile in memory and run

main

Three forms are allowed. The value main returns is the exit code.

FormExit code
void main()0
i32 main()what it returns
i32 main(i32 argc, u8 **argv)what it returns; argv holds the arguments
 

i32 main(i32 argc, u8 **argv)
{
  printf("%d argument(s), the first is the program\n", argc);
  return 0;

What goes where

  • File scope holds declarations: imports, types, functions, globals and constants.
  • Statements go inside functions.
  • Imports come first in a file, before any declaration.
  • Globals whose initialiser runs code are set up in order, before main.

i64 square(i64 n) { return n * n; }

i64 gBase = 7;
i64 gArea = square(gBase);   // runs before main

void main()
{
  printf("%d\n", gArea);
}

49

Comments

The same as C. Block comments don't nest.


/* A block comment
   over several lines. */
void main()
{
  // to the end of the line
  printf("comments are ignored\n");   /* or inline */
}

comments are ignored

A block comment still open at the end of the file is an error: unterminated comment.

Printing

printf works as in C. The compiler checks the arguments against the format.


void main()
{
  printf("plain text\n");
  printf("%s is %d years old\n", "Ada", 36);
  printf("[%5d] [%-5d] [%05d]\n", 42, 42, 42);
  printf("%x %X %c %.3f\n", 255, 255, 'A', 3.14159);
  printf("100%%\n");
}

plain text
Ada is 36 years old
[   42] [42   ] [00042]
ff FF A 3.142
100%
  • The first argument is always a format, so a literal % is written %%.
  • %d, %u, %x and %o print the full 64 bits: no need for %ld (it works too).
  • %s takes a C string, a slice (u8[]) or a String.

import str;

void main()
{
  i64 big = 5000000000;
  printf("%d %ld\n", big, big);

  u8[] word = "slice";
  String owned = str.from("String");
  defer owned.free();
  printf("%s, %s and %s\n", "C string", word, owned);
}

5000000000 5000000000
C string, slice and String

ktm's own conversions

%Q prints a string escaped as a C literal, and %C a character in upper case.


void main()
{
  printf("%Q\n", "say \"hi\"\n");
  printf("%C%c\n", 'h', 'i');
}

say \"hi\"\n
Hi

Every conversion, flag and width is listed on Format strings.

Printing to stderr

os.eprintf is printf to stderr, checked the same way.

import os;

void main()
{
  os.eprintf("warning: %s\n", "disk almost full");
}

Exiting early

Return from main, or call os.exit(code) from anywhere.


import os;

void check(i64 n)
{
  if (n < 0) {
    printf("negative, giving up\n");
    os.exit(0);
  }
  printf("%d is fine\n", n);
}

void main()
{
  check(3);
  check(-1);
  printf("never printed\n");
}

3 is fine
negative, giving up

os.exit ends the program at once: defer statements don't run. Returning from main runs them.

Scripts

ktm skips a first line that starts with #!, so a file can run as a script:

#!/usr/bin/env -S ktm -jit
void main() { printf("Hello from a script\n"); }
chmod +x hello.ktm
./hello.ktm
