UUIDs

uuid makes and reads UUIDs (RFC 9562). uuid.v7() starts with the time in milliseconds, so v7s sort by when they were made: as a database's primary key they keep its index compact, unlike random ones. uuid.v4() is 122 random bits.


import uuid;

void main()
{
  uuid.UUID a = uuid.v7();
  uuid.UUID b = uuid.v7();
  String s = a.string();
  printf("%d %d %d %d\n", s.len, a.version(), b.compare(a) > 0, uuid.v4().version());

  uuid.UUID back;
  printf("%d %d\n", uuid.parse(s, &back) && back.equals(a), uuid.parse("nope", &back));
  s.free();
}

CallWhat it does
uuid.v7(), uuid.v4()A new UUID; v7s from any thread are strictly increasing
u.string(), u.format(buf)The 36-character form, as a new String or into a 37-byte buffer
uuid.parse(text, &u)The canonical form in either case, 32 digits without hyphens, {...} or urn:uuid:...; false otherwise
u.version(), u.unixMs()4 or 7; a v7's time in Unix milliseconds
u.equals(o), u.compare(o), u.isNil(), uuid.nil()Comparing: v7s compare by time

A uuid.UUID is 16 bytes held by value, nothing to free. Its random bits come from the operating system (getrandom, arc4random).
