Keywords

These can't name a variable, a parameter or a declaration:

if else for while do switch case default break continue return goto fallthrough
try catch throw defer struct union enum fn module import pub private static const
extern inline asm sizeof alignof typeof self true false null

type and ad are keywords only where they start a declaration, so a variable can still be called type or ad.
