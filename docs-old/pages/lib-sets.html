Sets

set.Set<T> is a hash set: add, remove and test membership in O(1), and combine sets.

At a glance

ad set.Set s = set.new();
s.add(v)      // true if it was new
s.delete(v)   // true if it was there
s.has(v)  s.len  s.clear()
s.unionWith(&o)  s.intersection(&o)  s.diff(&o)  s.symDiff(&o)   // new sets
s.isSubset(&o)  s.equals(&o)

Adding and testing


import set;

void main()
{
  ad set.Set seen = set.new();
  u8[] visits[] = {"/home", "/about", "/home", "/blog", "/about"};
  for (auto v : visits) {
    if (seen.add(v)) { printf("first visit to %s\n", v); }
  }
  printf("%d distinct, has /blog: %d\n", seen.len, seen.has("/blog"));
}

Combining

These take a pointer to the other set, return a new set, and leave both alone.


import set, vec;

void show(u8 *label, set.Set *s)
{
  ad vec.Vec items = s.items();
  items.sortAsc();
  printf("%-12s", label);
  for (auto x : items) { printf(" %d", x); }
  printf("\n");
}

void main()
{
  ad set.Set evens = set.new();
  ad set.Set threes = set.new();
  for (i64 i = 1; i <= 6; i++) { evens.add(i * 2); }
  for (i64 i = 1; i <= 4; i++) { threes.add(i * 3); }

  ad set.Set u = evens.unionWith(&threes);
  ad set.Set both = evens.intersection(&threes);
  ad set.Set onlyEven = evens.diff(&threes);
  ad set.Set either = evens.symDiff(&threes);
  show("union", &u);
  show("both", &both);
  show("even only", &onlyEven);
  show("exactly one", &either);
  printf("both is a subset of evens: %d\n", both.isSubset(&evens));
}

union        2 3 4 6 8 9 10 12
both         6 12
even only    2 4 8 10
exactly one  2 3 4 8 9 10
both is a subset of evens: 1

Walking a set

In the order values were added:


import set;

void main()
{
  ad set.Set s = set.new();
  s.add(30);
  s.add(10);
  s.add(20);
  s.delete(10);
  i64 it = 0, v;
  while (s.next(&it, &v)) { printf("%d,", v); }
  printf("\n");
}

30,20,

s.items() gives the values as a vec.Vec (yours to free), which sortAsc() puts in order.

Values

  • Values are hashed and compared like map.Map's keys.
  • u8[] and String values are copied into the set.
  • For a set kept in order, use a map.Tree with bool values.
