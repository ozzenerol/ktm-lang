Directories and file status

Listing a directory, walking a tree, and asking what a path is.

The examples on this page work in a fresh temporary directory, made like this:

extern "c" u8 *mkdtemp(u8 *template);

u8 dir[32];
mem.copy(dir, "/tmp/ktm_docs_XXXXXX", 21);
mkdtemp(dir);

Listing names

fs.list(path) is the names in a directory, sorted, as a vec.Vec<String>. Free it with free(), which frees the names too.


import cstr, fs, mem, vec;

extern "c" u8 *mkdtemp(u8 *template);

void main()
{
  u8 dir[32];
  mem.copy(dir, "/tmp/ktm_docs_XXXXXX", 21);
  mkdtemp(dir);
  u8[] root = cstr.view(dir);
  u8 *names[] = {"b.txt", "a.txt", "c.log"};
  for (auto n : names) {
    ad String p = fs.join(root, cstr.view(n));
    fs.writeAll(p, "x");
  }

  bool ok;
  vec.Vec list = fs.list(root, &ok);
  printf("ok %d:", ok);
  for (auto name : list) { printf(" %s", name); }
  printf("\n");
  list.free();
  fs.remove(root, fs.REMOVE_RECURSE);
}

ok 1: a.txt b.txt c.log

Reading entries

fs.openDir gives each entry with its name, kind and full path. . and .. are left out.


import cstr, fs, mem;

extern "c" u8 *mkdtemp(u8 *template);

void main()
{
  u8 dir[32];
  mem.copy(dir, "/tmp/ktm_docs_XXXXXX", 21);
  mkdtemp(dir);
  u8[] root = cstr.view(dir);
  ad String sub = fs.join(root, "logs");
  ad String file = fs.join(root, "notes.txt");
  fs.makeDir(sub);
  fs.writeAll(file, "hi");

  ad fs.Dir d = fs.openDir(root);
  i64 files = 0, dirs = 0;
  bool pathsOk = true;
  for (fs.DirEntry *e = d.next(); e; e = d.next()) {
    if (e.kind == fs.FileKind.dir) { dirs++; } else { files++; }
    if (!e.path.endsWith(e.name)) { pathsOk = false; }
  }
  printf("%d dirs, %d files, paths end with the name: %d\n", dirs, files, pathsOk);
  fs.remove(root, fs.REMOVE_RECURSE);
}

1 dirs, 1 files, paths end with the name: 1
  • An entry has name, kind (an fs.FileKind: file, dir, link, other) and path, the directory joined with the name.
  • A symlink's kind is link, never what it points to.
  • The name and path are valid until the next next(): copy them to keep them.
  • Close it with d.close(), or declare it with ad as above.
  • A directory that can't be opened gives a Dir whose d.ok() is false and whose next() is null at once.
  • Entries come in the order the filesystem gives them. Use fs.list for sorted names.

Walking a tree

fs.walk(root, &visit, arg) calls bool visit(fs.DirEntry *e, void *arg) for every entry under root, a directory before what is in it. Return false to stop.


import cstr, fs, mem;

extern "c" u8 *mkdtemp(u8 *template);

bool countBytes(fs.DirEntry *e, i64 *total)
{
  if (e.kind == fs.FileKind.file) {
    fs.FileStat st;
    fs.stat(&st, e.path);
    *total += st.st_size;
  }
  return true;
}

void main()
{
  u8 dir[32];
  mem.copy(dir, "/tmp/ktm_docs_XXXXXX", 21);
  mkdtemp(dir);
  u8[] root = cstr.view(dir);
  ad String deep = fs.join(root, "a/b");
  fs.makeDirAll(deep);
  ad String f1 = fs.join(root, "a/one.txt");
  ad String f2 = fs.join(root, "a/b/two.txt");
  fs.writeAll(f1, "12345");
  fs.writeAll(f2, "1234567890");

  i64 total = 0;
  i32 r = fs.walk(root, &countBytes, &total);
  printf("walk returned %d, %d bytes in files\n", r, total);
  fs.remove(root, fs.REMOVE_RECURSE);
}

walk returned 0, 15 bytes in files

It returns 0 when every entry was visited, 1 when visit stopped it, -1 when a directory couldn't be read. It never follows a symlink into a directory.

File status

fs.stat(&st, path) fills an fs.FileStat, the same struct on every platform.

Field or methodHolds
st_sizeSize in bytes
st_modeType and permission bits
st_mtim, st_atim, st_ctim, st_btimModified, accessed, changed, created; each with tv_sec and tv_nsec
st_ino, st_dev, st_nlink, st_uid, st_gidAs in C
kind(), isFile(), isDir(), isLink()What it is
CallDescribes
fs.stat(&st, path)The path, following a symlink
fs.lstat(&st, path)The symlink itself
fs.fstat(&st, fd)An open file

All three return 0, or -1 with os.errno() set.


import cstr, fs, libc, mem;

extern "c" u8 *mkdtemp(u8 *template);

void main()
{
  u8 dir[32];
  mem.copy(dir, "/tmp/ktm_docs_XXXXXX", 21);
  mkdtemp(dir);
  u8[] root = cstr.view(dir);
  ad String file = fs.join(root, "data.txt");
  ad String link = fs.join(root, "latest");
  fs.writeAll(file, "0123456789");
  libc.symlink("data.txt", link.cstr());

  fs.FileStat st;
  fs.stat(&st, link);
  printf("stat: file %d, %d bytes, mode %o\n", st.isFile(), st.st_size, st.st_mode & 0x1FF);
  fs.lstat(&st, link);
  printf("lstat: link %d\n", st.kind() == fs.FileKind.link);
  printf("missing: %d\n", fs.stat(&st, "/no/such/path"));

  ad String real = fs.realPath(link);
  printf("resolves to data.txt: %d\n", real.endsWith("/data.txt"));
  fs.remove(root, fs.REMOVE_RECURSE);
}

stat: file 1, 10 bytes, mode 644
lstat: link 1
missing: -1
resolves to data.txt: 1

fs.realPath(path) is the absolute path with every symlink, . and .. resolved; its ptr is null when part of the path doesn't exist.

Times

date.isoFromTimespec(&t) formats a stat time as UTC ISO 8601:


import date, fs;

void main()
{
  fs.FileStat st;
  fs.stat(&st, "/");
  ad String when = date.isoFromTimespec(&st.st_mtim);
  printf("%d %c %d\n", when.len >= 20, when[10], when.endsWith("Z"));
}

1 T 1

Reading at an offset

fs.pread(fd, buf, off) and fs.pwrite(fd, data, off) don't move the file offset, so threads can share an fd.


import fs, libc;

void main()
{
  u8[] path = "/tmp/ktm_docs_pread.txt";
  fs.writeAll(path, "0123456789");
  i32 fd = libc.open("/tmp/ktm_docs_pread.txt", libc.O_RDWR);
  u8 buf[4];
  i64 n = fs.pread(fd, buf, 6);
  printf("%d bytes at 6: %s\n", n, buf[0:n]);
  fs.pwrite(fd, "AB", 0);
  n = fs.pread(fd, buf, 0);
  printf("%s\n", buf[0:n]);
  libc.close(fd);
  fs.remove(path);
}
