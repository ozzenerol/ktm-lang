TCP sockets

Listen, accept, dial, send. Sockets are plain i32 file descriptors; the helpers in net do the address work, and every POSIX socket call is in libc.

At a glance

i32 srv  = net.listen(8080, "127.0.0.1", 16);   // -1 on failure
i32 conn = net.accept(srv);                     // waits for a client
i32 cli  = net.dial("example.com", 80);         // a connected socket
net.send(conn, "hello\n");                      // never raises SIGPIPE
i64 n = libc.recv(conn, buf, sizeof(buf), 0);
libc.close(conn);

A server and a client

Both ends in one program, over loopback. Port 0 lets the kernel pick a free port; net.localPort says which.


import libc, net;

void main()
{
  i32 srv = net.listen(0, "127.0.0.1", 4);
  i32 cli = net.dial("127.0.0.1", net.localPort(srv));
  i32 conn = net.accept(srv);

  net.send(cli, "ping");
  u8 buf[64];
  i64 n = libc.recv(conn, buf, sizeof(buf), 0);
  printf("server got %s\n", buf[0:n]);

  net.send(conn, "pong");
  n = libc.recv(cli, buf, sizeof(buf), 0);
  printf("client got %s\n", buf[0:n]);

  libc.close(conn);
  libc.close(cli);
  libc.close(srv);
}

The calls

CallReturns
net.listen(port, bindaddr, backlog)A listening socket
net.accept(server)The next connection
net.dial(addr, port, nonBlocking, timeoutMs)A connected socket
net.send(sock, data, flags)Bytes sent, or -1 (never SIGPIPE)
net.peerAddr(sock)The peer's address as a String
net.localPort(sock)The port a socket is bound to
net.setNonBlocking, setBlocking, setNoDelay, setReuseAddrbool
net.setRecvTimeout(sock, ms), setSendTimeoutbool
  • Sockets are returned as i32, or -1 on failure (0 is a valid socket).
  • Addresses are a u8[]: a literal, a slice or a String.
  • dial takes a host name or an IPv4/IPv6 address, and tries every address the name resolves to.
  • A bind address must be numeric ("127.0.0.1", "::1"), "*" for any IPv4 address or "::*" for any IPv6.
  • Ports outside 0..65535 give -1. The sockets net makes are close-on-exec.

A tiny HTTP exchange


import libc, net, str;

void main()
{
  i32 srv = net.listen(0, "127.0.0.1", 4);
  i32 cli = net.dial("127.0.0.1", net.localPort(srv));
  i32 conn = net.accept(srv);
  u8 buf[256];

  net.send(cli, "GET /hello HTTP/1.0\r\n\r\n");

  i64 n = libc.recv(conn, buf, sizeof(buf), 0);           // the server side
  u8[] line, rest, path, version;
  str.splitFirst(buf[0:n], "\r\n", &line, &rest);
  str.splitFirst(line[4:], " ", &path, &version);          // after "GET "
  ad String reply = str.format("HTTP/1.0 200 OK\r\n\r\nyou asked for %s\n", path);
  net.send(conn, reply);
  libc.close(conn);

  n = libc.recv(cli, buf, sizeof(buf), libc.MSG_WAITALL);  // the client side
  u8[] head, body;
  str.splitFirst(buf[0:n], "\r\n\r\n", &head, &body);
  printf("%s", body);
  libc.close(cli);
  libc.close(srv);
}

A serving loop

The shape of a blocking server. One client at a time; for many at once, use coroutines.

import libc, net;

void main()
{
  i32 srv = net.listen(8080, "*", 16);
  if (srv == -1) {
    printf("can't listen on 8080\n");
    return;
  }
  while (true) {
    i32 conn = net.accept(srv);          // waits for a client
    if (conn == -1) { continue; }
    ad String peer = net.peerAddr(conn);
    printf("client from %s\n", peer);
    net.send(conn, "hello\n");           // -1 if the client already left
    libc.close(conn);
  }
}

Timeouts

  • net.dial(addr, port, false, ms) gives up after ms milliseconds with -1 and ETIMEDOUT. 0, the default, waits as long as the system does.
  • net.setRecvTimeout(sock, ms) makes a read give up with -1 and EAGAIN; setSendTimeout the same for writes.
  • dial blocks in connect either way. In a coroutine, use coro.dial, which pauses only the coroutine.

import libc, net, os;

void main()
{
  i32 srv = net.listen(0, "127.0.0.1", 4);
  i32 cli = net.dial("127.0.0.1", net.localPort(srv));
  i32 conn = net.accept(srv);
  net.setRecvTimeout(cli, 50);
  u8 buf[16];
  i64 n = libc.recv(cli, buf, sizeof(buf), 0);      // nothing comes
  printf("%d, EAGAIN: %d\n", n, os.errno() == libc.EAGAIN);
  libc.close(conn);
  libc.close(cli);
  libc.close(srv);
}

A peer that went away

Writing to a socket whose peer has closed raises SIGPIPE, which ends the program, as in C. Two ways out:

  • net.send adds MSG_NOSIGNAL: it returns -1 with EPIPE (or ECONNRESET) instead.
  • signal.handle(libc.SIGPIPE, libc.SIG_IGN) does the same for every write and send in the program.

import date, libc, net, os;

void main()
{
  i32 srv = net.listen(0, "127.0.0.1", 1);
  i32 client = net.dial("127.0.0.1", net.localPort(srv));
  i32 conn = net.accept(srv);
  libc.close(conn);                               // the peer goes away

  i64 r = 0;
  i32 err = 0;
  for (i64 i = 0; i < 50; i++) {
    r = net.send(client, "ping");
    if (r < 0) { err = os.errno(); break; }
    date.sleepMs(10);
  }
  printf("send: %d, EPIPE or ECONNRESET: %d\n", r, err == libc.EPIPE || err == libc.ECONNRESET);
  printf("still running\n");
  libc.close(client);
  libc.close(srv);
}

Unix domain sockets

net.unixListen(path, backlog) and net.unixDial(path). They return -1 on failure, also for a path longer than 107 bytes (103 on macOS).


import libc, net;

void main()
{
  u8[] path = "/tmp/ktm_docs.sock";
  libc.unlink("/tmp/ktm_docs.sock");
  i32 srv = net.unixListen(path, 4);
  i32 cli = net.unixDial(path);
  i32 conn = net.accept(srv);
  net.send(cli, "over a unix socket");
  u8 buf[64];
  i64 n = libc.recv(conn, buf, sizeof(buf), 0);
  printf("%s\n", buf[0:n]);
  libc.close(conn);
  libc.close(cli);
  libc.close(srv);
  libc.unlink("/tmp/ktm_docs.sock");
}

The raw calls

libc declares socket, bind, connect, getsockopt, poll, getaddrinfo and the rest, with the platform's structs and constants (AF_*, SOCK_*, SO_*, MSG_*, POLL*, the errno codes).

  • Address lengths are C's socklen_t, a u32: declare the ones you pass by address as u32.
  • net.htons, ntohs, htonl, ntohl convert to and from network byte order.

import libc, net;

void main()
{
  printf("%X %X\n", net.htons(0x1F90), net.htonl(0x7F000001));
  printf("%d\n", libc.inet_addr("127.0.0.1") == net.htonl(0x7F000001));
}
