YAML

yaml.Reader reads a YAML document front to back; yaml.Writer writes one in block style. A @yaml struct gets both for free.

Reading into a struct

Mark the struct @yaml and call fromYaml with a Reader:


import yaml;

@yaml struct Server { String host; i64 port; bool tls; String[] aliases; };

void main()
{
  u8[] text = "# the main server\n"
              "host: example.com\n"
              "port: 443\n"
              "tls: true\n"
              "aliases:\n"
              "  - www.example.com\n"
              "  - api.example.com\n";
  yaml.Reader r = yaml.readerNew(text);
  defer r.free();
  Server s;
  s.fromYaml(&r);
  defer s.freeDecoded();
  printf("%s:%d tls %d, %d aliases, the last %s\n", s.host, s.port, s.tls, s.aliases.len, s.aliases[1]);
}

example.com:443 tls 1, 2 aliases, the last api.example.com

yaml.readerNew(text, yaml.STRICT) makes unknown and missing keys errors, as with JSON.

Reading by hand

The Reader has the same calls as json.Reader: open a mapping and loop on nextKey(), open a sequence and loop on nextItem().


import yaml;

void main()
{
  u8[] text = "name: Ada   # a comment\n"
              "langs: [ktm, C]\n"
              "bio: |\n"
              "  first line\n"
              "  second line\n"
              "admin: true\n";
  yaml.Reader r = yaml.readerNew(text);
  defer r.free();
  r.beginObject();
  while (r.nextKey()) {
    u8[] k = r.key();
    if (k.equals("langs")) {
      r.beginArray();
      while (r.nextItem()) { printf("lang %s\n", r.readStr()); }
    } else if (k.equals("admin")) {
      printf("admin %d\n", r.readBool());
    } else {
      printf("%s: [%s]\n", k, r.readStr());
    }
  }
  r.finish();
}

name: [Ada]
lang ktm
lang C
bio: [first line
second line
]
admin 1

Scalar types

A plain (unquoted) scalar is typed by its form. A quoted or block scalar is always a string.

WrittenIs
true, False, TRUEA bool
null, ~, nothingNull
42, 0x1F, 0o17An integer
1.5, .inf, .nanA float
"42", 'yes', helloA string
 

import yaml;

void main()
{
  yaml.Reader r = yaml.readerNew("a: 0x1F\nb: \"0x1F\"\nc: ~\nd: 2.5\n");
  defer r.free();
  r.beginObject();
  r.nextKey(); printf("a int %d\n", r.readInt());
  r.nextKey(); printf("b string %s\n", r.readStr());
  r.nextKey(); printf("c null %d\n", r.isNull());
  r.nextKey(); printf("d is a float: %d\n", r.peek() == yaml.FLOAT);
  r.skipValue();
  r.finish();
}

a int 31
b string 0x1F
c null 1
d is a float: 1

Writing


import yaml;

void main()
{
  yaml.Writer w = yaml.writerNew();
  defer w.free();
  w.beginObject();
  w.key("name"); w.str("Ada");
  w.key("flag"); w.str("true");         // a string: quoted, or it would read as a bool
  w.key("count"); w.int(3);
  w.key("langs");
  w.beginArray(); w.str("ktm"); w.str("C"); w.end();
  w.key("tags"); w.beginArray(); w.end();
  w.end();
  ad String out = w.take();
  printf("%s", out);
}

name: Ada
flag: "true"
count: 3
langs:
  - ktm
  - C
tags: []
  • The Writer has beginObject, beginArray, end, key, rawKey, int, uint, float, bool, nil and str.
  • A string is quoted only when it would read back as something else: "true", "12", "", "a: b", a line break.
  • Used out of order, it throws yaml.ERR_WRITER.

What is supported

  • Block mappings and sequences, flow [] and {}.
  • Plain, single- and double-quoted scalars; | and > block scalars; comments; --- and ....
  • Not supported (an error that says so): anchors and aliases, tags, << merge keys, several documents in one text.

import yaml;

void main()
{
  yaml.Reader r = yaml.readerNew("lines:\n  - qty: two\n");
  defer r.free();
  try {
    r.beginObject();
    r.nextKey();
    r.beginArray();
    r.nextItem();
    r.beginObject();
    r.nextKey();
    r.readInt();
  } catch (Error e) {
    printf("%d %s\n", e.code == yaml.ERR_DECODE, e.message);
  }
}

1 2:10: lines[0].qty: expected an integer, got a string
